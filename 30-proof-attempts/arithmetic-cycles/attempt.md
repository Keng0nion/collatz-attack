## 我尝试证明的定理（精确陈述）

### 主目标 T1（未完成）

**T1**：不存在非平凡正环。即：不存在整数 m ≥ 1 与正整数周期轨道，使加速映射 T(n) = n/2（n 偶）、(3n+1)/2（n 奇）下轨道恰含 m 个局部极小。

第一轮把 T1 归约成一对显式不等式（第一轮第 13 步），**两侧共享同一条前提**：环上所有元素的绝对值均 ≥ X0（这条前提来自第 3 步的 |Λ| ≤ K/(3X0 − 1)；缺了它，已知正环 {1, 2} 就是 L 侧的反例：m = 1、K = 1，而 X0 = 3.25 × 2^60 时 L(1) ≥ q_5 = 41 > 1）。在带该前提的表述下：**U 侧**任何这样的 m 圈其奇数步数 K 满足 K < U(m)；**L 侧**任何这样的 m 圈满足 K > L(m)；两者对所有 m 同时成立即排除全部非平凡环（已知四个环的元素绝对值都不超过 136，全部落在前提之外，与这些不等式不冲突）。第一版在 L 侧漏了前提（U 侧带了），已改正，见文末「对反驳的回应」二。该归约的弱点在于：由 Λ 的上界到「K 的上界」这一步（第一轮 F7、本文件 F2）**没有证明**，U(m) 的交叉点只是数值观察。**本轮不改变这一状态。**

### 本轮真正立住或推进的五条命题（精确陈述）

**T2（窗口判据的可达范围定理，新）**：设 X0 ≥ 1，C = (3X0 − 1)ln 2，w = 1/C。则对每个整数 K ≥ C，K 都**不被**第一轮第 9 步的窗口判据排除（正侧与负侧同时成立）。等价说法：该判据能排除的整数 K 必满足 K < (3X0 − 1)ln 2 = (3 ln 2)X0 − ln 2 < 2.0795 X0（3 ln 2 = 2.07944154…、ln 2 = 0.69314718…；第一版把该常数印成 2.0814，已改正，见文末「对反驳的回应」三）。

**T3（幸存者族与阶梯上界，新）**：设 p_n/q_n 为 δ = log_2 3 的收敛项，δ 的连分数部分商为 a_n。则：

1. 对每个**奇数** n 与每个整数 m ∈ [1, q_{n+1}]，整数 K = m q_n 都不被**正侧**判据排除（前提：q_n q_{n+1} ≥ C），且 M+ < min{q_n : n 为奇数，q_n q_{n+1} ≥ C}；
2. 对每个**偶数** n 与每个整数 m ∈ [1, q_{n+1}]，整数 K = m q_n 都不被**负侧**判据排除（同一前提），且 M− < min{q_n : n 为偶数，q_n q_{n+1} ≥ C}。

（M± 的定义见第一轮第 9 步：使 1 至 M 全部被排除的最大 M。**注意**：负侧必须用偶数 n，且这一条与第 1 条不是「同一构造换一侧」；第一版把两侧写成同一条，是错的，见文末「对反驳的回应」一。）

**T4（有理候选定理，新，用于界定判据类）**：对每个长度 k 的奇偶字 s（含 K 个 1），令 c = φ(s)、D = 2^k − 3^K，其中 φ 由 φ(s0) = φ(s)、φ(s1) = 3φ(s) + 2^{|s|} 递推定义。则有理数 x(s) = c/D（分母为奇数，故属 Q_(2)）满足：T^k(x(s)) = x(s)，且其前 k 步奇偶向量恰为 s。因此**任何对每个字 s 都成立的必要条件都不可能排除任何参数对**；能起排除作用的只能是「x(s) 为整数」（等价于 D | c）或由整性派生的结构不等式。

**T5（1 圈的归约与封闭，新）**：设奇偶字为 1^K 0^L（K ≥ 2，L ≥ 1），c = 3^K − 2^K，D = 2^{K+L} − 3^K。则下列四条等价：

1. 存在非平凡 1 圈（K 个奇数步、L 个偶数步的环）；
2. D | c 且 D > 0；
3. D | 2^L − 1 且 2^L(2^K − 1) ≤ 3^K − 1（等价于 m := (2^L − 1)/D 是正整数）；
4. 存在 m ≥ 1 使 (m 3^K − 1)/(m 2^K − 1) = 2^L。

并且（本轮据此给出的封闭，必要条件写成 0 < N ln 2 − K ln 3 < 2^(−K)(1 + 2^(−K+1))，N := K + L）：**不存在 K ≤ 20000 的非平凡 1 圈**（本会话用精确整数算术逐个检验，见第 10 步）；而 K ≥ 20000 一侧由 Rhin 型线性型下界排除，门槛低到 K ≥ 108（见第 10 步；该下界为转引，未一手核对）。

**T6（最大元定向前缀引理与 c_max，新，辅助）**：把环旋到最大元 x_0 = max 后，每个前缀 (p, q_p) 满足 2^p > 3^{q_p}（正环）或 2^p < 3^{q_p}（负环）。又对一切以奇数步开头的字，c ≤ c_max(k, K) := 3^{K−1}(2^{k−K+1} + 1) − 2^k，且该界可达到。

## 论证（编号步骤，每步标注状态）

记号：加速映射 T；环长 k = K + L，K 为奇数步数、L 为偶数步数；δ = log_2 3；x_1, …, x_K 为环上奇数元素；Λ := k ln 2 − K ln 3。

### 1. 环方程 ——【已证：第一轮第 1 步；本轮脚本 F 段复核收敛项，D 段复核仿射结构】

环上元素满足 x = c/(2^k − 3^K)，c = Σ_{t=1}^{K} 3^{K−t} 2^{j_t}（j_t 为奇数步位置，0 = j_1）。正环迫使 2^k > 3^K，负环 2^k < 3^K。文献出处为 Böhm 与 Sontacchi 1978 的 Proposition 4 与 5（转引，原文未打开）；现代形式见 Halbeisen 与 Hungerbühler 1997 的 Lemma 2（转引）。

### 2. 乘积恒等式与 Λ ——【已证：第一轮第 2 步】

2^k = Π(3 + 1/x_t)，Λ = Σ ln(1 + 1/(3x_t))；正环 Λ > 0，负环 Λ < 0。

### 3. 窗口判据与它的区间长度形式 ——【已证：第一轮第 3、9 步；本轮的区间形式是重述】

对所有元素绝对值 ≥ X0 的环，|Λ| ≤ K/(3X0 − 1)。取 w = 1/((3X0 − 1)ln 2)，则

1. 正环满足 0 < k − Kδ ≤ K w，即 L ∈ (K(δ−1), K(δ−1) + K w]；
2. 负环满足 0 < Kδ − k ≤ K w，即 L ∈ [K(δ−1) − K w, K(δ−1))。

**本轮用到的形式**：判据排除 K 当且仅当上述相应区间内**不含整数**（因为 L = k − K 必须是整数）。这个「区间长度」形式是第 5 步全部推论的入口。

### 4. 连分数标准事实 ——【已证：经典结果；本轮 A 段以 80 位与 260 位两种精度核对】

记 p_n/q_n 为 δ 的收敛项，部分商 a_n。用到：|p_n − q_nδ| < 1/q_{n+1}；n 为奇数时 p_n − q_nδ > 0，偶数时 < 0；p_n/q_n > δ 当且仅当 n 为奇数。**本轮实跑**：部分商 a_0 至 a_29 = 1, 1, 1, 2, 2, 3, 1, 5, 2, 23, 2, 2, 1, 1, 55, 1, 4, 3, 1, 1, 15, 1, 9, 2, 5, 7, 1, 1, 4, 8，两种精度下逐项一致；q_19 至 q_24 = 397573379, 6189245291, 6586818670, 65470613321, 137528045312, 753110839881，与项目记录（`10-literature/notes/cycles.md` 第 87 行的复算）**逐位一致**；|p_n − q_nδ| < 1/q_{n+1} 对 n ≤ 27 全部成立，符号规律对 n ≤ 25 全部成立。

### 5. 可达范围定理 T2 ——【已证：本轮自证，纯逻辑，无计算依赖】

**证明**：区间 (K(δ−1), K(δ−1) + Kw] 的长度是 Kw。若 Kw ≥ 1，则它必含整数（取 ⌈K(δ−1)⌉ 即可：K(δ−1) < ⌈K(δ−1)⌉ ≤ K(δ−1) + 1 ≤ K(δ−1) + Kw；左端不含端点是因为 δ 无理性保证 K(δ−1) 非整数）。所以正侧判据不能排除这样的 K。Kw ≥ 1 等价于 K ≥ C = (3X0 − 1)ln 2。负侧区间 [K(δ−1) − Kw, K(δ−1)) 长度同为 Kw，同理。∎

**数值旁证（本轮实跑 C 段）**：X0 = 10^4（C = 20793.722）与 X0 = 10^5（C = 207943.461），对 K = C 至 C + 20000 扫描，被排除的个数都是 0。此定理把第一轮 T2a（「对每个 X0 存在无穷多未被排除的 K」）升级为「对每个 X0，**所有** K ≥ (3X0 − 1)ln 2 都未被排除」，从而给出该判据**可达范围**的硬上界，而不再只是一个存在性命题。

### 6. 幸存者族定理 T3 ——【已证：本轮自证】

**证明**：取奇数 n，令 K = m q_n（m ≥ 1）。由第 4 步，ε := p_n − q_nδ ∈ (0, 1/q_{n+1})，于是 Kδ = m p_n − mε。只要 mε < 1（由 m ≤ q_{n+1} 与 ε < 1/q_{n+1} 保证），就有 1 − frac(Kδ) = mε。正侧窗口条件是 1 − frac(Kδ) ≤ Kw = m q_n/C，故只需 ε ≤ q_n/C；而 ε < 1/q_{n+1} ≤ q_n/C 正是 q_n q_{n+1} ≥ C。∎

**推论（阶梯上界）**：K = q_n（取 m = 1）在 q_n q_{n+1} ≥ C 时不被排除，故 M+ < q_n；对最小的合格奇数 n 取最小即得 T3 第 2 条。

**负侧要用偶数 n（第一版在这里写错，本轮改正）**：负侧判据是 frac(Kδ) ≤ Kw，需要 frac(Kδ) 小；而由第 4 步，奇数 n 的 p_n − q_nδ > 0 给出 frac(q_nδ) = 1 − ε_n 接近 1，方向恰好相反，所以奇数 n 的 K = q_n 会被负侧判据排除。正确的陈述是：对**偶数** n 有 p_n − q_nδ < 0，令 e_n := q_nδ − p_n ∈ (0, 1/q_{n+1})，则 m e_n < 1 时 frac(m q_nδ) = m e_n，于是 e_n ≤ q_n/C（由 q_n q_{n+1} ≥ C 保证）给出负侧幸存。这一步不使用正性，因此只能给必要条件，不能给结论。

### 7. 有理候选定理 T4 ——【已证：本轮自证；与 Halbeisen 与 Hungerbühler 1997 的 Lemma 2 同型】

**证明要点**：设字 s 长 k、含 K 个 1，c = φ(s)、D = 2^k − 3^K。一旦已知 x(s) 的前 k 步奇偶向量是 s，Terras 仿射公式给出 T^k(x) = (3^K x + c)/2^k。而 c = x(s)·D = x(s)(2^k − 3^K) 按定义为真，故 T^k(x(s)) = x(s)·2^k/2^k = x(s)，**与 x(s) 是否为整数无关**。至于「前 k 步奇偶向量是 s」：按 φ 的递推逐位归纳即得（这是 Lagarias 的经典引理，Halbeisen 与 Hungerbühler 的 Lemma 2 即其现代形式）。D 为奇数，故 x(s) 的分母为奇数，迭代保持在 Q_(2) = {a/b : b 为奇数} 内，奇偶性由分子奇偶给出。∎

**数值复核（本轮实跑 D 段）**：长度 1 至 14 的**全部** 32766 个字，逐个用 Fraction 精确迭代 k 步：奇偶向量与字不符的个数 0，T^k(x) ≠ x 的个数 0。

**T4 的作用（这是本轮对「为什么初等方法只能到某个数量级」的第一个回答）**：任何对每个字都成立的条件都不可能排除任何 (k, K, 字)。判据想有排除力，就必须使用**只在整数环上成立**的性质。在本路线里这类性质目前只有两个来源：(i) 整性 x ∈ Z（等价于 D | c）；(ii) 由整性派生的结构不等式（chaining 里的 a_i ≥ 1，见第一轮第 5、6 步与本节第 12 步的说明）。这解释了为什么窗口判据（只由 Λ 上界与 x ≥ X0 推出，两者都由第 2 步的恒等式与实数序给出）会撞上第 5 步的天花板。

### 8. 由 T4 看「大小条件的最大增益」 ——【已证：本轮自证】

对字 1^K 0^L 的候选，x(s) = (1 − 2^(−K))/(2^ε − 1)，其中 ε = K + L − Kδ。故 x(s) ≥ X0 等价于 ε ≤ log_2(1 + 1/X0)；而窗口判据的条件是 ε ≤ K w = K/((3X0 − 1)ln 2)。两者之比约为 K/3：**「最小元素 ≥ X0」这一条正环通用信息，最多把窗口再加宽常数倍**，不可能改变第 5 步的量级结论。这条说明本轮的天花板不是「判据没写够」，而是「这一类信息本身不够」。

### 9. 1 圈的归约 T5 ——【已证：本轮自证，含精确数值复核】

**证明**：字 1^K 0^L 给 K 个连续奇数步。前 K 步全为奇数等价于 x ≡ −1 (mod 2^K)（经典事实；本轮 B 段在 (K, L) 网格上验证了它带来的等价关系），故 x + 1 = 2^K m，m ≥ 1。代入环方程 2^{K+L}x = 3^K x + 3^K − 2^K 得

    3^K (x + 1) = 2^K (2^L x + 1)。

由 gcd(2^K, 3^K) = 1 得 2^K | (x + 1) 与 3^K | (2^L x + 1)，即 x + 1 = 2^K m、2^L x + 1 = 3^K m（同一个 m）。消去 x 得 m = (2^L − 1)/D，D = 2^{K+L} − 3^K；再把 2^L x + 1 = 3^K m 与 x + 1 = 2^K m 相消得 T5 第 4 条。反向逐条可逆。∎

**由 m ≥ 1 得到的量化必要条件（本轮的关键一步）**：m ≥ 1 等价于 D ≤ 2^L − 1，即 2^L(2^K − 1) ≤ 3^K − 1，取对数得

    0 < N ln 2 − K ln 3 < 2^(−K)(1 + 2^(−K+1))（N := K + L）。

（严格写成带 (1 + 2^(−K+1)) 的因子更稳：由 ln[(1 − 3^(−K))/(1 − 2^(−K))] ≤ 2^(−K)/(1 − 2^(−K)) ≤ 2^(−K)(1 + 2^(−K+1))。该因子对第 10 步的门槛没有影响：门槛处判据两侧相差 12.6%，而该因子是 1 + 10^(−32) 量级。）

即：**非平凡 1 圈要求一个「指数级好」的有理逼近**（N/K 逼近 δ 到 2^(−K) 之内，更准确地说到 2^(−K)(1 + 2^(−K+1)) 之内）。同时 2^{K+L} > 3^K 又给出 L ≥ ⌈K(δ−1)⌉ 一侧；两侧夹逼后 L 只有唯一候选 L = bit_length(3^K) − K。这条唯一性是本步骤能把检验压成「每个 K 只查一个 L」的原因。

**数值复核（本轮实跑 B 段）**：

1. 归约恒等式的精确核对：K = 1 至 25、L = 1 至 39、D > 0 的全部组合，2^L x + 1 = 3^K m 的失败数 0；「m ≥ 1」与「区间条件」不等价的个数 0（全部用 Fraction 精确算术）。
2. **K = 1 至 20000 的完全检验**：全部用精确整数算术（bit_length(3^K) 给 ⌈Kδ⌉，无浮点），通过区间条件且通过整除条件的 (K, L, N) 只有 (1, 1, 2)，即平凡环；只通过区间条件的 K 也只有 K = 1。故 K ≤ 20000 内无任何非平凡 1 圈。
3. 独立核对（另一条路）：在 m 3^K − 1 = 2^L (m 2^K − 1) 上枚举 K ≤ 40、m ≤ 20000，解只有 (K, m, T) = (1, 1, 2)（对应平凡环 x = 1）。

### 10. 1 圈的封闭（m = 1 这一档） ——【已证，含一处转引输入】

第 9 步给必要条件 0 < N ln 2 − K ln 3 < 2^(−K)(1 + 2^(−K+1))（下面的门槛比较里把该因子并入 2^(−K)，因为它在门槛处小到 10^(−32) 量级）。另一侧用显式线性型下界：Simons 与 de Weger v1.43 的 Lemma 12 把 Rhin 1987 的命题代入 u_0 = 0、u_1 = K + L、u_2 = −K，给出

    |N ln 2 − K ln 3| > exp(−13.3(0.46057 + ln H))，H = max(N, K)

（**转引**：该式我未打开 Rhin 原文核对。出处有两处二手记录：本项目 `10-literature/notes/cycles.md` 第 67 行（记 SW v1.43 的 Lemma 12 与 Rhin 1987 的代入方式），以及本目录 `attempt-round1.md`（记 SW v1.43 提取文本第 643 至 648 行，并复现了 SW 的 K1 表）。两点合起来支持的只是「我复现了 SW 对 Rhin 的用法」，**不支持**「Rhin 常数本身正确」。）

**比较的方向（本轮修正过一次自己的判断，如实记录）**：该下界只按 H^(−13.3) 衰减，比 2^(−K) 衰减得**慢**，因此 K 一大，下界就会超过 2^(−K)，与必要条件相撞。这个方向容易搞反（我第一遍搞反了，认为指数级逼近是 Baker 型工具够不到的；本轮脚本 B2 段的实跑把方向定死）。本轮实跑给出门槛：**K ≥ 108 时下界 > 2^(−K)**（K = 108 处下界 3.47048 × 10^(−33) 对 2^(−108) = 3.08149 × 10^(−33)，比值 1.126；K = 20000 处比值约 1.05 × 10^(5958)）。

**结论**：K ≤ 20000 由第 9 步的精确检验封闭（本会话实跑）；K ≥ 20000 由上述转引下界封闭（门槛 108 已远低于 20000，重叠充分）。**所以 m = 1 这一档在「转引输入正确」的前提下已经封闭**。这一步的意义不在结论本身（文献里「无 1 圈」是 Steiner 1977 的定理），而在于：它把 m = 1 档所需要的一切写成了可复核的两段（精确检验 + 一条显式下界），并且纠正了「指数级逼近是 Baker 型工具的盲区」这个直觉错误。

### 11. 最大元定向前缀引理与 c_max ——【已证：本轮自证，辅助】

**前缀引理**：把环旋到最大元 x_0 后，所有元素满足 x_p ≤ x_0，于是 c_p ≤ (2^p − 3^{q_p})x_0；又 c_p > 0，故括号与 x_0 同号：正环给 2^p > 3^{q_p}（所有前缀），负环给 2^p < 3^{q_p}。∎ **实跑核对（E 段）**：四个已知环（{1,2}、{−1}、{−5,−7,−10}、{−17 族}）旋到最大元后，前缀违反数全部为 0。

**c_max 公式**：以奇数步开头的字里，c 的最大值在 j_t 取 k − K + t − 1（t ≥ 2）、j_1 = 0 时达到，求和化为 c_max = 3^{K−1}(2^{k−K+1} + 1) − 2^k。**实跑核对（E 段）**：对四个已知环所在 (k, K) 档，公式值与同档全部字的穷举最大值逐位一致（1、1、7、22009）。

**一点如实说明**：c_max 不能改进窗口判据。把它与 x ≥ X0 联立得到 D ≤ c_max/x_min，而该界与第 3 步的 Λ 界相比差因子约 2^{L+1}/K（L 为偶数步数），在典型情形（L ≈ 0.585K）是指数级更弱。本步骤因此只作为辅助与自检。
