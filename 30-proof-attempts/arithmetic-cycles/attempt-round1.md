## 我尝试证明的定理（精确陈述）

### 主目标 T1（未完成）

**T1**：对每个整数 m ≥ 1，不存在「m 圈」（在加速映射 T(n) = n/2 与 (3n+1)/2 下，元素全为正整数、非平凡、恰含 m 个局部极小）的周期轨道。

我尝试的具体路线是把它归约成一对**显式不等式**：

1. （U 侧）任何元素绝对值全 ≥ X0 的非平凡 m 圈，其奇数步数 K 满足 K < U(m)；
2. （L 侧）任何非平凡 m 圈满足 K > L(m)，

两者对所有 m ≤ M 同时成立即排除「m ≤ M 的非平凡环」，取 M → ∞ 即 T1。本次计算给出（X0 为「环上元素绝对值至少 X0」的验证界）：

| X0 | 我算出的交叉点（m ≤ 此值时 U(m) < L(m)） | 文献已发表同档结论 |
|---|---|---|
| 3.25 × 2^60 = 3.7469 × 10^18 | m ≤ 68 | SW Lemma 17（m ≤ 68，同一档） |
| 695 × 2^60 = 8.0128 × 10^20 | m ≤ 77 | He23 Theorem 23（m ≤ 91，更强） |

上表两个交叉点是**数值观察**：它用的是我自己的 J2 型上界 U(m)，而「U(m) < L(m) 即排除 m 圈」这一步并不是 SW 的已证判据（SW 的排除用的是 Lemma 16 的上界 K < K2(m)，其证明需要 champion A(m) 与经 K1 定位的 n(m)，我没有复现那一段；详见第 13 步与失败点 F7）。所以下表的「已发表同档结论」只表示档位相同，不表示我复现了他们的机制。

所以 T1 未完成：我的机具只到 m ≤ 68（与 SW 已发表结果同档，属于独立复现），换更大验证界也只到 m ≤ 77，而文献记录是 m ≤ 91，且 m 无上界时全部已知机具都停摆（SW 自己写「以现有技术似乎不能走多远，要覆盖本质更大的 m 范围需要全新的想法」，见 /tmp/sw143.txt 第 994 至 995 行）。**我不声称证明了 T1。**

### 可完成目标 T2（本次真正立住的命题，四条）

**T2a（收尾不可能性）**：设 X0 > 1，w = 1/((3X0 − 1)ln 2)。则对每个 K0 > 0 存在 K > K0 与整数 P，使 δ < P/K ≤ δ + w，其中 δ = log_2 3。等价说法：只用「Λ 上界 + K 是整数」这条必要条件的排除法（即 20-experiments/findings/cycles.md 第 2.5 节的窗口判据），对任何有限的验证界 X0 都留有无限多个未被排除的 K。

**T2b（双侧 chaining 上界）**：设一个非平凡环（正环或负环均可）有 m 个局部极小、K 个奇数步，且环上所有元素的绝对值 ≥ X0 ≥ 2。则

    |x_min| > C_m^{−1} · 2^{(δ−1)K/(δ^m−1)}，

其中 C_m = [(1+X0^{−1})^m B^{T'}]^{1/S}（正环）、C_m = [B^{T'}]^{1/S}（负环），B = (1+X0^{−1})^δ/2，S = (δ^m − 1)/(δ − 1)，T' = Σ_{i=1}^{m−1}(δ^i − 1)/(δ − 1)。**常数在分母**：C_m 就是 Simons 与 de Weger 的 c_m（我复算 C_2 = 0.764796，与他们第 8 页的 0.76479 吻合；极限 2^{−1/(δ−1)} = 0.30576）。本条初版印成 C_m·2^{K/S}，是错的（见「对反驳的回应」一）。

**T2c（m 无关的双侧下界）**：设 C = (3X0 − 1)ln 2，n* = max{n : q_n(q_n + q_{n+1}) < C}（q_n 为 δ 的连分数收敛项分母；该集合空时取 n* = 0，结论 K > q_0 = 1 平凡）。则任何非平凡环（正或负）满足 K > q_{n*}。

**T2d（K 门槛到周期下界的桥接，正环侧）**：若某非平凡**正**环的奇数步数 K > q_n（q_n 为 δ 的收敛项分母），则它在加速映射下的周期 k = K + L > δ q_n，在标准映射（含每个 3n+1 步）下的周期 > (1 + δ)q_n。负环方向相反（k < Kδ），本命题不适用（见第 12 步的说明与失败点 F5）。特别地 K > q_23 = 137,528,045,312 给出加速周期 ≥ 217,976,794,617、标准周期 ≥ 355,504,839,929（这两个数字与 frontier.md 第 22 行、notes/cycles.md 第 16 条记录的当前值逐位一致）。

## 论证（编号步骤，每步标注状态）

记号固定：加速映射 T(n) = n/2（n 偶）、(3n+1)/2（n 奇）。环有 K 个奇数步（奇数元素个数）、L 个偶数步、周期 k = K + L，以及 m 个局部极小（m ≤ K）。x_1, …, x_K 记环上的奇数元素（= 奇数步的起点），δ = log_2 3 = 1.58496…，2^δ = 3。

### 1. 环方程（Böhm 与 Sontacchi 形式）——【已证：本会话自证，并与 SW 原文一致】

**结论**：环上每个元素是整数 x，且必满足

    x = c / (2^k − 3^K)，c = Σ_{t=1}^{K} 3^{K−t} 2^{j_t}，

其中 j_1 < … < j_K ≤ k − 1 是奇数步的位置（0 = j_1，允许旋转规范化）。正环（元素为正）迫使 2^k > 3^K。

**证明（我的写法）**：把环按奇数元素切成 K 段，第 t 段从奇数元素出发做 3x + 1 再连续除以 2 若干次到达下一个奇数元素。逐段迭代得 2^{k}x = 3^{K}x + Σ_{t}3^{K−t}2^{j_t}（这是 Terras 仿射公式的乘积累计形式），整理即得 x = c/(2^k − 3^K)。c 的递推与闭式已在 20-experiments/findings/parity-vectors.md 第 4.1 节对 k ≤ 16 的全部 131070 个向量验证（不一致 0），本脚本第 G 段另以 k ≤ 18 的穷举复核了整除判据与真环的对应。

**与 SW 的一致性**：SW 的 chain equation（/tmp/sw143.txt 第 304 至 311 行）是 3^{k_i}a_i − 1 = 2^{k_{i+1}+ℓ_i}a_{i+1} − 2^{ℓ_i}，其中 x_i = 2^{k_i}a_i − 1 是局部极小。我把它改写为「3^{k_i}(x_i + 1) − 2^{k_i} = 2^{k_i+ℓ_i}x_{i+1}」，代入 x_i + 1 = 2^{k_i}a_i 后与 SW 的式子逐项相等（我手算复核过），所以两者是同一个方程。

### 2. 乘积恒等式与 Λ——【已证：本会话自证】

**结论**：2^k = Π_{t=1}^{K}(3 + 1/x_t)，从而

    Λ := k ln 2 − K ln 3 = Σ_{t=1}^{K} ln(1 + 1/(3x_t))，

正环 Λ > 0（因 2^k > 3^K），负环 Λ < 0。

**证明**：把第 1 步的分段等式 2^{j_2}x_2 = 3x_1 + 1 等逐段相乘，左端乘出 2^kΠx_t，右端乘出 Π(3x_t + 1) = 3^KΠx_t(1 + 1/(3x_t))，约去 Πx_t 即得。

### 3. 窗口下界（SW Corollary 5 型）——【已证：本会话自证；与 SW 同型】

**结论**：对所有元素绝对值 ≥ X0 ≥ 1 的非平凡环（两侧通用），

    |Λ| ≤ K/(3X0 − 1)。

**证明**：由第 2 步，|Λ| = Σ_t|ln(1 + 1/(3x_t))|，且逐项有 |ln(1 + 1/(3x_t))| ≤ ln(1 + 1/(3|x_t| − 1))（负元素取等号；正元素取严格小于，因为 ln(3x/(3x−1)) < ln((3x)/(3x−1))·——具体地 1 + 1/(3x) < 1 + 1/(3x−1)），于是 |Λ| ≤ Σ 1/(3|x_t| − 1) ≤ K/(3X0 − 1)，用到 ln(1+t) ≤ t/(1−t)（0 ≤ t < 1）与 |x_t| ≥ X0。注：「3X0 − 1」对正环偏保守，正环可用更小的分母（其实可用 3X0 而不是 3X0 − 1）；本文件统一用两侧通用的 3X0 − 1，因此与 SW 的 m/X0 形式比较时不能混用。

对照：SW 的 Corollary 5 给 Λ < m/X0（m 为局部极小个数，见 /tmp/sw143.txt 第 426 至 432 行），比我的强当 K > 3m；两者都只用初等工具。20-experiments/findings/cycles.md 第 2.5 节的判据用的就是第 3 步这一形式。

### 4. 连分数标准事实——【已证：经典结论；本会话按 SW Lemma 9 的原文核对并数值复核】

记 p_n/q_n 为 δ 的收敛项，(a_n) 为部分商。用到五条标准事实：

1. **（Lemma 9(a)）** 若 |p − qδ| < 1/(2q)，则 p/q 是收敛项。
2. **（Lemma 9(b)）** |p_n − q_nδ| > 1/(q_n + q_{n+1})。
3. **（Lemma 9(c)）** 若 q ≤ q_n，则 |p − qδ| ≥ |p_n − q_nδ| 对一切整数 p 成立。
4.（经典上界）|p_n − q_nδ| < 1/q_{n+1}。
5. **（Lemma 9(d)）** n 为奇数时 p_n − q_nδ > 0，n 为偶数时 < 0。

本会话核对：`results/arithmetic_cycles_check.txt` 第 H 段（`scripts/arithmetic_cycles_check.py` 的 H 节）对 n = 0 至 89 逐条验证了第 4 条与第 5 条，全部成立；其前一次运行在 80 位精度下 n ≥ 86 报不符，提高到 260 位后消失，且 260 位与 420 位重算的 91 个部分商完全一致（同一输出文件的「精度自检」行）。**这一条是标准的，我不声称它是新结论，只声称我已核对。**

### 5. chaining 引理（正侧）——【已证：本会话自证；与 SW Lemma 6 同型，常数取我的版本】

**结论**：设环的局部极小为 x_0, …, x_{m−1}，第 i 条链从 x_i 上升 k_i 个奇数步到局部极大 y_i，再经 ℓ_i 次折半到 x_{i+1}（Σk_i = K，Σℓ_i = L）。若所有元素 ≥ X0 ≥ 2，则

    x_{i+1} < B x_i^δ，  B := (1 + X0^{−1})^δ / 2。

**证明**：正环的局部极小是奇数，且它后面连续 k_i 个奇数迫使 x_i ≡ −1 (mod 2^{k_i})，即 x_i + 1 = 2^{k_i}a_i（a_i ≥ 1 为整数），且 y_i = 3^{k_i}a_i − 1。于是

    x_{i+1} = y_i/2^{ℓ_i} < (y_i + 1)/2^{ℓ_i} = 3^{k_i}a_i/2^{ℓ_i}

（第一处严格不等式对 ℓ_i ≥ 1 成立），再用 ℓ_i ≥ 1（每条链末尾至少有一次折半，因为 y_i 是局部极大而环非平凡）：

    ≤ (1/2)·3^{k_i}a_i = (1/2)·2^{k_iδ}a_i = (1/2)·2^{k_i(δ−1)}·2^{k_i}a_i = (1/2)·2^{k_i(δ−1)}(x_i + 1)。

而 2^{k_i} = (x_i + 1)/a_i ≤ x_i + 1，故 2^{k_i(δ−1)} ≤ (x_i + 1)^{δ−1}，于是

    x_{i+1} < (1/2)(x_i + 1)^{δ} ≤ (1/2)(1 + X0^{−1})^δ x_i^δ = B x_i^δ

（末步用 x_i ≥ X0）。∎

**与 SW 的差异（一处需要记录的细节）**：SW 的 Lemma 6 印作 x_{i+1} < b^δx_i^δ 且定义 b = (1 + X0^{−1})^{1/δ}2^{−1/δ}，即 b^δ = (1 + X0^{−1})/2；但同一段推导里显示的不等式是 (1/2)(1 + X0^{−1})^δx_i^δ（见 /tmp/sw143.txt 第 458 至 462 行）。两式的差别是 X0 的指数 δ 与 1，数值上差 1/(δX0) 量级（X0 = 3.25 × 2^60 时约 10^{−19}，对他们的任何应用都无影响），但严谨版本应是 (1 + X0^{−1})^δ/2，因为我用到的是 (1 + X0^{−1})^δx_i^δ ≥ (x_i + 1)^δ。**这是一处印式与本式不一致，不是数学缺口；我采用自己的常数 B。**如有形式化项目在跟这条线，这个指数值得核对。

### 6. chaining 上界（SW Lemma 7 型）——【已证：本会话自证】

**结论**：条件同第 5 步，则

    |x_min| > C_m^{−1} · 2^{(δ−1)K/(δ^m−1)}，

且进而 Λ < m·C_m·2^{−(δ−1)K/(δ^m−1)}（用 SW 的 Corollary 5 形式 Λ < m/x_min；若改用第 3 步的 K/(3x_min) 形式则系数是 K·C_m/3）。其中 C_m = [(1+X0^{−1})^m B^{T'}]^{1/S}（极限（X0 → ∞）2^{−1/(δ−1)} = 0.30576…，与 SW 的 c_m 同值）。**常数在分母**：初版把这一步印成 |x_min| > C_m·2^{K/S}，是把 C_m^{−1} 写成了 C_m，方向错误，且该错印有具体反例（见「对反驳的回应」一）。

**证明**：由第 5 步对 i = 1, …, m−1 迭代得 x_i < B^{1+δ+…+δ^{i−1}}x_0^{δ^i}，相乘：

    Π_i x_i < B^{T'} x_0^{S}， S = (δ^m − 1)/(δ − 1)， T' = Σ_{i=1}^{m−1}(δ^i − 1)/(δ − 1)。

另一方面 Π_i(x_i + 1) = Π_i 2^{k_i}a_i = 2^{K}Π_i a_i ≥ 2^K，且 x_i + 1 ≤ (1 + X0^{−1})x_i，故

    Π_i x_i ≥ (1 + X0^{−1})^{−m}·2^{K}。

两式合起来给 x_0^{S} > (1 + X0^{−1})^{−m}B^{−T'}2^{K}，开 S 次方得 x_min = x_0 > [(1 + X0^{−1})^{−m}B^{−T'}]^{1/S}·2^{K/S} = C_m^{−1}·2^{K/S}（x_0 可取 x_min，由环的循环性可旋转）。最后 Λ < m/x_min < m·C_m·2^{−K/S} 得第二式。∎

**数值复核**：把第 6 步的上界当作 Λ 的上界，与第 4 步第 2 条的连分数下界联立，解方程

    m·C_m·2^{−(δ−1)x/(δ^m−1)} = log_2 2/(2x)

的根 U(m)（SW 的 §6.2 把同一方程的解记作 J2(m)，见 /tmp/sw143.txt 第 721 至 760 行；脚本里变量 cm 就是 C_m）。初版在此处把系数写成 1/(3C_m) 的字面值而方程却仍按 C_m 计算，属文本与脚本不一致，已按脚本改正（两种常数下解出的 U 相差 3.4 倍，但交叉点都是 69 与 78，故只损文本、不损数字）。我用自己的常数实现，与 SW 第 12 页的表逐位对照（`results/arithmetic_cycles_check.txt` 第 D 段）：

### 7. 上界的收尾形式——【已证：SW §6.2 的结论；本会话读数与数值复核】

**结论**：若 K > U(m)（U 为第 6 步方程的解），则 (K + L)/K 必是 δ 的收敛项。

**这条的证明我用 SW 的原话**：/tmp/sw143.txt 第 723 至 745 行写「Lemmas 7 and 9(a) imply that (K+L)/K is a convergent to δ whenever K > J2(m)」——即 Λ 的指数小上界使 |(K+L) − Kδ| < 1/(2K)，再由 Lemma 9(a) 得它是收敛项。**我没有独立重写这一步的细节**，只复核了它依赖的两个部件（第 4 步与第 6 步）。

### 8. 广义 Crandall 下界——【已证：本会话自证；与 SW Lemma 10 同型，并要求了 m 无关形式】

**（8a）m 无关形式**：设 C = (3X0 − 1)ln 2，n* = max{n : q_n(q_n + q_{n+1}) < C}。则任何非平凡环（正或负）满足 K > q_{n*}。

**证明**：反设 K ≤ q_{n*}。取 m_0 = 使 q_{m_0} ≥ K 的最小下标（存在，因 q_{n*} ≥ K）。由第 4 步第 3 条（用于 q = K ≤ q_{m_0}）

    |(K + L) − Kδ| ≥ |p_{m_0} − q_{m_0}δ| > 1/(q_{m_0} + q_{m_0+1})，

即 |Λ| > log_2/(q_{m_0} + q_{m_0+1})。另一方面第 3 步给 |Λ| ≤ K/(3X0 − 1) ≤ q_{m_0}/(3X0 − 1)（用 K ≤ q_{m_0}）。两式联立得 (3X0 − 1)ln 2 < q_{m_0}(q_{m_0} + q_{m_0+1})；但 m_0 ≤ n* 且 q_n(q_n + q_{n+1}) 随 n 递增，故 q_{m_0}(q_{m_0} + q_{m_0+1}) < C = (3X0 − 1)ln 2，矛盾。∎

**（8b）m 相关形式（SW Lemma 10）**：若 m(q_n + q_{n+1}) ≤ X0 ln 2，则 K > q_n。此处 m 是局部极小个数；把（8a）里的 |Λ| ≤ K/(3X0 − 1) 换成 SW Corollary 5 的 Λ < m/X0 即得（我按 /tmp/sw143.txt 第 582 至 601 行复核了他们的推导）。

**为什么需要两种形式**：收尾时用（8b），因为它对每个 m 给出更强的下界；讲不可能性时用（8a），因为它对正负两侧同时成立且不依赖 m（SW 的框架只处理正环）。

### 9. 双侧窗口判据（必要条件）——【已证：本会话自证；与 20-experiments/findings/cycles.md 第 2.5 节同结论】

**结论**：设 w = 1/((3X0 − 1)ln 2)。则

1. 若存在元素绝对值 ≥ X0、奇数步数为 K 的非平凡正环，则 1 − frac(Kδ) ≤ Kw；
2. 若存在这样的负环，则 frac(Kδ) ≤ Kw。

**证明**：正环 Λ > 0 且 Λ = K ln 2·((K+L)/K − δ)，由第 3 步 Λ ≤ K/(3X0 − 1) 得

    0 < (K + L) − Kδ ≤ K/((3X0 − 1)ln 2) = Kw。

但 K + L 是整数且 > Kδ，故 K + L ≥ ⌈Kδ⌉，于是 1 − frac(Kδ) = ⌈Kδ⌉ − Kδ ≤ Kw。负环把 Λ 换成 |Λ| 同法。∎

逆否形式就是排除规则：正侧「1 − frac(Kδ) > Kw 则不存在奇数步数为 K 的正环」，负侧「frac(Kδ) > Kw 则不存在这样的负环」。

**独立复核**：脚本第 B 段用全扫描（预筛加 150 比特整数算术精判）重算 20-experiments/findings/cycles.md 第 4.5 节的两张 M+、M− 表，**14 个格子逐格一致**（10^6、10^8、3×10^9、10^10、3×10^10、10^11、10^12 七档的正负两侧），例如 10^12 档：正侧最小幸存 10781274、负侧 5446238，与该文件的 10781273、5446237（M 值 = 最小幸存减一）吻合。

### 10. 收尾不可能性（T2a）——【已证：本会话自证，新】

**证明**：因 q_n → ∞，可取奇数 n 使 q_nq_{n+1} ≥ C = (3X0 − 1)ln 2（这样的 n 有无穷多个）。令 K = q_n、P = p_n。由第 4 步第 5 条，（i）奇数 n 给 p_n − q_nδ > 0，即 P/K > δ；（ii）第 4 条给 0 < p_n − q_nδ < 1/q_{n+1}。于是

    0 < P/K − δ < 1/(q_nq_{n+1}) ≤ 1/C = w，

即 K 满足第 9 步的必要条件而未被排除。而 q_n 随 n 无界，故对任意 K0 都能取到 K > K0。∎

**数值旁证**：脚本第 C 段对七档 X0 做全扫描，最小幸存者与「（半）收敛项分母中的最小幸存者」**逐档一致**，且标签显示全部是半收敛项分母（如 X0 = 10^12 正侧的最小幸存 10781274 = q_13 + 1·q_14，负侧 5446238 = q_12 + 28·q_13；X0 = 10^6 正侧 2966 = q_7 + 4·q_8）。对 X0 = 10^20、10^40 无法全扫描，只在候选集内找到最小幸存者（6586818670 与 2.056322188733986 × 10^20），仍都是半收敛项分母。**结论：窗口判据的幸存集对任何有限 X0 非空，且随 X0 无界增长；这条判据在数学上不可能收尾。**

### 11. 双侧 chaining（T2b 的负侧部分）——【已证：本会话自证，新（相对 SW 只做正环）】

**负环与 3x−1 的化归**：设 x < 0 是负环上的元素，令 n = |x|。则 T 在负整数上的偶步与奇步分别对应 U(n) = n/2（n 偶）、(3n − 1)/2（n 奇）。于是「T 的非平凡负环」与「U 的非平凡正环」一一对应，周期与奇数步数都不变。

**U 的链式结构**：U 的局部极小 n_i 后面连续 k_i 个奇数步（各步形如 v ↦ (3v − 1)/2）迫使 n_i ≡ 1 (mod 2^{k_i})，即 n_i = 2^{k_i}a_i + 1（a_i ≥ 1；a_i = 0 只给 n_i = 1，即 U 的平凡不动点）。链末（第 k_i − 1 个奇数元素）为 v = 3^{k_i−1}·2a_i + 1，其后一步到达 y_i = 3^{k_i}a_i + 1。注意链长 k_i 是极大游程，故 a_i 为奇数、y_i 为偶数，下降段从 y_i 起全是折半，于是 n_{i+1} = y_i/2^{ℓ_i} 且 ℓ_i ≥ 1。

**chaining 不等式（负侧）**：

    n_{i+1} = (3^{k_i}a_i + 1)/2^{ℓ_i} ≤ (1/2)(3^{k_i}a_i + 1) ≤ (1/2)[(n_i − 1)^δ/a_i^{δ−1} + 1] ≤ (1/2)[(n_i − 1)^δ + 1] ≤ B n_i^δ，

末步用到 (n_i − 1)^δ ≤ n_i^δ 与 1 ≤ ((1 + X0^{−1})^δ − 1)n_i^δ（后者由 (1+t)^δ − 1 ≥ δt（δ ≥ 1，t ≥ 0）与 δX0^{δ−1} ≥ 1 保证，X0 ≥ 2 时成立）。

**上界**：Π(n_i − 1) = Π2^{k_i}a_i = 2^KΠa_i ≥ 2^K，且 n_i ≥ n_i − 1 > 0，故 Πn_i ≥ 2^K；与 chaining 的 Πn_i < B^{T'}n_0^{S} 联立得 n_min > C_m^{−1}2^{K/S}（常数在分母，与第 6 步同；初版此处也印成 C_m2^{K/S}，一并改正），其中负侧的 C_m 没有 (1 + X0^{−1})^m 因子（因为 n_i ≥ n_i − 1 无需放大），且 X0 ≥ 2 时 C_m ≤ 1，所以初版的方向错误在负侧只会把界变弱。

**检验（本轮新做，反驳意见促成的）**：把三个已知负环化为 U 环后逐条核对，前提（环上所有元素绝对值 ≥ X0）成立时，修正版全部通过；印出版在 {−5, −7, −10}、X0 = 2 处给出反例（阈值 6.0 > |x_min| = 5）。原始输出见 `results/refutation_check.txt` 第 3 节（脚本 `scripts/refutation_check.py`）。

**|Λ| 的上界**：由 U 的乘积恒等式 2^k = Π(3 − 1/n_i)，|Λ| = Σ ln(1 + 1/(3n_i − 1)) ≤ K/(3X0 − 1)。所以负侧与正侧走同一套收尾：|Λ| ≤ K/(3X0 − 1) 与 |Λ| > log_2/(q_n + q_{n+1}) 相撞。

**意义**：文献侧（SW）的 chaining 明确只对正环陈述；本项目 20-experiments 对负侧用的是第 9 步的窗口判据（没有 chaining）。第 11 步给负侧补上了同型的上界，从而负侧也能进入第 13 步的两侧夹逼。

### 12. K 门槛到周期下界的桥接（T2d）——【已证：本会话自证，新；补 notes/cycles.md 缺口 6】

**证明（只对正环；负侧方向相反，见下）**：正环满足 2^k > 3^K，取对数得 k ln 2 > K ln 3，即 k = K + L > Kδ。于是 K > q_n 给 k > Kδ > δq_n。而标准映射（把每个 3x + 1 与每次折半各计一步）下的周期是 k + K（每个奇数步比加速映射多出 3x + 1 那一步），故 > (1 + δ)q_n。∎

**负侧方向相反，本引理不适用**：负环满足 2^k < 3^K，即 k < Kδ，同样推不出周期下界。负侧要另找出口（例如 K > q_n 与 L ≥ m ≥ 1 给 k ≥ q_n + 1，或对负环用 δ 的另一侧；我没有做，见失败点 F5）。

**数值**：脚本第 H 段复算 ⌈δ·q_23⌉ = 217,976,794,617、⌈(1 + δ)·q_23⌉ = 355,504,839,929，与 frontier.md 第 22 行、notes/cycles.md 第 16 条记录的当前值逐位一致；且 q_23 = 137,528,045,312 与项目笔记第 16 条复算的四个数完全对齐（脚本第 A 段另核对了 q_19 至 q_24 六个收敛项分母，全部一致）。
