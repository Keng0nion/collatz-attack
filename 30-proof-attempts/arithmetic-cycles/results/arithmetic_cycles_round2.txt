B. 1 圈（奇偶字 1^K 0^L）的精确判别与 K <= 20000 的完全检验
========================================================================

推导（本脚本用的必要充分条件，详见 attempt.md 第 9 步）：
  设字为 1^K 0^L，则 c = 3^K - 2^K，D = 2^(K+L) - 3^K，x = c/D；
  1 圈存在 <=> x 是正整数 <=> D | c；
  又由 x + 1 = 2^K m（m >= 1）得 D | 2^L - 1 且 m = (2^L - 1)/D >= 1，
  故 2^L (2^K - 1) <= 3^K - 1 且 2^(K+L) > 3^K；
  后一式给出 L >= L0 := bit_length(3^K) - K，前一式给出 L <= L0（因为 2^(L0+1) > 2(3/2)^K >
  (3^K-1)/(2^K-1) 对 K >= 1 成立），故 L = L0 是唯一候选。

K = 1 的候选（应给出平凡环）：
  K=1: N=2 L=1  D=1  区间条件=True  整除条件=True  x=1

对 K = 1..20000 逐个检验（全部用精确整数算术，无浮点）：
  通过区间条件且通过整除条件的 (K, L, N)（即 1 圈候选）：[(1, 1, 2)]
  只通过区间条件的 K：[1]
  结论：K = 2..20000 内没有非平凡 1 圈（这是本脚本的直接检验范围）。

归约恒等式的精确核对（用 Fraction 验算，不看整性）：对 (K, L) 令 D = 2^(K+L) - 3^K，
  c = 3^K - 2^K，x = c/D，m = (x+1)/2^K；应恒有 2^L x + 1 = 3^K m 且
  (m >= 1) <=> (D <= 2^L - 1) <=> (2^L (2^K - 1) <= 3^K - 1)。
  K = 1..25, L = 1..39, D > 0 的全部组合：2^L x + 1 = 3^K m 失败数 = 0（应为 0）
  (m >= 1) 与区间条件不等价的个数 = 0（应为 0）

独立核对（三参数方程 m 3^K - 1 = 2^L (m 2^K - 1)，只对小的 K、m 枚举）：
  即 T := (m 3^K - 1)/(m 2^K - 1) 必须是 2 的幂。
  K <= 40, m <= 20000 的解 (K, m, T=2^L)：[(1, 1, 2)]
  （T = 2 对应 K=1, m=1 的平凡环，x = 2^K m - 1 = 1。）

B2. 与超越论输入的衔接（为什么 m = 1 这一档是「可封闭」的）
  由本文件第 9 步，非平凡 1 圈的必要条件是：存在整数 N 使 0 < N ln2 - K ln3 < 2^(-K)。
  Rhin 1987 型显式下界（数值按本项目文献笔记转引 Simons 与 de Weger v1.43 的 Lemma 12，
  我未打开 Rhin 原文）：|N ln2 - K ln3| > exp(-13.3 (0.46057 + ln H))，H = max(N, K)。
  比较要点：2^(-K) 随 K 指数衰减，而下界只按 H^(-13.3) 多项式衰减，故 K 一大，下界就大于
  2^(-K)，于是必要条件与下界相撞。求门槛 K0（K >= K0 时下界 > 2^(-K)）：
    K0 = 108（即 K >= 108 时，Rhin 型下界 > 2^(-K)）
    在 K = 108 处：下界 = 3.47048e-33，2^(-K) = 3.08149e-33，比值 = 1.12623
    在 K = 20000 处：下界 = 2.63535e-63，2^(-K) = 2.51239e-6021，下界/2^(-K) = 1.04894e+5958（远超 1）
  结论（本文件第 10 步）：m = 1 档由「K <= 20000 的精确检验（本脚本 B 段，已实跑）」
  加「K >= 108 的 Rhin 型下界（转引，未一手核对）」共同封闭，相容于文献把该档归于
  Steiner 1977 的记载（Wikipedia 与项目笔记均为二手）。
