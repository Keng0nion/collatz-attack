## 我尝试证明的定理（精确陈述）

**记号**。T 为加速科拉茨映射：T(n) = n/2（n 偶）、(3n+1)/2（n 奇）。T^k 为第 k 次迭代。对 v ∈ {0,1}^k 记 m(v) 为其中 1 的个数，c(v) 由递推 c(空) = 0、c(v0) = c(v)、c(v1) = 3c(v) + 2^{|v|}（|v| 为当前长度）定义。v_k(n) ∈ {0,1}^k 为 n 的前 k 步奇偶向量，称 n 的「长度 k 奇偶词」。σ(n) = min{d ≥ 1 : T^d(n) < n} 为**首降时间**（σ(n) = ∞ 表示永不下降）。D_k = {n ≥ 1 : T^k(n) < n}。对 Z_2 上的点同样定义奇偶词（「n 偶」即 2 进赋值 ≥ 1），编码映射 Ψ(x) = x 的无穷奇偶词。

**主定理（本路线的完整产物）**：(S1) 至 (S7) 同时成立。

**(S1)（编码定理；第一轮，本轮复核）** 对每个 k ≥ 1：（一）若 v_k(n) = v 则 T^k(n) = (3^{m(v)}n + c(v))/2^k，且 v_k 只依赖 n mod 2^k、该映射在 [1, 2^k] 上是双射；（二）D_k = ⊔_{v : 2^k > 3^{m(v)}} {n ≡ a_v (mod 2^k), n ≥ ⌊θ_v⌋ + 1}，θ_v = c(v)/(2^k − 3^{m(v)}）；（三）每个 D_k 是 2 自动集，有显式自动机（状态数 ≤ 2^k + max_v s_v）；（四）科拉茨猜想 ⟺ ∪_{k≥1} D_k = Z_{>0} ∖ {1}。

**(S2)（2 进闭包版本的完全解；本轮新）** 记 Ψ(x) 为 x ∈ Z_2 的无穷奇偶词。则：
1. Ψ: Z_2 → {0,1}^N 是双射，且 Ψ∘T = σ∘Ψ（σ 为单边移位）；
2. 对每个 k，T^k 在 Z_2 上恰有 2^k 个不动点，且 Fix(T^k) = {x_v : v ∈ {0,1}^k}，其中 x_v = c(v)/(2^k − 3^{m(v)}) ∈ Q ∩ Z_2；x_v 的 T 精确周期恰为 v 的原始根长；精确周期为 k 的点数是 Σ_{d|k} μ(k/d)2^d；
3. T 在 Z_2 上的每个周期点都是有理数（与已知定理一致，见「与文献的关系」）；
4. 对 x ∈ Z_2，T^j(x) = 1 对某个 j 成立，当且仅当 x 的奇偶词从某位起等于 (1,0,1,0,…)；因此集合 R_2 = {x ∈ Z_2 : 轨道到达 1} = ⋃_{j≥0} T^{−j}(1) 是可数集（T 是双射，每个 T^{−j}(1) 恰含一点），其余集在 Z_2 中测度为 1；
5. 推论：**「2 进闭包版本的科拉茨猜想」（即 Z_2 上一切点都到达 1）为假**，反例包括 −1（不动点）与 4/5（正有理三圈 4/5 → 2/5 → 1/5 → 4/5）；把它限制到正有理数也无救（4/5 就是正有理数）。

**(S4)（非下降集的结构与「永不下降」判据；本轮新）**
1. 精确结构：对每个 k，{n ≥ 2 : σ(n) > k} = ⊔_{w ∈ {0,1}^k} {n ≡ a_w (mod 2^k), n ≤ Θ_w}，其中 Θ_w = min{θ_{w|_i} : i ≤ k，2^i > 3^{m(w|_i)}}（若集合为空则 Θ_w = +∞）；

### 二、2 进闭包层（本轮新）

**步骤 5（已证）** Ψ 是单射。设 x ≠ y ∈ Z_2 有相同的无穷奇偶词。对每个 j，两者同属一个长度 j 的类，故由仿射公式 T^j(x) − T^j(y) = 3^{m_j}(x−y)/2^j，即 x − y = 2^j(T^j(x) − T^j(y))/3^{m_j}。因 T^j(x), T^j(y) ∈ Z_2，右端属于 2^j Z_2；这对一切 j 成立，故 x − y ∈ ⋂_j 2^j Z_2 = {0}。∎

**步骤 6（已证）** 逐层双射。设 v_j: Z/2^j → {0,1}^j 为残数类到长度 j 词的映射（由步骤 1 良定义）。它是单射：对 a 与 a + 2^j（同类 mod 2^j，故长度 j 词相同），仿射公式给出 T^j(a + 2^j) = T^j(a) + 3^{m_j}；因 3^{m_j} 为奇数，两者的第 j+1 位奇偶相反，故两个提升落入模 2^{j+1} 的不同类。归纳得逐层单射；再由 |Z/2^j| = |{0,1}^j| = 2^j 得双射。∎
独立验证：`checks_automata_v2.py` A1 段（k ≤ 12）。

**步骤 7（已证）** Ψ 是满射，且 Ψ∘T = σ∘Ψ。满射：给定无穷词 w，令 C_j 为长度 j 前缀对应的残数类；C_j 是 Z_2 的非空闭集且 C_{j+1} ⊆ C_j，由 Z_2 的紧性（或有限交性质）⋂_j C_j ≠ ∅；由步骤 5 的单射性该交恰为一点，即 Ψ 的满射性。共轭关系 Ψ(T(x)) = σ(Ψ(x)) 直接来自 T 的定义（T 的第 i 位奇偶 = Ψ(x) 的第 i+1 位）。∎
**这一步与 Bernstein 与 Lagarias 1996 的共轭定理陈述一致**（转引，见「与文献的关系」），我给出的是一个自包含的初等证明，不依赖他们的等距性与唯一性论证。独立验证：`checks_automata_v2.py` A2 段在 N ≤ 13 的全部 2^N 个 x 与全部 j ≤ N 上核对「T^j(x) ≡ 1 (mod 2^{N−j}) ⟺ 词的后 N−j 位为 (1,0) 交替」，212944 组比对无一不符。

**步骤 8（已证）** 周期点定理：(S2) 二。设 w = v^∞（v 长度 k），x = Ψ^{−1}(w)。由共轭关系 Ψ(T^k(x)) = σ^k(w) = w = Ψ(x)，再用单射性得 T^k(x) = x；而 x 的长度 k 词是 v，故仿射公式给出 x = c(v)/(2^k − 3^{m(v)}) = x_v。反之若 T^k(x) = x，取 v = v_k(x)，同样得 x = x_v。故 Fix(T^k) 与 {0,1}^k 一一对应，|Fix(T^k)| = 2^k。精确周期：x_v 的 T 周期 = v^∞ 的最小周期 = v 的原始根长；于是精确周期 k 的点数 = 原词数 = Σ_{d|k} μ(k/d)2^d（原词计数公式的验证见 A4 段，k ≤ 18 暴力一致）。∎
独立验证（三种独立路径）：A3a（对每个长度 ≤ 7 的词，分数迭代给出的词恰为 v；254 个词，不符 0）、A3b（T^k(x_v) = x_v，分数精确）、A3d（d < 2k 内无杂散周期）、A3e（模 2^24 见证：3^m X + c ≡ 0 (mod 2^k) 且商 ≡ X (mod 2^{24−k})）。**整数周期点表**（A5 段，周期 ≤ 12）复现的结果是：0、−1（周期 1）、{1,2}（周期 2）、{−5,−7,−10}（周期 3）、从 −17 起的 11 元环（周期 11），此外无整数周期点。这与项目 `findings/parity-vectors.md` 第 96 行记录的 k ≤ 32 完备环搜索（同样的四个环族）互为独立见证，且方法与它完全不同（这里是 2 进不动点公式，那里是奇偶向量穷举）。

**步骤 9（已证）** 「到达 1」的刻画：(S2) 四。1 的奇偶词是 (1,0) 交替（1 → 2 → 1）。若 T^j(x) = 1 则 x 的词从第 j 位起是 (1,0) 交替；反之若从第 j 位起是 (1,0) 交替，则 T^j(x) 的词是 (1,0) 交替 = 1 的词，由单射性 T^j(x) = 1。∎
推论：R_2 = ⋃_{j≥0} T^{−j}(1)；因 T 是双射（步骤 7：Ψ 为双射且 σ 为双射），每个 T^{−j}(1) 是单点集，故 R_2 可数、其余集满测度。**因此 2 进闭包版本的猜想为假**，且失败集的测度是 1。独立验证：A6 段（4/5 构成三圈、1/3 一步到 1、−1 不动点）、A6b 段（4/5 的奇偶词周期为 (0,0,1)，不是 (1,0) 交替，故 4/5 永不到达 1）。

**步骤 10（已证，方法层面的推论）** 任何只用 2 进结构（紧性、测度、遍历性）的论证都不能证明猜想：因为同样的论证会作用于 Z_2 上，而该层命题为假（步骤 9）。这与 `frontier.md` 第三节第 1 条（零测集屏障）方向一致，本步骤把它变成一个带证明的陈述。**注意它的范围**：它排除的是「只用 2 进结构」的论证，不排除同时使用整数算术（序、整除、素因子）的论证——后者正是猜想所需。

### 三、截断层（本轮新）

**步骤 11（已证）** T 不诱导任何固定模的自映射；T 诱导的是「模数收缩」系统 Z/2^{s+1} → Z/2^s。前者：a ≡ a + 2^s (mod 2^s) 但一般不满足 T(a) ≡ T(a + 2^s) (mod 2^s)；最小反例 s = 1（0 与 2 同为偶数类，像为 0 与 1，不同类）。后者：若 a ≡ b (mod 2^{s+1}) 则两者同奇偶，故 T(a) − T(b) = (a − b)/2 或 3(a − b)/2，均被 2^s 整除。∎
独立验证：`checks_automata_v2.py` F1（s ≤ 8 全部 2^{s+1} 个提升，失败 0）与 F2（最小反例 s = 1）。
**这一步的意义**：任何「在模 2^s 的有限状态空间上把 T 当作动力系统来判定」的写法，在原理上就已经不成立（连自映射都不是）；「有限状态截断」要成为动力系统，必须像 Shallit 与 Wilson 那样引入额外状态（他们用反向表示加进位状态），而那也正是 i 无界问题无法回避的地方。

**步骤 12（已证）** 上升前缀 ⟹ 整类不下降。设词 v 的长度 k 满足 3^{m(v)} ≥ 2^k，则对类内一切 n：T^k(n) = (3^{m}n + c)/2^k ≥ 3^{m}n/2^k ≥ n（c ≥ 0）。∎

**步骤 13（已证）** 定理 D 两支。
（一）设 w 的每个前缀上升，令 w' = w1^{k−a}（k ≥ a）。其长度 i 的前缀：i ≤ a 时为 w 的前缀（上升）；i > a 时为 w 与 i−a 个 1，其 1 的个数为 m(w) + (i−a)，于是 3^{m(w')|_i} = 3^{m(w)}·3^{i−a} ≥ 2^a·3^{i−a} ≥ 2^a·2^{i−a} = 2^i（这里用到 w 的整词上升：3^{m(w)} ≥ 2^a）。故 w' 的所有前缀上升，由步骤 12 该类的每个成员 n 满足 T^i(n) ≥ n（i ≤ k），即 σ(n) > k。
（二）设 w 有下降前缀，i_0 最小。对 n ∈ C_r，n 的长度 i_0 词是 w|_{i_0}（因 i_0 ≤ a），由仿射公式与 D := 2^{i_0} − 3^{m(w|_{i_0})} > 0 得 T^{i_0}(n) < n ⟺ c < D·n ⟺ n > θ_{w|_{i_0}}；故 n > θ ⟹ σ(n) ≤ i_0。
（三）两支合起来给出：**「σ 在 C_r 上取任意大的有限值」⟺「w 全前缀上升」**（第一支给无界侧，第二支给「非全上升侧一切高于 θ 的成员都有 σ ≤ i_0、其余在有限例外集 E_r 内」）；并给出 (S3) 五的不可能性。**第二版改正**：初版此处写成「σ 无界（含 σ = ∞）⟺ 全前缀上升」，那是把「有限个例外」当成「有界」——例外集 E_r 的成员可能永不下降（n = 1 就是这种成员，它属于类 1 mod 4 而该类词 (1,0) 有下降前缀）。完整等价需要 (S3) 第 4 条的输入 (∗)，见该处与「对反驳的回应」一。

### 四、证书与元数学层

**步骤 20（已证，关于形式）** (S6) 的四条：位权两点消去、多项式渐近否决、势函数充要条件与循环性、证书判据与二分。全部是第一轮的结论，本轮复核了其脚本（I、J、K 段）与数学论证，未发现错误。要点：
1. 位权形式（含 a·x + b·popcount(x)）在 x = 2^k − 1 与 x = 2^k 两点上的差分互为相反数，故不可能同时严格下降——这精确解释了 `findings/smt-certificate.md` 观察到的不可满足核 {1,2} 与 {3,4}（它们是 k = 1、2 的实例）。
2. 任何非空 T 不变域上不存在良基严格下降势函数（环的存在性使求和矛盾）。
3. 「存在某个信息函数 φ 与深度 d 使 T^{d(φ(n))}(n) < n 对一切 n ≥ 2 成立」⟺ 猜想（⟸ 取 φ(n) = σ(n)；⟹ 由步骤 4 的链式论证）。

**步骤 21（已证）** 代价定理 (S7)。若猜想为真，则 L = Z_{>0} ∖ {1}（由步骤 4），而 Z_{>0} ∖ {1} 是余有限集；若 C 含一切余有限集则 L ∈ C，故「L ∉ C」⟹ 猜想为假。∎
**这一步是本路线最重要的元数学结论**：它说明「自动机路线的不可能性定理」不但目前不存在，而且**在猜想为真的前提下不可能存在**——任何这样的定理都会顺手证否猜想。第一轮只用「并集非正则」这一特例表达了同一意思（那时用「正则集」，本轮把它推广到任何含余有限集的类 C，例如 2 自动集、⟨N, +, V_2⟩ 可定义集、半线性集、密度为 1 的集合类）。
**同时必须记下它的逆向含义**：这个代价论证不能用来支持猜想；它只是说这条路线的「不可能性」方向没有出口。

**步骤 22（已证）** 剩余类限制不构成限制。对固定 a ≥ 1 与 r，记 C(r) 为「一切 n ≥ 1、n ≡ r (mod 2^a) 的轨道到达 1」。则 C(r) 蕴含猜想：给定任意 n ≥ 1，令 r' = T(n) mod 2^a，则 T(n) ≡ r' (mod 2^a)，由 C(r') 得 T(n) 的轨道到达 1，故 n 的轨道到达 1。∎
**意义**：把猜想「限制到某个剩余类」在逻辑上完全没有减弱它；这与步骤 13、15 一致（坏类存在于每一层），也解释了为什么 mod 2^a 的截断永远无法给出部分结果。

## 失败点清单（逐条说明为什么是缺口，以及跨过它需要什么）

**缺口 1（主缺口，性质已定量）：不存在、且不可能存在无条件的「自动机路线不可能」定理。**
为什么是缺口：需要证明的命题形如「∪_k D_k 不是 2 自动集」或「有限自动机不能判定猜想」。由 (S7)（步骤 21），任何这类命题（只要类的定义包含余有限集）都蕴含猜想的否定；由于猜想被广泛预期为真，这条路线的不可能性定理实际上是被封死的。**这不是「技术未达到」而是「逻辑上自毁」**：证明它等于证否猜想。
跨过它需要什么：改成**条件形式**，例如「若猜想为假且反例集 S 属于某类（正则、可自动识别、可定义于 ⟨N,+,V_2⟩），则 ∪_k D_k 非正则」。这类定理不蕴含 ¬猜想，但也不蕴含猜想，属纯元数学注释。我未找到（也未构造出）非平凡的条件形式；是否有，我不知道。

**缺口 2（本轮新，最精确的一处；第二版据反驳意见细化）：Z = {n ≥ 2 : σ(n) = ∞} 没有完整刻画，而 Z = ∅ 恰是猜想。**
为什么是缺口：步骤 16 把猜想等价地写成 Z = ∅，但 Z 的成员由无穷多条不等式刻画（(S4) 二）。**第二版新增的分解**（由反驳方指出的 (∗) 与 Terras 猜想的关系推出）：
1. （已证）Z ⊇ {n ≥ 2 : n 的无穷奇偶词全前缀上升}，且每个这样的 n 都在 Z 中（步骤 12 与 13 一）；
2. （等价改写）令 A := {n ≥ 2 : n 的奇偶词全前缀上升}（即 τ(n) = ∞ 的集合，τ 为 Terras 的系数停时），(∗) := Z ⊆ A（即每个永不下降的 n ≥ 2 的奇偶词全前缀上升）。则 **Z = ∅ ⟺ A = ∅ 且 (∗) 成立**。
3. 其中 A = ∅ 等价于「τ(n) < ∞ 对一切 n ≥ 2 成立」，(∗) 则是 Terras 系数停时猜想 τ(n) = χ(n) 的一个特例（只涉及 χ = ∞ 的成员）；前者据 Winkler 的预印本摘要自述未证（转引自 `notes/stopping-times.md` 第 17 条），后者据同笔记第 91 条未证。两者我都没有证明。
跨过它需要什么：（a）判定 A 是否为空：需要关于「奇偶词的 1 密度长期维持在 log_3 2 ≈ 0.6309 以上」的不可能性定理，这与发散轨道一侧的困难同类（`frontier.md` 第三节第 11 条：发散轨道无技术）；（b）判定 (∗)：它在 a ≤ 44 的逐类形式上可由 Barina 的 2^71 验证兑现（因为例外集 ⊆ [2, 3^a]，而 3^44 < 2^71），但 (∗) 的完整形式与 Z 的完整刻画仍无证。**我仍然不知道 (a) 是否比猜想容易**（这一点必须说清楚，不能暗示这是捷径）。

**缺口 3（第一轮缺口 5 的延续）：证书语法只覆盖「按 n 指定深度」型。**
为什么是缺口：步骤 20 的判据针对形式「d(φ(n))」；不属于这一形式的证明手段至少有三类：（a）非良基序（实数型测度、平均下降，Tao 型论证即此类）；（b）把「下降」换成别的偏序结构；（c）不变量型论证。这些都没有被分析。
跨过它需要什么：先给这类证书写一个精确语法，再谈不可能性定理。一个值得做的第一步：给「测度型」证书写语法（例如「存在有界函数 M 与步数 K，使每 K 步内某显式量平均下降」），然后检查步骤 20 的循环性论证能否推广；可以预期：若该量的取值域良基则推广成功，若允许实值则应失败于 [3,N] 上的逃逸时间（第一轮步骤 10 的显式见证）。

**缺口 4（第一轮缺口 3）：势函数类只覆盖两族。**
为什么是缺口：位权形式（无条件）与「次数 ≥ 1 的多项式加有界位权」（渐近）已被否决；**位权无界且多项式次数 ≥ 1 的混合形式**未被覆盖（渐近论证失效，因为位权扰动不再被主项压制）。
跨过它需要什么：用三点或四点恒等式（在 2^k − 1、2^k 之外再加 2^k + 2^{k−1} − 1 等点）寻找反例族；这些点的位集合差分的消去结构可以逐个算清，属可枚举的一步。我没有做。

**缺口 5（诚实标注）：本文件全部结论都在「受限版本」与「证书形式」两层，对原猜想本身零进展。**
为什么是缺口：由步骤 9（2 进闭包版本为假）与步骤 21（代价定理），这条路线的两层都已封闭或定位：受限版本的真值与猜想不一致，不可能性方向在逻辑上自毁。**本路线没有第三条出口。**
跨过它需要什么：不知道。任何声称「自动机或有限状态路线给了猜想部分结果」的说法，都必须先说明它落在步骤 4（等价改写）、步骤 9（闭包层，错方向）还是步骤 21（代价自毁）之中。

**必须显式排除的三种误读（错误）**：
1. 「D_k 是自动集且有显式自动机 ⟹ 可用自动机判定猜想」——错（步骤 4 是等价改写，步骤 11 说明连自映射都不存在，步骤 21 说明不可能性方向自毁）。
2. 「2 进侧已完全解决 ⟹ 猜想在 2 进侧已被证明」——错，恰相反：2 进侧的答案是「几乎一切点都不到达 1」（步骤 9）。
3. 「本文件的定理 D 是猜想的部分结果」——错。定理 D 是关于**证书形式**（mod 2^a 的逐类深度）的完整分类，它既不排除更强的证书形式，也不排除猜想；而且由步骤 22，「限制到剩余类」本身不构成限制。
4. 「至多有限个例外 ⟹ 有界」（**本文件第一版犯过，第二版已改正**）——错。例外集有限，但它的成员可能永不下降（n = 1 就是这样的成员：词 (1,0,1,0,…) 的前缀 (1,0) 下降、θ = 1、σ(1) = ∞），因此把「有限例外」当成「有界」会得到一个未证的等价（即 (S3) 第 4 条的 (∗)，其完整形式等价于 Terras 系数停时猜想）。

## 与文献的关系（哪些已知结果支持或否决本路线）

**支持（或与本文件一致）的部分**：

1. **Büchi 与 Bruyère 定理**（转引，我据两处二手来源核对：Cambridge 期刊论文《A dichotomy for k-automatic expansions of Presburger arithmetic》的摘要句「the k-automatic subsets of N are exactly those definable in the structure (N, +, V_k)」，作者归属标为 Büchi 与 Bruyère；以及 2026 年 arXiv:2605.28408 提到「Büchi 与 Bruyère 定理」与 BA_k 可判定）：S ⊆ N 是 k 自动集当且仅当 S 在 ⟨N, +, V_k⟩ 中可定义，且该理论可判定。**我未打开 Bruyère 的原始论文**；本文件只在步骤 21 用它的表述形式（自动性 = 可定义性），不使用其证明。
2. **Shallit 与 Wilson**（第一轮亲自下载并读全文，本轮沿用）：对每个 i ≥ 0，S_i = {n : 轨道到达 1 前恰用 i 次 3x+1} 是 2 自动集。他们的结果是「每个固定 i 一个自动机」，且该文没有任何不可能性陈述。本文件的步骤 11 补充了一个他们没有写的观察：T 甚至不诱导固定模上的自映射，因此「有限状态」必须靠额外状态实现。
3. **Bernstein 与 Lagarias 1996**（转引，见项目 `notes/two-adic.md` 第 1 至 8 条与 `frontier.md` 第一节第 15 条）：T 在 Z_2 上共轭于移位、共轭映射处处不可微；另一条相关的已知定理是「T 在 Z_2 上的周期轨道由有理数组成」（`frontier.md` 第一节第 15 条注明其转引自 Rozier，后者引 Lagarias 1990；我未打开这两处原文）。本文件的定理 A 是这些陈述的初等重述与自包含证明；**我没有使用他们关于等距性与唯一性的更强结论**，也没有使用「处处不可微」（后者正是 `frontier.md` 第三节第 10 条记录的「共轭信息屏障」：共轭不能武器化）。
4. **Böhm 与 Sontacchi 1978**（转引）：环的充要条件 x = c/(2^k − 3^m)。本文件的 x_v 公式与之同源，只是把「环」的语境换成「2 进周期点」（后者不需要整除性，因为 2^k − 3^m 总是 2 进可逆元）。
5. **Terras 1976 与 Everett 1977**（转引，见 `notes/stopping-times.md`）：停时层集与阈值结构。本文件步骤 15 给出其精确形式，与本项目 `findings/parity-vectors.md` 的 K2 精确版一致。
6. **`notes/barriers.md` 第 24 条与 `frontier.md` 第二节第 7 条**：「有限覆盖 + 固定下降深度的证书不存在」。本文件的定理 D 把它细化为精确分类（哪些类坏、坏类恰为全前缀上升词、坏类计数 N_a），并明确指出这不是对猜想的新进展（步骤 22 与缺口 5）。
