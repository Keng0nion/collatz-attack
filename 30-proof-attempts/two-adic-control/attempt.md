## 我尝试证明的定理（精确陈述）

**主目标（未证）：周期猜想 PC_3。** 对每个 x ∈ ℚ ∩ Z_2（分母为奇数的有理 2 进整数），加速科拉茨映射 T_3（x 偶取 x/2，x 奇取 (3x + 1)/2）的轨道 T_3^0(x), T_3^1(x), … 最终周期。

**本轮实际证成的定理（本文给出完整证明，并有脚本核验）。**

**定理 T1（等距刚性）。** 设 φ: Z_2 → Z_2 是 2 进等距，即对所有 x, x′ ∈ Z_2 有 v_2(φ(x) − φ(x′)) = v_2(x − x′)，且 φ ∘ S = S ∘ φ，其中 S(x) = (x − (x mod 2))/2 是 2 进移位。则 φ = id，或 φ = σ，其中 σ(x) = −1 − x。

推论 T1′：对任意两个奇数 a, b，T_a 与 T_b 之间的等距共轭恰好两条：Ψ_+ = Φ_b ∘ Q_a 与 Ψ_− = Φ_b ∘ σ ∘ Q_a；其中保奇偶的那一条（Ψ_+）唯一。特别地 T_a 的等距中心化子恰为 {id, Φ_a ∘ σ ∘ Q_a}，它是二阶群。

**定理 T2（整数不保持）。** 设 a, b 为奇数，并设存在 p ≥ 1 使 |Fix(T_a^p) ∩ ℤ| > |Fix(T_b^p) ∩ ℤ|，其中 Fix 表示不动点集。则**不存在任何双射** Ψ: Z_2 → Z_2 同时满足 Ψ ∘ T_a = T_b ∘ Ψ 与 Ψ(ℤ ∩ Z_2) ⊆ ℤ ∩ Z_2。

范围说明：T2 对 Ψ 不作任何正则性假设（连续、可测、等距一概不必）；反向的不等式不给出任何结论；a = b 时 Ψ = id 保持 ℤ，故定理只在 a ≠ b 时有内容。p ≤ 8、a, b ∈ {1, 3, 5, 7, 9, 11, 13} 的精确计数谱见 `results/round2_run1.txt` 第 74 到 85 行，被覆盖的有序对包括 a = 3 对 b ∈ {1, 5, 7, 9, 11, 13}（p = 1 或 2）、a = 1 对 b ∈ {5, 7, 9, 11, 13}（p = 1）、a = 5 对 b ∈ {1, 3, 7, 9, 11, 13}。

**命题 O1（搬运的同义反复性）。** 记 S_a := Φ_a(ℚ ∩ Z_2) = {T_a 的最终周期点}，设 Ψ = Φ_b ∘ Q_a 如 T1′。则 Ψ(S_a) = S_b，且 PC_a ⟺ Ψ(ℚ ∩ Z_2) ⊆ S_b。即：把「有理点都是最终周期点」这句话沿共轭搬运，其真值条件正是猜想本身，搬运不提供独立信息。

### 二、共轭的刚性（本轮新证）

**3. 块码刻画。** 状态：**已证（本文完整初等证明）**。
陈述：φ: Z_2 → Z_2 连续且 φ ∘ S = S ∘ φ，当且仅当存在局部常值函数 c: Z_2 → {0, 1}（即存在 k 使 c(x) = c(x mod 2^k)）使

  φ(x) = Σ_{i ≥ 0} c(S^i x)·2^i。

等价地：以 x_n 记 x 的第 n 个二进制位，则 φ(x) 的第 n 位等于 c(x_n, x_{n+1}, …, x_{n+k−1})。
证明：由 φ ∘ S = S ∘ φ 得 φ(x) = 2φ(Sx) + (φ(x) mod 2)；记 c(x) := φ(x) mod 2，迭代即得 φ(x) ≡ Σ_{i < n} c(S^i x)·2^i (mod 2^n)，令 n → ∞ 得公式（2 进收敛）。反向：对任意 c，按公式定义的 φ 直接代入即得 φ ∘ S = S ∘ φ；而 φ 连续 ⟺ c 连续 ⟺ c 局部常值（{0, 1} 取离散拓扑，Z_2 全不连通）。◻
核验：输出第 5、17 到 19 行（脚本 A2 对窗口 k ≤ 3 的全部块码与抽样 x 检查 S ∘ φ = φ ∘ S，不符 0 个）。

**4. 定理 T1 的证明。** 状态：**已证（本文完整初等证明）**。
设 φ 等距且 φ ∘ S = S ∘ φ。由步骤 3 的递推，c(x) = φ(x) mod 2 满足 φ(x) = 2φ(Sx) + c(x)。
等距性给出「x ≡ x′ (mod 2) ⟺ φ(x) ≡ φ(x′) (mod 2)」：正向由 v_2(φ(x) − φ(x′)) = v_2(x − x′) ≥ 1 给出；反向若 φ(x) ≡ φ(x′) (mod 2) 而 x ≢ x′ (mod 2)，则等距性给出 v_2(φ(x) − φ(x′)) = 0，矛盾。故 c(x) 只依赖 x mod 2，即 c(x) ≡ (x mod 2) + γ (mod 2)，γ = c(0)；单射性（等距的推论）排除 c(0) = c(1)。
于是对每个 n，利用 (x_i + γ) mod 2 = x_i + γ − 2γx_i（x_i 为第 i 位），得

  φ(x) ≡ Σ_{i < n} c(S^i x)·2^i ≡ (1 − 2γ)·(x mod 2^n) + γ(2^n − 1) (mod 2^n)。

γ = 0 时右式 ≡ x (mod 2^n) 对一切 n 成立，故 φ = id；γ = 1 时右式 ≡ −1 − x (mod 2^n)，故 φ = σ。◻
定量范围：结论的每一个量词都覆盖全部 x, x′ ∈ Z_2；不假设 φ(0) = 0（σ(0) = −1）；不额外假设满射（等距自动给出单射，id 与 σ 本身是满射）。
核验：输出第 5 到 16 行（脚本 A1：窗口 k = 1、2、3 的全部 4 + 16 + 256 个块码中，等距者恰为 2 + 2 + 2 个，且每一个都是 id 或 σ 的冗余窗口表示）。

**5. 推论 T1′ 的证明。** 状态：**已证**。

### 三、算术不透明性（本轮新证）

**8. 周期点的参数化与整数计数谱。** 状态：**已证（本文完整初等证明）**。
陈述：对每个奇数 a 与每个 p ≥ 1，

  Fix(T_a^p) = {c_v / (2^p − a^{m_v}) : v ∈ {0, 1}^p} = Φ_a( Fix(S^p) )，Fix(S^p) = {A/(1 − 2^p) : 0 ≤ A < 2^p}，

其中 m_v 是 v 中 1 的个数，c_v 由递推 c_0 = 0、c_{i+1} = a^{v_i} c_i + 2^i v_i 给出。特别地 |Fix(T_a^p)| = 2^p 且这 2^p 个数互不相同。
证明：一方面，若 x 的奇偶向量为 v，则沿 v 复合仿射映射得 T_a^p(x) = (a^{m_v} x + c_v)/2^p（递推即复合的展开），令其等于 x 得 x = c_v/(2^p − a^{m_v})（分母为奇数，故该分数属于 Z_2）。另一方面，Φ_a 把 S^p 的不动点集双射地映到 T_a^p 的不动点集（Φ_a ∘ S^p = T_a^p ∘ Φ_a），而 S^p(y) = y 等价于 y 的二进制数字序列以 p 为周期，即 y = A/(1 − 2^p)（0 ≤ A < 2^p）。对这样的 y，记 v 为 A 的二进制数字（恰好 p 位），则 Φ_a(y) 的奇偶向量恰是 v（因为 Q_a(Φ_a(y)) = y，而 Q_a 的 2 进展开就是奇偶序列），于是对 y 用第一条结论得 Φ_a(y) = c_v/(2^p − a^{m_v})。两个方向合起来给出上述等式（也说明候选式不会重复）。◻
**两点必须写清的细节**：（i）这里不能只用「代数代入」证明反向包含（候选点未必以 v 为其真实奇偶向量），必须经由共轭 Φ_a 走一遍，这一步是本轮的一个技术要点；（ii）**「Φ_a 保低 p 位」是错的**（第二版曾以此作为下述结论的理由，经反驳指出并已由 A9 第 (1) 组复核：Φ_3(1) = −1/3 ≡ 5 (mod 8) ≠ 1、Φ_5(1) = −1/5 ≡ 3 (mod 4) ≠ 1；Φ_a(y) ≡ y (mod 2^p) 只对 p = 1 与（a = 3、y = 1 时）p = 2 这类偶然情形成立）。正确的理由用**等距性**（步骤 1，第一轮脚本 C2 与本轮 A9 第 (2) 组核验）：Fix(S^p) = {A/(1 − 2^p)} 满足 A/(1 − 2^p) ≡ A (mod 2^p)，故它是模 2^p 的完整剩余系；而 Φ_a 是等距，等距蕴含「x ≡ x′ (mod 2^p) ⟺ Φ_a(x) ≡ Φ_a(x′) (mod 2^p)」，故 Φ_a 把完整剩余系映成完整剩余系，于是 Fix(T_a^p) = Φ_a(Fix(S^p)) 也是模 2^p 的完整剩余系（A9 第 (2) 组对 a = 3、5 与 p ≤ 5 逐点核到 |Fix(T_a^p) mod 2^p| = 2^p）。
核验：输出第 65 到 85 行。给出的表包括 |Fix(T_a^p) ∩ ℤ|（p = 1 到 8，a = 1、3、5、7、9、11、13）。**内部一致性检查**：a = 3 的行是 2, 4, 5, 4, 2, 7, 2, 4，与已知的整数圈完全吻合（不动点 {0, −1}、二圈 {1, 2}、三圈 {−5, −7, −10}；第 11 位的 −17 圈因周期 11 > 8 不出现），且 a = 5 的 1, 3, 1, 3, 6, 3, 15, 3 中出现二圈 {−1, −2}（p = 2 时贡献 2）与五圈 {1, 3, 8, 4, 2}（p = 5 时贡献 5）；这些都是独立于本计算的已知事实，故可作为参数化公式的旁证。

**9. 定理 T2 的证明。** 状态：**已证（本文完整初等证明）**。
设 Ψ 是双射且 Ψ ∘ T_a = T_b ∘ Ψ。对每个 p ≥ 1，Ψ 把 Fix(T_a^p) 双射地映到 Fix(T_b^p)（x 被 T_a^p 固定 ⟹ Ψ(x) 被 T_b^p 固定；反之由 Ψ^{−1}）。若又有 Ψ(ℤ ∩ Z_2) ⊆ ℤ ∩ Z_2，则 Ψ 把 Fix(T_a^p) ∩ ℤ 单射地映入 Fix(T_b^p) ∩ ℤ，故

  |Fix(T_a^p) ∩ ℤ| ≤ |Fix(T_b^p) ∩ ℤ| 对一切 p ≥ 1 成立。

这与假设中某个 p 的反向不等式矛盾。◻
**注意这一步不依赖任何正则性假设**，因此它排除的不只是等距共轭，而是**一切**双射共轭（包括不连续、不可测、不保测的）。范围：a ≠ b；覆盖的 (a, b) 对由步骤 8 的计数谱决定，本轮算到 p ≤ 8、a, b ≤ 13。
核验：输出第 65 到 85 行（计数谱本身的全部数值由精确公式给出）。

## 失败点清单（逐条说明为什么是缺口，以及跨过它需要什么）

**失败点 1（主要缺口）：主目标未证，而且它不是技术引理。**
由步骤 2 与 13，PC_3 等价于「3x + b 族无发散轨道」，其中 b = 1 那一档就是科拉茨猜想的无发散半边（frontier.md 门槛 2、barriers.md 第 22 条记录 Lagarias 2010 的判断：排除发散轨道须先证明迭代具有显式伪随机性质，属公开硬问题）。本轮的三条定理全部是**否定性**的：它们说明共轭给不出信息，而不是给出信息。跨过主缺口需要有外部工具（轨道伪随机性质或刚性不变量），本路线内部没有。

**失败点 2：「共轭不变论证不能证明猜想」未被形式化为定理。**
理由：步骤 12 第 2 条是严格的逐字传递论证（只要存在保测共轭，a = 3 与 a = 5 的一切共轭不变量相同；而 a = 5 的整数命题有有限反例 13 的 7 元环），但「任何只用共轭不变性质的论证都不能证明」这一句含有一个未定义的「论证类」。跨过它需要选定一个形式框架（模型论、可证性逻辑或「不变量类」的代数定义）并证明主目标不属于该类；这属于证明论层面，不改变猜想本身。

**失败点 3：非等距共轭的完整分类未做（窗口 ≥ 5）。**
理由：步骤 7 的两类证书对每个固定窗口 k 都是有限判定过程，本轮已跑到 k ≤ 4（含 k = 4 的全部 65536 个块码，独立复现了反驳者宣称的同一结果）。窗口 ≥ 5 仍未做。跨过它需要以下任一条：（一）把证书程序推到更大的 k（k = 5 有约 43 亿个块码，逐码枚举不可行，需要改用「不解码整张表」的判定，例如直接判定纹理：若 c 依赖高于第 0 位，则存在某个 p ≤ P(k) 使 F_p 非双射——这条猜想在 k ≤ 4 上被 A9 第 (3) 组的过滤实验否证，故需要别的原理）；（二）证明一般定理「连续且与 S 交换的双射必为等距」。**关于（二）的现状**：反驳者宣称有这样一条证明（其思路是限制在稠密集 ∪_p Fix(S^p) 上得到相容的层置换族，从而非扩张（Lipschitz 常数 1）），并称 k = 4 的穷尽是它的实例；我在本轮未能核实其证明（其答复没有给出该步的细节），也不能用自己的论证补出「相容的层置换族 ⟹ 保低 p 位」这一步——恰恰相反，A9 第 (3) 组显示周期层条件比双射弱得多（k = 2、3、4 分别有 2、4、18 个依赖高位的块码通过 p ≤ 8 的层过滤却仍非双射），故这一步需要真正的论证而非密度论证。若（二）成立，则 T1 直接给出全部窗口的分类，失败点 3 消失；在它被核实之前，本文仍把 k ≥ 5 列为缺口。

**失败点 4：T2 的覆盖依赖整数周期点计数谱，只算到 p ≤ 8、a ≤ 13。**
理由：定理的适用条件是「存在 p 使计数(a, p) > 计数(b, p)」；本轮以精确公式算出 p ≤ 8 的谱（步骤 8），因此 a, b ≤ 13 的大部分有序对被覆盖（输出第 85 行列出 25 对，另有反向的不等式不成立者如 11 与 13 之间的对未覆盖）。跨过它需要：整数周期点计数谱的一般规律（现在只有计算值；例如 a = 11、13 在 p ≤ 8 内的计数恒为 1，因而与任何同样恒为 1 的 a 之间无法用本方法区分），或换一个对共轭保持且在整数侧可算的不变量（例如「整数周期点的符号分布」或「整数周期点集合的势随 p 的增长阶」）。

**失败点 5：「archimedean 大小不是 2 进不变量」只有描述性表述。**
理由：步骤 12 第三条说明了机理（|·| 只在 ℚ 上定义、零测、不连续），但「无法承载」是对「表达」一词的直觉用法。跨过它需要给「2 进可表达的算术量」下定义并证明 |·| 不属于该类。

**失败点 6：本轮没有打开任何一手文献。**

### 附录：步骤 1 与 2 的自足化证明

**步骤 1。** 设 a 为奇数。

（一）T_a 定义良好：x 奇时 ax + 1 为偶，故 (ax + 1)/2 ∈ Z_2。连续性：两个分支分别在既开既闭的 2Z_2 与 1 + 2Z_2 上等于 x ↦ x/2 与 x ↦ (ax + 1)/2，都是连续的（且后者是等距复合平移）。
（二）满射且 2 对 1：T_a(2y) = y，T_a(2y + 1) = ay + (a + 1)/2（a 奇时 (a+1)/2 为整数），两分支的像都是整个 Z_2，而 {2y : y ∈ Z_2} 与 {2y + 1 : y ∈ Z_2} 是 Z_2 的划分。
（三）保测：对 Borel 集 A，T_a^{−1}(A) ∩ 2Z_2 = 2A（测度 μ(A)/2），而 2y + 1 ∈ T_a^{−1}(A) ⟺ y ∈ (A − (a+1)/2)/a，故 T_a^{−1}(A) ∩ (1 + 2Z_2) = 1 + 2·(A − (a+1)/2)/a（测度也是 μ(A)/2，因为 a 是 Z_2 中的单位，乘单位与平移都保 Haar 测度）。合起来 μ(T_a^{−1}(A)) = μ(A)。
（四）Φ_a 的构造与双射性：由 Φ_a(0) = 0 与两条递推 Φ_a(2y) = 2Φ_a(y)、Φ_a(2y + 1) = (2Φ_a(y) − 1)/a 逐层定义（Φ_a(y) mod 2^n 只依赖 y mod 2^n，且相邻层相容，因为两条分支都保同余）；反过来给定 0/1 序列，递推 x = 2T_a(x) 或 x = (2T_a(x) − 1)/a 唯一确定 x，故 Φ_a 是双射且 Q_a = Φ_a^{−1} 满足 Q_a(x) = Σ_{i ≥ 0}(T_a^i(x) mod 2)·2^i。
（五）共轭关系：y 偶时 T_a(Φ_a(y)) = T_a(2Φ_a(Sy)) = Φ_a(Sy)；y 奇时 2Φ_a(Sy) − 1 为奇，乘 a^{−1} 后 Φ_a(y) 为奇，故 T_a(Φ_a(y)) = (aΦ_a(y) + 1)/2 = Φ_a(Sy)。即 T_a ∘ Φ_a = Φ_a ∘ S。保奇偶：Φ_a(2y) 为偶，Φ_a(2y + 1) = (2Φ_a(y) − 1)/a 为奇（分子奇、a 是单位）。
（六）Φ_a 是等距：先由逐层递推得非扩张性（Lipschitz 常数 1）（x ≡ x′ (mod 2^n) ⟹ Φ_a(x) ≡ Φ_a(x′) (mod 2^n)，对 n 归纳）；于是 Φ_a 在 Z/2^n 上诱导良定义的映射 Φ_{a,n}。由 Φ_a 的满射性，Φ_{a,n} 满（任给残数 r，取 x 使 Φ_a(x) = r，则 Φ_{a,n}(x mod 2^n) = r）；有限集上的满射即双射。若 v_2(x − x′) = d < d′ = v_2(Φ_a(x) − Φ_a(x′))，取 n 使 d < n ≤ d′，则 x ≢ x′ (mod 2^n) 而 Φ_a(x) ≡ Φ_a(x′) (mod 2^n)，与 Φ_{a,n} 单射矛盾。故 d′ ≤ d；与非扩张性给出的 d′ ≥ d 合并得 d′ = d，即 Φ_a 是等距。
（七）Φ_a 保 Haar 测度：等距把以 x 为心、半径 2^{−n} 的球映为以 Φ_a(x) 为心、同半径的球（由 (六)），而 Haar 测度由球的测度 μ(B(x, 2^{−n})) = 2^{−n} 与球生成的 σ 代数决定，故保测。

**步骤 2。** 记 S_a := {x : Q_a(x) ∈ ℚ}。

（一）Q_a(x) 的 2 进展开就是 x 的奇偶序列（步骤 1 第 (四) 条）。
（二）有理 2 进整数的展开最终周期：若 z ∈ ℚ ∩ Z_2，取 e ≥ 1 使 2^e ≡ 1 (mod 分母)，则 z·(2^e − 1) ∈ ℤ ∩ Z_2 = ℤ，把 z 写成 2 进级数即得展开最终周期。反之最终周期的展开显然是有理的。
（三）于是 Q_a(x) ∈ ℚ ⟺ x 的奇偶序列最终周期。末者等价于存在 N ≥ 0、p ≥ 1 使 T_a^N(x) 与 T_a^{N+p}(x) 的奇偶序列相同（后者就是前者的第 N 位起的平移），而由 Q_a 的单射性，这等价于 T_a^{N+p}(x) = T_a^N(x)，即 x 最终周期。
（四）最终周期 ⟹ x ∈ ℚ：若 T_a^p(z) = z 且 z 的奇偶向量为 v（长度 p，含 m 个 1），则沿 v 复合仿射映射得 z = c_v/(2^p − a^m)（分母奇、非零），故 z ∈ ℚ；再由 T_a^{−1}(y) ⊆ {2y, (2y − 1)/a} 保持 ℚ ∩ Z_2，沿轨道反推 N 步即得 x ∈ ℚ。
（五）合起来：Φ_a(ℚ ∩ Z_2) = S_a ⊆ ℚ ∩ Z_2（这就是一般奇数 a 的 Bernstein 半）；反向包含 S_a ⊇ ℚ ∩ Z_2 正是周期猜想 PC_a。
