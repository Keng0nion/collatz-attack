## 我尝试证明的定理（精确陈述）

**记号。** 全篇用加速映射 T(n) = n/2（n 偶），T(n) = (3n+1)/2（n 奇）。对 n ≥ 1 与 j ≥ 1：

1. v_j(n) ∈ {0,1}^j：前 j 步的奇偶向量（第 i 位是 T^{i−1}(n) 的奇偶，i = 1 至 j）；
2. S_j(n)：v_j(n) 中 1 的个数；c_j(n) 由递推给出（追加 0 时 c 不变，追加 1 时 c ← 3c + 2^{j−1}），于是恒等式
   T^j(n) = (3^{S_j(n)}·n + c_j(n)) / 2^j； (1)
3. χ(n) = min{ j ≥ 1 : T^j(n) < n }（不存在时取 ∞）；τ(n) = min{ j ≥ 1 : 3^{S_j(n)} < 2^j }（不存在时取 ∞）；
4. D_j(n) = 2^j − 3^{S_j(n)}；对向量 v 记 D_v = 2^{|v|} − 3^{S(v)}，只在 D_v > 0 时定义 θ_v = c_v / D_v；
5. E_k = { r ∈ [1, 2^k) : χ(r) ≥ k+1 }；α_k = { r ∈ [1, 2^k) : τ(r) ≥ k+1 }；
6. 「猜想」指：每个 n ≥ 1 在标准映射下到达 1（在 T 的语言下即轨道最终进入二元环 {1,2}）。

## 论证（编号步骤，每步标注状态）

### 第 1 步（已证，完整初等证明）：χ = ∞ 与反例的等价

**命题 1.1.** 若 χ(n) = ∞，则 T^j(n) ≥ n 对一切 j ≥ 1，特别地 n 的轨道不含 1（n ≥ 2 时）。

*证明.* χ(n) = ∞ 按定义即「不存在 j 使 T^j(n) < n」，故 T^j(n) ≥ n ≥ 2 > 1 对一切 j ≥ 1 成立，1 不在轨道中。∎

**命题 1.2.** 若存在 n ≥ 2 使 χ(n) = ∞，则猜想不成立。

**命题 1.3.** 若猜想成立，则对一切 n ≥ 2 有 χ(n) < ∞。

*证明.* 设 n 到达 1，首次取到 1 的步数为 j ≥ 1，则 T^j(n) = 1 < n，故 χ(n) ≤ j。∎

**推论 1.4（等价）. 猜想 ⟺ 不存在 n ≥ 2 使 χ(n) = ∞。**

*证明.* 分别取命题 1.2 与 1.3 的逆否。∎

**两处口径必须写清（本轮新增的说明）。**

1. 「χ(n) = ∞」蕴含「n 的轨道不含 1」（命题 1.1），但反向不成立：非最小反例可以跌破自身而永不到达 1（例如猜想假、且 N 的轨道最终进入一个最小元大于 N 的环时，环上较大的元素都是这种情形：它们的轨道永不达到 1，但会在环内跌破自身）。最小性只保证不跌破 N 本身。另一方面，最小反例 N 必满足 χ(N) = ∞（若 χ(N) = j < ∞，则 T^j(N) < N 的轨道是 N 的轨道的一段、同样不含 1，与最小性矛盾）；反过来 χ(n) = ∞ 只说明 n 是某个反例，不必最小。第 1.4 条的等价只需要「χ = ∞ ⟹ 反例」这一个方向，不受影响。
2. 最小反例 N 的轨道元素 T^t(N) 都是反例（其轨道是 N 的轨道的一段），因而都 ≥ N；但**它们不必满足 χ = ∞**（例如猜想假且 N 的轨道最终进入一个最小元大于 N 的环，则环上较大的元素都满足 χ < ∞）。这一点决定了下面第 2、3 步只能用「χ(N) = ∞」这一个条件，不能用「轨道元素都满足 χ = ∞」。

### 第 2 步（已证，完整初等证明）：阈值判据与余量传递

**命题 2.1（阈值判据）.** 对一切 x ≥ 1、j ≥ 1：
T^j(x) ≥ x ⟺ 3^{S_j(x)} > 2^j，或（当 3^{S_j(x)} < 2^j 时）x ≤ θ_{v_j(x)}。
（3^{S_j} = 2^j 不可能：S_j ≥ 1 时 3^{S_j} 为奇数，S_j = 0 时 1 < 2^j。）

*证明.* 由 (1)：T^j(x) − x = ((3^{S_j} − 2^j)x + c_j)/2^j。若 3^{S_j} > 2^j，则 3^{S_j} − 2^j ≥ 1（整数），故右端 ≥ (x + c_j)/2^j > 0。若 3^{S_j} < 2^j，则等价于 c_j ≥ (2^j − 3^{S_j})x，即 x ≤ θ。∎

**命题 2.2（余量传递）.** 设 x 为奇数、χ(x) ≥ k+1。则对一切 j ≤ k：r := x mod 2^k 满足 T^j(r) ≥ r。特别地 x mod 2^k ∈ E_k。

*证明.* 固定 j ≤ k。r 与 x 的前 j 位奇偶向量相同，故同用 S_j、c_j、D_j。若 D_j < 0，则 T^j(r) − r = ((3^{S_j} − 2^j)r + c_j)/2^j ≥ (r + c_j)/2^j > 0（S_j ≥ 1 时 c_j ≥ 1；D_j < 0 迫使 S_j ≥ 1）。若 D_j > 0，则由命题 2.1 与 χ(x) ≥ k+1 ≥ j+1 得 x ≤ θ_{v_j}，而 r ≤ x，故 r ≤ θ_{v_j}，再由命题 2.1 得 T^j(r) ≥ r。∎

**范围与边界.** 命题对一切奇数 x ≥ 1、一切 k ≥ 1 成立，无附加条件。数值复核：本轮 D6 段在 x ≤ 2^12、k ≤ 12 上逐点检查「χ(x) ≥ k+1 ⟹ 对一切 j ≤ k 有 (x mod 2^j) ∈ E_j」，违反 0 个（E_j 用暴力定义算出）。

### 第 3 步（已证，本轮新增）：筛饱和引理，以及它宣判的 no-go

**命题 3.1（筛饱和）.** 设 x ≥ 3 为奇数。则
χ(x) = ∞ ⟺ 对一切 k ≥ 1：(x mod 2^k) ∈ E_k。

*证明.*
(⟹) 设 χ(x) = ∞。固定 k，记 r = x mod 2^k。对每个 j ≤ k 用命题 2.2 的同一计算即可（那里只用到 χ(x) ≥ k+1，而 χ(x) = ∞ 蕴含之）：T^j(r) ≥ r。故 χ(r) ≥ k+1，即 r ∈ E_k。
(⟸) 设一切 (x mod 2^k) ∈ E_k。取任意 j ≥ 1，再取 k > max(j, log_2 x)（即 2^k > x）。此时 x mod 2^k = x，故 x ∈ E_k，即 χ(x) ≥ k+1 > j，特别地 T^j(x) ≥ x。j 任意，故 χ(x) = ∞。∎

**推论 3.2（同余约束层面已饱和，no-go）.** 由命题 3.1，「对一切 k：N mod 2^k ∈ E_k」这条约束系统与「χ(N) = ∞」等价。因此：

1. **不可能存在「更强的同余约束」。** 精确地说：任何形如「N mod 2^k ∈ S_k（对一切 k，或对某个 k）」、且由「χ(N) = ∞」蕴含的约束，都已被本文的 E_k 约束蕴含（因为两者等价）。因此任何以奇偶向量、模 2^k 剩余类、阈值截断为工具的论证，能从「χ(N) = ∞」提取的全部同余信息就是这套约束本身；要产生矛盾必须使用这套约束之外的东西（正整数的大小与排序、2 进展开的有限性、环方程的算术、或轨道的无界性结构）。
2. **有限层永不矛盾。** 对每个 k，类 2^k − 1 (mod 2^k) 整类落在 E_k：直接计算给出 T^j(2^k − 1) = 3^j·2^{k−j} − 1（1 ≤ j ≤ k），于是起点 T^{j−1}(2^k − 1) = 3^{j−1}·2^{k−j+1} − 1（其中 2 的指数在 j ≤ k 时至少为 1）为奇数，即前 k 步全为奇数步，S_j = j，3^{S_j} > 2^j，于是该类每个元素的 χ 都 ≥ k+1。所以任何「取有限多层、逐类筛除」的论证形式都不可能产生矛盾；这也是本项目边界地图第三节第 5 条（无界下降深度屏障）的同一事实的另一种说法。
3. **量化形态**：见第 4 步。

**状态.** 已证（命题 3.1 是初等引理，证明完整）。**关于新颖性我不作主张**：命题 3.1 的 (⟹) 是若干已知事实（余量传递 + 阈值类常值性）的直接组合，我未检索到同款等价包装，但不能排除文献或社群中已有等价说法。数值复核：D6 段 0 违反；2^k − 1 ∈ E_k 由 `verify_lemmas.py` 的 C4 附段在 k ≤ 18 上复核通过（与本条的统一证明一致）。

### 第 5 步（已证，完整初等证明；本轮新增，文献定位见后）：轨道有界性与系数侧的二分

**定理 5.1（二分定理）.** 设 n ≥ 3 为奇数。记 y_1 = n, y_2, y_3, … 为轨道的奇数子序列（依次出现的奇数元素，不要求递增；y_{t+1} = (3y_t + 1)/2^{b_t}，b_t = v_2(3y_t + 1) ≥ 1；对奇数起点良定义），B_t = b_1 + … + b_t。则

(i) n 的轨道无界；
(ii) { j ≥ 1 : 3^{S_j(n)} > 2^j } 是无穷集；
(iii) n 的轨道不是最终周期的

三者等价。并且若轨道有界，则存在 j₀ 使一切 j ≥ j₀ 满足 3^{S_j(n)} < 2^j；此时轨道最终进入一个周期环（若轨道不到达 1，则是不含 1 的环，各项 ≥ 3）。

*证明.*

**预备恒等式（精确形式与亏损形式）.** 由 y_{t+1} = y_t(3 + 1/y_t)/2^{b_t} 迭代得
2^{B_t}·y_{t+1}·(y_1y_2…y_t) = y_1·(3y_1+1)(3y_2+1)…(3y_t+1)，
取对数并整理得**亏损恒等式**
t·ln3 − B_t·ln2 = ln(y_{t+1}/y_1) − Σ_{s≤t} ln(1 + 1/(3y_s))。
还有 S_{B_t} = t（前 B_t 步恰含 t 个奇数步，即 y_1, …, y_t）。
（两式本轮由 D1、D2 段在 n ≤ 2000、t ≤ 60 上精确复核：整数恒等式 0 违反，对数形式相对误差 1e−9 内 0 违反，S_{B_t} = t 0 违反。）

**(a) 有界 ⟹ 最终周期 ⟹ 最终低于临界.** 有界轨道在正整数上取值有限，由决定性映射的抽屉原理最终周期（存在 s < s' 使 T^s(n) = T^{s'}(n)），即进入某环（周期 p、含 m 个奇数步）。环上取一元 x：环方程 2^p x = 3^m x + c_p(x)。若 m = 0 则 T^p(x) = x/2^p = x 迫使 x = 0，不可能；故 m ≥ 1，从而 c_p(x) ≥ 1（该向量至少有一个 1 位）。于是 x(2^p − 3^m) = c_p(x) ≥ 1 > 0，特别地 **2^p > 3^m**（这里正性本质：x > 0）。设进入时刻为 j₀₀，则对一切 j ≥ j₀₀ 有 S_{j+p} = S_j + m，故 S_j ≤ S_{j₀₀} + p + m(j − j₀₀)/p，从而 limsup_j S_j/j ≤ m/p < log_3 2（最后一步：m log_2 3 < p 即 m/p < 1/log_2 3 = log_3 2）。取 j₁ 使一切 j ≥ j₁ 有 S_j/j < log_3 2，则 S_j log_2 3 < j，即 3^{S_j} < 2^j。

**(b) 无界 ⟹ (ii).** 设轨道无界。此时奇数子序列的项**两两互异**（若 y_s = y_{s'} 而 s < s'，由决定性该轨道自 s 起周期，即有界，矛盾），且都是正整数。由亏损恒等式：
若 ln(y_{t+1}/y_1) ≥ Σ_{s≤t} ln(1 + 1/(3y_s))，则 t·ln3 ≥ B_t·ln2，即 3^t ≥ 2^{B_t}，也就是**在第 B_t 层系数侧成立：3^{S_{B_t}} = 3^t ≥ 2^{B_t}**。
而 Σ_{s≤t} ln(1 + 1/(3y_s)) ≤ (1/3)Σ_{s≤t} 1/y_s ≤ (1/3)H_t ≤ (1/3)(1 + ln t)（第一个不等号用 ln(1+u) ≤ u；第二个不等号用「t 个互异正整数倒数之和 ≤ H_t」，即最小的 t 个正整数取到最大；第三个用 H_t ≤ 1 + ln t）。所以**只要 y_{t+1} ≥ y_1·e^{1/3}·t^{1/3}，第 B_t 层系数侧就成立**。
最后用计数论证证明「无限多次 y_{t+1} ≥ y_1 e^{1/3} t^{1/3}」：假设不然，即存在 t₁ 使一切 t ≥ t₁ 有 y_{t+1} < y_1e^{1/3}t^{1/3}。则 y_{t₁+1}, …, y_{t+1} 是 t − t₁ 个两两互异的正整数，且都 < y_1e^{1/3}t^{1/3}（因为 s ↦ y_1e^{1/3}s^{1/3} 递增且 s ≤ t）。故 t − t₁ ≤ y_1e^{1/3}t^{1/3}，即 (t − t₁)³ ≤ e·y_1³t。三次式增长快于一次式，这个不等式的解集有界：用 3 ≥ e 做保守化，D13(b) 段对整数判据 (t − t₁)³ ≤ 3y₁³t 给出最大解 t（例如 y₁ = 2^71、t₁ = 0 时为 1.987…×10^32，有限；y₁ = 3、t₁ = 0 时为 9），矛盾于 t 任意大。
于是这样的 t 有无穷多个，对应无穷多个层 B_t 满足 3^{S_{B_t}} ≥ 2^{B_t}；又 3^{S} 为奇数、2^{B} 为偶数（B_t ≥ t ≥ 1），等号不可能，故 3^{S_{B_t}} > 2^{B_t}，即 (ii)。（D13(a) 段对上述充分条件逐点整数核对：命中前提的 2945 个点中违反 0。）

**(c) (ii) ⟹ (i).** 即 (a) 的逆否：轨道有界则只有有限多层满足 3^{S_j} > 2^j（(a) 给出自 j₁ 起全部反号）。∎

**推论 5.2（liminf 形式；与文献关系见第六节）.** 设 n ≥ 3 为奇数且轨道无界。则对每个 δ > 0，只有有限多个 t 满足 B_t ≥ t(log_2 3 + δ)；等价地
liminf_{j→∞} S_j(n)/j ≥ log_3 2。

*证明.* 若 B_t ≥ t(log_2 3 + δ)，则亏损 t·ln3 − B_t·ln2 ≤ −δt·ln2，代入亏损恒等式得
ln y_{t+1} ≤ ln y_1 − δt·ln2 + (1/3)(1 + ln t) → −∞（t → ∞），
故对充分大的这类 t 有 y_{t+1} < 1，矛盾（y_{t+1} ≥ 1）。余下为索引换算：由 B_t < t(log_2 3 + δ) 对一切 t ≥ t₁ 得，对 j ∈ (B_{t−1}, B_t] 有 S_j = t（该区间内恰完成第 t 个奇数步，且 j ≤ B_t），故 S_j/j ≥ t/B_t > 1/(log_2 3 + δ) = log_3 2/(1 + δlog_3 2)；对每个足够大的 j 取相应的 t，再令 δ → 0，得 liminf_{j} S_j/j ≥ log_3 2。∎
