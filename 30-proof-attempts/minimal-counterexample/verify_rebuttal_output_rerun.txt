A. chi >= tau 是否恒成立（n <= 200000，a = 3）
   chi < tau 个数 = 0   （0 表示 chi >= tau 在范围内成立）
   chi > tau 个数 = 0   （0 表示本范围内 CST chi = tau 成立）
   一行证明（chi >= tau）：若 T^j(n) < n，由 T^j(n) = (3^{S_j}n + c_j)/2^j 且 c_j >= 0 得
   3^{S_j} n <= 3^{S_j} n + c_j < 2^j n，故 3^{S_j} < 2^j，即 tau(n) <= j。
