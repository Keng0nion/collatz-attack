## 我尝试证明的定理（精确陈述）

**主目标 (T1)**：存在一条只用以下初等工具的论证，对验证界 `X0 = 695·2^60`（或任何 `X0 ≤ 2^71`），证明「不存在满足如下条件的非平凡 m 圈：其 m 满足 `m ≤ M*`」且 `M* > 91`（即超过 Hercher 2023 已发表的 `m ≤ 91`），并且**不使用** Rhin 1987 的线性型对数下界：

1. Simons 与 de Weger v1.43 的 Lemma 7（链式增长不等式，纯初等）、Corollary 5、Lemma 9（连分数基本事实）、Lemma 10（一致 K 下界）；
2. Hercher 2023 的 Theorem 14、Theorem 16、Theorem 21、Lemma 22（区间内最小分母）与其 2026 年勘误的重推。

**结论**：**不成立，且失败点被定位到两步**。

1. **数值上（并且有两种口径，取决于 Theorem 21 尾部的地位）**：在几何尾部成立（Hercher 发表形态加 2026 勘误的替代推导）时，`X0 = 695·2^60` 与 `2^71` 至 `2^73`、`10^22` 处 `M* = 91`（与 Hercher 已发表值相同）；第一次超过 91 需要 `X0 ≈ 1.723×10^22`（本文二分求出，比 `2^71` 高 0.86 个数量级），此时 `M* = 92`。**若只承认第三方 Lean 项目采用的「健全」尾部（其他窗口极小值只用平凡界 `3/X0`），同一台机具的上限是 `M* = 82`**（我在 `dt2_soundtail.py` 中复现，停滞点 `K = 4.64028×10^18`，与他们的结果逐位一致）。所以「`M* > 91`」这句话现在必须带条件；不带条件时只有 `M* = 82` 是两种口径都承认的。
2. **逻辑上**：(T1) 作为定理不成立。终点一步「圈蕴含 `K < K_up`」要求分离界**对一切 K 一致有效**。Rhin 1987 是一致界（这正是它不可替代之处）；初等连分数分离界是**逐区间**的，把它当一致界用等价于额外假设「`log_2 3` 的部分商尾部不超过一个显式双重指数阈值」（见步骤 7 与局部结论 L2）。

**副目标 (T2)**（本路线被点名的方向）：改进 `3^m` 与 `2^k` 的分离界以推进 m 圈前沿。**结论：不可能**。我给出并核验了一条「天花板」引理：在本机具的结构内，分离界（无论初等还是超越论，无论多强）对终点门槛的全部贡献上界是 **7.3%**（`m = 91` 处，理想口径与实际口径之比 1.073），而 `m = 92` 的缺口是 **3.89 倍**；在另一处口径下所需的分离界提升是 `1.19×10^18` 倍，而 Dirichlet 定理对任何分离界的提升空间上限只有 100 倍（局部结论 L1）。

## 论证（编号步骤，每步标注状态）

记号：`δ = log_2 3 = 1.5849625...`（无理数；`δ` 的超越性由 Gelfond 与 Schneider 定理给出，这是标准事实、本轮未核验、也未用到）；`p_n/q_n` 为收敛项；`Λ = (K+L)ln 2 − K ln 3 > 0`，其中 `K`、`L` 分别是圈中奇数与偶数元素个数（SdW 记号），`m` 是局部极小值个数；`ψ(K) = min{ ‖jδ‖ : 1 ≤ j ≤ K }`；`Φ_m(K) = m c_m 2^{−(δ−1)K/(δ^m −1)}`，`c_m = (1+X0^{−1})^{m(δ−1)/(δ^m−1)} b^{E_m(δ−1)/(δ^m−1)}`，`E_m = Σ_{i=1}^{m−1}(m−i)δ^i`，`b = (1+X0^{−1})^{1/δ}/2^{1/δ}`；`gap⁺(q) = (⌈qδ⌉ − qδ)/q`。

### 步骤 2：区间最小值的精确值（分离引理的可用形态）【已证（引 SdW Lemma 9(c)）+ 已核验（穷举）】

引理：设 `q_N ≤ K < q_{N+1}`（`q_N` 为不超过 `K` 的最大收敛项分母），则 `ψ(K) = |q_N δ − p_N|`。

证明：由 Lemma 9(c)，对一切 `q ≤ q_N` 有 `‖qδ‖ ≥ |q_Nδ − p_N|`，故 `min_{j ≤ q_N}‖jδ‖ = |q_Nδ − p_N|`；而 `[q_N, q_{N+1})` 内的最小值取在「第二类最佳逼近」处，它们是收敛项或中间分数 `q_N + t q_{N−1}`。

核验（`dt2_struct.py`，用 300 位有理截断做精确整数取模，误差 `<10^{−250}`）：
1. `min_{1≤j≤q_N}‖jδ‖ = |q_Nδ − p_N|`，`N = 2` 至 `17` 全部穷举通过，违反 0 档；
2. 区间版本 `min_{q_N ≤ j < q_{N+1}}‖jδ‖ = |q_Nδ − p_N|`，`N = 2` 至 `14`（区间长不超过 `10^7`）全部穷举通过，最小值点都是 `j = q_N`；
3. 中间分数候选 |`(q_N + t q_{N−1})δ − (p_N + t p_{N−1})`| 对 `t = 1, …, a_{N+1}−1`、`N = 2` 至 `44` 全部不小于 `|q_Nδ − p_N|`（最小比值恰为 1.000000）。

即：旧版 attempt.md 的「结论 A」在其使用范围内（把 `ψ(K)` 取成 `|q_Nδ − p_N|`）**是对的**，本轮把它从「引定理」升级为「引定理加穷举核验」。

#### 步骤 4b：Theorem 21 的尾部条款（第二轮反驳的焦点，本文主结论的直接依赖）

Theorem 21 的结论里有两处「尾部」项：`3/(2^v−1)` 与 `3(m2−1)/(2^v−1)^δ`（后者在原始印刷版写作 `3(m2−1)/(2^v−1)^δ`）。原始证明用「`n_{i+1} < n_i^δ` 链 + `T` 递减」直接得出它，**2026 年勘误明确承认这一步「contains an error」**，改为：把 `x_i = log_2(n_i+1)`、`S(x) = Σ 3/(2^{x_i}−1)`（由 `T(n_i) < 3/n_i`）视为 `m2` 元函数的极大问题；`S` 逐坐标凸且递减，可行多面体（`x_i ≥ 1`、`x_{i+1} ≤ δx_i`、`x_1 ≤ δx_{m2}`、`Σx_i ≥ W`，`W = (m2/m)K`）上的最大值在顶点，且顶点分析给出 `S ≤ 3/(2^v−1) + 3(m2−1)/(2^{δv}−1)`，`v = W(δ−1)/(δ^{m2}−1)`。

**我对勘误这条替代推导做了两项可复核的核查（`dt2_corr.py`，注意这是数值支持，不是证明）**：

2. 「极大在顶点」：对 `m2 = 3, 4, 5, 6` 枚举全部约束子集（`m2` 个活跃约束）解出可行顶点（分别 3、4、5、6 个），最大 `S` 恰在活跃集 `{G_1, …, G_{m2−1}, W}`（即全增长约束加和约束，坐标是几何序列）处取到，其值与勘误给出的界**在所有显示位上相同**（比值 1.0）；另外「某个 `x_i = 1` 时 `Σx` 不超过 `(δ^{m2}−1)/(δ−1)`（`m2 = 8` 时 66.4，`m2 = 60` 时 1.7×10^{12}）远小于 `W`（约 10^{19} 至 10^{20}）」也复核通过。

1. **改善起点买不到前沿**：`X0 = 695·2^60`（2^69.4）与 `2^71` 至 `2^73`、`10^22` 都给 `M* = 91`（**在几何尾部口径下；健全尾部口径见步骤 4b，那里是 82**），与 Hercher 已发表值相同；第一次超过 91 的门槛由二分求出为 `X0 = 1.7234×10^22`（`dt2_check2.py` 第 (B) 节，对 `X0` 二分 60 步），即比 `2^71` 高 0.86 个数量级；`2^74 = 1.889×10^22` 是该门槛之上一档。即 Hercher 用弱起点不是浪费，`91` 就是这台机具在这些 `X0` 下的边界。
2. **停滞机制**：链每步把 `K` 跳到「上方逼近记录」的某一个分母，只有当 `eps < gap⁺(当前 K)` 时才能前进。`eps ≈ (97(M−m2)+73)/(54 X0·3K log2)` 随 `K` 只按 `1/K` 衰减，而记录上 `gap⁺(K) ≈ 1/(1.585K²)`（记录乘积 `q·gap⁺(q)` 单调不增且 ≈ `1/(1.585q)`，`dt2_struct.py` 第 (Q3) 节 320 条记录全过；实测 `gap⁺(q_41) = 6.32183×10^−41` 而 `1/(1.585q_41) = 8.1×10^−21`，故**必须写成 `1/(1.585K²)`**），于是前进条件给出停点 `K < 约 70.9 X0/(97(M−m2)+73)`。`M = 92` 时最紧的一步是 `K = 7.7692117e19`（即 `q_41`）、`m2 = 88`：`eps = 6.5948×10^−41`，而前进只需 `eps < gap⁺(K) = 6.32183×10^−41`，两者之比 1.043（差 4.3%）；这已是「所有可行 `m2` 中 eps 最小者」（我逐个试过），所以这一档是硬停。**但要说明这是「第一道墙」的局部数字**：`X0 = 2^74` 处 `M = 92` 走通后，链在 `M = 93` 又停住（`K = q_43 = 2.05632×10^20`，该步最优 `m2 = 90`，`eps = 8.345×10^−43` 对 `gap⁺(q_43) = 6.2447×10^−43`，比值 1.336）；诚实口径是 `K` 层面的 3.89 至 4.33 倍（`m = 92`），而不是「只差 4.3%」。
3. **前沿增长律**：用 `10^23 → 101`、`2^100 → 136`、`10^40 → 186` 三点得 `M*(X0) ≈ 5.0·log_10 X0 − 14`（逐段斜率 4.93 与 5.05；离散台阶使 `M*` 在局部有 ±5 的波动，例如 `2^85` 与 `2^90` 之间只前进 2）。这与旧版 attempt.md「结论 D」的量级一致，本轮由独立实现再确认。

### 步骤 7：终点上界的一致性问题【缺口】（本路线的主要失败点）

**逐区间论证只给出**：对每个 `N`，若 `ln2·|q_Nδ − p_N| ≥ Φ_m(q_N)`，则参数为 `m`、且 `K ∈ [q_N, q_{N+1})` 的圈不存在。这是一个**有限**命题，可逐一验证。

**但要得到「圈蕴含 `K < K_up`」需要**：对一切 `N ≥ N_0`（`q_{N_0} > K_up`）C_N 都成立，这是一个**无穷合取**。C_N 的真假完全由部分商 `a_{N+1}` 决定：`C_N` 失败当且仅当 `a_{N+1} > ln 2/(q_N Φ_m(q_N))`，即部分商超过一个随 `q_N` **双重指数增长**的显式阈值。任何显式的部分商上界（例如「`a_n ≤ A` 对一切 `n`」或「`a_n ≤ n^C`」）都能把它变成有限验证，但**据我所查，`log_2 3`（乃至 `log 2`）的部分商上界没有任何已知定理**；我也没有找到文献给出其无界性（无界性同样是猜想）。因此：

> 初等版「`K < K_up`」是一个**条件定理**：条件为 `log_2 3` 的部分商尾部不出现「冠军」（超过上述双重指数阈值的部分商）。

对照：SdW 的 `K_2`（Lemma 16）**恰恰是用 Rhin 来封住指标范围**（`K < K_1(m) < q_{n(m)−1}` ⇒ `n ≤ n(m) − 2` ⇒ `a_{n+1} ≤ A(m)`，而 `A(m)` 是对已算出的 `a_200001` 为止的有限检查），从而把无穷合取变成有限合取。**这就是 Rhin 在同一条链里不可替代的原因：它提供的不是精度，而是一致性。** 旧版 attempt.md 与 rebuttal-2 都把这台机具当作「可以整体初等化」，本节指出该判断缺一步。

### 步骤 8：天花板的量化【已证（我自己的引理）+ 已核验（数值表）】

见局部结论 L1。要点：本机具（Lemma 7 的 `Φ_m` + 任何分离界 + 自举的 `K_low`）的排除条件可以写成「`K_low(m) > K_surv(m)`」，其中

## 失败点清单（逐条说明为什么是缺口，以及跨过它需要什么）

1. **[缺口]（主缺口）终点上界的一致性。** 初等连分数分离界是逐区间的，`C_N` 的成立与否取决于部分商 `a_{N+1}` 是否低于阈值 `ln 2/(q_N Φ_m(q_N))`；要对一切 `K > K_up` 断言排除，必须知道这个阈值在 `N → ∞` 时永远不被突破。跨过它需要以下三者之一：(a) `log_2 3` 部分商的显式上界（例如 `a_n ≤ A` 对一切 `n`，或任何低于上述双重指数阈值的显式界）——我查不到任何文献结果，故标为未知；(b) 一个显式无理测度 `|δ − p/q| > C/q^μ`（可由其推出部分商上界），这属于超越论工具（不是初等），且我复算过它在本问题尺度上的要求（`dt2_l2.out` 第 (2) 节）：以 `μ = 3.6` 为例，要在最紧点 `K = K_low(92) = 7.769×10^{19}` 处压过 `Φ_92(K) = 1.058×10^{−4}`，需要常数 `C ≥ 5.5×10^{47}`；`μ = 3.0` 也要 `C ≥ 6.4×10^{35}`。已知的那类无理测度结果给不出这种量级的常数，所以 (b) 形式上是「非初等」，实际也不足以救场；(c) 换一个不依赖 `K` 上界的终点机制（例如把自举末步的「发散」做成对所有 `m` 可用）。

## 局部新结论（含独立验证方式）

**L1（天花板引理；本路线的核心负结果）** 设 `Φ_m` 为任意关于 `K` 严格递减的上界函数（这里用 SdW Lemma 7 的 `Φ_m`），`K_low(m)` 为任何机制给出的圈上 `K` 的下界。若本机具（即：用 `Λ ≥ 分离界` 与 `Λ < Φ_m(K)` 两条不等式取矛盾）排除了参数 `m`，则必有 `K_low(m) > K_surv(m) := max{K : ln2·|q_{N(K)}δ − p_{N(K)}| < Φ_m(K)}`。
证明要点：对固定的 `K`，两条不等式矛盾当且仅当 `ln2·ψ(K) ≥ Φ_m(K)`（因为最强的合法下界就是真值 `ln2·ψ(K)`，任何分离界都不超过它），而由步骤 2 的引理 `ψ(K) = |q_Nδ − p_N|`；于是 `K` 能否被排除与分离界的强弱无关。
**独立验证**：`dt2_up.py`（计算 `K_surv`）与 `dt2_ladder.py`、`dt2_frontier.py`（计算 `K_low`）；关键数字：`m = 92` 时 `K_surv = 3.36568×10^20`、`K_low = 7.76921×10^19`（差 4.33 倍），而理想分离界只把 `K_surv` 降到 `3.16648×10^20`（比值 1.063）。

**L2（一致性引理，显式阈值）** 在步骤 7 的口径下，初等版「圈蕴含 `K < K_up`」等价于：对一切使 `q_N > K_up` 的 `N`，有 `a_{N+1} ≤ ln 2/(q_N Φ_m(q_N))`。该阈值随 `q_N` 双重指数增长：例如 `m = 92`、`q_N = 10^{30}` 时 `Φ_92(10^{30}) ≈ 10^{−69821725690}`，阈值为 `ln2/(q_N Φ_m(q_N)) ≈ 10^{6.98×10^{10}}`（即要求 `a_{N+1}` 不超过约 `10^{69821725659}`），远超任何已算出的部分商（SdW 只算到 `a_200001`）。
**独立验证**：阈值公式与数值见 `dt2_l2.py` 与其输出 `dt2_l2.out` 第 (1) 节；`dt2_struct.py` 第 (Q3) 节核验了「记录乘积 `q·gap⁺(q)` 沿上方逼近记录单调不增」（320 条记录全过），这正是 `C_N` 的真假由 `a_{N+1}` 单独决定的机制；`dt2_ladder.py` 的 `q_min` 函数按同一结构给出 Lemma 22 的分母。

**L3（初等包络与 Rhin 包络同量级）** 在 `m = 89` 至 `95`、`X0 = 695·2^60` 上，`K_surv(m)/(1.4784 m δ^m) ∈ [0.95, 0.999]`（表见步骤 8）。即：把 Rhin 换成初等分离界，在同一 `m` 上门槛只降不到 5%；「去超越论」在精度上不亏，但在一致性上不可用（步骤 7）。
