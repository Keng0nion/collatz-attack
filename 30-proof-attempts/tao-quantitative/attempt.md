## 我尝试证明的定理（精确陈述）

**主目标 T1（未证成）.** 存在绝对常数 C_0 ≥ 1，使集合
A_{C_0} := { N ∈ ℕ : Col_min(N) > C_0 }（Col_min(N) 为 N 的 Collatz 轨道最小元）
的上对数密度为零；即 Col_min(N) ≤ C_0 对一组下对数密度为 1 的 N 成立。这里上对数密度定义为 Λ(A) := limsup_{x→∞} ( Σ_{N ≤ x, N ∈ A} 1/N ) / log x。

**次目标 T2（未证成；比 T1 强）.** Λ(A_1) = 0，其中 A_1 := { N : 轨道永不取到 1 }。

强弱方向（本路线上一轮曾被审读指出写反，此处为更正后的口径）：A_{C_0} ⊆ A_1 对一切 C_0 ≥ 1 恒成立（避开 [1, C_0] 蕴含避开 1），故 T2 ⟹ T1。一般地严格强（玩具映射 U(N) = N/2（偶）、N + 3（奇）满足 T1（取 C_0 = 3）而 T2 假，上一轮以自写脚本在 N ≤ 200000 上核对：A_3 = ∅、|A_1 ∩ [1,200000]| = 66666 = |3ℤ|）。在 3x+1 上，结合「所有 n < 2^71 到达 1」这一有限计算记录（据 `10-literature/frontier.md:28`，Barina 2025，同行评审论文；本轮未重做该计算），二者反而等价：不存在最小元落在 [2, 2^71) 的轨道，故 A_{C_0} = A_1 对一切 C_0 < 2^71 成立。

**参照（不是我的目标）.** 猜想本身是 A_1 = ∅，即 T1 与 T2 的非量化加强。Tao 定理（Theorem 1.3，本次核对原文）给的是：对任意 f(N) → ∞，Λ({N : Col_min(N) > f(N)}) = 0；定量形式见第 7 步。

**本次尝试的更强估计 T3（未达目标；只得到条件性弱化）.** 设 F(k) := 自然密度{ n : χ(n) ≥ k }（χ 为 Terras 停时；等价地 F(k) = A(k−1)/2^{k−1}，见第 1 步）。本轮尝试的目标是给出显式常数的
F(k) ≤ C·(k−1)^{−1/2}·exp( −(k−1)·D )，D = ln 2 − H(log_3 2) = 0.034688185232…（nat）。
结果：把问题归约到「边界因子」Q(E_m) ≤ C m^{−1/2} 这一步是已证的（第 11 步的恒等式，加「倾斜因子 ≤ 1」这一项，即 F ≤ exp(−mD)·Q(E_m)；两侧界见局部结论 B 与 D1），边界因子本身是经典 ladder 理论的结论、本轮只在数值上复核到 5 位有效数字（第 16 步、局部结论 G1），**没有重做证明**；而「初等路线」这一侧，我证明了一个条件性弱化（第 14 步：假设丢番图输入 η(d) ≥ c/d 则 Q(E_m) ≤ 1/m + 0.695 c^{−1/2} m^{−1/4}），并给出了初等路线不可能更好（至 m^{−1/4}）的理由（第 15 步）。

**新增的数值猜想 T4（数值，非定理）.** 数据支持
F(k) ≈ 10.8 · exp( −(k−1)D ) · (k−1)^{−3/2}
（m = k−1 ∈ [1000, 30000] 内常数波动 ±4%；见第 17 步与局部结论 G1）。它比 T3 的 m^{−1/2} 多一个 m^{−1}，多出来的 m^{−1} 恰是倾斜因子 E_tilt[e^{−cZ_m} | 可容许]，这一点由第 11 步的恒等式精确刻画。

**固定记号.** 加速映射 T(n) = n/2（n 偶）、T(n) = (3n+1)/2（n 奇）；S_k(n) 为 n, T(n), …, T^{k−1}(n) 中奇数个数；λ_k(n) = 3^{S_k(n)}/2^k；系数停时 τ(n) = min{k ≥ 1 : λ_k(n) < 1}；Terras 停时 χ(n) = min{k ≥ 1 : T^k(n) < n}；可容许串、A(m)、F(k)、p、q、D、c、Q(E_m)、Z_m 的定义见第 1、11、12 步。

## 论证（编号步骤，每步标注状态）

状态标签只用四种：【已证】（给出证明或来源）、【缺口】（未证）、【错误】（已知为假）、【等价于原命题】（循环论证，不得使用）。

### 第一阶段：Tao 论证的引理级拆解与逐条定量要求

**第 1 步（字典与一次下降的密度）.【已证（初等）】**
对 m ≥ 1，映射「n 的模 2^m 剩余类」到「n 的前 m 个奇偶符号」是双射，λ_k 只依赖前 k 个符号。于是
(1.1) F(k) = A(k−1)/2^{k−1}，其中 A(m) := #{ ε ∈ {0,1}^m : 对一切 1 ≤ i ≤ m 有 3^{S_i(ε)} ≥ 2^i }，
S_i(ε) 为前 i 位中 1 的个数。证明：长度 m 的每个符号模式恰好对应模 2^m 的一个剩余类；而 λ_i(n) ≥ 1 只依赖前 i 个符号；在长度为 2^m 的整数倍的区间上精确计数即得。全量词：k ≥ 2（m ≥ 1）；边界情形 k = 1 时 F(1) = 1（空串可容许），n = 1 要单独处理（τ(1) = 2 而 χ(1) = ∞，作为密度不影响，计数时会差 1，本路线的程序里显式处理）。
旁注：把 F(k) 与 *实际* 停时 χ 的密度联系起来的定理是 Terras 1976（δ[χ ≥ k] = P[τ ≥ k]）；**我本轮没有打开 Terras 原文**，只在 n ≤ 2^20 上数值确认 τ 与 χ 一致（check_B，0 个不一致），以及 F(135) = 5.331277×10^{−5} 与 Terras 原表印出的 5.3312×10^{−5} 逐位相符（该印刷值由笔记转述，见 `20-experiments/findings/parity-vectors.md:144` 与 `stoptime-stats.md`；我未打开 Terras 原文核对印刷值本身）。
定量要求：这一步给出的是精确的有限层密度，误差为零；后面所有步骤的误差都必须在这种精度上相加。

**第 2 步（局部时间的 2 进等分布）.【已证（论文，本人核对原文）】**
Tao 的 Proposition 1.9（arXiv:1909.03562v7 §1.3，Section 4 证明）：设 N 取值于 2ℕ+1，若存在 c_0 > 0 与 n′ ≥ (2+c_0)n 使 d_TV(N mod 2^{n′}, Unif((2ℤ+1)/2^{n′}ℤ)) ≪ 2^{−n′}，则 d_TV(赋值向量 ⃗a^{(n)}(N), Geom(2)^n) ≪ 2^{−c_1 n}，c_1 > 0 为绝对常数。原文照录（1.12）式同此。
定量要求：需要在 n 高达 c log N 的时间尺度上控制赋值向量；误差是指数小的 2^{−c_1 n}。

**第 3 步（乘性误差：为什么必须用对数密度）.【已证（论文）】**
论文 §1.1 原文：「We remark that the multiplicative inaccuracy of exp(O(n^{1/2})) in (1.17) is the main reason why we work with logarithmic density instead of natural density in this paper」。即典型轨道的乘性误差形如 exp(O(√n))。
定量要求：任何把结论升级为自然密度的尝试都必须把 exp(O(√n)) 压到自然密度可容忍的量级，或换掉采样机制。这一条与 Tao 侧的另一处原文互相印证：§1.1 写明「the uniform (or logarithmic) measure does not enjoy any invariance properties with respect to the Collatz map」，并举了「Col_min(N) < x^θ 对 [1,x] 几乎所有 N、且 Col_min(N′) ≤ x^{θ²} 对 [1,x^{θ²}] 几乎所有 N′，两句话不能拼接」的例子（我本次核对了这一整段）。

**第 4 步（首达位置的稳定：全文最难的定量输入）.【已证（论文）】**
Proposition 1.11（照录要点）：取 α := 1.001，N_y 服从对数均匀分布 Log(2ℕ+1 ∩ [y, y^α])，则对充分大 x 有
(1.19) P(T_x(N_y) = +∞) ≪ x^{−c}（y = x^α, x^{α²}）；
(1.20) d_TV( Pass_x(N_{x^α}) , Pass_x(N_{x^{α²}}) ) ≪ log^{−c} x。
论文原文并注明：「The estimate (1.19) is easy to establish; it is (1.20) that is the most important and difficult conclusion of Proposition 1.11」，且「any bound of the form O((log log x)^{−1−c}) would have sufficed」，且「it may be possible to improve the bound in (1.20) further, perhaps all the way to x^{−c}」。
定量要求：这是把几乎处处性质跨尺度搬运的唯一来源；它把「第一次落到 x 以下的位置」这个随机变量在相邻两个尺度上稳定住。

**第 5 步（机制：3 进细尺度混合）.【已证（论文）】**
Proposition 1.14：Osc_{m,n}(P(Syrac(ℤ/3^nℤ) = Y mod 3^n))_Y ≪_A m^{−A}（任意固定 A > 0）；Proposition 1.17 与其等价（特征函数衰减 ≪_A n^{−A}）；Section 7 的组合机器：Lemma 7.4（黑集是两两分离的三角形之并）、Lemma 7.6（更新过程单步增量有指数尾、均值在 (4,16)）、Lemma 7.7（首达位置分布近似均匀）、Proposition 7.8（单调性）、Lemma 7.9（穿过足够多三角形时通常访问足够多白点）、Lemma 7.10（大三角形在长穿越后很少被立刻遇到）。这些引理名与内容我本轮从论文正文与目录中核对到（未逐条重证）。
定量要求：全部为 ≪_A 型（对任意固定 A）与「足够多」型常数；显式化需要把 Lemma 7.4 至 7.10 的分离常数、Props 1.17 与 1.14 的全部 ≪_A 常数、以及 Theorem 3.1 的「充分大」全部有效化（据笔记 `10-literature/notes/tao-almost-all.md:83` 的缺口 3 也记同一件事）。

**第 6 步（压缩迭代及其输出形状）.【已证（论文）】**
论文 §3 用命题 1.11 作压缩迭代：取 J = J(x, N_0) 为使 y := x^{α^{−J}} < N_0^{1/α} 的首个自然数，沿 j = 1, …, J 迭代，每步误差 O((α^j log y)^{−c})，几何级数求和得 P(B_{x^{1/α}}) ≥ 1 − O(log^{−c} N_0)，覆盖区间后即 Theorem 3.1（照录）：
(6.2) 对 N_0 ≥ 2 与 x ≥ 2，(1/log x)·Σ_{N ∈ 2ℕ+1 ∩ [1,x], Syr_min(N) > N_0} 1/N ≪ 1/log^c N_0，隐含常数绝对。
论文并注明 Remark 1.4：C_δ ≪ exp(δ^{−O(1)})（我本次核对了这两个式子）。

**第 7 步（按固定阈值读：每级一个正上界）.【已证（论文原句的直接读法）】**
(6.2) 对每个固定 N_0 = C 给出
(7.1) Λ(A_C) ≤ K·(log C)^{−c}，K、c 为绝对常数，右端与 x 无关，是一个正数。
关键点：让这个界消失的唯一途径是让 C → ∞；对每个固定 C 它都不消失。论文 §3 证明开头的原文照录：「We may assume that N_0 is larger than any given absolute constant, since the claim is trivial for bounded N_0.」（我本次核对了这句）。范围限定：这是本框架逐层估计的形状，不是「任何证明都如此」的主张。

**第 8 步（层分解与并集障碍）.【已证（初等）】**
记 B_m := { N : min O(N) = m }，O(N) 为 N 的前向轨道。则
(i) A_1 = ⊔_{m ≥ 2} B_m（不交并），且 B_m ⊆ A_{m−1}；
(ii) 对每个 X，对数权重 Σ_{N ∈ A_1, N ≤ X} 1/N = Σ_{2 ≤ m ≤ X} Σ_{N ∈ B_m, N ≤ X} 1/N（有限和）；
(iii) 对每个固定 C_0：Λ(A_1) ≤ Λ(A_{C_0}) + Σ_{m=2}^{C_0} Λ(B_m) ≤ ε(C_0) + Σ_{C=1}^{C_0−1} ε(C)，其中 ε(C) 是任何形如「Λ(A_C) ≤ ε(C)」的逐层界。
推论：**就 A 族这一种信息形式而言**，即使把每级界改进到可和（远强于现有记录的形状），这条路径给出的也只是 Λ(A_1) ≤ Σ_C ε(C)，即一个常数，而不是 0；按记录的 ε(C) = K(log C)^{−c} 级数发散，这条路径什么也不给。**限定（本会话按反驳意见补上，见第 (v) 项）：这条推论只排除「A 族逐层界」这一种信息形式，不排除别的逐层形式。**
(iv) 抽象上还可造出「A 族每级界很小、并集却满对数密度」的配置：取归一化常数 c = 1/(ζ(2)−1)，令 B_m 的对数密度为 c·m^{−2}，则 Σ_{m≥2} c m^{−2} = 1 而 Σ_{m > C} c m^{−2} ≈ c/C，于是每层 Λ(A_C) 任意小，而 Λ(A_1) = 1。这说明「形如 Λ(A_C) ≤ ε(C) 的信息」不足以控制并集。**注意它并不说明「逐层信息」整体不够**：在该配置里每个 B_m 的对数密度 δ_m = c m^{−2} > 0，即 B 族逐层信息在该配置中明确失效；反过来，见第 (v) 项，B 族逐层信息足够。
(v) **B 族逐层信息与 T2 等价（本会话按反驳意见补入；推导由反驳方给出，我在本会话独立复核了每一步）。** 记 B_m = {N : min O(N) = m}（m ≥ 2）。对每个 M ≥ 2 有
    A_1 = （⊔_{2 ≤ m ≤ M} B_m）⊔ A_M，因为 A_M = {min > M} = ⊔_{m > M} B_m，
于是由 Λ 的次可加性（对数权重为正可加）
    Λ(A_1) ≤ Σ_{m=2}^{M} Λ(B_m) + Λ(A_M)。
若对每个**固定** m ≥ 2 有 Λ(B_m) = 0（纯逐层陈述，不需要任何对 m 一致的估计），则右端第一项是**有限个零之和 = 0**；再用 Tao 的逐层界 Λ(A_M) ≤ K(log M)^{−c}（第 7 步）并令 M → ∞，得 Λ(A_1) ≤ limsup_{M→∞} K(log M)^{−c} = 0，即 T2。反之 T2 ⟹ Λ(B_m) = 0（因为 B_m ⊆ A_1）。所以**给定 Tao 的 Theorem 3.1，T2 等价于「对每个固定 m ≥ 2，Λ(B_m) = 0」**。这条改写的意义：(甲) 它撤回了「T2 需要跨层估计」这一必要性断言（旧的失败点 2 与下一步第 4 条，见下）；(乙) 它给出一个形式更具体的等价目标，在单个固定的 m 上不要求对 m 一致；(丙) 由它得一个矫正后的边界陈述：**凡「B 族逐层信息不足」的映射，必然违反 Tao 型的逐层结论（即 Λ(A_M) ↛ 0）**，因为上述推导只用到 Λ(B_m) = 0 与 Λ(A_M) → 0 两条。
    验证（本会话实际运行）：`check_J_toy.py 20000`（我自写，输出 `checks/out_J_toy.txt`）在反驳方给出的玩具映射 f(N) = 1（N 奇）、N/2（N ≡ 0 mod 4）、2（N ≡ 2 mod 4）上核对：C ≥ 2 的各层计数为 0（C = 1 时 10000 = X/2）；对数权重 logweight({S_min > 1})/log X = 0.4941、logweight({S_min > 2})/log X = 0；恒等式（第 (ii) 项）在 x = 20000、10000、2857 上用 Fraction 精确算术逐位成立（三处均相等）。

**第 9 步（陷阱不可见性与方向更正）.【已证（初等）】**
设猜想失败、某 N_0 的轨道不达 1。则 A_1 ⊇ O(N_0) ∪ { 2^k y : y ∈ O(N_0), k ≥ 0 }，于是对一切 X ≥ N_0 有 logweight(A_1 ∩ [1,X]) ≥ 1/N_0，即一个与 X 无关的常数；而本框架的一切估计都是 o(log X) 或「常数乘以 log X」的形状，因此全部与「猜想失败」相容。
方向更正（本路线上一轮按审读意见改写，此处保留）：由上一段的加倍链可见 Λ = 0 与「集合非空但稀疏」完全相容，因此 T1 与 T2 **并不必然**要求排除陷阱；要把某一层推到 0，只需要一个强于逐层正上界（第 7 步）的输入。它可以是 (α) 结构性排除 A_{C_0} = ∅，也可以是 (β) 一个 3x+1 特有的、强于 (log C)^{−c} 的该层对数密度上界。本报告不主张 (α) 是唯一可能（上一轮曾主张，属无效推理，已撤回）。

**第 10 步（类层面不可达性：陷阱引理）.【已证（初等）＋本会话重跑数值核对】**
定义映射 C_q（q 为奇数，q ≥ 3）：C_q(N) = N/2（N 偶），C_q(N) = 3N + q（N 奇）。则

(iii) qℤ 的自然密度为 1/q，故对每个 B < q 有 dens{ N : S_min(N) > B } ≥ 1/q。

### 第二阶段：本会话的新推进（边界因子的精确分解与损耗定位）

以下第 11 至 15 步是本会话新做的；定理陈述与证明在「局部新结论」一节给出，这里只记它们在论证中的位置与状态。

**第 11 步（倾斜恒等式：把 Chernoff 路线丢掉的东西精确写出来）.【已证（初等，本会话新）】**
对 m ≥ 1，记 c := ln(p/q) = 0.536207535136215…（nat），P_tilt 为每位取 1 的概率 p、取 0 的概率 q 的乘积测度，Q(E_m) := P_tilt(可容许)，Z_m := S_m − m p。则**恒等式**
(11.1) F(m+1) = A(m)/2^m = exp(−mD) · Q(E_m) · E_tilt[ e^{−c Z_m} | 可容许 ]，
其中 E_tilt[· | 可容许] 是条件期望。证明见局部结论 D1（一行乘法，逐项把 2^{−m} 改写成 p^S q^{m−S}·exp(−mD − cZ)）。
意义：第 13 步的 Chernoff 路线给出的界是 F ≤ exp(−mD)·Q(E_m)，即 (11.1) 中把因子 E_tilt[e^{−cZ_m} | 可容许] 丢掉（它是 < 1 的因子）。数值上这个因子 ≈ 16.2/m（局部结论 G1），因此该路线与实测幂次 3/2 之间**恰好差 m^{−1}**；这也是本会话能给出的、对「框架内部还能改进多少」的最精确回答。

**第 12 步（轮换恒等式：把 Q(E_m) 变成一个计数量的期望）.【已证（初等，本会话新）】**
把长度 m 的可容许串条件写成部分和条件：ε ∈ {0,1}^m，增量 ξ_j = +q（ε_j = 1）、−p（ε_j = 0），P_0 = 0，P_i = Σ_{j≤i} ξ_j（注意 P_i = S_i − i p，故可容许 ⟺ P_i > 0 对一切 1 ≤ i ≤ m，因为 P_i ≠ 0 由 p 无理保证），按周期读指标（P_{i+m} = P_i + K，K := P_m）。把 j ∈ {0, …, m−1} 叫「好位置」，若 P_j < P_i 对一切 j < i ≤ j+m；记 R(ε) 为好位置个数。则
(12.1) j 是好位置 ⟺ 从 j 起的轮换是可容许串；
(12.2) E_unif[R] = m·A(m)/2^m = m·F(m+1) 与 E_tilt[R] = m·Q(E_m)（两种测度下都成立）。
证明见局部结论 E1。意义：把一个「全时间约束的生存概率」改写成一个**计数量的期望**，从而能用计数论证去逼近它——这是本轮全部下界与上界尝试的入口。

**第 13 步（好位置的块结构与 K 的符号判据）.【已证（初等，本会话新）】**
沿用第 12 步的记号。若 K < 0 则 R = 0；若 K > 0 则 R ≥ 1。好位置按环序把 m 步切成长度 d_t 的 R 个连续块（Σ_t d_t = m），块和 e_t 满足 e_t = d_t q − Z_t（Z_t 为该块内 0 的个数），且 e_t > 0、Σ_t e_t = K 精确成立（沿环望远镜求和）。证明见局部结论 E1 的 (iii)(iv)。
意义：K 是本框架里最便宜的量（它的二阶矩是 m p q），而 (R, K) 之间的这种精确耦合是第 14、15 步的全部原料。

**第 14 步（劣质块不等式与条件性 m^{−1/4}）【已证（初等）＋一个未证前提】**
记 η(d) := min_{1 ≤ t ≤ d} min_{ℓ ∈ ℤ} |t q − ℓ|。则对每个串，(R − 1)·η(m) < K（R ≥ 2 时）。更强地，若**假设** η(d) ≥ c/d 对一切 d ≥ 1（c > 0 常数），则 K ≥ c·R²/m，从而 R ≤ √(K_+ m/c)（K_+ = max(K,0)），取倾斜期望并用 E[K_+] ≤ E|K| ≤ √(m p q) 与 Jensen 得
(14.1) Q(E_m) ≤ 1/m + (pq)^{1/4} c^{−1/2} m^{−1/4} = 1/m + 0.6946·c^{−1/2}·m^{−1/4}。
证明见局部结论 E4、E5。状态：不等式部分【已证（初等）】；前提「η(d) ≥ c/d」【缺口】（等价于 log_3 2 的部分商有界，见第 15 步与局部结论 F1）。数值取 c ≈ 0.0177（局部结论 F1 实测的最低记录，m 到 10^13 量级）时右端的系数约为 5.2，即 (14.1) 对 m ≳ 750 才有内容。**这是本轮在边界因子上的全部收获：一个条件性的 m^{−1/4}，距目标 m^{−1/2} 还差 m^{1/4}。**

**第 15 步（初等路线为什么到不了 m^{−1/2}）.【部分已证（关于约束系统的观察）＋两条数值否决】**
本轮我把「只用第 13、14 步的原料」能走的路都试了一遍，结论是：在这套原料下至多 m^{−1/4}。第 (1) 条是对约束系统的严格观察，第 (2)(3) 条是数值事实，都可复核。
(1) 劣质块的长度与超额是反比的：e_t ≥ η(d_t) ≈ c/d_t。若要用 Σ_t e_t = K 控制块的个数 R，在「d_t 可小」的方向上只能得到 R ≲ √(K m/c)（第 14 步的 Hölder/Cauchy–Schwarz 上界），而**这个上界在给定原料下是紧的**：取 R 个等长块 d ≈ √(mc/K)、每块超额 ≈ c/d，则 Σ_t d_t = m、Σ_t e_t ≈ K 同时成立，R ≈ √(Km/c) ≈ m^{3/4}（K ≈ √m）。也就是说，这些不等式本身允许多达 m^{3/4} 个好位置，故它们推不出 m^{−1/2}。数值佐证：check_E_rotation 的候选极值构造（按最小超额块拼接）在 m = 64、256、1024 上只给出 R = 3、3、12（远小于 m^{3/4}），说明这个「极端配置」并不是真的可达，但控制它需要的是**超出第 13、14 步的额外结构**。
(2) 「R 被 K/q 控制」这条路**已证伪**（【错误】）：本会话全枚举 m ≤ 22 得 max_ε (R − K_+/q) = ⌊m/3⌋·0.70951，其中 0.70951 = (2p−1)/q 精确到 5 位（check_H_kq，输出见局部结论 H1）。即最坏情况下 R − K_+/q 以线性速度增长，没有「每串版」的 R ≤ C + K_+/q。

为什么是缺口：第 9 步：单条坏轨道加它的加倍链，对 [1,X] 的对数权重 ≥ 1/N_0，是常数，与框架的一切 o(log X) 型结论相容。跨过它需要：能察觉「常数级对数权重」的估计形式，或不依赖密度的结构性定理（刚性、不变量）。注意方向：这一条不构成「必须排除陷阱」（见第 9 步的方向更正）。

4. **Remark 1.4 的启发式缺一个前置定理（文献到缺口的定位）。**
为什么是缺口：把「陷阱存在」升级为「陷阱层的对数密度为正」，需要陷阱前驱树的正密度定理。本会话亲自核对：Wirsching 的预印本原文写「Three unbridged gaps」与「a proof of positive density of a 3n+1 predecessor set is beyond the reach of methods applied so far to 3n+1 dynamics」；且 arXiv:2608.27617（提交日期 2026 年 8 月 27 日）的摘要末句原文为「Conjecture 2 is his route to it and remains open.」即该纲领到 2026 年 8 月仍未闭合。另外，唯一已知的无条件前驱计数下界（Krasikov 与 Lagarias 2003 的 π_a(x) ≥ x^{0.84}，据 `frontier.md:20`）是计数型，与控制对数密度相容（计数 ≍ x^γ 的集合其对数权重被 Σ_j 2^{j(γ−1)} = O(1) 控制，对数密度可以是 0）。跨过它需要：前驱集合的对数密度（或正密度）定理，或者一条不经过前驱密度的间接机制。

5. **T3 的边界估计（m^{−1/2}）没有在初等路线内证成。**
为什么是缺口：第 14、15 步。第 15 步 (1) 给出论证性的理由：只用「块划分 + 块超额与块长反比 + Σe_t = K」这三件原料，Hölder 优化的结果是 R ≲ √(Km/c) ≈ m^{3/4}（K ≈ √m），且该极端配置与这些不等式相容，故推不出 R ≲ √m。第 15 步 (2) 更给出一个精确的反面事实：任何「每串版」的 R ≤ C + K_+/q 都被线性增长的数据否定。跨过它需要：(i) 一条真正不同的输入——经典梯变量/Wiener–Hopf 结构（第 16 步，非初等，本会话未证明）；或者 (ii) 一个能利用「极端串在倾斜测度下极不可能」的新论证（本轮只测出这个现象：全枚举的极端串给出线性增长，但倾斜抽样 20000 次里 max(R − K_+/q) 只有 1.1√m 量级）。要跨过它，我认为需要 (ii) 这种局部化论证，而不是继续优化不等式。

6. **尖锐形式 m^{−3/2} 需要「夹道 + 端点」的联合公式。**
为什么是缺口：第 17 步。F = e^{−mD}·Q(E_m)·E_tilt[e^{−cZ_m}|可容许]，前两个因子已被精确刻画（第 16 步、局部结论 G1），第三个因子实测 ≈ 16.3/m，而它的严格化等价于 Chung–Feller 型的 P(Z_m = z, 可容许) ≈ (z/m)·P(Z_m = z)·Θ(1)（z = O(1)）这类联合公式，本会话未证。跨过它需要：把经典夹道理论对两点零均值游走写成显式常数形式，或一次针对性的初等证明。**注意：即使跨过，它对 T1 与 T2 也没有帮助**（它只改进框架内部的幂次，第 19 步）。

7. **丢番图输入 η(d) ≥ c/d 未证。**

### D1（本会话新）倾斜恒等式
陈述：对 m ≥ 1，
A(m)/2^m = exp(−mD) · Σ_{ε 可容许} p^{S(ε)} q^{m−S(ε)} · exp(−c·(S(ε) − m p))，
且右侧和式内的权重之和满足 Σ_{ε 可容许} p^S q^{m−S} e^{−c(S−mp)} = exp(−mH(p))·A(m)（与 S 无关的因子——这正是恒等式的全部内容）。等价地 F(m+1) = exp(−mD)·Q(E_m)·E_tilt[e^{−cZ_m} | 可容许]。
证明：对每个可容许 ε，把 2^{−m} 写成 p^S q^{m−S}·exp(−m ln 2 − S ln p − (m−S)ln q)；再用 S = mp + Z 与恒等式 S ln p + (m−S)ln q = −mH(p) + Z ln(p/q) 化简便得 2^{−m} = p^S q^{m−S} exp(−mD − cZ)。∎
边界情形：m = 0（k = 1）时 Z = 0、F(1) = 1，恒等式平凡成立。

### E1（本会话新）轮换恒等式与块结构
陈述：(i) 第 12 步的「好位置 ⟺ 轮换可容许」；(ii) E_unif[R] = m·A(m)/2^m 与 E_tilt[R] = m·Q(E_m)；(iii) K < 0 ⟹ R = 0，K > 0 ⟹ R ≥ 1；(iv) 好位置给出 R 个连续块，Σ_t d_t = m、e_t = d_t q − Z_t > 0、Σ_t e_t = K 精确。
证明：(i) 轮换的部分和是 P_{j+i} − P_j，而可容许 = 全部部分和 > 0（P_i ≠ 0 由 p 无理）；(ii) 轮换是 {0,1}^m 上的置换且两种测度的权重在轮换下不变，故 m 个事件「第 j 个轮换是好位置」等概率；(iii) K < 0 时 i = j + m ∈ (j, j+m] 给出 P_{j+m} = P_j + K < P_j；K > 0 时取 j* = argmin_{0 ≤ i < m} P_i，则 (j*, j*+m] 上的值都严格大于 P_{j*}（跨过 m 的部分用 P_{i} = P_{i−m} + K > P_{i−m}，同周期内不同位置的值互不相等由 p 无理保证）；(iv) 相邻好位置 j_t < j_{t+1} 满足 P_{j_t} < P_{j_{t+1}} < P_{j_t} + K，沿环望远镜求和得 Σ_t e_t = K；e_t = (#1)q − (#0)p = d_t q − Z_t。∎
边界情形：m = 1（R = 1，K = q）；R = 1 时唯一块长 m；m ≥ 2 时若 K < 0 则 R = 0 而块结构退化（不适用）。

### E4、E5（本会话新）劣质块不等式与条件性 m^{−1/4}
陈述：记 η(d) := min_{1 ≤ t ≤ d} min_{ℓ ∈ ℤ}|t q − ℓ|。
(E4a) 对每个串与 R ≥ 2，(R − 1)·η(m) < K。
(E4b) 若 η(d) ≥ c/d 对一切 d ≥ 1，则 K ≥ c R²/m，即 R ≤ √(K_+ m/c)。
(E5) 在 (E4b) 的前提下，Q(E_m) ≤ 1/m + (pq)^{1/4}c^{−1/2}m^{−1/4}。
证明：(E4a) 由 e_t = d_t q − Z_t > 0 且 Z_t ∈ ℤ 得 e_t ≥ η(d_t) ≥ η(m)；再 (R−1)η(m) ≤ Σ_t e_t = K。(E4b) Σ_t d_t = m 与 Cauchy–Schwarz 给 Σ_t 1/d_t ≥ R²/m，故 K = Σe_t ≥ cΣ1/d_t ≥ cR²/m。(E5) 由 (E4b) 取倾斜期望、Jensen（E√K_+ ≤ √(E K_+)）与 Cauchy–Schwarz（E[K_+] ≤ E|K| ≤ √(mpq)）得 E_tilt[R] ≤ 1 + √(m/c)·(mpq)^{1/4}，再除以 m。∎
边界情形：R ≤ 1 时 (E4b) 仍可写成 R ≤ 1 + √(K_+m/c)；m = 1 平凡。

## 若要继续，下一步最该做什么

按「收益与可行性」排序，并明确哪些不该再做。

1. **把边界因子的严格化做在「局部化」而不是「不等式优化」上（本会话最明确的下一步）。**
