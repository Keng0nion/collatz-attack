# 实验：全量验证地基（Collatz 总停时全扫描，n 不超过 2^28）

实验日期：2026 年 10 月 18 日。机器：macOS（darwin arm64），8 核，8 GiB 内存。

## 目的

把「地基」做实：在自算力允许的最大范围内，逐条核验每个正整数最终都到达 1，并给出该范围内总停时的最大值、取到它的 n，以及完整的停时纪录保持者序列。三项交付对应任务原文的 (a)、(b)、(c)：

1. (a) 全部 n 不超过上限都最终到达 1；
2. (b) 总停时的最大值与其对应的 n；
3. (c) 停时纪录保持者序列（严格纪录）。

另外按任务要求，把结果与 OEIS 的 A006577（总停时）与 A006877（停时纪录）中可对齐的部分逐条核对，列出不一致处。

## 方法

### 计数约定

与 OEIS A006577 完全一致：映射 C(n) = n/2（n 偶）、C(n) = 3n+1（n 奇）；总停时 len[n] 为到达 1 所需的 C 步数，每个折半与每个 3n+1 各计 1 步；len[1] = 0。注意这与 Terras 停时 chi（用加速映射 T(n) = n/2 或 (3n+1)/2，取首次降到 n 以下所需的步数）不是同一个量，本实验两者都算，但分开报告。

### 算法（记忆化加重记忆化下降，scripts/sweep.c）

1. 表 len 为 268435457 个 uint16（512.0 MiB），0 对 n 大于等于 2 表示尚未填入；len[1] = 0。
2. 按 n 递增填表。n 偶：len[n] = len[n/2] + 1。n 奇：从 n 沿标准映射步进，直到当前值 x 严格小于 n（这一步就是加速的实质：不必走到 1，只走到跌破自身），然后 len[n] = 已走步数 + len[x]。
3. 因为 x 严格小于 n，len[x] 必定已在之前的迭代中填好。于是表中每一个 len[n] 都对应一条显式的、逐步下降的有限轨迹，由对 n 的归纳即得「n 到达 1」。任意一步都不使用「猜想为真」这个假设；这是有限核验，不是概率论证。
4. 安全边界：单条轨迹步数上限 10^7，超过即报错退出（那意味着非平凡循环或发散，程序绝不把它绕过去）；3x+1 之前做溢出检查；输入上限有硬上界 2^29 且只接受十进制数字。

### 校验设计

1. 校验 A：对 n 从 1 到 1000000 的每一个 n，用完全独立的、不做记忆化也不加速的教科书式循环逐步走到 1，与表值逐条比对。
2. 校验 B：对全部纪录保持者（63 个）做同样的直接模拟比对。
3. 校验 C：对 [1, 2^28] 内的 200000 个 xorshift64 可复现随机点做直接模拟比对。
4. 校验 D：全表偶数的递推一致性 len[n] 等于 len[n/2] 加 1（134217728 个偶数逐条）。
5. 校验 E：用加速映射独立计算 Terras 停时 chi 在 [3, 250000] 上的最大值，与文献记载值对照（data 来源见下）。
6. 独立再模拟（Python，任意精度整数）：scripts/sweep_check.py 用纯 Python 重算全部 63 个纪录点与 3000 个随机点（n 不超过 1000000），与 C 程序输出比对。
7. OEIS 逐条核对：scripts/sweep_check.py 读 oeis.org 的 b 文件，与 sweep 导出的 (n, len[n])（n 不超过 1000000）及纪录表逐条比对。

### 参照数据（外部，非本工作计算结果）

1. A006577 的 b 文件：10000 项（n = 1 至 10000），抓自 https://oeis.org/A006577/b006577.txt 。序列定义（OEIS 页原文）：Number of halving and tripling steps to reach 1 in '3x+1' problem；offset 1，a(1) = 0。
2. A006877 的 b 文件：148 项，抓自 https://oeis.org/A006877/b006877.txt ；文件头自述数据取自 Eric Roosendaal 的 3x+1 Delay Records（as of 2024-08-06）。定义（OEIS 页原文）：these values for the starting value set new records for number of steps to reach 1；注释明确「Both the 3x+1 steps and the halving steps are counted」，与本实验计数约定相同。
3. A006878 的 b 文件：148 项纪录值（步数），抓自 https://oeis.org/A006878/b006878.txt ，用于核对纪录点的步数。
4. Terras 1976 记载的 chi 最大值（n 不超过 250000 时为 135，在 n = 35655 处）：本项目的文献笔记 10-literature/notes/stopping-times.md 第 25 行记录了这一数值并注明出处为原文第 251 至 252 页。本实验只把它当作外部对照值。

## 完整命令行

以下命令均在 collatz-attack/20-experiments 目录下执行：

```
mkdir -p results/oeis
curl -s -o results/oeis/b006577.txt https://oeis.org/A006577/b006577.txt
curl -s -o results/oeis/b006877.txt https://oeis.org/A006877/b006877.txt
curl -s -o results/oeis/b006878.txt https://oeis.org/A006878/b006878.txt
cc -O3 -Wall -Wextra -o scripts/sweep scripts/sweep.c
/usr/bin/time -p ./scripts/sweep 268435456 results/sweep_records.tsv results/sweep_lens.tsv > results/sweep.txt 2> results/sweep.stderr
./.venv/bin/python scripts/sweep_check.py results/sweep.txt
```

编译无警告（cc 为 Apple clang 21.0.0）。程序打印自己的完整命令行，见 results/sweep.txt 第 2 行。

## 耗时

1. 程序内部计时（最终一次运行，写入 results/sweep.txt）：填表 2.54 s，全表扫描与五项校验合计 3.45 s。
2. 墙钟（/usr/bin/time -p，见 results/sweep.stderr）：real 5.21 s，user 3.24 s，sys 0.11 s。
3. 同为 2^28 的另一次完整运行（修补一处输出措辞之前）墙钟为 real 8.35 s。两次相差 5 至 8 秒量级，远低于 15 分钟预算，因此无需降低上限，也未降低上限。

## 关键数字

1. 上限与实际范围：N = 268435456（2^28），本次核验覆盖 n 从 1 到 268435456 的全部整数，一个不漏。
2. (a) 有限总停时条目 268435456 / 268435456（在该范围内），即范围内每个 n 都有一条显式下降到 1 的轨迹。
3. (b) 范围内最大总停时 956，其对应的 n = 226588897（唯一取到最大值）。
4. (c) 范围内纪录保持者 63 个；前几个与后几个：1、2、3、6、7、9、18、25、27、54，以及 127456254（950 步）、169941673（953 步）、226588897（956 步）。完整 63 项见 results/sweep_records.tsv。
5. 耗时：程序内部总计 3.45 s（填表 2.54 s）；墙钟 real 5.21 s（同规模另一次运行 8.35 s）。上限 2^28 的核验比 15 分钟预算低两个数量级。
6. 校验 A：n 从 1 到 1000000 全量直接模拟零不一致（该范围内最大 524 步，轨迹峰值 56991483520）。
7. 校验 B：63 个纪录点直接模拟零不一致。校验 C：[1, 2^28] 内 200000 个随机点直接模拟零不一致（样本中最大 677 步，样本轨迹峰值 306296925203752）。
8. 校验 D：134217728 个偶数逐条满足 len[n] 等于 len[n/2] 加 1，零不一致。
9. OEIS A006577：逐条比对 10000 项（n = 1 至 10000），不一致 0 处，缺失 0 处。
10. OEIS A006877 与 A006878：148 项中 63 项落在 2^28 以内，这 63 项的 n 与步数逐条比对，不一致 0 处；其余 85 项超过 2^28，未核对（范围之外）。
11. Python 独立再模拟（任意精度整数）：63 个纪录点加 3000 个随机点，零不一致。
12. 校验 E：Terras 停时 chi 在 [3, 250000] 上的最大值为 135，唯一取到于 n = 35655，与文献笔记记录的 Terras 数值一致（这是程序与外部值的对照，不是新结果）。

## OEIS 逐条核对结果

1. A006577 逐条核对（n = 1 至 10000）：0 处不一致。前 24 项两列并列见 results/sweep.txt 的核对报告。
2. A006877 逐条核对（范围内 63 项）：0 处不一致；每项的步数同时与 A006878 核对，0 处不一致。
3. 不能核对的部分：A006577 的 b 文件只到 n = 10000；A006877 的 148 项中有 85 项大于 2^28（最小的一项 268549803 略大于 2^28），这些项在本实验的范围之外，未核对，不能算作通过。
4. 一处口径说明：A006877 的 b 文件第 1 项是 n = 1（0 步），本实验的纪录扫描同样从 n = 1 起算，两者口径一致。
5. 对本实验 (b) 与 (c) 的意义：外部纪录表的第 63 项（226588897，956 步）之后，下一项 268549803 已超过 2^28。也就是说，在本实验范围内，(b) 的最大值 956 与 (c) 的 63 项纪录序列与外部纪录表逐项一致，双方互为独立佐证（外部数据自身的正确性由 OEIS 与其数据来源负责，不是本实验验证的）。

## 这个实验不能证明什么

1. 不能证明科拉茨猜想。核验范围只有 n 不超过 2^28；对任何更大的 n，本实验一无所证。
2. 不能排除非平凡循环，也不能排除发散轨道。只有「轨迹全部元素大于 2^28」的循环、或起点大于 2^28 的发散轨道，才可能完全不触及本次扫描；本实验没有触及，不等于它们不存在。
3. 不能给出任何密度、渐近或增长规律。956 只是区间 [1, 2^28] 内的有限极大值，不蕴含最大值随上限如何增长，也不涉及「几乎所有 n」型陈述。
4. 「全部 n 不超过 2^28 到达 1」这条结论依赖本程序实现的正确性。独立复核覆盖的是：n 从 1 到 1000000 的全量直接模拟、200000 个均匀随机点、63 个纪录点、以及 Python 任意精度的 3000 个随机点；一个只在未被抽样路径上生效的系统性缺陷不会被上述检查发现。
5. 与 OEIS 的核对只覆盖可对齐的部分：A006577 的公开数据止于 n = 10000，A006877 的 148 项中只有 63 项落在本实验范围内，其余 85 项未核对。
6. 不能作为 Terras 系数停时猜想或任何文献断言的新证据。校验 E 只说明本程序复现了一个已知文献数值，且只覆盖 [3, 250000]，不能外推。
7. 不能说明纪录保持者序列到此为止。226588897 与 956 步只是 2^28 以内的最后一项纪录，A006877 的下一项（268549803）就已经超出本实验范围。
