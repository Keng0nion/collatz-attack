# 停时分布实验（stoptime-stats）

计算日期：2026 年 10 月 18 日
计算范围：n 从 1 到 2^24 = 16,777,216（含端点），全部精确计算，无抽样。

一句话结论：在 n 不超过 2^24 的范围内，总停时的经验分布与「随机游走加漂移」启发式模型在前两阶矩上吻合到百分级（分带均值的斜率相对差 0.50%；顶部带均值模型比经验高 1.46%、标准差模型比经验低 3.52%，两处都以经验值为分母，见第五节第 4 条），但在形状上明显偏离正态：两尾都比同矩正态重，右尾在阈值 t = 500 处的超越计数是正态预测的约 1900 倍。范围最大值 704（在 n = 15,733,191 处）只有用重尾极值模型才接近得起来（上尾 1% 的 Gumbel 矩拟合预测 690.5，低 1.9%），同矩正态只预测 516 至 526。与之对照，Krasikov 与 Lagarias 的 x^0.84 型计数下界（实际线性规划指数 γ = 0.8417566）在 x = 2^24 处折合成的覆盖比例只有 7.19%，缺口随 x 以约 x^(−0.1582) 扩大；把下界推到 1 需要指数从 0.8417566 抬到 1（λ 从 1.7922310 抬到 2，乘 1.115928），而按文献十点的幂律外推（本次计算的拟合，R² = 0.99496），在 x = 2^24 处覆盖 50% 需 k ≈ 69、覆盖 99% 需 k ≈ 24,965（后者对应 3^(k 减 1) 约 10^11911 个同余类）。以上全是范围性观察与曲线拟合，不构成任何证明。

## 一、目的

1. 对 n 不超过 2^24 精确计算总停时（OEIS A006577 意义）的完整分布，并顺带精确计算 Terras 停时分布（标准步与加速步两套）。
2. 与「随机游走加漂移」启发式模型对照：分带均值与标准差、形状（正态性）、极值（范围最大值的分布类型）。
3. 把 Krasikov 与 Lagarias 的 x^0.84 型下界与实际数据放在一起：画出实际覆盖率与下界覆盖率的缺口形状，估计要把下界推到 1 还需要什么样的定量增益。

纪律声明：本文件是实验记录，不是证明。所有结论都写成「在此范围内观察到什么」。

## 二、方法

### 2.1 精确计算（C 程序，scripts/stoptime_dist.c）

**三个量**（均用标准映射：奇数走 3n+1，偶数走 n/2）：

1. `tot[n]`：总停时，首次到达 1 的步数（OEIS A006577）。
2. `cs[n]`：Terras 停时（标准步计），首次使轨迹值严格小于 n 的步数。
3. `ca[n]`：Terras 停时（加速步计），加速映射 T(n) = n/2（偶）、(3n+1)/2（奇）下首次使轨迹值严格小于 n 的步数。

**算法**：对 n 从 2 到 N 递增扫描。对每个 n，用无查表的循环沿轨迹走，直到值首次跌破 n，其间步数即 `cs[n]`；跌破点设为 m（m < n，故 `tot[m]` 已算好），于是 `tot[n] = cs[n] + tot[m]`。这是一趟前向动态规划，无递归、无哈希，内存为三个 `uint16` 数组（每个 2^24 项，合计约 100 MB 量级）。`ca[n]` 用独立一趟循环（加速映射）计算。

**安全设计**：单条轨迹 1,000,000 步安全上限（触发即报错退出，因为那将意味着反例或程序错误；本次未触发）。程序另外打印「全部 n 均到达 1」；该行是静态标签，其实质依据是本次运行的两个可核对事实：（一）三个直方图的计数合计都恰好等于 16,777,216 = 2^24（我用脚本复核过），即每个 n 都算出了有限停时；（二）安全上限从未触发。这不是引用外部结论（例如「已验证到 2^68」那类文献边界），只覆盖本次范围。

**整数类型**：轨迹中间值用 `unsigned long long`（64 位）。本次没有单独记录轨迹峰值，所以「64 位足够」不是我自己算出来的直接事实，而是一个间接推断：转储的逐点值与独立实现、OEIS b 文件、OEIS 纪录序列三项比对全部一致（见 2.2 与 4.2），若中途发生 64 位溢出，这些比对不可能全部通过。这只对 n 不超过 2^24 的范围有效。

**n = 1 的约定**：χ(1) 无定义（1 到 4 到 2 到 1 永不小于自身），程序把 `cs[1] = ca[1] = 0` 按占位记录，且两套 χ 的统计一律只用 n = 2 至 N（分母 16,777,215）。总停时 `tot[1] = 0` 有定义并计入直方图（所以直方图计数合计含它），但汇总与统计里的总停时均值同样按 n = 2 至 N 计算（代码里分母取 N 减 1）。

**输出**：直方图 `stoptime_tot_hist.csv`、`stoptime_chistd_hist.csv`、`stoptime_chiacc_hist.csv`；按 band = floor(log2 n) 的二维直方图 `stoptime_tot_band2d.csv`、`stoptime_chiacc_band2d.csv`；总停时纪录 `stoptime_records.txt`；汇总 `stoptime_dist_summary.txt`；可选的逐点转储 `stoptime_dump.csv`（n 不超过 2^18 = 262,144，供外部逐点核对）。

### 2.3 「随机游走加漂移」启发式模型（下称漂移模型）

设定：用加速映射 T(n) = n/2（偶）、(3n+1)/2（奇）；假定奇偶序列 iid 均匀（各 1/2），且 3n+1 近似为 3n。于是每加速步在 log2 尺度的增量取

* 偶数步：−1（概率 1/2）；
* 奇数步：log2 3 减 1 = +0.5849625（概率 1/2）。

由此（数值均由本次脚本内计算）：

* 漂移 μ = (log2 3 减 2)/2 = **−0.2075187496**，每加速步；
* 波动 σ = log2 3/2 = **0.7924812504**（注意它等于 log_4 3 = 0.79248125，也是 Korec 1994 定理里的常数）；
* 每自然对数单位的加速步数 1/(|μ| ln 2) = 6.952119，标准步则是它的 1.5 倍（1.5 来自「标准步数 = 加速步数 加 奇数步数」而奇数步约占一半）。

**总停时模型**：从 L = log2 n 下降到 0 的首次通过。漂移占优时（L 远大于 σ²/μ² = 14.58）

* 均值 E ≈ 1.5·L/|μ|（回归斜率 7.22826）；
* 方差 Var ≈ 2.25 σ² L/|μ|³ 加 0.25·L/|μ|（后项来自「标准步数 = 加速步数 加 奇数步数」的二项噪声）；
* 于是标准差按 L 的平方根增长。

**Terras 停时模型**（加速步，从「刚出发」这一近乎零距离的尺度看）：

* 扩散极限：χ_acc 近似等于 (σ/|μ|)²·Z² = **14.5836·Z²**（Z 标准正态），即 P[χ_acc ≥ k] ≈ erfc(√(k/14.5836)/√2)；
* 大偏差速率：事件「前 k 步内不跌破起点」等价于奇步占比不低于 1/log2 3 = log_3 2 = 0.6309298，由伯努利率函数在 p = 1/2 处取值（单位比特）得 P[χ_acc ≥ k] ≈ 2^(−0.050044·k)，即每步乘 0.9659。

**极值模型**：对顶部带的分布既用「同矩正态的期望最大值 m 加 s·√(2 ln M)」（M 为样本数），也对上尾 1% 做 Gumbel 矩拟合，再算该尾样本数的期望最大值。

### 2.4 Krasikov 与 Lagarias 下界的载入与缺口定义

文献输入（**不是我算的**）：项目笔记 `10-literature/notes/stopping-times.md` 第 60 行转引自 arXiv:math/0205002（Krasikov 与 Lagarias 2003，Acta Arithmetica 109, 237 至 258）表 2 的十点 γ_k（k = 2 至 11）与 k = 11 的线性规划值 λ = 1.7922310。发表表述是 π_a(x) ≥ x^0.84 对充分大的 x 成立（a 不被 3 整除；x_0(a) 原文未给显式值）。我**没有**独立核验该线性规划证书，也没有重跑其计算。

我这边的运算：γ = log2(1.7922310) = **0.8417566**（脚本内计算）。把「π_1(x) ≥ x^γ」折算成覆盖比例（被下界保证「轨道包含 1」的整数占 n 不超过 x 的比例）即 x^(γ 减 1)。本次范围内实际覆盖率为 1（所有 n 都到达 1）。

缺口定义：覆盖比例 x^(γ 减 1) 与 1 的差；以及为达到给定覆盖目标 f（在给定尺度 x）所需的指数 γ = 1 + ln f/ln x。

### 2.5 γ_k 的外推（本次计算的拟合）

把十个文献 γ_k 的「1 减 γ_k」分别对 k 与 ln k 做最小二乘（脚本内计算），得到两种拟合与外推。这是纯曲线拟合，只有描述性价值。

## 六、这个实验不能证明什么

1. **不能证明 Collatz 猜想，也不能证明任何有限范围之外的轨道行为。** 「此范围内全部 n 到达 1」是对 n 不超过 2^24 的计算事实，与 n 超过 2^24 的情形无关；把范围推大不改变这一点。
2. **不能证明停时分布的正态性或非正态性。** 卡方与偏度峰度都是有限范围、有限样本的经验陈述：卡方在 8.4e6 样本下几乎必然拒绝任何连续分布（它只说明「不是精确正态」，不给出偏离的极限定理），Gumbel 拟合是同一批数据的内样本拟合，既不是独立验证，也不能判定极值指数的类型（Gumbel 与 Fréchet 或 Weibull 之争需要尾部渐近定理）。
3. **不能证明 Krasikov 与 Lagarias 下界的任何改进、上限或不可能性。** 缺口数字是「本次范围内实际覆盖率恒为 1」与文献下界表述的换算对比；文献定理写的是「对充分大的 x」（x_0(a) 未给显式值），所以 2^24 处的 7.19% 只是把它按指数形式外推的示意，不是定理在该尺度上的断言，也不是我能保证该定理在 2^24 处成立的结论。我未独立核验 λ = 1.7922310（来自项目笔记转述）也未重跑其线性规划证书。
4. **γ_k 外推没有预测价值。** 它是在十个文献值上的曲线拟合；R² 是内样本量，幂律形式本身是我选的（也试了几何形式，两者外推结论差到荒谬），k ≈ 69 与 k ≈ 24,965 这类数字只能当数量级示意。
5. **漂移模型的吻合不能外推。** 前两阶矩在 n 不超过 2^24 内吻合到百分级，这只说明模型在这一尺度上「不坏」，不证明它在更大范围或极限情形成立；形状上的偏离（两尾更重）恰恰说明模型在那里已经失败。模型本身还忽略了 3n+1 的加 1 项与到达 1 之前的最后几步。
6. **不能把「Terras 停时生存率与笔记里的动态规划值吻合」当作对文献定理的验证。** 那是与项目内另一次会话的计算比对（同为有限范围的经验量），不是对 Terras 1976 密度定理的核对。
7. **不能给出密度层面的结论。** 本次没有计算任何自然密度；F(k) 的有限范围计数与 Terras 定理中的密度极限之间的差别（区间不是模式周期的整数倍）本次只在 k = 50 与 100 两个点上间接看到（0.74% 与 3.73% 的偏低），未做系统误差分析。
