## 一、目的

对应实验任务（workflow.ts 的 parity-vectors 条目）的四项要求：

1. 验证 Terras 仿射公式：给定长度 k 的奇偶向量 v，T^k(x) 等于 (3^m x 加 c) 除以 2^k，其中 m 为 v 中奇步（1）的个数。用精确整数枚举验证 c 的递推。
2. 验证环方程：环上的整数满足 x = c 除以 (2^k 减 3^m)，且正环要求 2^k 大于 3^m。
3. 数值检验 Bernstein 与 Lagarias 型共轭映射在小范围上的行为。
4. 「引理杀手」：把文献与工程实践中常见的启发式中途断言取成精确命题，在可枚举范围内穷举搜反例，记录最小反例。

方法要点（三条自我纠错，供复核者注意）：

1. 原文式 (1.5) 给出的是 Phi^{-1}（奇偶向量编码），不是 Phi。第一版脚本把两者当成同一个映射，导致 6628 处「不一致」；修正后 (1.6) 精确有理数与低位剥离递推给出同一个 Phi，而 (1.5) 实现是它的逆，两者互为逆映射（复合恒等式 0 失败）。

3. 共轭方程的位数：S 会吃掉最低位，比较时必须多取一位，否则出现纯属截断的「失败」。

## 四、原始输出摘要

### 4.1 A 组：仿射公式与 c 的递推

1. c 的递推（追加 0 时 c 不变、追加 1 时 c 变成 3c 加 2^|v|）与闭式（c 等于 3^{m-1-idx} 2^{i_idx} 之和）在**长度 1 至 16 的全部 131070 个向量**上完全一致，不一致数 0。
2. 仿射公式 T^k(x) = (3^m x 加 c) 除以 2^k（含整除性检查）在 **k 不超过 14、全部 x 属于 [1, 2^k) 的 32752 个组合**上成立，失败数 0；另有 200 个位宽 60、100、160 的随机 x（固定种子）与 k 不超过 40 的抽样，失败数 0。
3. 模 2^k 残数到长度 k 奇偶向量的映射是双射（k 不超过 16）；区间 [1, 2^n] 上每个长度 k 向量恰好出现 2^{n-k} 次（k 不超过 n 不超过 15，131038 个格），异常数 0。
4. 首降向量计数 A(k)（k = 1 至 18）：
   `1 1 0 1 2 0 3 7 0 12 0 30 85 0 173 476 0 961`。
   **A(3) = 0**：不存在任何长度 3 的向量满足「前两位比不小于 1、第三位比小于 1」，故集合 chi = 3 为空（这一条对全部正整数 x 成立，不只是范围结论）。A(6)、A(9)、A(11)、A(14)、A(17) 同样为 0，这些是我在 k 不超过 18 的枚举内的结果。
5. 累计密度 sum A(k)/2^k（k 不超过 18）等于 0.971409。

### 4.2 B 组：环方程

1. 四个已知环全部由判据精确复现：
   x = 1（k = 2, m = 1, c = 1, 2^k 减 3^m = 1）、x = -1（k = 1, m = 1, c = 1, 差值 -1）、x = -5（k = 3, m = 2, c = 5, 差值 -1）、x = -17（k = 11, m = 7, c = 2363, 差值 -139）。正环满足 2^k 大于 3^m，三个负环都满足 2^k 小于 3^m。
2. Python 完备搜索 k 不超过 20：枚举 2097150 个向量，命中的环去重后为正环 {1, 2} 与三个负环族（-1；-5, -7, -10；-17 及其 10 个同族元素）。
3. C 完备搜索 **k 不超过 32**：枚举 **8589934590** 个向量（剪枝跳过 2545358193 个），程序自记 130.42 秒。满足整除性的命中 116 次，**全部通过奇偶向量一致性检查**；去重后恰好 4 个环（1 族与 -1、-5、-17 三族），T^k(x) = x 逐环直验通过。
   计数口径（经复核员指出后已改进程序并写入输出）：全零向量节点（c = 0，共 32 个，k 等于 1 至 32）上整除性平凡成立，对应退化解 x = 0（T(0) = 0，不属于任何非零环），本脚本按约定排除在外；若把它们计入，整除成立节点共 148 个。复核员用无剪枝穷举独立确认了这一口径差异，并确认除 x = 0 外没有被剪枝隐藏的解。
   剪枝的完备性（本脚本自己的论证，供反驳）：候选解是 x = c 除以（2^k 减 3^m）；若 |2^k 减 3^m| 大于 c，则 0 小于 |x| 小于 1，不可能是非零整数，故跳过不丢解。另外脚本对候选 x 设了 2 的 62 次方为界的范围检查；对 k 不超过 32 的真环，Böhm 与 Sontacchi 的界 |x| 小于 3^k（3^32 约 2 的 60.7 次方，转引自项目文献笔记 cycles.md 第 37 行）保证不会有真环被该检查漏掉。本次运行里 116 次整除命中全部通过一致性检查，说明没有任何命中被该界挡掉。
4. 「只看整除、不查奇偶向量一致性」的伪命中数：k 不超过 20 时为 0，k 不超过 32 时也为 0；1 圈型向量（形如 1^m 0^j）上出现的正环只有平凡环 x = 1。

### 4.3 C 组：Bernstein 与 Lagarias 共轭

原文（我自行下载的预印本 PDF，Bernstein 与 Lagarias 1996，第 2 页与第 5 页）给出：式 (1.4) Phi(x) 同余 x 模 2；式 (1.5) Phi^{-1}(x) 等于奇偶向量编码；式 (1.6) Phi(x) 等于负的 3^{-l} 2^{d_l} 之和；Theorem 3.1 与 Corollary 3.1a 给出置换循环结构的稳定性与阶；表 2.1 给出 n 不超过 6 的循环、表 2.2 给出 n 不超过 20 的 |X_{n,j}|。上表数据我以 pdftoppm 渲染为图像后逐格读出（文本层会吞掉负号，故公式以图像为准）。

本次结果：

1. 两种独立的 Phi 实现（(1.6) 的精确有理数、低位剥离递推）在 **N 不超过 12、全部 x 小于 2^N** 上一致，不一致数 0；与 (1.5) 实现的复合恒等式 (1.5) o Phi = id 与 Phi o (1.5) = id 各 0 失败。
2. 精确函数方程 Phi(2x) = 2 Phi(x)、Phi(2x+1) = (2 Phi(x) 减 1)/3、Phi(x) 同余 x 模 2，在 x 不超过 2^12 上共 12288 次检查，失败数 0。
3. 不动点与 2 循环（模 2^24）：Phi(-1) = -1、Phi(1/3) = 1/3、Phi(1) = -1/3、Phi(-1/3) = 1、Phi(Phi(1)) = 1 全部成立。
4. 共轭方程 S o Phi^{-1} = Phi^{-1} o T（等价于原文式 (1.3)）在 N 不超过 14、32766 个 x 上成立，失败数 0。
5. **原文表 2.1 与表 2.2 逐格复核**：n 不超过 6 的循环集合与表 2.1 完全一致；n 等于 2 至 18 的 |X_{n,j}| 与表 2.2 逐格相符（不符行数 0）；循环长度全是 2 的幂（异常 0）；n 不小于 6 时「三条长度 2^(n-4) 的长循环」全部成立（不符 0）。
6. C 程序把同一检查推到 **n 不超过 30**（n 等于 30 时处理 536870912 个奇残数）：阶恒为 2^(n-4)、长循环恒为三条、长度恒为 2 的幂，三条长循环的代表元始终是 5、9、41；n 不超过 20 的计数与表 2.2 逐格相符。
7. 有理点：1 映射到 -1/3、-1 映射到 -1、1/3 映射到 1/3、-1/3 映射到 1、1/5 映射到 13/21、3/5 映射到 1/7、1/7 映射到 -11/3、1/9 映射到 115/111、5/7 映射到 -1/5、-1/5 映射到 5/7，全部为有理数，且与递推实现模 2^20 相符。

### 4.4 D 组：引理杀手

四个精确命题，各自的最小反例（x 不超过 2^18，k 不超过 12 或按注明）：

**K1（同一奇偶向量内 T^k(x) 是否小于 x 恒定）**：命题为假。在 x 不超过 2^13、k 不超过 12 的范围内有 21 组违反。最小反例：**k = 2，向量 (1, 0)，x = 5 时 T^2(x) = 4 小于 5，而 x = 1 时 T^2(x) = 1 不小于 1**（两者奇偶向量相同）。若要求两个 x 都不小于 2，最小反例是 k = 2、向量 (0, 1)、x = 6 与 x = 2。结构性原因：T^k(x) 小于 x 等价于 x 大于阈值 theta_v = c_v/(2^k 减 3^m)，所以每一类的「小元素」都可能与「大元素」行为不同。

**K2（停时层集是模 2^j 的完整剩余类之并）**：朴素版为假，**最小反例是 j = 2、x = 5（属于集合）与 x = 1（同类但不属于）**；在 j 不超过 12、x 不超过 2^18 上仅此 1 组违反。精确版（把阈值截断写进判据：chi(x) = j 当且仅当 v = pv_j(x) 满足 3^{m_j} 小于 2^j、且 x 大于 theta_j、且对一切 i 小于 j 有 3^{m_i} 不小于 2^i 或 x 不超过 theta_i）在 x 不超过 2^18、j 不超过 12 上**逐点核对不符次数为 0**。

**K3（Terras 系数停时猜想 tau(x) = chi(x)，x 不小于 2）**：本轮范围内未找到反例。
   1. 直接模拟：x 不超过 2^18 全部相符（0 不符）；再推到 **x 不超过 2^30（1073741824）**，0 不符，用时 16.05 秒；该区间内 chi 的最大值 395，首次出现在 x = 217740015。
   2. 向量侧完备搜索：**tau 不超过 40 的全部 x**（1228671536 个首降向量，访问 15263013070 个节点）中，破坏猜想且 x 不小于 2 的个数为 0。
   3. 精确边界结构：theta_v 不小于 1 的首降向量（k 不超过 20）有 4402 个；但其中「类内最小正元素 x_min 不超过 theta_v」的只有 1 个，即 k = 2、v = (1,0)、x_min = 1（就是被猜想排除的 x = 1 这一例外）。theta 的最大值是 24.5385（k = 8）。**最接近反例的程度依赖口径，三种口径在 k 不超过 40 上分别是**：
      口径甲（全部首降向量，x_min 取类内最小正元素，含零残数类）：最小 gap 为 x_min 减 theta 等于 **2.000000**，出现在 k = 1、v = (0)、x_min = 2（该类是正偶数，theta = 0，即完全无风险）；
      口径乙（只看 c 大于 0 的向量）：最小 gap 为 **2.285714**，出现在 k = 4、x_min = 3、theta = 5/7；
      口径丙（归一化接近度 theta 除以 x_min，违反当且仅当它不小于 1）：最大值 **0.495069**，出现在 k = 8、x_min = 39，即该口径下最接近反例的是 k = 8 这个向量。
   4. 空层集：在 x 不超过 2^30 的实测直方图中，chi 等于 3、6、9、11、14、17、19、22、25、28、30、33、36、38、41、44、47、49、52、55、57、60 的计数全为 0，与 A(k) = 0 的枚举一致。

**K4（停时在同余类上均匀）**：精确计数版为假，**最小反例是 (n, k, a, j) = (1, 1, 0, 1)**，即 x 不超过 2 时「chi = 1 且 x 为偶数」的计数 1 与均匀值 1/2 不符。k 不超过 7、n 不超过 18 的范围内有 141230 个违反组合。补充测量（相对偏差上确界）：j = k 的「自然模数」情形下，k = 2 时为 3.0、k = 4 时为 15.0（结构性的，因为层集只支撑在部分类上）、k = 3 与 k = 6 时为 0；跨模数情形（例如 k = 3, j = 2）为 3.0039 到 3.0001，随 n 收敛极慢。

**密度定理的有限区间表现（附加测量）**：Terras 密度定理 delta[chi 不小于 k] = P[tau 不小于 k] 在 X = 2^28 上，逐 k（k 等于 1 至 240，不只每 5 一档）实测比值与 1 的偏离上确界为：k 不超过 155 时 **2.5502%（在 k = 135）**，k 不超过 200 时 10.4540%（在 k = 200），k 不超过 240 时 15.4630%（在 k = 211）。动态规划给出 P[tau 不小于 135] = 0.00005331，与项目文献笔记（stopping-times.md 第 82 行）转述的 Terras 原表值 5.3312 乘 10 的负 5 次幂相符（该值我只在本笔记内核对，未打开 Terras 原文）；复核员用精确有理数独立复现了我的 P 值。

## 六、这个实验不能证明什么（至少三条，以下逐条列出）

1. **不能证明仿射公式、c 的递推、双射这些全称命题**。它们只在 k 不超过 16（或 14、15，按条目）与给定 x 范围上被枚举；有限枚举不构成对全部 k 与全部 x 的证明。这些命题本身是初等恒等式，但本实验给出的是抽样与枚举验证，不是证明。
2. **不能证明不存在非平凡正环**。完备环搜索只覆盖 k 不超过 32 的奇偶向量长度；周期大于 32 的环完全未被触及。文献记录的周期下界是加速映射下 217976794617 量级（该数字出自项目文献笔记 cycles.md，我没有一手核对原文），本实验离该量级差 10 个数量级。负环只有 -1、-5、-17 三族这一事实同样只在 k 不超过 32 上被复核，不排除更长的负环。此外，「完备」二字依赖剪枝完备性与候选解界（见 4.2 第 3 条）这两处本脚本自己给出的论证；这两处论证若错，完备性即失效。
3. **不能把 tau = chi 的检验结果说成对猜想的证明或对更大范围的外推**。我的范围（x 不超过 2^30，以及 tau 不超过 40 的全体 x）完全落在项目文献笔记所记载的 Terras 验证范围（tau 不超过 2592）之内；因此这是用完全不同的方法（直接轨道模拟加向量侧阈值判据）做的一次独立复核，既不是新范围，也不构成证明。此外 x = 1 是已知例外（tau = 2 而 chi 为无穷），必须显式排除。
4. **不能证明 Bernstein 与 Lagarias 的定理**。表 2.1、表 2.2 的逐格相符与「阶等于 2^(n-4)、三条长循环」在 n 不超过 30 上的成立，是对原文定理的一次数值复核；n 不超过 30 的结果不排除 n 更大时定理所描述的模式失效（尽管原文已证明对一切 n 不小于 6 成立，我的计算并未证明这一点）。我给出的原文表数据是自行下载预印本并渲染页面图像读出的，存在人工转录风险，虽然逐格比对全部相符这一点降低了该风险。
5. **不能证明「整除判据足够」**。k 不超过 32 的搜索中没有出现「满足整除性但奇偶向量不一致」的伪命中，这只是范围事实；我没能证明伪命中不存在，也没有证明它们必然存在。
6. **不能把直方图空缺（chi 等于 3、6、9 等的计数为 0）全部当成结构性事实**。其中只有 chi = 3 这一条有简短的结构性论证（首降条件在 k = 3 上自相矛盾）；其余空缺只是 x 不超过 2^30（或 k 不超过 18 的 A(k) 枚举）内的实测结果。
7. **不能给出密度定理的误差项**。实测比值在 X = 2^28 上到 k 约为 200 时偏离 1 约 10%，但这是单一 X 的观测；我没有推导有限区间误差项的界，因此无法说明在别的 X 上偏离会是多少。
8. **不能替代对文献的一手核对**。Terras 1976、1979 与 Böhm 与 Sontacchi 1978 的原文我没有打开（项目文献笔记记录了打开状态）；本文中「Terras 验证到 tau 不超过 2592」「F(135) = 5.3312 乘 10 的负 5 次幂」等均转引自项目笔记，标注为未经我一手核对。
