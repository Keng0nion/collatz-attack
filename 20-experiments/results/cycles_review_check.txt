复核点一：判据排除上界的前提
==========================================================================
M+ = 10781273，M- = 5446237（X0 = Y0 = 10^12）
                 环   k   m  |x_min|   m<=M+   m<=M-  |x_min|>=10^12
       {1,2}（平凡正环）   2   1        1    True    True           False
              {-1}   1   1        1    True    True           False
       {-5,-7,-10}   3   2        5    True    True           False
           {-17 族}  11   7       17    True    True           False
          {0}（不动点）   1   0        0    True    True           False

结论：已知五个环的 m 全部 <= M+ 与 M-，且它们的 |x_min| 全部远小于 10^12，
      因此「不存在奇数步数 <= M± 的环」若不加前提就是错的；
      正确写法是「在 |x| >= X0（即已知环之外）的前提下」。
      判据推导（§2.5 的 X* >= X0 一步）与判据脚本 [4] 节都带了这个前提，
      是 findings 正文的口径漏写，不是计算错误。

==========================================================================
复核点二：百分比基准
==========================================================================
本工作门槛 = 984573000000.0
文献门槛   = 1.09951162778e+12（2^40）
文献/本工作 = 1.1167396  => 文献门槛比本工作高 11.674 %
本工作/文献 = 0.89546393  => 本工作比文献低 10.4536 %

结论：写「本工作比文献低约 12%」用了「高」的分母（11.674%），是错的；
      正确说法是「文献门槛比本工作高约 11.67%」或「本工作比文献低约 10.45%」。
