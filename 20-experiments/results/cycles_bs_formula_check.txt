Böhm 与 Sontacchi 环判据形式核验

[1] 四个已知环：用判据反解 x = c / (2^k - 3^m) 并核验
    从 -17 起加速环长 k = 11，奇数步数 m = 7
    环元素（加速）：[-17, -25, -37, -55, -82, -41, -61, -91, -136, -68, -34]
    奇数步位置：[0, 1, 2, 3, 5, 6, 7]
  正整数环 1 -> 2 -> 1:
    k = 2, m = 1, 2^k - 3^m = 1  [2^k > 3^m（正解条件）]
    c（求和）= 1
    c（递推）= 1  （两法一致：True）
    x = c/(2^k-3^m) = 1 余 0  整数解：True
    判据给出的 x = 1，直接迭代 T^2 后回到自身：True
  负整数环 -1 -> -1:
    k = 1, m = 1, 2^k - 3^m = -1  [2^k < 3^m（负解）]
    c（求和）= 1
    c（递推）= 1  （两法一致：True）
    x = c/(2^k-3^m) = -1 余 0  整数解：True
    判据给出的 x = -1，直接迭代 T^1 后回到自身：True
  负整数环 -5 -> -7 -> -10 -> -5:
    k = 3, m = 2, 2^k - 3^m = -1  [2^k < 3^m（负解）]
    c（求和）= 5
    c（递推）= 5  （两法一致：True）
    x = c/(2^k-3^m) = -5 余 0  整数解：True
    判据给出的 x = -5，直接迭代 T^3 后回到自身：True
  不动点 0 -> 0:
    k = 1, m = 0, 2^k - 3^m = 1  [2^k > 3^m（正解条件）]
    c（求和）= 0
    c（递推）= 0  （两法一致：True）
    x = c/(2^k-3^m) = 0 余 0  整数解：True
    判据给出的 x = 0，直接迭代 T^1 后回到自身：True
  负整数环 从 -17 起的加速环:
    k = 11, m = 7, 2^k - 3^m = -139  [2^k < 3^m（负解）]
    c（求和）= 2363
    c（递推）= 2363  （两法一致：True）
    x = c/(2^k-3^m) = -17 余 0  整数解：True
    判据给出的 x = -17，直接迭代 T^11 后回到自身：True

    四个已知环全部由同一判据复现：True

[2] 随机奇偶向量抽检：两套 c 公式是否逐位一致（k <= 60）
    20000 个随机向量中两法不一致的个数：0

[3] 充分性抽检：对随机向量，若 (2^k - 3^m) 整除 c 则 x 必是 k 步环点
    抽检向量数：400000，其中整除命中 54026 个，全部通过 T^k(x)=x 与奇偶一致性核验

[4] 正负两侧的分界（2^k 与 3^m 的大小）
    正整数环 1 -> 2 -> 1: k = 2, m = 1, 2^k = 4, 3^m = 3, 2^k > 3^m
    负整数环 -1 -> -1: k = 1, m = 1, 2^k = 2, 3^m = 3, 2^k < 3^m
    负整数环 -5 -> -7 -> -10 -> -5: k = 3, m = 2, 2^k = 8, 3^m = 9, 2^k < 3^m
    不动点 0 -> 0: k = 1, m = 0, 2^k = 2, 3^m = 1, 2^k > 3^m
    负整数环 从 -17 起的加速环: k = 11, m = 7, 2^k = 2048, 3^m = 2187, 2^k < 3^m

结论：负数环恰好落在 2^k < 3^m 一侧；判据 x = c/(2^k-3^m) 对两侧同一形式，
      因此「阳性对照」只需去掉 2^k > 3^m 这一条对正解的限制。
