## 一、要证明或要检验的精确陈述

### 1.1 记号（先定义，后计算）

1. `δ := log 3 / log 2 > 1`（论文 Definition 15，`/tmp/h5.txt:505` 至 `:506`）。
2. 设存在 m 圈（非平凡）；`n_1, ..., n_m` 为其局部极小值（按出现顺序，论文 Definition 6，`/tmp/h5.txt:170` 至 `:174`），`n_{m+1} := n_1`；`k_i` 为紧随 `n_i` 的连续奇步数；`K := Σ_{i=1}^m k_i`；`T(n_i) := Σ_{t=0}^{k_i−1} 1/C^t(n_i)`。
3. `x_i := log(n_i + 1)/log 2`（勘误，`/tmp/corr.txt:23` 至 `:26`）。
4. 窗口：`m₂` 个连续局部极小值，按勘误的约定排在 `n_{m−m₂+1}, ..., n_m`；坐标记 `y_j := x_{m−m₂+j}`（`j = 1, ..., m₂`）。
5. `W := (m₂/m)·K`；`v := W·(δ − 1)/(δ^{m₂} − 1)`。
6. `S(y) := Σ_{j=1}^{m₂} 3/(2^{y_j} − 1)`（勘误 `corr.txt:35` 至 `:40`）。

### 1.2 两条可行集

1. 严格版 `P^<`：`y_j ≥ 1`（`j = 1..m₂`）；`y_{j+1} ≤ δ y_j`（`j = 1..m₂−1`）；**回绕** `y_1 < δ y_{m₂}`；`Σ y_j ≥ W`。这是勘误原文列的约束（顶点句 `corr.txt:43` 至 `:46`）。
2. 闭版 `P`：把回绕改写成 `y_1 ≤ δ y_{m₂}`，其余不动。
3. 约束命名：`L_j` 为 `y_j ≥ 1`；`G_j`（`j = 1..m₂−1`）为 `y_{j+1} ≤ δy_j`；`G_{m₂}` 为回绕；`W` 为和约束。共 `2m₂ + 1` 条。

### 1.3 四条待证陈述

1. **陈述 A（窗口引理）**：在「窗口取 Σx 最大」的读法下：(a) `Σx(窗) ≥ (m₂/m)K`；(b) `x_{m−m₂} ≤ x_m`；(c) `x_{m−m₂+1} < δx_m`。
2. **陈述 B（顶点引理）**：`S` 在 `P` 上的最大值在 `P` 的顶点处取到；且 `P` 的顶点集合恰为 `(v, δv, ..., δ^{m₂−1}v)` 的 `m₂` 个循环排列。
3. **陈述 C（闭化无损）**：对每个 `y ∈ P^<` 有 `S(y) ≤ S(v, δv, ..., δ^{m₂−1}v)`。
4. **陈述 D（收尾）**：`Σ_{j=0}^{m₂−1} 3/(2^{δ^j v} − 1) ≤ 3/(2^v − 1) + 3(m₂ − 1)/(2^v − 1)^δ`。

### 1.4 三条被点名的假设（原样陈述）

1. `(H1)` 回收锥含于非负卦限：`rec(P) ⊆ [0, ∞)^{m₂}`。
2. `(H2)` `S` 沿回收方向不增。
3. `(H3)` 可行集可闭化：把回绕的严格不等号读成 `≤` 合法且无损。

4. **Step 4a（已证）：陈述 A(a)。**
   取「`Σx` 最大」的窗 `W*`：`Σx(W*) ≥ Σx(鸽笼窗) ≥ Σk(鸽笼窗) ≥ (m₂/m)K`。中间一步逐项用 `k_i ≤ x_i`（Step 2a），最后一步用 Step 2d。窗口的循环重排是自由的（Definition 6 明说「every cyclic permutation of these minima yields to the same results」，`h5.txt:170` 至 `:174`），与论文第 13 页对鸽笼窗所写的 `W.l.o.g.` 同一手法。

5. **Step 4b（已证）：`(t+1)^δ − t^δ ≥ δ > 1`（`t ≥ 1`）。**
   中值定理：`(t+1)^δ − t^δ = δξ^{δ−1}`，`ξ ∈ (t, t+1)`，而 `ξ ≥ t ≥ 1`、`δ − 1 > 0`，故右端 `≥ δt^{δ−1} ≥ δ > 1`。
   两个用途：(i) 由 `n_{i+1} < n_i^δ` 得 `n_{i+1} + 1 < n_i^δ + 1 < (n_i + 1)^δ`，取对数得 `x_{i+1} < δx_i`（**严格**，与论文第 13 页同一句一致）；(ii) 取 `t = 2^v − 1`（`≥ 1`，因 `v > 1`，Step 3）得 `2^{δv} − 1 ≥ (2^v − 1)^δ`，即陈述 D 的那一步。

6. **Step 4c（已证）：陈述 A(b)。**
   窗 `{m−m₂+1, ..., m}` 与相邻窗 `{m−m₂, ..., m−1}` 长度同为 `m₂`，两和之差为 `x_{m−m₂} − x_m`；由 `W*` 的最大性知该差 `≤ 0`，故 `x_{m−m₂} ≤ x_m`。边界 `m₂ = m` 时没有「窗前一格」，(b) 不用。

7. **Step 4d（已证）：陈述 A(c)。**
   对相邻对 `(m−m₂, m−m₂+1)` 用 Step 2b 得 `x_{m−m₂+1} < δx_{m−m₂}`；与 Step 4c 合并得 `x_{m−m₂+1} < δx_m`（严格）。需要 `m₂ ≤ m − 1`；`m₂ = m` 时直接对 `i = m` 用 Lemma 20 的注记得 `x_1 < δx_m`，而 `x_{m−m₂+1} = x_1`，同样是 (c)。

8. **Step 5（等价于勘误版设定）：假想圈的窗口向量 `x ∈ P^<`。**
   四条约束逐条：(i) `x_j ≥ k_j ≥ 1`（Step 2a）；(ii) 链严格（Step 4b）；(iii) 回绕严格（Step 4d）；(iv) `Σx ≥ W`（Step 4a）。本路线没有任何一步等价于科拉茨猜想本身；最接近「勘误要证的那条」的是 Step 12 的汇合步，其真伪以「假想的 m 圈存在」为条件。

9. **Step 6（已证，替代路线）：`max_P S` 存在。**
   `P` 闭、非空（取 `y_j ≡ a`，`a ≥ max(1, W/m₂)`）。取任一可行点 `y⁰`，`c₀ := S(y⁰) > 0`，令 `L := {y ∈ P : S(y) ≥ c₀}`。若某 `y ∈ L` 的全部坐标都 `> B := log2(1 + 3m₂/c₀)`，则每项 `3/(2^{y_j} − 1) < 3/(2^B − 1) = c₀/m₂`，求和得 `S(y) < c₀`，矛盾；故 `L` 中每点必有一个坐标 `≤ B`，再由链约束（**含回绕**）向前递推 `m₂ − 1` 步得全部坐标 `≤ δ^{m₂−1}B`，又有下界 `≥ 1`，故 `L ⊆ [1, δ^{m₂−1}B]^{m₂}`，紧。又 `L` 闭（`P` 闭、`S` 连续），故 `S` 在 `L` 上取到最大值；而 `P \\ L` 上 `S < c₀ ≤ max_L S`，故 `max_P S = max_L S`，最大值在 `P` 中取到。
   注：这一步只用「水平集有界加闭性」，不需要任何多面体结构定理。

10. **Step 7（已证）：任何极大点都是 `P` 的顶点。**
    设 `y*` 取到 `max_P S`。若 `y*` 不是顶点，则活跃约束的秩 `< m₂`（秩判据：`y ∈ P` 是顶点当且仅当活跃约束的系数行张成 `R^{m₂}`；秩 `< m₂` 时取活跃行空间正交补中的非零 `d`，对充分小的 `ε > 0` 有 `y ± εd ∈ P`：活跃约束保持取等，非活跃约束由有限性与严格性保持严格）。
    于是 `y* ± εd ∈ P`，两者 `S` 值都 `≤ max_P S = S(y*)`；凸性给 `S(y*) ≤ (S(y*+εd) + S(y*−εd))/2`，故两者都等于 `S(y*)`；但 `S` 严格凸（Step 1）且 `d ≠ 0`，给出反向严格不等式，矛盾。故 `y*` 必为顶点。

11. **Step 8（已证）：顶点集合的识别。**
    设 `y ∈ P` 为顶点，则活跃约束的秩 `= m₂`，特别地至少 `m₂` 条约束活跃（`P` 有 `2m₂+1` 条）。下界约束 `L_j` 在 `P` 上永不活跃（Step 9），故活跃约束取自 `{G_1, ..., G_{m₂}, W}`（共 `m₂+1` 条），于是至少 `m₂` 条来自这 `m₂+1` 条。
    若 `G_1, ..., G_{m₂}` 全部活跃，则逐次代入得 `y_1 = δ^{m₂}y_1`，而 `y_1 ≥ 1 > 0`，故 `δ^{m₂} = 1`，与 `δ > 1` 矛盾（勘误原文写「`x_m = δ^{m₂}x_m`, and hence `δ = 1`」，按 `x_m > 0` 读是对的）。
    故：和约束 `W` 活跃，且恰有 `m₂ − 1` 条链约束活跃。取「缺的那条边」把循环图断开，剩下的 `m₂ − 1` 条等式沿一条经过全部 `m₂` 个坐标的通路递推，得 `y` 是 `(a, δa, ..., δ^{m₂−1}a)` 的循环排列；和约束活跃给出 `a·(δ^{m₂} − 1)/(δ − 1) = W`，即 `a = v`。
    反之这些点确为 `P` 的顶点：链约束行的正交补由 `(1, δ, ..., δ^{m₂−1})` 张成，和约束行与它的内积是 `(δ^{m₂} − 1)/(δ − 1) ≠ 0`，故 `m₂ − 1 + 1 = m₂` 条活跃行线性无关，秩 `= m₂`。

12. **Step 9（已证）：可行点处没有坐标等于 1。**
    若 `y_j = 1`，沿链向前递推（含回绕）得 `y_{j+t} ≤ δ^t`，故 `Σy ≤ 1 + δ + … + δ^{m₂−1} = (δ^{m₂} − 1)/(δ − 1) < W ≤ Σy`（严格不等号来自 Step 3 的 `c > 1`），矛盾。

13. **Step 10（已证）：陈述 B 与 C。**
    `S` 关于坐标对称，而顶点族是同一向量的循环排列，故 `S` 在顶点族上是常数，等于 `S(v, δv, ..., δ^{m₂−1}v)`。由 Step 6 与 Step 7，`max_P S` 就取这个值，给出陈述 B。
    该点本身在 `P^<` 里：`v > 1`（Step 3），链约束取等（`≤` 允许），回绕严格（`v < δ·δ^{m₂−1}v = δ^{m₂}v`），和约束取等。于是 `P^< ⊆ P` 给 `S(y) ≤ max_P S = S(v, δv, …, δ^{m₂−1}v)` 对一切 `y ∈ P^<` 成立，这给出陈述 C。（顺带得到比「可闭化」更强的结论：`max_{P^<} S` 也在同一点取到。）

14. **Step 11（已证）：陈述 D。**
    `δ^j v ≥ δv`（`j ≥ 1`）配合 `f` 递减（Step 1）得 `Σ_{j=1}^{m₂−1} 3/(2^{δ^j v} − 1) ≤ (m₂ − 1)·3/(2^{δv} − 1)`；再用 Step 4b(ii)。

15. **Step 12（等价于勘误要证的陈述，汇合）：窗口的 T 和。**
    `T(n_{m−m₂+1}) + Σ_{i=m−m₂+2}^m T(n_i) = Σ_{i=m−m₂+1}^m T(n_i) < Σ_{i=m−m₂+1}^m 3/(2^{x_i} − 1) = S(x) ≤ S(v, δv, …, δ^{m₂−1}v) ≤ 3/(2^v − 1) + 3(m₂ − 1)/(2^v − 1)^δ`
    与勘误（`corr.txt:15` 至 `:22` 的目标式）逐字相符。

**缺口登记**：本路线的论证链上没有未解缺口；未做到的只有两处复核动作（Step 3 的渲染图复核、Step 2 各条抽取文本的逐页核对），已在该步就地标明。

## 三、三条被点名假设的显式推导，及「其中两条不必要」的判定

1. **(H1) 已证。** `rec(P) = {d : A(y + td) ≤ b 对一切 y ∈ P、t ≥ 0} = {d : Ad ≤ 0}`（`P = {y : Ay ≤ b}`）。取下界约束那一行：约束是 `−y_j ≤ −1`，故 `d` 必须满足 `−d_j ≤ 0`，即 `d_j ≥ 0`。故 `rec(P) ⊆ [0, ∞)^{m₂}`。
   附注（同一式）：若 `d, −d ∈ rec(P)`，则 `d ≥ 0` 且 `−d ≥ 0`，故 `d = 0`，即 `P` 不含直线。这一条是经典极点表示定理的前提，但本报告主论证不用它（见下条）。
2. **(H2) 已证。** 对 `d ∈ rec(P)` 有 `d ≥ 0`，故 `y + td ≥ y` 逐坐标成立；而 `S` 逐坐标递减（Step 1），故 `S(y + td) ≤ S(y)`。
3. **判定：`(H1)` 与 `(H2)` 对结论不必要（我的结论，附理由）。** 它们是「`P = conv(顶点) + rec(P)`，再对凸组合用 Jensen」这条经典路线的前提；那条路线还要额外引用极点表示定理（本报告未证）。而 Step 6 与 Step 7 用的是「水平集有界加闭性」与「严格凸性加秩判据」，全部初等，且直接给出「极大点即顶点」。故 `(H1)`、`(H2)` 与极点表示定理都不是缺口，而是可以整条绕开的替代路线；项目内 `rederivation-erratum.md:83` 与 `:363` 的两种补法走的是经典路线，按本条判定：其结论成立，但前提可减弱。
4. **(H3) 已证。** `P^< ⊆ P` 作为集合包含（把 `<` 放宽成 `≤`），故 `sup_{P^<} S ≤ max_P S`，而后者由 Step 10 等于 `S(v, δv, …, δ^{m₂−1}v)`；再由 Step 10 末句，该点本身就在 `P^<` 中，故闭化连一点损失都没有。
   附注（表述问题）：勘误原文写「attains its maximum value at a vertex of the polytope determined by … `x_{m−m₂+1} < δx_m` …」，而含严格不等号的集合不是闭多面体，谈不上「顶点」，字面上不成立；闭化之后才成立，且按本条无损。这是「表述修正」，不是新数学。


则

1. `P^< ⊆ P`；
2. S 在 P 上的最大值存在；
3. S 在 P 上的**每一个**最大值点都是 P 的顶点；
4. P 的顶点集合恰为 `(v, δv, …, δ^{m₂−1}v)` 的 m₂ 个循环排列，其中 `v := W(δ−1)/(δ^{m₂}−1)`，且这些点都在 `P^<` 中；
5. 于是 `max_P S = max_{P^<} S = S(v, δv, …, δ^{m₂−1}v)`。

**应用（勘误版需要的那一条）**：取 `W = (m₂/m)·K`，则 (P1) 由 Theorem 21 的前置条件与 `c > 1` 给出（见 Step 3 与 10.1 第 4 条）；窗口向量 x 满足 `x ∈ P^<`（Step 5），故

```text
Σ_{i=m−m₂+1}^m T(n_i)  <  S(x)  ≤  S(v, δv, …, δ^{m₂−1}v)  ≤  3/(2^v − 1) + 3(m₂ − 1)/(2^v − 1)^δ
```

口径：本条全部在勘误版内；不使用印出版的那一步，不引用第三方 m ≤ 82，不动 X₀ 与 `1.4784·m·δ^m`。

### 10.3 编号论证（每步标注）

4. **Step 4（已证）**：四条子结论。4a：最大窗满足 `Σx ≥ Σk(鸽笼窗) ≥ (m₂/m)K`（逐项 `k_i ≤ x_i`）；4b：`(t+1)^δ − t^δ = δξ^{δ−1} ≥ δt^{δ−1} ≥ δ > 1`（中值定理，`ξ > t ≥ 1`），故 (i) `x_{i+1} < δx_i`（取 `t = n_i`），(ii) `2^{δv} − 1 > (2^v − 1)^δ`（取 `t = 2^v − 1 ≥ 1`）；4c：窗 `{m−m₂+1, …, m}` 与 `{m−m₂, …, m−1}` 之和差为 `x_{m−m₂} − x_m`，最大性给 `x_{m−m₂} ≤ x_m`；4d：由 4b(i) 与 4c 得 `x_{m−m₂+1} < δx_m`。

6. **Step 6（已证）**：`max_P S` 存在。P 闭且非空（取 `y_j ≡ max(1, W/m₂)`）；取 `y⁰ ∈ P`、`c₀ := S(y⁰) > 0`；若 `y ∈ P` 的全部坐标 `> B := log₂(1 + 3m₂/c₀)`，则每项 `< c₀/m₂`，故 `S(y) < c₀`；于是水平集 `L := {y ∈ P : S(y) ≥ c₀}` 的每点至少有一坐标 `≤ B`，再由链约束（含回绕）向前推 `m₂ − 1` 步得全部坐标 `≤ δ^{m₂−1}B`，配合下界得 `L ⊆ [1, δ^{m₂−1}B]^{m₂}` 紧；L 闭、S 连续，故 `max_L S` 存在；而 `P ∖ L` 上 `S < c₀ ≤ max_L S`，故 `max_P S = max_L S`。此步只用闭性与水平集有界，不用任何多面体表示定理。
7. **Step 7（已证）**：任一最大值点都是顶点。秩判据：`y ∈ P` 是顶点当且仅当其活跃约束的系数行张成 `R^{m₂}`（两个方向都给出：秩满时若 `y = λu + (1−λ)v`，每条活跃行被迫在 u、v 上同时取等，故 `u − v` 正交于张成组，`u = v`；秩不满时取正交补中 `d ≠ 0`，得 `y ± εd ∈ P`）。若最大值点 `y*` 非顶点，取这样的 d 与充分小 ε，则 `y* ± εd ∈ P`，最大值性给
   `S(y*) ≤ (S(y* + εd) + S(y* − εd))/2`，而严格凸性（Step 1，`d ≠ 0`）给反向严格不等式，矛盾。
8. **Step 8′（已证，本轮改写）**：顶点集合的识别，分四条。
   1. 记链约束行 `G_j := y_{j+1} − δy_j`（`j = 1, …, m₂`，下标循环）。全部 m₂ 条 G 行线性无关：它们组成的矩阵为 `C = S_m − δI`（`S_m` 是 m₂ 轮换置换矩阵），C 的特征值为 `ζ − δ`（ζ 跑遍全部 m₂ 次单位根），故 `det C = ∏_ζ (ζ − δ) = (−1)^{m₂}(δ^{m₂} − 1) ≠ 0`（δ > 1）。脚本 [8] 以 δ 为符号变量在 m₂ = 2 至 6 上核对了同一恒等式。
   2. 任一可行点处下界约束不活跃（Step 9）；全部链约束同时取等也不可行（绕一圈得 `y_1 = δ^{m₂}y_1`，而 `y_1 ≥ 1 > 0`，故 `δ^{m₂} = 1`，与 δ > 1 矛盾）。故一个顶点至多有 `m₂ − 1` 条链约束活跃；秩判据要求至少 m₂ 条活跃约束，可用的只有 m₂ 条链约束加和约束这 m₂ + 1 条，于是恰为「和约束活跃 + 恰 m₂ − 1 条链约束活跃」。
   3. 删去第 `j₀` 条链约束后，其余 m₂ − 1 条 G 行的正交补是一维的，由「断点在 `j₀`」的循环等比向量 w 张成：`w_{j₀+1+t} = δ^t`（`t = 0, …, m₂ − 1`，下标循环）。对 `j ≠ j₀` 有 `w_{j+1} = δw_j`，故 `⟨G_j, w⟩ = 0`；而 `⟨(−1, …, −1), w⟩ = −(δ^{m₂} − 1)/(δ − 1) ≠ 0`，故这 m₂ − 1 条 G 行与和行线性无关，秩恰为 m₂。脚本 [8] 逐 (m₂, j₀) 验证了子阵秩、该正交性与该内积非零。
   4. 解「和约束取等 + 除 `G_{j₀}` 外全部取等」的方程组（系数行列式按第 3 条非零，解唯一）：得 y 是 `(a, δa, …, δ^{m₂−1}a)` 的循环排列；和约束给 `a(δ^{m₂} − 1)/(δ − 1) = W`，即 `a = v`；被删的那条约束因 `δ^{m₂}v > v` 自动满足。故顶点集合恰为该族的 m₂ 个循环排列，且每个都是顶点。
   与第九节的差别在第 1 条与第 3 条：前九节用一句「活跃行空间的正交补」概括，本轮展开为可逐行核对的显式论证。
9. **Step 9（已证）**：可行点无坐标等于 1。若 `y_j = 1`，沿链一圈得 `y_{j+t} ≤ δ^t`，故 `Σy ≤ (δ^{m₂} − 1)/(δ − 1) < W ≤ Σy`，矛盾；「< W」用的正是 (P1)（Step 3 推论）。脚本 [4] 以精确有理枚举核对：固定任一坐标等于 1 后 `Σy` 的最大值恒等于 `(D^{m₂} − 1)/(D − 1)`，42 个 (D, m₂, j) 组合全部一致。

### 10.4 三条被点名假设的显式推导，及「其中两条不必要」的判定
