## 三、结论（按证据强度分层）

### 3.1 已证（自足纸面论证；未形式化、未经第三方复核）

1. **顶点引理**（前提 (P1)：`W > (δ^{m₂} − 1)/(δ − 1)`）：`max_P S` 存在；每个极大点都是 P 的顶点；P 的顶点集合恰为 `(v, δv, …, δ^{m₂−1}v)` 的 m₂ 个循环排列（`v = W(δ−1)/(δ^{m₂}−1)`）；该点落在严格版 `P^<` 内，故
   `max_P S = max_{P^<} S = S(v, δv, …, δ^{m₂−1}v)`
   （闭化**零损失**，比「闭化后上界仍安全」更强）。三路独立书写：`route-1.md:273` 至 `:330`（含 `det C = (−1)^{m₂}(δ^{m₂} − 1)` 与「删一条链约束」的显式线性代数）、`route-2.md:42` 至 `:58`、`route-5.md:120` 至 `:154`。
2. **(P1) 不可省**：v < 1 时顶点分类失效。反例：m₂ = 2、δ = 3/2、W = 3/2，P 的顶点集合恰为 `(1,1)`、`(1,3/2)`、`(3/2,1)`，与预测族不相交（`route-1.md:319`）。应用里 (P1) 由已证的 `c > 1` 满足（`c = 60 + log₂(112590/97) > 61`，手算证明）。
3. **更强的坐标下界**：`y_j ≥ v` 对一切可行点与一切坐标成立（z3 精确 LRA 断言 `P ∧ (y_j < v)` 为 unsat；4393 个可行样本上精确最小比 = 1.000000000000）。它顺带把勘误「先排除 `x_i = 1`」那一步的字面跳跃绕开成一条真命题。
4. **读法缺口收口**：收口为「显式假设按 Σx 读」加自足替代表述（直接取 Σx 最大窗，构造 R2），不再依赖原文措辞。按 Σk 读不行的三条独立证据：m = 4 的整数等价链反例、`route-3.md:101` 的反例、`P′` 上的显式反例 `y* = (W − m₂ + 1, 1, …, 1)`。
5. **「Ψ 关于 K_lo 非降」**：两条路线独立给出四步初等证明（`route-3.md:146` 至 `:151`、`route-4.md:153` 至 `:167`），并经逐行复核。此前的项目状态只有「作者自述的推理加 11 点网格」。
6. **m = 92 旧句为假，撤回方正确**：两条独立的越界见证与一个区间阈值（见 3.2 第 1 条）。
7. **结构性结论**：38 条假设账本的依赖闭包无环（0 个环）；TARGET 的闭包 27 个节点且不含印出版已否证步与已撤回断言；顶点句只用定理 21 的假设 (H21)，不用待证尾项界，故无循环引用。

### 3.2 数值观察（未证，引用必须标注）

1. **m = 92 被排除型的越界阈值**：`K_cross ∈ [313195478959172262767.2965, 313195478959172262933.83]`（200 轮二分，相对宽度 5.3×10⁻¹⁹），小于 `U(92)`；两侧台阶值分别是 `Ψ = K*` 与 `Ψ = 7941964418702608664581`。越界见证：`K_lo = 3.3×10²⁰` 给 `Ψ = 7941964418702608664581 > U(92)`；`K_lo = U(92)` 给 `Ψ = 1.5678296618531818732906×10²² > U(92)`。

### 3.3 结论层（可直接对外写的统一表述）

> **m = 92 不被排除。** 直接依据：从 SdW v1.44 给出的合法起点下界 `L = 7.5311×10¹¹` 出发，自举链在 `77692117359936589403` 处停滞（不动点），远低于 `U(92) = 1.4784·92·δ⁹² = 343025970248850209780.0748`，比值 `0.2264904820575957716256207`。**加强（条件性）**：Ψ 关于起点非降（两条独立初等证明，未形式化、未经第三方复核）且 `Ψ(K*) = K* < U(92)`（数值观察），故一切 `K_lo ≤ K*` 的起点都不能排除 m = 92。**不得再引**：「对起点稳健——即使虚构起点 `K > 10²⁰`，链也只走到 `2.0563×10²⁰`」；该句作为全称是假，作为区间读法 `[L, U(92)]` 也是假。
