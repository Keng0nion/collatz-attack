## 一、本轮目标（一句话）

给「m = 92 起不排除」这条条件性加强所依赖的唯一未证前提 `Ψ(K*) = K*`（`K* = 205632218873398596256`）一条非网格来源：一轮之内产出严格证明、严格区间证书或严格否证三者之一，并把「K* 是 `[L, K_cross)` 内最大不动点」与「K_cross 的 19 位定位」按证据类型分开登记。

这是二级目标（一级目标是证明科拉茨猜想）。它不动 m 的上限，也不动验证界，只把 m = 92 那一格的支撑依据从「数值观察」升级或降级。

## 三、本轮目标的精确形态

### 3.1 待判命题

**(F)**：`Ψ(K*) = K*`。其中：

1. `K* = 205632218873398596256`（即 2.05632218873398596256×10²⁰）；
2. `Ψ(K)` 是项目口径下的自举映射：在区间 `(δ, δ + ε_opt(K))` 内分母最小的分数之分母（用 Hercher 论文 Lemma 22 的连分数公式），`ε_opt(K) = min{ ε(m₂, K) : m₂ 可行 }`（`70-research/cycle-1/scripts/r4x_core.py:30` 至 `:31`）；
3. `ε(m₂, K) = (A(m₂) + 3/(2^v − 1) + 3(m₂ − 1)/(2^v − 1)^δ) / (3 K log 2)`，`v = (m₂/m)K(δ − 1)/(δ^{m₂} − 1)`；`A(m₂)` 的三段形式见 `r4x_core.py:92` 至 `:105`。

### 3.2 现有证据（本轮只作转引，未复算）

1. 两套独立实现、两级精度一致，仍标「未证」（`70-research/cycle-1/summary.md:46`）。
2. 在 K* 这一格，连分数分歧法记录 `k = 42`、`ck = 2`、γ 分母等于 `205632218873398596256`、「在区间内？True」，并打印左右余量 `6.24468×10⁻⁴³` 与 `8.34875×10⁻⁴²`（`70-research/cycle-1/scripts/results/r4x_run3.out:8`，本轮读过该行）。
3. **同一格还缺一次独立的最小性穷举**：`r4x_run4.py` 的修正清单穷举在其覆盖的六个参数上全部与 Lemma 22 一致（`scripts/results/r4x_run4.out:10` 至 `:15`），但那六个参数里**没有 K***（`r4x_run4.py:74` 至 `:75` 的 CASES 只到 7.53×10¹¹、7.77×10¹⁹、3.3×10²⁰、3.43×10²⁰，本轮逐行读过）。这是本轮最便宜的一条真实空缺。

## 四、子问题（五条，可独立攻击）

1. **K* 的定义链条**：K* 是哪一个 m₂、哪一种约定（`min_eps` 还是 `max_feasible`）、哪一个 K 之下的输出？`route-3.md:137` 记「最优 `m_2 = 89`」，`route-4.md:141` 记「末步 `m2 = 88`」，`ledger.md:23` 记「m₂ = 88 处链的不动点」，三者如何统一？两种约定下 `Ψ(K*)` 是否同值（若不同值，先裁决定义，再谈命题）？
2. **落点不等式的严格化**：`p/K* ∈ (δ, δ + ε_opt(K*))`（取 `p = ceil(δ K*)`）能否用严格有理界证明？现有余量在 10⁻⁴² 至 10⁻⁴³ 量级（`r4x_run3.out:8`），必须给出 δ、`2^v − 1`、`(2^v − 1)^δ` 与 ε 的严格上下界，才能排除「余量算错」。
3. **最小性的完备证书**：「区间内不存在分母小于 K* 的分数」能否由收敛与半收敛清单**完备**给出？在 K* 这一格（`k = 42`、`ck = 2`）还缺哪些前提：端点无理、连分数数字的严格性、清单截断、以及 Lemma 22 在有理端点的弱化（`route-4.md:280` 至 `:283`）？
4. **ε_opt 的取法**：K* 处 ε 最小的 m₂ 与论文链条读法所用的 m₂ 不同，后果是什么？两种约定下 (F) 是否都成立？「Ψ 的定义」应以哪一种为准（并说明它与论文 Theorem 21 及勘误的用法是否一致，须回一手原件核对）？
5. **极大性与平台性**：`K* 是 [L, K_cross) 内最大不动点`（现为数值观察，`route-4.md:188` 至 `:190`）需要什么？`route-4.md:230` 的「当且仅当」除 (F) 与非降性外，是否还需要 `(K*, K_cross)` 上的平台性？本轮若不能证，按哪种证据等级登记，并给出下一轮的最小入口。

## 五、攻击路线（五条，方法互不相同）

1. **name**：连分数严格证书
   **mission**：严格有理算术路线。不复用 `r4x_core.py` 的浮点路径，只借 `r4x_rig_helpers.py` 的 δ 严格有理界，自己实现 `v`、`2^v − 1`、`(2^v − 1)^δ`、`ε(m₂, K*)` 的有理上下界，得到 δ 与 `δ + ε_opt(K*)` 的有理区间；再用精确连分数展开（`fractions` 递归，不借 mpmath）得到 γ，输出 γ 与 K* 的比较证书，含左右余量的严格界与所依据的 δ 界宽度（既有 δ 界宽度约 1.8×10⁻²⁴⁴，见 `scripts/results/r4x_run4.out:7`）。判据：退出码 0，且证书判定 γ 等于 K* 或给出反证。禁止把 mpmath 的分歧法输出当证书。

2. **name**：收敛与半收敛清单穷举
   **mission**：枚举对拍路线。把 `r4x_run4.py` 的 G2 式穷举补跑到 K* 本身（现缺这一格，见 `r4x_run4.py:74` 至 `:75`），并在 `min_eps` 与 `max_feasible` 两种约定下各跑一遍，另跑「小分母直接搜索」（G3 式）作反向核验。判据：两种约定下最小分母都给 K*；若不一致，如实报出并把它升级为子问题 1 的定义裁决，而不是取有利的一方。

3. **name**：落点不等式的初等化归
   **mission**：纸面解析路线。把 (F) 化归为有限的不含浮点的比较：写出 `p` 的确定方式，把 `p/K* − δ < ε_opt(K*)` 展开成显式不等式组（ln2 与 ln3 的有理界、幂函数与指数的界），并写出最小性要用到 Lemma 22 的哪一条与哪些前提。若某一步不可初等化，把那一步写成新的门槛登记（精确化本身是增量，不是失败）。方法：纯手算与公式变形，数值只作锚点自检，不写引理名以外的引用。

4. **name**：敌意否证探针
   **mission**：反例搜寻路线（对抗）。设定明确否证判据：在 K* 的严格有理邻域与 `[L, K_cross)` 上搜索三类反例，即 `Ψ(K) < K*` 的点、大于 K* 的不动点、使 γ 不等于 K* 的 K。找到即产出可核查见证；找不到只写成核对边界，**不得写成「已证」**（`learnings.md:44`）。方法：定向搜索加严格有理比较，实现与路线 1 互不复用代码。

5. **name**：一手原件复算与定义裁决
   **mission**：文献复算加定义审计路线。重下 `hercher5.pdf` 与 `corrigendum.pdf` 并自行核对 md5（第 1 轮计划第七节第 2 条记的两个本机历史值见 `70-research/cycle-1/plan.md:107` 至 `:108`；须自行复测，不得照抄），逐字核对 Lemma 22 与 Theorem 21 的陈述（ε 的指数位置、A 的三段形式、m₂ 的可行条件、窗口与回绕约束），据此把「Ψ 的定义」写死成唯一一份可引用定义（含约定、区间端点开闭、K* 属于哪一个 m₂ 的输出），裁决子问题 1 与 4；并携带落盘：把 `audit-report.md:193` 与 `:221` 的「Ψ 非降未证」更新为现行状态，把引用补上 md5 与行数。判据：定义表与两份脚本的**实跑**输出逐项对齐，不许引旧日志。
