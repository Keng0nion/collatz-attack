## 三、落点不等式的显式不等式组

### 3.1 输入：ln 2 与 ln 3 的严格有理界（初等）

`ln 2 = 2·atanh(1/3) = 2·Σ_{k≥0} (1/3)^{2k+1}/(2k+1)`（各项为正，部分和为下界）；
`ln 3 = ln 2 + 2·atanh(1/5)`；
尾界 `Σ_{k>N} x^{2k+1}/(2k+1) < x^{2N+3}/((2N+3)(1 − x²))`（初等几何级数比较）。
取 `N = 60`：实跑 `ln2 区间宽度 = 3.770×10⁻⁶¹`、`原始 delta 区间宽度 < 1e-55`、向内取整到分母 10⁸⁰ 后 `delta 区间宽度（取整后）= 1.406×10⁻⁶⁰`，`[PASS] 向内取整仍是严格界` 两条。

### 4.3 替代路线：Farey 邻元引理（不需要 Lemma 22 的一般形式）

**引理（初等，两行）**：若 `a/b < c/d` 且 `bc − ad = 1`，则一切满足 `a/b < u/v < c/d` 的分数都有 `v ≥ b + d`。

**用在本格**（三段覆盖 `(δ, δ + ε_opt)`）：

1. `δ ∈ (F(1), F(2))`（由 (P1) 的柱体归属），`δ + ε_opt ∈ (F(2), F(3))`（由 (L)、(U)）；

4. 而 `γ ∈ (δ, δ + ε_opt)` 本身分母恰为 `K*`。

**结论**：`(δ, δ + ε_opt(K*))` 内无分母小于 `K*` 的分数。**证据类型：已证（初等，判据全为精确整数）**。
