### 1.2 Theorem 21 逐字（第 13 页渲染图核对；`pdftoppm -png -r 150 -f 13 -l 15 h5.pdf pg`）

本轮把第 13、14、15 页渲染成 PNG 后逐字读过（抽取文本把分式与上标压平，不可直接引用）。逐字转写：

> **Theorem 21.** *Let K be the number of odd numbers in a given m-cycle, and let L be the number of even numbers in it. Further, assume there exists a positive integer m₂ with*
> m₂ ≤ m *and* (δ^{m₂} − 1)/(δ − 1) · log((162/97)·X₀)/log(2) ≤ (m₂/m)·K.
> *Let* v = (m₂/m)·K·(δ−1)/(δ^{m₂}−1). *Then we get*
> δ < (K+L)/K < δ + 1/(K·3 log(2)) · ( (97(m − m₂) + 73)/(54·X₀) + 3/(2^v − 1) + 3·(m₂ − 1)/((2^v − 1)^δ) ).
> *If m₂ = m − 1 we get the better estimate*
> δ < (K+L)/K < δ + 1/(K·3 log(2)) · ( 3/X₀ + 3/(2^v − 1) + 3·(m − 2)/((2^v − 1)^δ) )
> *and for m₂ = m*
> δ < (K+L)/K < δ + 1/(K·3 log(2)) · ( 3/(2^v − 1) + 3·(m − 1)/((2^v − 1)^δ) ).

**四项裁决点（本轮的核对结论）**：

1. **ε 的指数位置**：末项是 3·(m₂−1)/((2^v − 1)^δ)，即 δ 是括号 **(2^v − 1)** 的指数，不是 2 的指数。勘误给出的中间量是 3(m₂−1)/(2^{δv} − 1)，再换成 (2^v − 1)^δ（因 2^{δv} − 1 > (2^v − 1)^δ）。项目 `r4x_core.py:100` 至 `:105` 用的就是 (2^v − 1)^δ，**与印出版一致**。
2. **A(m₂) 的三段形式**：一般式 (97(m − m₂) + 73)/(54·X₀)；m₂ = m − 1 时为 3/X₀（第 14 页证明末段逐字：「For m₂ = m − 1, the first sum ∑^{m−m₂}_{i=1} T(n_i) = T(n₁) can be better bounded above by 3/X₀, as seen in Remark 7」）；m₂ = m 时该项为 0（同页：「For m₂ = m, this first sum is empty and therefore zero」）。**注意 3/X₀ 与一般式代入 m₂ = m−1 得到的 170/(54X₀) 不是同一个数**（3 < 170/54 ≈ 3.1481，故第二段确实「better」）；项目 `r4x_core.py:92` 至 `:97` 的写法与印出版一致。
3. **m₂ 的可行条件**：`m₂ ≤ m` 且 (δ^{m₂} − 1)/(δ−1) · log((162/97)X₀)/log(2) ≤ (m₂/m)K。左端关于 m₂ 指数增长、右端线性增长，故可行集是 `{1, 2, …, m₂_max(K)}` 形式的**下段**（本轮 `c2r5_defaudit.py` 第 1 节的可行门槛表逐格实测）。定理原文首段还提到「若唯一满足该不等式的非负整数是 m₂ = 0」（逐字：*If the only nonnegative integer fulfilling the given inequality is m₂ = 0, Corollary 17 and Corollary 19 give good upper bounds*）——即 m₂ = 0 不入本定理，可行集只在**正整数**中取。
4. **窗口与回绕**：第 13 页逐字：「There are m₂ consecutive local minima which are directly followed by at least (m₂/m)·K o-steps in total. (If this would not be the case, all of the sums k₁+···+k_{m₂}, k₂+···+k_{m₂+1}, … and k_m+k₁+···+k_{m₂−1} would be smaller than (m₂/m)·K. But adding these m sums together gives m₂·K, as every k_i occurs in exactly m₂ such sums and ∑k_i = K, which contradicts the assumption.) W.l.o.g., let these m₂ consecutive local minima be n_{m−m₂+1}, …, n_m.」——**窗是循环（回绕）窗**（含 k_m + k₁ + …），选定后按循环旋转把窗放到末尾，这是「窗口」与「回绕」的两条约束的全部原文依据。

### 1.3 Lemma 22 逐字（第 15 页渲染图核对）

> **Lemma 22.** *Let 0 < α < β be two real numbers with continued fraction expansions* α = [a₀; a₁, …, a_{k−1}, a_k, …] *and* β = [a₀; a₁, …, a_{k−1}, b_k, …]. *Then every fraction in the open interval (α, β) has a denominator which is not smaller than the one of* γ = [a₀; a₁, …, a_{k−1}, c_k] *with* c_k = min(a_k, b_k) + 1.

**三项裁决点**：

1. **区间是开的**：逐字「in the open interval (α, β)」；第 15 页同页还有「nonempty open interval」（`h5.txt:143` 亦有）。项目把 Ψ 定义成开区间内的最小分母，与原文一致。
2. **两种 parity 都印全**：k 偶时「increasing the partial denominator increases the fraction」，得 a_k < b_k 与 [a₀;…,a_k] < α < [a₀;…,a_k+1] < β；k 奇时「decreasing the partial denominator increases the fraction」，得 a_k > b_k 与 α < [a₀;…,b_k+1] < β < [a₀;…,b_k]。两种情形都给 c_k = min(a_k, b_k) + 1。**这意味着 c_k 的取法与 k 的 parity 有关，但结论形式统一**；实现时不能只处理一种 parity（旧材料只记了奇数支，本轮补全）。
3. **它只给「不小于」，要成为「最小」还须 γ 落在区间内**：这是本轮证书显式核对的一条（`c2r5_cert.py` 第 2 节打印 γ > δ_hi 与 γ < β_lo 两个严格比较）。

## 二、Ψ 的定义（唯一可引用的版本）

以下定义是本轮把印出版 Theorem 21、Lemma 22 与项目实现（`r4x_core.py`）逐项对齐后的产物。**凡项目内引用 Ψ 的地方，请引用本节编号（D1）至（D8），不要再引各脚本的 docstring。**

**(D1) 映射 m ↦ δ、X₀、C。** δ := log 3 / log 2（Definition 15，`h5.txt:506`）；X₀ := 695·2⁶⁰ = 801280445701758648320（Definition 4 印出版）；C := log₂((162/97)·X₀) = 70.1808063283083640726545127109…（本轮严格区间 [70.18080632830836407265451271, 70.18080632830836407265451271]，宽度 7.9×10⁻⁹⁹）。

**(D2) 可行集。** 固定整数 m ≥ 2 与实数 K > 0：

> F_m(K) := { m₂ ∈ ℤ : 1 ≤ m₂ ≤ m 且 geom(m₂)·C ≤ (m₂/m)·K }，其中 geom(m₂) := (δ^{m₂} − 1)/(δ − 1)。

（不取 m₂ = 0；见第 1.2 节第 3 条。）F_m(K) 是形如 {1, …, m₂_max(K)} 的下段；等价地 m₂ ∈ F_m(K) 当且仅当 K ≥ K_thresh(m₂) := (m/m₂)·geom(m₂)·C。

**(D3) 每格的界。** 对 m₂ ∈ F_m(K)：

> v(m₂, K) := (m₂/m)·K·(δ − 1)/(δ^{m₂} − 1)；
> A(m₂) := 0（m₂ = m）、3/X₀（m₂ = m − 1）、(97(m − m₂) + 73)/(54·X₀)（其余）；
> ε(m₂, K) := [ A(m₂) + 3/(2^{v} − 1) + 3(m₂ − 1)/((2^{v} − 1)^{δ}) ] / (3·K·log 2)。

**(D4) 两种约定。**

> **约定 M（min_eps，最紧）**：ε_opt^M(K) := min{ ε(m₂, K) : m₂ ∈ F_m(K) }，取到最小值的 m₂ 记为 m₂*(K)。
> **约定 F（max_feasible，论文链条读法）**：ε_opt^F(K) := ε(m₂_max(K), K)。

约定 M 是定理 21 的**逐格取最紧**读法（定理对每个可行的 m₂ 都给一个上界，故可取下确界）；约定 F 是论文 Theorem 23 七步链的实测读法（见第 4 节）。恒有 ε_opt^M(K) ≤ ε_opt^F(K)，故 Ψ^M ≥ Ψ^F。

**(D5) Ψ 的定义（开区间、最小分母）。**

> 对 K > 0 且 F_m(K) ≠ ∅：Ψ_m(K) := min{ q ≥ 1 : 存在整数 p 使 p/q ∈ (δ, δ + ε_opt^M(K)) }（区间**两端都开**）。
> 若 F_m(K) = ∅：Ψ_m(K) 无定义（定理 21 首段把它交给 Corollary 17 与 19，本项目不对该情形使用 Ψ）。
> 若采用约定 F，记 Ψ_m^F(K) 为同一公式但把 ε_opt^M 换成 ε_opt^F。

**(D6) 定理 21 给出的结论（Ψ 的用途，来自 Theorem 21 与 Lemma 22，不是定义）。** 设存在 m 圈，其奇数元素数（步数）为 K。则对每个 m₂ ∈ F_m(K)：δ < (K+L)/K < δ + ε(m₂, K)。由于 (K+L)/K 约分后分母整除 K，且它落在 (δ, δ + ε_opt^M(K)) 内，于是

> **K ≥ Ψ_m(K)**（对固定的 m，这是定理 21 加 Lemma 22 给出的 K 下界映射）。

**(D7) 自举链。** K₀ 给定，K_{n+1} := Ψ_m(K_n)（越界判据：若某步 K_{n+1} > U(m) 则排除该 m；U(92) = 1.4784·92·δ⁹² ≈ 3.4302597×10²⁰，来自 Simons 与 de Weger 定理 3 的引用形式，本项目口径）。

**(D8) 与项目实现的对应。** `r4x_core.py:150` 至 `:170` 的 `best_m2(convention)` 正是 (D4) 的两种约定；`r4x_core.py:173` 至 `:212` 的 `psi()` 返回 (D5) 的值（用连分数分歧法实现 Lemma 22）；`A_of`（`:92` 至 `:97`）与 (D3) 一致；`feasible`（`:84` 至 `:85`）与 (D2) 一致。本轮新增的严格实现是 `70-research/cycle-2/scripts/c2r5_rig.py`（自足有理区间库，不 import 项目浮点路径）。

**一处必须写清的措辞**：(D5) 的 Ψ 用**开区间**；「K ≥ Ψ_m(K)」这条结论对开闭端点的敏感性为零，因为定理 21 给的是严格不等式（δ < (K+L)/K < δ + ε）；而 Lemma 22 只对开区间陈述最小分母，故定义取开区间是唯一与 Lemma 22 相配的取法。

### 5.3 证书用到并自证的三条引理

**引理 1（Stern-Brocot 最小分母）**：设 A < B 为有理数。从 0/1 与 1/0 出发，反复做「整段跳」（左端 x/y 保持、右端 z/w 保持，取最大 k 使 (x + kz)/(y + kw) ≤ A 并跳到那里；右边对称），首个严格落在 (A, B) 内的中项 (x + z)/(y + w) 就是区间内分母最小的分数，其分母 = y + w。
证明：起点 z y − x w = 1；跳过单步与整段跳都保持该 unimodular 关系（对 (x + kz, y + kw) 与 (z, w)：z(y + kw) − (x + kz)w = zy − xw = 1，右侧对称同理）。于是括号内任意 p/q 满足 p/q − x/y ≥ 1/(q y) 与 z/w − p/q ≥ 1/(q w)（分子为整数不为零），相加得 1/(y w) = z/w − x/y ≥ (y + w)/(q y w)，即 q ≥ y + w；而返回时中项的分母恰为 y + w 且中项在区间内，故它就是最小分母。【本引理是自足证明，脚本 `c2r5_rig.py:simplest_fraction` 的 docstring 同。】

**引理 2（连分数前缀的区间证书）**：给定 r ≤ s，若 r 与 s 的整数部分相同（设为 n）且 r > n，则 [r, s] 内每点的连分数展开首位都是 n；把二者按高斯映射 1/(x − n)（在 (n, n+1) 上连续递减）变换后递归，即得任意长度的公共前缀证书。【脚本 `c2r5_rig.py:certified_prefix`。机制测试：`certified_prefix(415/93, 415/93) = [4, 2, 6]` 与真值 [4; 2, 6, 7] 的前缀一致；δ 的 120 位证书与 mpmath 抽取的前 120 位在**同一精度口径**下一致（首次对照用的是 59 位截断值与 120 位证书，故不一致，已改为同位对照）。】

**引理 3（可行性 ⟺ v ≥ C）**：m₂ ∈ F_m(K) ⟺ v(m₂, K) ≥ C。证明：把 K_thresh(m₂) = (m/m₂)·geom(m₂)·C 代入 v = (m₂/m)K(δ−1)/(δ^{m₂}−1)，得 v = C；又 v 关于 K 严格增，两边同真同假。【用于第六节的单调性论证。】
