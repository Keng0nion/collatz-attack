## 二、编号论证

### 2.1 引理 A（ε_opt 非增）——已证（本路线自证，初等）

1. **(A1)** 固定 m₂：`v(m₂,K) = (m₂/92)K/geom(m₂)` 关于 K 严格增（系数为正，因 `δ > 1 ⟹ geom(m₂) > 0`）；`t ↦ 2^t − 1` 与 `t ↦ t^δ` 均严格增取正，故 `ε(m₂,K)` 的方括号内关于 K 非增；再除以 `3K·ln 2`（K 的严格增函数）得 `ε(m₂,·)` 关于 K 严格减。
2. **(A2)** 前提左端 `G(m₂)` 与 K 无关，故可行集单增：`K₁ ≤ K₂ ⟹ F(K₁) ⊆ F(K₂)`。
3. **(A3)** 故 `K₁ ≤ K₂` 时 `ε_opt(K₂) ≤ min_{m₂∈F(K₁)} ε(m₂,K₂) ≤ min_{m₂∈F(K₁)} ε(m₂,K₁) = ε_opt(K₁)`。即 **ε_opt 非增**。
4. **(A4) 推论（区间套）**：`K ≥ K*` 时 `(δ, δ + ε_opt(K)) ⊆ (δ, δ + ε_opt(K*))`。
5. **与第 1 轮的关系**：`70-research/cycle-1/route-4.md:159` 至 `:170` 已给同一结论；本路线独立重写（不复用其代码），差别只在 (A3) 的写法。
6. **注**：`ε_opt` 非增但**不连续**：`m₂` 跳进可行集时 `ε_opt` 会离散下降（本次实测见 §4.2 第 3 条）。

### 2.2 引理 B（单模区间引理）——已证（本路线自证，初等）

**陈述**：设 `p/q < r/s < p'/q'`，且 `p'q − p q' = 1`。则 `s ≥ q + q'`。

**证明**：`r/s − p/q = (rq − sp)/(sq) ≥ 1/(sq)`（分子为正整数）；同理 `p'/q' − r/s ≥ 1/(s q')`。两式相加：
`p'/q' − p/q ≥ (q + q')/(s q q')`。而 `p'/q' − p/q = (p'q − p q')/(q q') = 1/(q q')`。代入得 `1/(q q') ≥ (q + q')/(s q q')`，即 `s ≥ q + q'`。∎

**注 1**：`p'q − p q' = −1` 时把两式相减方向互换，同得 `s ≥ q + q'`；本次证书用到的是 `+1`（`[C1]`）。
**注 2**：该引理是纯整数命题，不含 δ、不含实数、不引用 Lemma 22。

### 2.3 引理 C（本格连分数机制）——已证（本路线自证，初等；连分数数字本身登记为未形式化）

设 `γ = p/K*`、`P/Q`（见 §6.2 的 `[C]` 段），满足 `P/Q < δ < γ` 且 `P·K* − p·Q = 1`。

1. `δ` 的连分数前 44 项（本次 `route4_probe_seq.py` 实跑，与 `materials.md:166` 一致）：`A[:44] = [1,1,1,2,2,3,1,5,2,23,2,2,1,1,55,1,4,3,1,1,15,1,9,2,5,7,1,1,4,8,1,11,1,20,2,1,10,1,4,1,1,1,1,1]`，即 `A_42 = A_43 = 1`、`A_44 = 37`。
2. `γ = [A_0; … ; A_41, A_42 + 1] = [A_0; … ; A_43]`（末段 1 的两种写法给同一分数），分母为 `q_41 + q_42 = K*`（`[C4]`）。
3. 由 1 与 2：`δ = [A_0; … ; A_41, 1, 1, 37, …]`、`γ = [A_0; … ; A_41, 2]`（末项下标 42 为偶，故增大末项即增大分数）。于是「`x > γ`」等价于「`CF(x)` 的前 42 项与 δ 相同且第 43 项（下标 42）`≥ 2`」，从而 `c_k = min(1, B_42) + 1 = 2` **自动成立**。
4. **推论**：只要 `ε_opt(K) > γ − δ`，Lemma 22 的 γ 就是 `p/K*`，且 `p/K* ∈ (δ, δ + ε_opt(K))`；此时「`Ψ_true(K) = K*`」等价于「区间内不存在分母小于 `K*` 的分数」。
5. **㊟ 第 4 条的「⟸」不需要 Lemma 22 的上界侧**：由引理 B，只要 `(δ, δ+ε) ⊆ (P/Q, γ)`，区间内一切分数分母 `≥ Q + K* = K*`。这正是第 1 轮 `materials.md:17` 记的「论文未证 γ 落在区间内」那一步的替代。
