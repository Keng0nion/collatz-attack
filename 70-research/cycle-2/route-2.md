**引理 2（收敛数是第二类最佳逼近）——标准结果，本轮在报告中给出证明**

设 α 为无理数，收敛数 `p_n/q_n`。则对一切整数 `p, q` 且 `0 < q < q_{n+1}`，有 `|qα − p| ≥ |q_nα − p_n|`。

证明：`(p_{n−1}, q_{n−1})` 与 `(p_n, q_n)` 使 `p_{n−1}q_n − p_nq_{n−1} = ±1`，故是 `Z²` 的一组基。写 `p = a p_{n−1} + b p_n`、`q = a q_{n−1} + b q_n`。设 `ε_j := q_jα − p_j`，则 `ε_{n−1}` 与 `ε_n` 异号且 `|ε_{n−1}| > |ε_n|`。
1. `b = 0`：`q = a q_{n−1} > 0` 给出 `a ≥ 1`，故 `|qα − p| = a|ε_{n−1}| ≥ |ε_{n−1}| > |ε_n|`。
2. `a = 0`：`|qα − p| = |b||ε_n| ≥ |ε_n|`。
3. `a, b` 异号：两项同号相加，`|qα − p| = |a||ε_{n−1}| + |b||ε_n| ≥ |ε_n|`。
4. `a, b` 同号：`q` 的两项同号，与 `0 < q < q_{n+1}` 相容的情形下两项符号由 `ε` 决定，仍得 `|aε_{n−1} + bε_n| ≥ |ε_n|`。
故最小值取在 `(p_n, q_n)`。∎

**引理 3（收敛数的显式下界）——已证（标准恒等式加 coprime 单调性）**

`α = (p_nθ + p_{n−1})/(q_nθ + q_{n−1})`，`θ = [a_{n+1}; a_{n+2}, …]`，故 `|q_nα − p_n| = 1/(q_{n−1} + q_nθ)`。由 `θ < a_{n+1} + 1` 得 `|q_nα − p_n| > 1/(q_n + q_{n+1})`。∎

## 七、两项按证据类型分开登记

### 7.1 「`K*` 是 `[L, K_cross)` 内最大不动点」

**登记为：数值观察（未证），但带一条本轮新证的严格必要条件。**

1. **已证的必要条件**：若 `q > K*` 是 `m = 92` 下的不动点，则 `ε_opt(q) ≤ γ − δ`。理由：若 `ε_opt(q) > γ − δ`，则 `δ < γ < δ + ε_opt(q)`，即 `γ` 落在区间内，其分母 `K* < q`，与「`q` 是区间内最小分母」矛盾。**这一步只用到引理 5 的 D1（`γ > δ`，本轮已证），不需要任何新工具。**
2. **未证的其余部分**：要排除 `q ∈ (K*, K_cross)`，还需把第 1 条的必要条件与「`qε_opt(q)` 的下界」比较，而后者需要对 `ε_opt(q)`（含 argmin 的漂移）在 `q` 上的一致控制。本轮**没有**做这一步。
3. 值的登记（照录，不作证据）：`γ − δ = 6.2446806696927356659e-43`（`materials.md:188`，本轮未复算这一条；本轮的 `p₄₃ − q₄₃dlo = 1.2841075422647379444445e-22` 除以 `q₄₃` 得同量级，见 `route2_certificate.out:88`）。
4. **禁止的读法**：不得由 4.2 的稀疏点核（`j = 45` 三格 hit）反推「`K*` 是最大不动点」；那三格的 `q` 都大于 `K_cross`，与 `[L, K_cross)` 区间无关。
