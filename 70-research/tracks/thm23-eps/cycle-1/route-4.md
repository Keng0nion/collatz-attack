## 三、方法与判定纪律（严格有理区间算术）

1. **区间库**（`scripts/route4_rig.py`，本次亲跑）：全部端点用 `fractions.Fraction`；超越函数一律「正项级数部分和 = 下界 + 显式余项界 = 上界」：
   1. `ln2 = 2·Σ_{k≥0} (1/3)^{2k+1}/(2k+1)`，余项 ≤ `(9/8)·3^{−(2N+3)}/(2N+3)`；`ln3 = 2·Σ (1/2)^{2k+1}/(2k+1)`，余项 ≤ `(4/3)·2^{−(2N+3)}/(2N+3)`（等比求和；N = 80）。
   2. `ln t (1≤t<2) = 2·atanh(u), u=(t−1)/(t+1) ∈ [0,1/3)`，余项 ≤ `2u^{2N+3}/((2N+3)(1−u²))`；一般 `x = 2^e·t` 时 `ln x = e·ln 2 + ln t`（整数比较定 e，精确）。
   3. `exp y (0≤y≤1) = Σ y^n/n!`，余项 ≤ `(y^{N+1}/(N+1)!)/(1−y/(N+2))`（N = 30）；`y>1` 时先折半再平方；`y<0` 取倒数。
   4. `2^v = 2^{⌊v⌋}·exp(r·ln2)`（r<1，避免大指数平方）；`(2^v−1)^δ` 用恒等式 `= 3^{⌊v⌋}·exp(r·ln3 + δ·ln(1−2^{−v}))`，其中 `ln(1−z) ∈ [−(z+2z²), −z]`（0<z≤1/2，由 `ln(1−z) = −Σ z^k/k` 逐项界得）——这条恒等式是本轮为避免「大指数连乘平方」而推导的，与慢路径 `exp(δ·ln(2^v−1))` 互为独立路线。
   5. 每步结果**向外取整**到 `10^{-130}` 网格（`snap`）：保严格性，同时把分母位数压住（否则 `δ^{91}` 走区间乘积到 4500 位、传入 exp 级数后放大 30 倍，单次求值要上百秒——本轮实测并修掉）。
2. **自测（本次亲跑，`route4_out/rig_selftest.txt`）**：区间宽度实测 `ln2 1.06e-118（N=120 时）/ 2.34e-80（N=80）`、`ln3 1.4e-51`、`delta 2.02e-51`；`exp(1)` 区间宽 1.25e-201 且含 mpmath 的 e；`2^{1/2}` 宽 7.5e-119 且含 mpmath 值；连分数例 `gamma_q(100/201, 101/203)` 输出 `{'q': Fraction(203, 1), 'k': 2, 'ak': 100, 'bk': 101, 'ck': 101, 'n_common': 2}` ✓（教科书例：区间内最小分母的真值 404，Lemma 22 的下界 203，与论文口径一致）；300 组随机小分母区间核对中「区间内不得存在分母 < q 的分数」违反数 = 0，另有 111 组因端点为有理数、连分数有限而按设计报「需收窄」（不计入判定）。
3. **Lemma 22 的机器口径**（本次亲读第 15 页）：`k` = 两个区间连分数的首个相异下标，`c_k = min(a_k,b_k)+1`，`K' = 分母([a_0;…;a_{k−1},c_k])`。本库对两侧区间各自做「逐项确定、遇歧义即报 need_refine」的严格连分数走法；本轮所有步都不需要收窄（区间宽 ~1e-130 ≪ 1/q_k²，见下）。注意论文 Russell 页（第 15 页）Lemma 22 **陈述**印 `ck = min(ak, bk) + 1`（正确），**证明体内**两处印成 `ck := ak + 1 = min(ak + bk) + 1` 与 `ck := bk + 1 = min(ak + bk) + 1`（笔误）；本轮按陈述实现。
4. **单调性引理（本次自证，报告内证明）**：`K ↦ ε₇(K)` 严格递减。证明：`ε₇ = c·B(v)/v`，其中 `v = cK`（`c = (δ−1)/(δ⁹¹−1) > 0`），`B(v) = 3/(2^v−1) + 270/(2^v−1)^δ`。`d/dv[B(v)/v] = (vB'(v) − B(v))/v²`，而
   `vB'(v) − B(v) = −v·ln2·2^v·[3/(2^v−1)² + 270δ/(2^v−1)^{δ+1}] − 3/(2^v−1) − 270/(2^v−1)^δ < 0`，
   故 `B(v)/v` 严格递减，`c>0` 给出 `ε₇` 关于 `v`（从而是 `K`）严格递减。**推论**：任给印刷约定，`{K : 该约定把 ε₇(K) 印成给定位串}` 是区间（端点在阈值处），窗口反演因此只需解一次方程。§4.7 的数值见证（4 组区间比较）只是核实现。

## 六、七步取整约定穷举

1. **约定空间与判据**。印刷规则三种：`ceil`（向上取整）、`round`（四舍五入，half-up）、`trunc`（截尾），各作用在 1 位或 2 位小数上；另有「去零变体」（允许尾数整数末位零被抹去，如向上取整 2 位小数给出的 `6.90` 记作 `6.9`）。K 的印刷按论文印出的有效位数（第 1 步 2 位，第 2 至 7 步各 3 位）。组合维度：`K 回代 4 态（exact/trunc/round/ceil）× K 印刷 3 态 × ε 印刷 6 态（3 规则 × 2 位数）× A 2 态（+73 / +1）× X0 2 态（695 / 704）` = **288 组**；再加去零变体 **576 组**。轨迹只由 `(K 回代, A, X0)` 决定，共 **16 条轨迹**；`K 印刷` 与 `ε 印刷` 是事后核对。每步核对四件事：`m2max` 是否等于印数 m2、K 串、ε 串、以及第七步 K 串。

## 七、搜到的反例与搜不到的覆盖面

**搜到的反例（每条都来自精确有理比较）**

1. **R1（削弱现行解释的唯一性）**：`2.0603×10²⁰` 在四舍五入与进位两种 2 位小数约定下都印「1.11」（`step7_stdout.txt:20`、`:51`、`:60`）。故「只有 2.06×10²⁰ 能印 1.11」在允许非自然输入时为假；2.06×10²⁰ 的独特性只在「三窗口」层面成立（它是截尾窗口里的那个十进制点）。
2. **R2（削弱「取整传播」机制）**：三位有效数字档位 `[2.055, 2.065)×10²⁰` 内只有约 3.4% 的值能印 1.11（窗口宽 3.45×10¹⁶ 对档位宽 1.0×10¹⁸）。若把现行解释读作「论文把 K 取整到 2.06 档位」，则它**不能**支撑复现。
3. **R3（排除「我方有偏」）**：用第六步精确输出 `K* = 205632218873398596256` 代入，六种约定印出 1.20/1.22/1.23/1.23/1.30/1.23，无一为 1.11。加之七步 K 数值与本方记录逐位相同，说明「我方中间量取法有偏」在本步不成立（本方 K* 与链条自洽）。
4. **R4（排除一条自然读法）**：用论文印出的截断值 `2.05×10²⁰` 回代，六种约定印出 1.40/1.44/1.45/1.45/1.50/1.45，无一为 1.11。故「论文把 K 截到印出的 2.05×10²⁰ 再回代」这条读法被排除。
5. **R5（内部不一致）**：288 组（去零变体下 576 组）里没有任何一组能同时复现七步印数；能达 6 步的恰两个组合，且都卡在第 7 步的 ε 上。等价说法：第 1 至 6 步要求 ε 印刷 = **向上取整 1 位小数**，第 7 步的 1.11 要求 ε 印刷 = **截尾 2 位小数**（在 2.06×10²⁰ 处），两者互斥。

**搜不到的覆盖面（正面结论，均为「全集」而非抽样）**

1. **C1（窗口完备）**：三窗口的完整刻画（§5.2）覆盖全部实数 K（由 §3.4 单调性引理保证集合是区间，端点由 §5.1 的严格包围给出）。任何 K 不落在三窗口（或其 2×10⁻⁹ 的不确定带）之一，六种约定都不印 1.11。
2. **C2（K 印刷规则唯一）**：`trunc` 是唯一规则（16 条轨迹 × 7 步全部命中；`round` 在第 1、2、5、6 步失败，`ceil` 七步全败）。
3. **C3（ε 印刷规则在 1 至 6 步唯一）**：向上取整 1 位小数。
4. **C4（常数唯一）**：`A = +73`（陈述页印数）、`X0 = 695·2⁶⁰`（印出版）。
5. **C5（m2 规则唯一）**：`m2 = 最大可行 m2`，给出印数序列 47/67/77/82/86/88/91；每步都带「m2max 可行 + m2max+1 不可行」的严格证书，且可行集为前缀（脚本内断言）。
6. **C6（第七步 K 输出的钝性）**：q₇ = 7941964418702608664581 在七个候选输入下完全相同（§6.7）——印数 `K > 7.94×10²¹` 对本步输入分歧不敏感，因此「第七步到底喂了什么 K」只能靠 ε 判、不能靠 K 判。
7. **C7（链条 K 层对约定不敏感）**：七步 q 值在 16 条轨迹下完全相同——「K 的取整传播」在数值层是不可见的；可见差异全部落在 ε 的印刷层（相对差异 1% 至 1.6% 足以改变 1 位小数的 ceil 结果）。

## 八、失败点清单（本轮实际踩到的坑，全部在出结论前修复）与未做之事

1. **实现层面的失败点（均已修复并复跑；这是本轮「失败点清单」的实体）**：
   1. `ln_rat_bounds` 里「找 e 使 2^e ≤ x < 2^{e+1}」的两个 while 方向写反 → 死循环（跑到 e → −∞，`num << -e` 爆炸）。症状：自测进程 10 分钟无输出。修法：改 `> 0` / `≤ 0`。
   2. 链脚本的 `δ^{m2}` 表用未 snap 的区间连乘 → 分母位数 91×130 ≈ 11800 位，传入 exp 级数后单次 ε 求值 125 秒（锚点：`route4-out/probe2.txt` 显示 `GEOM[47]` 位数 6117/6108、中间量 187707 至 197588 位）。修法：每步 `snap` 到 10⁻¹³⁰ 网格 + 用 `POW[m2]`（δ^{m2}）而非 GEOM 做分母。修后单步 0.2 至 0.3 秒。
   3. `eps_interval` 的 `v` 分母误用 `geom(m2) − 1`（等于 (δ^{m2}−δ)/(δ−1)）而不是 `δ^{m2} − 1` → v 偏小（85 → 49.5），ε 整体偏大约 1e4 倍。症状：mpmath 硬校验报「ε 区间未含 mpmath 值」。修法：改用 POW 表。
   4. ε 指数的符号写反（把 `6.9·10⁻³²` 的指数存成 +32）→ ε 印刷核对全部给出无意义的 0/1。修法：指数按真值存负号，尾数 = ε/10^指数。
