## 三、方法：四个自足引理与证书组成

本路不复用任何旧脚本做判决：`r5_rig.py` 从零实现（只依赖标准库 `fractions`）。它与 cycle-2 的 `c2r5_rig.py` 在算法思想上有重叠（Stern-Brocot 下降、区间连分数前缀），但代码、参数、运行环境都是本轮新写；本路的判决只依赖下文引理与本轮机器证书，不依赖任何旧脚本的输出。

### 3.1 引理 A（Farey 邻居下界；本轮自足证明）

**陈述**：设 a/b < c/d 为有理数且 bc − ad = 1。则开区间 (a/b, c/d) 内每个有理数 p/q 满足 q ≥ b + d，且 q = b + d 只在 p/q = (a+c)/(b+d) 时发生。

**证明**：设 a/b < p/q < c/d。则 pb − aq > 0 与 cq − pd > 0 都是整数，故 pb − aq ≥ 1 且 cq − pd ≥ 1。于是

  q = q(bc − ad) = d·(pb − aq) + b·(cq − pd) ≥ d + b。

等号要求两个整数都等于 1（且 bc − ad = 1，已设）。此时由 pb − aq = 1 与 ad + 1 = bc 得 p = (aq + 1)/b = (a(b+d) + 1)/b = a + (ad + 1)/b = a + c；于是 p/q = (a+c)/(b+d)。∎

这条引理就是本路「连分数路径」的全部内容：只要找到夹住区间的 Farey 邻居对，分母下界立刻得到，且对**整个区间**成立——不需要对具体 w 逐点检验。

### 3.2 引理 B（收敛分数的单参数族与两条恒等式；本轮自足证明）

**陈述**：设实数 x 的连分数为 [a₀; a₁, a₂, …]，收敛分数 p_n/q_n。固定 n，对实数 t > 0 令 S(t) = (t·p_n + p_{n−1})/(t·q_n + q_{n−1})（即 [a₀; …; a_n, t] 的值）。则

1. S 在 t > 0 上严格单调（S′(t) = (p_n·q_{n−1} − p_{n−1}·q_n)/(t·q_n + q_{n−1})²，分子是 ±1）；
2. x = S(t*)，其中 t* = [a_{n+1}; a_{n+2}, …] ∈ (a_{n+1}, a_{n+1} + 1)；
3. 对 0 < t₁ < t₂：S(t₂) − S(t₁) = (t₂ − t₁) / ((t₂·q_n + q_{n−1})·(t₁·q_n + q_{n−1}))。

**证明**：1 与 3 是直接代数（3 的分子 = (t₂ − t₁)(p_n·q_{n−1} − p_{n−1}·q_n)，配合 p_n·q_{n−1} − p_{n−1}·q_n = ±1 与 S 单调知符号为正）；2 是标准恒等式 [a₀; …; a_n, t] = (t·p_n + p_{n−1})/(t·q_n + q_{n−1}) 与 x = [a₀; …; a_n, t*] 的展开定义。∎

**推论（本步专用形式，已证）**：本轮证书给出 a44 = 37、a45 = 4，故 t* ∈ (37, 38) 且 38 − t* = 1 − 1/[a45; a46, …] ∈ (3/4, 4/5)（用 [a45; …] ∈ (4, 5)）。取 n = 43，记 T = q44 + q43、γ = p43/q43 = S(∞)、S38 = S(38)：

  S38 − δ = (38 − t*) / (T·(t*·q43 + q42))
  γ − δ = 1 / (q43·(t*·q43 + q42))

且 t*·q43 + q42 ∈ (q44, T)（由 t* ∈ (37, 38) 与 q44 = 37·q43 + q42）。于是

  3/(4T²) < S38 − δ < 4/(5·T·q44)，1/(q43·T) < γ − δ < 1/(q43·q44)。

两端都是精确有理数，可手算复核；这就是本路全部「距离」判定。

### 3.3 引理 C（区间连分数前缀证书；本轮自足实现并自检）

**陈述**：设 L < U 为有理数。逐次执行：若 floor(L) = floor(U) = n 且 L > n，记下 n，并把 (L, U) 换成 (1/(U − n), 1/(L − n))（高斯映射在 (n, n+1) 上递减，故端点交换）；当 floor(L) ≠ floor(U) 或 L 为整数时停止。则 (L, U) 内每个实数的连分数展开都以记下的序列为前缀。

**证明**：x ∈ (L, U) ⟹ floor(x) = n（floor 单调、两端相同、L > n 排除边界情形）；x − n ∈ (L − n, U − n)，取倒数得 1/(x − n) ∈ (1/(U − n), 1/(L − n))；对新区间归纳。∎

自检锚点（**本次亲跑**，`results/r5_rig_selftest.log`）：415/93 的 ±10⁻⁹ 邻域证书给出前缀 [4, 2, 6]——正确地止在跨过终止点处（该处两侧第 4 位分别是 7 与 6）。

### 3.4 引理 D（Stern-Brocot 中项搜索；本轮自足实现）

**陈述**：设 A < B 为有理数。从括号 x/y = 0/1、z/w = 1/0 出发（z·y − x·w = 1），每步取中项 (x+z)/(y+w)：若 ≤ A 则把下界换成中项；若 ≥ B 则把上界换成中项；若严格落在 (A, B) 内则返回。则返回分数是 (A, B) 内分母最小者。

**证明**：全过程保持括号 unimodular（z·y − x·w = 1：初值为 1；两类替换各自直接验证）与 x/y ≤ A < B ≤ z/w。返回时括号的中项即返回值；由引理 A（括号是 Farey 邻居对，中项分母 = y + w 恰好取到下界）知其为最小分母。∎

每步只用整数运算（比较用交叉相乘）；本步搜索步数约等于相关连分数系数之和（约三百）。

### 3.5 机器证书的组成（`r5_cert.py` 一次运行，全部断言通过，退出码 0）

1. δ 的包络 (L, U)：两条独立走法（ln 3 走 atanh(1/2)；ln 3 = ln 2 + 2·atanh(1/5)）各自给严格区间，取交集；宽度 2.53531×10⁻¹³⁶。
2. 前缀证书：139 位系数；残余区间给出下一位系数的范围。
3. 收敛分数表、整数恒等式、印数取整判据、引理 B 推论的两条距离不等式。
4. Stern-Brocot 走法：三种 w 各走内、外两个有理区间，共六次（夹逼）。
5. Farey 夹逼（引理 A 直接套用）：两次精确比较给出包含关系。
