## 四、(b) 窗口的严格区间证书

`scripts/d3wt_cert.py`：只用 `fractions.Fraction` 精确运算、自写 atanh 级数（ln）与自写 Taylor 级数（exp，显式尾项界 `z^{N+1}(N+2)/((N+1)!((N+2)q − p))`，取 2 的幂归约加连续平方使整数规模恒定），所有超越结果的入口出口都做 30 位定向有效数字舍入（`SIG = 30`）；不用 mpmath 定案。

**算法基座（已证，纯代数恒等）**：取 x := K/K_thresh(M)，则对任何 δ、C 恒有 v(M,K) = C·x 与 v(M−1,K) = ρ_M·C·x（ρ_M = ((M−1)/M)(δ^M − 1)/(δ^{M−1} − 1)）。故 `2^{C(1+u)} = Q·2^{Cu}`、`s = s_base·2^{ρ_M C u}`，小指数用 `e^z ∈ [1+z, 1+z+z²]`（0 ≤ z ≤ 1）封闭，`(t−1)^δ` 与 `(s−1)^δ` 用 `(1+y)^δ ∈ [1 + δ_lo y_lo, 1 + δ_hi y_hi + (δ_hi y_hi)²]`（0 ≤ δy ≤ 1）分解。

**[0] 原语自检（判据可翻 False）**：定向舍入的包含性（下界 ≤ 真值 ≤ 上界，5 组含 10⁴⁰ 与 3.05×10³³ 量级）True；exp(77) > exp(76) True；exp(0) == 1 True。

**[1] 常数**：δ 区间宽 1.671×10⁻²⁸，C 区间宽 3.898×10⁻²⁷（30 位有效数字口径）；`(2^C − 1)^δ ∈ [3.0531938055841308709325...×10³³, ...]`（与 mpmath 的 3.053193805584130870933×10³³ 同量级同前缀）；`3/2^C − 97/(54X0) == 0` 判据 True；`P1 = 3/(Q(Q−1))`。

**[2] 逐档符号（M = 2 至 92，91 行，全为严格判定，无「未定」）**：
