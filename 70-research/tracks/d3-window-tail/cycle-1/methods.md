## 二、已知的不可能性结果

### 2.1 文献定理与结构性障碍

1. **族层面的不可判定性只杀统一方法**：广义 Collatz 判定不可判定（Conway 1972）；{g : range(g) = ω} 是 Π⁰₂ 完备（Kurtz 与 Simon 2007）。出处：`barriers.md:26` 至 `:28`；`frontier.md:48`。边界：不给 3x+1 本身任何不可判定性或独立性结论。
2. **纯测度论与遍历论论证必失败**：整数集在 2 进整数中测度零；3x+1 与 5x+1 在 Z₂ 上完全同构而在整数上行为不同。出处：`barriers.md:50`（Tao 的公开表述）、`barriers.md:56`（Lagarias 2010 的第一手表述）、`frontier.md:47`。
3. **符号不敏感与常数不敏感的论证必失败**：负整数上有三个非平凡环（{−1}、{−5, −7, −10}、从 −17 起的 11 元环）；5x+1 有环 13 → 33 → 83 → 13。出处：`barriers.md:62`、`:63`。
4. **固定下降深度的证书不存在**：对每个 k，类 n ≡ −1 (mod 2^k) 中每个数的前 k 个加速步全为奇步、严格上升；且 sup T_m / m 无界（Crandall 1978 定理 (2.2)）。出处：`barriers.md:61`（该条自标为笔记作者推断，附 Hercher 引理 8 与 SdW 重述支持）、`barriers.md:64`。边界：允许「归约到已验小数」的更强覆盖**未被排除**（`barriers.md:71`、`frontier.md:49` 标为缺口）。
5. **印出版 Hercher 定理 21 的「窗口尾部」推导不能按原样使用**：该步含一条对 ℓ ≥ 2 为假的幂不等式 n 的 δ 的 ℓ 次方 ≤ n 的 δ 次方（δ² = 2.512106128692261009 > δ）与一处方向相反的推理；作者 2026 勘误逐字承认 contains an error。出处：`frontier.md:163`；`60-audits/hercher-t21/rederivation-as-printed.md:10` 与 `:98` 至 `:99`（本次亲读：第二个不等号对 ℓ ≥ 2 为假，n = 2 时 2 的 δ² 次方 = 5.7045… > 2 的 δ 次方 = 3）。界线：被证否的是推导不是结论；m ≤ 91 的恢复走勘误版（附条件、未形式化）。
6. **m 圈方法的天花板**：界对 m 指数增长、对 K 次指数增长，每档依赖连分数门槛与验证界；一次性排除所有 m 无已知机制。出处：`barriers.md:36`；`cycles.md:122`。
7. **密度路线与「几乎所有」路线的最后一跳**：Krasikov 猜想 x^(1−ε) 未证；Tao 自述固定常数版「很可能与整个猜想一样难，并且超出本文方法的范围」。出处：`barriers.md:47`、`:49`；`frontier.md:68`、`:69`。
8. **有限验证不构成全称命题**：任何有限验证都是单称命题的合取，无已知桥梁；且「有限覆盖加固定下降深度」形式在原理上不存在（与 2.1 之 4 合读）。出处：`verification.md:64`；`barriers.md:91` 至 `:92`。
9. **被撤回或撤回后的宣称**：Opfer 2011 由作者本人撤回其「所有顶点恰好一次」推理；Metzger 1995「唯一循环」作者补记承认证明有缺口。出处：`barriers.md:75`；`frontier.md:45`。

## 三、本机工具实测（能做什么、不能做什么）

本节每条均为本次实测：探针脚本 `/tmp/d3probe.py`（mpmath、gmpy2、sympy、z3、numpy）与 `/tmp/d3probe_gmp.c`（cc 与 GMP），解释器为 `20-experiments/.venv/bin/python`（3.12.7）。本节只列「这类问题」相关的能／不能，未跑到的逐一标注。

1. **mpmath 1.3.0**。能：高精度求值与正确打印（本次实测：`mp.dps = 200` 下 `mp.nstr(log 3 / log 2, 50)` 给 `1.5849625007211561814537389439478165087598144076925`）。不能：`"%.50f"` 只给 float64 精度（同一数打印为 `1.58496250072115607565592654282227158546447753906250`，与 nstr 前 16 位相同、第 17 位起分道），显示层信号不得当真值；数值精度不是证书，判据须落精确有理比较（见 1.2 之 13）。
2. **gmpy2 2.3.2**。能：`mpq` 精确有理；定向舍入包络（本次实测：v 取精确有理数 753622181/10000000，`context(precision=120, round=RoundDown/RoundUp)` 下 2^v 的下界 `48561063336395017810332.81133041723939`、上界 `48561063336395017810332.811330417242687`，两值可分辨）；`iroot(2^300 − 1, 3)` 给地板且精确性标志 False、`r³ ≤ N < (r+1)³` 为 True。不能：可分辨包络不是证书，要成为证书须逐项写单调化归；本机无独立 libmpfr（本次实测 `ls /opt/homebrew/lib/libmpfr*` 无匹配），定向舍入只经 gmpy2 自带绑定；MPFR「正确定向舍入」的文档本次未核。
