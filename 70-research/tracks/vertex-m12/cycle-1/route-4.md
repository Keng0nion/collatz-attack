## 三、初等论证：枚举 = 顶点集（编号论证，每步标注）

本节给出命题 R4 的完整证明。全部论证只用：有限条非严格线性不等式的算术语义、两点中点的定义、有限维线性代数（秩、零核）、以及「有限项的极值可达」。**不使用** (L1)、不使用顶点引理（任何解析分类结论）、不使用凸分析定理、不使用 v 的数值、不使用任何机器输出。

### Step 0（定义性，已证）：顶点即「不可作两点的中点」

按 §1.2 的定义，y ∈ P 是顶点当且仅当不存在 y′, y″ ∈ P、y′ ≠ y″，y = (y′ + y″)/2。这一定义与「y 不能写成 P 中两相异点的真凸组合」等价；两个方向的等价性各一行：

1. 若 y = λy′ + (1−λ)y″（λ ∈ (0,1)，y′ ≠ y″），取 d = y′ − y″ ≠ 0。对任意 t ∈ [−λ, 1−λ]，y + t d = (λ+t)y′ + (1−λ−t)y″ ∈ P（系数和恒为 1，且按 t 的区间非负，这是 P 为半空间交这一事实的逐条代入）。取 t = min(λ, 1−λ) > 0，则 y ± t d ∈ P 且 t d ≠ 0，即 y 是两相异点的中点。
2. 反向：中点本身是 λ = 1/2 的凸组合。

**标注**：已证（初等）。用到的唯一「凸」语义是「两可行点的凸组合仍满足同一条非严格线性不等式」这一逐条代入的事实——这属于半空间的算术语义，不是凸分析定理；本路线把它记作「零凸性依赖」的准确含义（见 §五 的依赖清单）。

### Step 1（记号，已证）：约束的法向量与活跃集

把 2m₂+1 条约束写成 (a_i, b_i, ⊵_i)，i = 1..2m₂+1，其中 ⊵_i ∈ {≥, ≤}，a_i ∈ Q^{m₂} 是该行左端的系数向量（例如 C1 的第 j 条为 a = e_j、b = 1、⊵ = ≥；C2 的第 j 条为 a = e_{j+1} − δe_j（指标循环）、b = 0、⊵ = ≤；C3 为 a = (1,…,1)、b = W、⊵ = ≥）。点 y 处的**活跃集** I(y) := {i : a_i·y = b_i}（两种方向一视同仁，等号即活跃）。

**标注**：已证（定义性）。

### Step 2（判据的一个方向，已证）：活跃秩 = m₂ ⟹ 顶点

设 rank{a_i : i ∈ I(y)} = m₂。设反，若 y = (y′ + y″)/2，y′, y″ ∈ P，y′ ≠ y″。对每个 i ∈ I(y)：

1. 若 ⊵_i 是「≥」：a_i·y′ ≥ b_i 且 a_i·y″ ≥ b_i，两式平均得 a_i·y = b_i，故两个不等式都取等：a_i·y′ = a_i·y″ = b_i，于是 a_i·(y′ − y″) = 0。
2. 若 ⊵_i 是「≤」：a_i·y′ ≤ b_i 且 a_i·y″ ≤ b_i，平均仍给 a_i·y = b_i，同理 a_i·y′ = a_i·y″ = b_i，a_i·(y′ − y″) = 0。

于是 d := y′ − y″ 落在全部活跃法向量张成的空间的核里；该空间秩为 m₂，核为 {0}，故 d = 0，与 y′ ≠ y″ 矛盾。故 y 是顶点。

**标注**：已证（初等）。**这一方向不使用取到性、不使用有界性、不使用 convexity 定理**；只用「两式平均值夹在两端」这一算术。

### Step 3（判据的另一方向，已证）：顶点 ⟹ 活跃秩 = m₂

设 y ∈ P 是顶点。设反，若 r := rank{a_i : i ∈ I(y)} < m₂，则存在 d ∈ R^{m₂}、d ≠ 0，使 a_i·d = 0 对一切 i ∈ I(y) 成立（齐次线性方程组的非平凡解）。对 i ∉ I(y) 定义间隙 s_i：

1. 若 ⊵_i 是「≥」：s_i := a_i·y − b_i > 0；
2. 若 ⊵_i 是「≤」：s_i := b_i − a_i·y > 0。

对每个 i ∉ I(y) 取 ε_i := s_i / (2(|a_i·d| + 1)) > 0（有限个，故 ε := min_i ε_i > 0）。对任意 0 < ε′ < ε：

1. 对 i ∈ I(y)：a_i·(y ± ε′d) = b_i（因为 a_i·d = 0），即活跃约束保持取等；
2. 对 i ∉ I(y)：「≥」情形 a_i·(y ± ε′d) = a_i·y ± ε′a_i·d ≥ a_i·y − ε′|a_i·d| > a_i·y − s_i = b_i；「≤」情形 a_i·(y ± ε′d) ≤ a_i·y + ε′|a_i·d| < b_i。

于是 y ± ε′d ∈ P 且两者相异（ε′d ≠ 0），y 是两相异点的中点，与顶点矛盾。故 r = m₂——即指标集 I(y) 里存在 m₂ 个线性无关的法向量。

**标注**：已证（初等）。**两种不等式方向的双向扰动处理**就在这里写全：活跃约束保持取等（对 ≥ 与 ≤ 同一条算术），非活跃约束靠正间隙吃下扰动（对 ≥ 取 b_i + s_i 一侧、对 ≤ 取 b_i − s_i 一侧，各自方向不同但都只用有限个正数的极小值）。

### Step 4（捕获引理，已证）：每个顶点必被某个 m₂ 元子集捕获

设 y* 是顶点。由 Step 3，活跃法向量在 R^{m₂} 中张成满秩空间，故从 I(y*) 中可取 m₂ 个下标 i_1 < … < i_{m₂} 使 {a_{i_1}, …, a_{i_{m₂}}} 线性无关。于是：

1. 子集 S* = {i_1, …, i_{m₂}} 是 2m₂+1 条约束的一个 m₂ 元子集，必出现在枚举 E 的遍历表里（`itertools.combinations(range(2m₂+1), m₂)` 遍历全部 m₂ 元子集，每个恰一次，见 §四 的枚举空间审计）；
2. S* 对应的方程组 a_{i_k}·y = b_{i_k}（k = 1..m₂）的系数方阵秩为 m₂，故解唯一；y* 满足这 m₂ 条等式（因为在活跃集里），所以该方程组的唯一解就是 y*；
3. y* ∈ P。故若解方程与可行性判定被正确实现（§四 的代码审计），枚举会把 y* 收进结果集。

**标注**：已证（Step 3 + 线性代数 + 组合遍历的完备性）。这正是命题文案里「每个顶点必被某个 m₂ 元子集捕获」的落点；它**没有**使用 (L1)（(L1) 的作用是反方向地砍掉「C1 活跃」的那些子集，本引理不需要砍）。

### Step 5（枚举不产生伪顶点，已证）：每个命中点都是顶点

设枚举从子集 S 得到解 y（即：方程有唯一解、秩 = m₂、且 y 通过精确可行性判定）。则在 y 处 S 中每条约束取等，即 S ⊆ I(y)（指数组的秩 = m₂ 是子集本身的秩，故 rank{a_i : i ∈ I(y)} ≥ m₂；又只有 m₂ 个变量，故恰为 m₂）。由 Step 2，y 是顶点。

**标注**：已证（Step 2 + 秩的单调性）。注意：这一方向**不需要** I(y) 恰为 S；即使有更多约束同时取等（退化顶点，如阈值档的 (5, 6)），结论不变。

### Step 6（汇总，已证）：E = 顶点集

Step 4（顶点 ⊆ E）与 Step 5（E ⊆ 顶点）合起来即命题 R4：对任意 m₂ ≥ 1、δ > 1、W > 0，枚举结果集恰为 P 的顶点集。**注意 P 不必有界、不必非空的外围假设**：若 P = ∅ 则顶点集空、枚举输出也空（每个子集的解都过不了可行性判定，或子集秩亏）；若 P 非空无界（本例 W > 0 时显然非空且无界），Step 2 至 Step 5 的论证逐字不变——极点判据本来就不需要取到性。

**标注**：已证（初等）。**与勘误论证的关系**：勘误 `corrigendum.txt:43` 至 `:46` 需要的是「S 在 P 上取到最大值且某个最大点在顶点取到」——那是**另一条**论证（凸函数在无界多面体上的取到性与极值点可达性），本路线不主张也不依赖它；`rederivation-erratum.md:83` 已把该处登记为「需补的引理」。本路线只钉「枚举 = 顶点集」这一环。
