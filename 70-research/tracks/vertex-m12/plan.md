## 三、命题冻结与参数锚点（攻击轮第一步，先冻后跑）

命题 R(m₂, δ, W)：多面体 P(m₂, δ, W) 的全部可行顶点恰为解析的 m₂ 个循环旋转。

1. P 的约束（照 `r2_common.constraint_list` 的逐字转写）：C1 为 y_j ≥ 1（j = 1 至 m₂）；C2 为 y_{j+1} ≤ δ y_j（指标循环，含回绕）；C3 为 Σy ≥ W。
2. 解析旋转：v·(δ 的 r 次幂, …, δ 的 r+m₂−1 次幂)（r = 0 至 m₂ − 1），v = W(δ−1)/(δ^{m₂}−1)。
3. 参数锚点（首跑口径）：δ = 126797/80000（沿袭 A1/E4 口径）；W = 2000（与 m₂ = 10 阳性对照同参，保证两档可比）；m₂ 档按 10（对照）、12（主档）、13 与 14（视算力）。
4. 依赖边界（须写进产物）：
   1. 允许依赖：约束表逐字转写、初等线性代数（顶点当且仅当活跃约束法向量秩 = m₂；等号约束在双向扰动下迫使扰动为零）、精确有理算术、组合枚举完备性；
   2. 禁止依赖：(L1)、顶点引理的任何结论、凸性推导、v 的数值信息。违者本核对降级为循环论证。

3. 与路线二的区分：独立代码路径加不同算术引擎的交叉验证，不是同一脚本跑两遍。

2. 判据：审计文档与代码逐条对应；任何隐性依赖或语义偏差都要在报告里点名（例如 feasible 的 < 与 ≤ 边界符号、秩判据的满秩定义）。

## 十、风险与预案

1. 对照不过（m₂ = 10 重跑与基线不符，或 C 版与 Python 版不一致）：先冻结缺陷定位（代码、环境、定义三方向），差异子集对拍；修好前不得开跑 12 档。
2. m₂ = 12 出现反例顶点：先怀疑自己的定义与实现（`learnings.md:28`），按三重复核（定义核对、参数核对、双实现对拍）确认后再落反例证书并上报；口径照 `route-1.md:319` 至 `:320` 的证据边界写法，不夸大。
3. 算力不足：m₂ = 12 单档是底线必须完成；13、14 按实测倍率决定；做不动就写投影估算与未推档声明，不留半成品。
4. 多核正确性：分片必须确定性、无重无漏（按组合字典序编号区间切分并校验总数），不得用随机采样代替穷举。
5. 快速通道正确性：任何预筛（模素数秩等）只允许判死（筛除秩亏），候选顶点必须过精确通道复验才能入集。
6. 中断续跑：分片级落盘，日志记录每片状态，支持断点续跑。
