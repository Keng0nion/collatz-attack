## 三、逻辑断言专列（不涉具体数字）

2. **L2（化归两行）**：K₁ < K₂ ⟹ m\*(K₁) ∈ F(K₁) ⊆ F(K₂) 且 ε(m\*, K₂) < ε(m\*, K₁) ⟹ ε_opt(K₂) < ε_opt(K₁)。成立，前置条件是 argmin 存在（F 有限非空）——A1a 与 P2 已给。

4. **L4（整数恒等式）**：`x/y ≤ δ_lo < p/q < γ ≤ z/w` 且 `z·y − x·w = 1` ⟹ `q ≥ y + w`。成立，证明即 `q = y(zq − pw) + w(py − xq) ≥ y + w`。
