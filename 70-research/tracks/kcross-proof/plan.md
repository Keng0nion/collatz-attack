### 1.2 本调度员的攻法（一句话）

先做定义裁决——把「K_cross」在三个含义之间写死，并裁决 cycle-2 内部「已证（条件性）」对「未证」的相互矛盾登记；再按「ε_opt 严格递减 + 端点严格证书 + γ 落在开区间」的初等论证给出阈值与方程根等同的解析证明；同时给阈值本身一套不经过根命名的精确算术区间证书，以半收敛清单完备性穷举做独立复算，以定向反例搜索做压力测试；最后把「K_cross 的严格区间」与「它就是该根」两件事按证据类型分开登记。

## 二、现状把脉（事实与判断分开；判断部分一律标「本调度员推断」）

### 2.1 三个「K_cross」必须区分

1. **T：动力学越界阈值。** 链从 K_lo 出发按 K_{n+1} = Ψ_92(K_n) 迭代，「越界」指某次迭代 > U(92)。T := inf{K_lo : 越界}。cycle-1 的二分判据就是这个（`cycle-1/route-4.md:196` 逐字）。这是「19 位数值二分区间」与「严格下界 3.131547906×10²⁰」所描述的对象。
2. **R：方程根。** ε(92, K) = γ − δ 的唯一实根，其中 γ = 325919355854421968365/205632218873398596256（由 Lemma 22 的连分数构造，分母恰为 K* = 205632218873398596256，`c2r5_cert.log` [2]）。在 [3.12, 3.15]×10²⁰ 上与 ε_opt(K) = γ − δ 同根（主导权，route-5 报告 §5）。
3. **数值锚点**：T（等价地 R，若等同成立）的高精度数值定位（19 位二分区间 `cycle-1/route-4.md:201` 至 `:203`；findroot 值 `materials.md:216`）。

疑点里的「K_cross 就是该根」= **T = R**，是一个非平凡命题，不是同义反复。**注意：route-5 自己的『K_cross』是直接把 R 定义成 K_cross 后给的区间（`c2r5_cert.py:180` 逐字「K_cross 的严格根隔离：eps_opt(K) = gamma - delta 的根」），所以它的『47 位严格区间』在对象上属于 R，不能直接当作对 T 的断言。**

### 2.3 我读出的缺口结构（**本调度员推断，待各路验证或推翻**）

1. **非降性未必是实质前提。** route-5 两侧都用了第 1 轮「Ψ 非降」（`:318` 至 `:319`），但左行（K_lo < R 永不越界）可以换成更弱的直接论证：K < R 时 ε_opt(K) > γ − δ（ε_opt 严格递减，route-5 §6.2 第 1.2 步已证且初等 + ε_opt(R) = γ − δ 由主导权）⟹ 开区间 (δ, δ + ε_opt(K)) 仍含 γ ⟹ Ψ(K) ≤ K*（γ 是该区间内的一个分数，分母 K*）⟹ 迭代重复得全部 K_n ≤ K* < U(92)。**若这条成立，识别的条件性可从「依赖非降性」降到「依赖 ε_opt 严格递减 + 四条端点证书」，而后者全是初等或可重跑证书。** 这是本轮第一号待验假设。
2. **阈值 T 本身还缺一套不经过根命名的两侧证书**：显式有理数 T_hi < T_lo，左端对一切 K_lo ≤ T_hi 证「永不越界」，右端对一切 K_lo ≥ T_lo 证「首步越界」。这就是疑点要求的「严格区间证书」形态，也是把「47 位」从 R 搬到 T 的唯一途径（若 T = R 已被证，两者自然是同一区间；但证书形态应当两条腿都站住）。
3. **识别依赖的四条端点事实全部是转引**：(a) γ > δ 且 γ − δ < ε_opt(K*)（`c2r5_cert.log` [1]、[2]）；(b) Ψ_92(K*) = K*（[3]）；(c) simplest(δ_lo, γ) = 12587715785705330118969/7941964418702608664581 且 7941964418702608664581 > U(92)（[6]）；(d) K* < U(92)（同 [6]，K* = 2.06×10²⁰ < 3.43×10²⁰）。它们由 c2r5_rig.py 一处实现承载——独立机制复算是第二号任务（cycle-2 自认「半收敛清单完备性穷举在 K* 与 K_cross 格本轮未跑」，`route-5.md:337`）。
4. **域与端点书是缺口，不是形式**：链的取值域、Ψ 有定义的条件（由 (D2) 等价于 K ≥ 92C ≈ 6456.6，本调度员代入算，未证不涉及）、K_lo 与 K* 的大小关系、K_lo = R 时的开闭（γ 是开区间内点，端点情形对结论无影响，但必须逐条写死）。呼应 learnings 三之 7：担保「无洞」要写出起算位置。
5. **结构原因与脆弱点**：识别成立的结构原因是 K* < U(92) < 7941964418702608664581（U(92) 恰夹在 Ψ 在 R 处的两个台阶值之间，`c2r5_cert.log` [6] 与 [3]）。既然 U(92) 来自 SdW 的 1.4784·92·δ⁹²、R 来自 X₀ = 695×2⁶⁰ 的 ε 公式，**任何口径变动都可能移动 R 而不移动 U(92)**；arXiv v3 的 704×2⁶⁰ 分叉（`route-5.md:85`）必须量化并登记「T = R 相对于哪个口径」。这是第三号任务（第五路专办）。

## 六、验收标准与登记纪律

1. **证据类型逐句标注**：已证（本轮自足论证）／严格证书（可重跑、退出码 0）／初等证明／数值观察／转引（写明来源文件与行号）。「已证」不得用于形式化未做、未经第三方复核的结论（门槛 12）。
2. **两件事分开登记**：表格两行——「K_cross（阈值 T 或根 R，写明对象）的严格区间」与「T = R 的识别」；每行给定义、区间或结论、前提清单、出处（脚本路径与日志行）。
3. **数字可追溯**：每个数字能 grep 到出处；参数表与实跑日志不一致时以日志为准。
4. **前提最小化**：第一路必须交付前提表，并明确回答「非降性是否实质前提」；若识别真依赖非降性，照实写，不得为了好看而假称已经去掉。
5. **反例面显式化**：第二路与第四路都要列出「若识别为假，必然出现哪种见证」，并逐条核否或标未核。
6. **复算闸门**：`cycle-1/verify.py` 的检查项要与本方案第三、六节一一对应（至少：四条端点事实、两侧证书、区间嵌套、退出码）。
7. **写作纪律**：中文正文不用半角连字符；破折号用「——」；并列用「、」；编号用 1. 2. 3.。
