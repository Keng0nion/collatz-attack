### 2.2 Theorem 21（Ψ 的一切量的一手定义处）

**【本次亲读（渲染图）】**第 13 页（`/tmp/kcross_extract/pg-13.png`），逐字：

> **Theorem 21.** *Let K be the number of odd numbers in a given m-cycle, and let L be the number of even numbers in it. Further, assume there exists a positive integer m₂ with*
> `m₂ ≤ m and (δ^{m₂} − 1)/(δ − 1) · log((162/97)·X₀)/log(2) ≤ (m₂/m)·K.`
> `Let v = (m₂/m)·K·(δ − 1)/(δ^{m₂} − 1). Then we get`
> `δ < (K + L)/K < δ + 1/(K · 3 log(2)) · ( (97(m − m₂) + 73)/(54 · X₀) + 3/(2^v − 1) + 3 · (m₂ − 1)/((2^v − 1)^δ) ).`
> *If m₂ = m − 1 we get the better estimate*
> `δ < (K + L)/K < δ + 1/(K · 3 log(2)) · ( 3/X₀ + 3/(2^v − 1) + 3 · (m − 2)/(2^v − 1)^δ )`
> *and for m₂ = m*
> `δ < (K + L)/K < δ + 1/(K · 3 log(2)) · ( 3/(2^v − 1) + 3 · (m − 1)/((2^v − 1)^δ) ).`

三项裁决点（我亲读该页后与 `route-5.md:65` 至 `:70` 的转写逐条对照一致）：
1. ε 的第三项是 `3·(m₂ − 1)/((2^v − 1)^δ)`：δ 是括号 `(2^v − 1)` 的**指数**（勘误版形式）。
2. A(m₂) 三段：一般式 `(97(m − m₂) + 73)/(54 · X₀)`；`m₂ = m − 1` 段是 `3/X₀`；`m₂ = m` 段为 0。
3. 前提段逐字还有一句（同页）：
   > `If the only nonnegative integer fulfilling the given inequality is m₂ = 0, Corollary 17 and Corollary 19 give good upper bounds for (K+L)/K. Now let the inequality be true for some integer m₂ > 0.`
   即 m₂ = 0 不入本定理，可行集只在**正整数**中取（对应项目 `(D2)` 的 `1 ≤ m₂ ≤ m`）。

### 2.4 Lemma 22（「区间内最小分母」的一手陈述与两支证明）

**【本次亲读（渲染图）】**第 15 页（`/tmp/kcross_extract/pg-15.png`），逐字：

> **Lemma 22.** *Let 0 < α < β be two real numbers with continued fraction expansions α = [a₀; a₁, …, a_{k−1}, a_k, …] and β = [a₀; a₁, …, a_{k−1}, b_k, …]. Then every fraction in the open interval (α, β) has a denominator which is not smaller than the one of γ = [a₀; a₁, …, a_{k−1}, c_k] with c_k = min(a_k, b_k) + 1.*

证明两支逐字（同页）：

> `If k is even, increasing the partial denominator increases the fraction. Thus, we have a_k < b_k and [a₀; a₁, …, a_{k−1}, a_k] < α < [a₀; a₁, …, a_{k−1}, a_k + 1] < β. If we choose c_k := a_k + 1 = min(a_k + b_k) + 1, we get the fraction with smallest denominator in this interval.`
> `If k is odd, decreasing the partial denominator increases the fraction. Thus, we have a_k > b_k and α < [a₀; a₁, …, a_{k−1}, b_k + 1] < β < [a₀; a₁, …, a_{k−1}, b_k].`

**两处我亲读才注意到的一手细节（供下游裁决时用）**：
1. 陈述句写 `c_k = min(a_k, b_k) + 1`，而证明里两处都印成 `min(a_k + b_k) + 1`（把逗号印成加号）；按上下文（even 支 a_k < b_k 故 c_k = a_k + 1）陈述句才是正确形式。**这是印刷出入，不是数学分歧**；`route-5.md:79` 与 `route-3.md:169` 的转写都只抄了陈述句。
2. 证明的两支**各自把 γ 放进了区间内**（even 支给 `[a₀;…,a_k] < α < [a₀;…,a_k+1] < β`；odd 支给 `α < [a₀;…,b_k+1] < β`）。故「γ 落在区间内」在论文自己的证明里有依据；但**Lemma 22 的陈述句本身只给「不小于」**，作独立引用时仍须另核 γ 的落点——这正是项目两条严格证书各自显式打印的两个比较（`c2r5_cert.log` 第 41 行、`route1_cert.out` 的 `[C9]` 与 `[G2]`）。
