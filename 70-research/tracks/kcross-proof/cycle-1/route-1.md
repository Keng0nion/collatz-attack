## 二、解析证明

### 2.1 初等引理（每条给出完整证明）

**L1（固定 m₂，ε(m₂, ·) 在 K > 0 上严格递减）。** 记 c := (m₂/m)·(δ − 1)/(δ^{m₂} − 1) > 0（m ≥ m₂ ≥ 1，δ > 1），则 v = c·K 严格增。写
ε(m₂, K) = N(K) · (3K·log 2)^{−1}，N(K) := A(m₂) + 3/(2^{v(K)} − 1) + 3(m₂ − 1)/((2^{v(K)} − 1)^{δ})。
1. v ↦ 2^v 严格增且 v > 0 时 2^v > 1，故 t := 2^v − 1 > 0 严格增；t ↦ 3/t 严格减，t ↦ 3(m₂ − 1)/t^δ 非增（m₂ ≥ 2 时严格减，m₂ = 1 时为 0）；故 v ↦ N 严格减。
2. N(K) > 0（A ≥ 0 且 3/(2^v − 1) > 0）。
3. K ↦ (3K·log 2)^{−1} 严格减且为正。
故 K′ > K 时 ε(m₂, K′) = N(K′)·(3K′log 2)^{−1} < N(K)·(3K log 2)^{−1} = ε(m₂, K)（两个正因子各自严格变小）。∎
【与项目旧记录的关系：`cycle-1/route-4.md:153` 至 `:158` 给的是「非增」，`route-1`（cycle-2）的引理 M 给「严格递减」（`results/route1_extra.out:7`）；本条的差别是把 N > 0 与两个正因子相乘这一步写全。】

**L2（可行集单调、下段）。** 由 (D2)：m₂ ∈ F_m(K) ⟺ K ≥ K_thresh(m₂)（两边同除正数 geom(m₂)C/(m₂/m)… 具体地 geom(m₂)·C > 0 且 m₂ > 0，故等价变形合法）。于是 K₁ ≤ K₂ ⟹ F_m(K₁) ⊆ F_m(K₂)。∎

**L3（ε_opt 严格递减；且可行集不变时连续）。**
1. 设 K₁ < K₂ 且 F_92(K₁) ≠ ∅，取 m\* ∈ F_92(K₁) 使 ε_opt(K₁) = ε(m\*, K₁)。由 L2，m\* ∈ F_92(K₂)，故 ε_opt(K₂) ≤ ε(m\*, K₂) < ε(m\*, K₁) = ε_opt(K₁)（末一步用 L1）。∎
2. 若在区间 I 上 F_92 取常值 S（有限、非空），则 ε_opt = min_{m₂ ∈ S} ε(m₂, ·) 于 I；每个 ε(m₂, ·) 是连续函数的复合（v 连续、2^v − 1 > 0、正底数实数幂连续、K > 0），有限个连续函数的最小连续。∎
【与项目旧记录的关系：与 `cycle-2/route-4.md:51` 至 `:56` 的引理 A（非增）同路线；本条的严格性与连续性部分是本文件为 IVT 需要而写的。】

**L4（单模区间引理，即 cycle-2/route-4.md:60 至 `:64` 的引理 B；此处重述并自证）。** 设 p/q < r/s < p′/q′，且 p′q − p q′ = 1（unimodular）。则 s ≥ q + q′；且 s = q + q′ 只在 r/s = (p + p′)/(q + q′) 时取到。
证明：r/s − p/q = (rq − sp)/(sq) ≥ 1/(sq)（分子是正整数）；p′/q′ − r/s = (p′s − rq′)/(s q′) ≥ 1/(s q′)。两式相加：p′/q′ − p/q = (p′q − p q′)/(q q′) = 1/(q q′) ≥ 1/(sq) + 1/(s q′) = (q + q′)/(s q q′)，故 s ≥ q + q′。等号情形要求两个分子都等于 1，直接解出 r = p + p′、s = q + q′。∎

∎

**注 B7（这条路径的关键不对称）**：B3 只需要「γ 落在开区间内」，即 Ψ 的最小值集合**非空且含 γ**；它**不需要**「γ 是里面分母最小者」。因此 K_lo < R 一侧**完全不需要**最小性证书、也不需要非降性、也不需要 Ψ(K\*) = K\*。

### 4.3 开闭端点的细账

### 5.2 过程性失败三条（全部当场定位并修正，登记为经验）

1. **float64 打印陷阱**：首版脚本用 `float()` 打印区间端点，给出 `eps_opt(K*) = 8.973221708617136468e-42`，而旧日志是 `8.973221708617136016326e-42`（差在第 17 位有效数字）。定位：错在**本方打印**而非数学值（改为精确有理打印后与旧日志一致到 22 位，k1 日志 `:22` 至 `:23`）。教训与 `methods.md` 第 3 节第 2 条同款：**任何要进报告的小量都必须用精确有理或定点打印**。
