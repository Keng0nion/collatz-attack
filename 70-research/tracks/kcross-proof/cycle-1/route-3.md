### 3.3 机制 i：SB 双亲括号（全称结论，不依赖任何清单完备性）

1. `gamma` 的 Stern-Brocot 双亲（由 `gamma` 的连分数直接构造，不做搜索）：
   低端 `u = 202780263237295321099/127940101513462006853`，高端 `v = 123139092617126647266/77692117359936589403`。
2. 四点核验（全部精确有理比较）：
   1. `u` 与 `v` unimodular（`|p_u q_v − q_u p_v| = 1`）——True；
   2. 分母和 `q_u + q_v = 205632218873398596256 = K*`——True；
   3. `u < delta_lo`**严格**——True；`v > beta_hi`**严格**——True；
   4. 中项 `(p_u + p_v)/(q_u + q_v) = gamma`——True。
3. **结论（全称）**：对任意最简分数 `p/q ∈ (delta, beta)`，有 `u < delta < p/q < beta < v`，于是
   `p/q − u ≥ 1/(q q_u)`、`v − p/q ≥ 1/(q q_v)`，相加得 `v − u = 1/(q_u q_v) ≥ (q_u + q_v)/(q q_u q_v)`，
   即 **`q ≥ q_u + q_v = K*`**。又 `gamma ∈ (delta, beta)`（`gamma > delta_hi` 与 `gamma < beta_lo` 两条严格有理比较）给出反向不等式，故**区间内最小分母恰为 `K*`**。
4. 该论证只用到两条初等不等式与精确有理比较，**不需要 Lemma 22 的清单形式**。
