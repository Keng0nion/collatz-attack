## 二、已知的不可能性结果

分四组：定理级、项目内已证或已登记、与本疑点直接相关的被排除见证形态、缺口。凡非定理者逐条标明。

**2.1 定理级（约束方法族或参数族，不约束单个猜想）**

1. **族层面不可判定**：广义 Collatz（按剩余类分段仿射）的判定问题不可判定（Conway 1972）；集合 {g : range(g) = ω} 是 Π⁰₂ 完备（Kurtz 与 Simon 2007）。出处：`barriers.md:26` 至 `:28`、`frontier.md:30`。界线：只杀「一条统一定理覆盖一大类映射」，不给 3x+1 任何独立性结论。
2. **零测集屏障**：Z 在 Z₂ 中可数、测度零；3x+1 与 5x+1 在 Z₂ 上完全共轭而在整数上行为不同。故纯测度或遍历论证、以及对全部奇 a 同时有效的论证必败。出处：`barriers.md:50`、`:56`；`frontier.md:47`、`:63` 至 `:64`。
3. **符号与常数敏感性**：负整数有三个非平凡环；5x+1 有环 13 → 33 → 83 → 13。故不区分正负、或不依赖 a = 3 的论证必败。出处：`barriers.md:62` 至 `:63`（含项目自验）。
4. **无界下降深度与无界相对高度**：对每个 k，类 n ≡ −1 (mod 2^k) 的前 k 步严格上升，故「有限个剩余类加固定步数下降」的证书不存在（`barriers.md:61`；文献侧支持是 Hercher 引理 8，论证本身标注为笔记作者的推断加本地核验）；Crandall 1978 定理 (2.2)：sup T_m / m 无界（`barriers.md:64`，转引，原文本次未开）。推论：任何「一次扫完」的覆盖证书与任何「高度被初始值固定倍数控制」的势函数都不存在。
5. **差不等式框架的级上限**：每级 k 的最佳指数就是该级线性规划的值（Krasikov 与 Lagarias 定理 2.2）；Applegate 与 Lagarias II 自述指数收敛于 1 以下、变量消去法有其限度。出处：`barriers.md:44`、`:46`。界线：该框架内算力不能替代结构理论。

**2.2 项目内已证或已登记的「必然失败」**

6. **用「放大的有理替代 δ」当严格性检验，方向写反**：放大 δ 只让链约束更容易满足，通过它不蕴含真 δ 情形通过。出处：`learnings.md:38`；`cycle-1/scripts/route3_recheck.py:304` 至 `:306` 仍在犯（本轮未重跑该脚本）。
7. **网格、大 dps、双实现一致都不能当证明**：网格只作机制检查或反例搜索；有限点的严格证书只证那一点；「数值观察」不得写成「定理」。出处：`learnings.md:29`、`:44`；`cycle-2/route-1.md:283`。直接推论：不许用任何网格或采样支持「T = R」。

4. **gmpy2（精确整数与有理数，加 MPFR 包装的定向舍入）**：能：`mpq` 精确分数（本次复算 `7941964418702608664581/214072842063828923281`）；把 context 的 round 设成 `RoundDown` 与 `RoundUp` 后，`2^74.772951607598` 给出可分辨的 `3.227760467642759e+22` 与 `3.2277604676427909e+22`（差约 `3.19×10⁸`）。不能：本机 `/opt/homebrew/lib/libmpfr*` 实测无匹配（`zsh: no matches found`），定向舍入只能走 gmpy2 自带的 MPFR 包装；拿到的是浮点包络，拼成证书还要逐项写出单调性。
5. **sympy（符号代数）**：能：把引理的代数骨架写对（本次 `diff(3/(2**x − 1), x, 2)` 化简为 `3*2**x*(2**x + 1)*log(2)**2/(2**x - 1)**3`，对 `x > 0` 可读为正）。陷阱：`solve_univariate_inequality(2**x > 3, x)` 本次返回 `log(3)/log(2) < x`，这类判定由数值求值驱动（本次未核其内部依据），不能当证明。不能：判定含超越常数的命题本身。
6. **z3（SMT）**：能：线性有理片段精确（本次 `a + b ≥ 3 ∧ a ≤ 1 ∧ b ≤ 2 ∧ a + b > 5` 返回 `unsat`）、多项式实数片段精确（本次 `y² + y + 1 = 0` 返回 `unsat`），可用它做线性可行性与顶点枚举。不能：5.3.1 无 `Pow`（本次 `hasattr(z3, "Pow")` 为 False），把 `2^c = 3` 编码后返回 `unknown`。故含 `2^{x}` 的目标函数不能直接交给它——本疑点的 ε 恰含 `2^v` 与 `(2^v − 1)^δ`，这两项必须自建界。
7. **numpy（批量浮点）**：能：采样与反例探针。不能：无严格算术（本次 `numpy.float64(2**53 + 1) == numpy.float64(2**53)` 为 True），2⁵³ 以上的整数已不可分辨——本疑点的阈值 `K_cross ≈ 3.1×10²⁰` 远超此线，凡「用 float 定位阈值或识别 T = R」的做法一律不可用。
8. **标准库 fractions**：能：精确有理比较，本轮已用它做两套根区间的相含判定与「同一分母 K* 的两个分数不能同落区间」的计数界（本次实跑，两条都 True）。不能：不处理超越量，`2^v`、`log` 之类必须先化归成有理上下界。
9. **cc 加 GMP**：能：确定性大整数扫描（本次 `/opt/homebrew/include/gmp.h` 与 `libgmp.a` 在机，`cc -O2 -I/opt/homebrew/include -L/opt/homebrew/lib gmptest.c -lgmp -o gmptest` 编译并运行成功，输出 `515377520732011331036461129765621272702107522002`，即 3^100 + 1）。不能：本机没有 C 的区间算术库，实数不等式若要严格界必须自实现向外舍入。
10. **总括**：本疑点的三种产物（单点的严格不等式、两套区间的相含与计数界、有限清单的完备核对）本机够用；不够用的是机器核验（无证明助手），以及直接判定含 `2^v` 的超越命题（必须自建单调化归与有理界）。
