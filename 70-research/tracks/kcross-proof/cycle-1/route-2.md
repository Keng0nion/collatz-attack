### 2.5 证书 A（下侧，日志 [4] 节）：对一切 K_lo ∈ D_92 且 K_lo ≤ T_hi，永不越界

1. **A1【有限精确检查】**：对一切 m₂ ∈ F_92(T_hi) 比较 ε(m₂, T_hi) 与 γ − δ。实测 F_92(T_hi) = {1, …, 92}（92 项全部判定 True，未定 0 项），**全部 92 项的 ε 下界 > (γ − δ) 上界**，最小余量在 m₂ = 92 处为 `1.075910×10⁻¹⁶³`，次小在 m₂ = 91 处为 `5.124296×10⁻⁴²`，第三小在 m₂ = 90 处为 `8.850347×10⁻⁴²`（逐项数值在日志里可见）。
2. **A2【全称化归，初等】**：ε_opt 关于 K 严格递减。证明两行：设 K₁ < K₂、m\* 为 K₁ 处的 argmin，则 m\* ∈ F(K₁) ⊆ F(K₂)（可行集关于 K 单调），且 ε(m\*, ·) 严格递减（引理 L1，见 2.7），故 ε_opt(K₂) ≤ ε(m\*, K₂) < ε(m\*, K₁) = ε_opt(K₁)。于是**对一切 K ∈ [92C, T_hi]，ε_opt(K) ≥ ε_opt(T_hi) = min_{m₂ ∈ F_92(T_hi)} ε(m₂, T_hi) > γ − δ**（末步是 A1）。**这一步把「T_hi 一个点」化为「整个下侧区间」**，是计划里要求补的化归引理，本路不用 Ψ 非降性。
3. **A3【已证，三步】**：γ > δ（由 [0] 节的精确比较 gamma > delta_hi）且 γ − δ < ε_opt(K)（A2），故 γ ∈ (δ, δ + ε_opt(K))。由 (D5)，γ = p₄₃/K\* 是落在该开区间内、分母为 K\* 的分数，故 **Ψ_92(K) ≤ K\***。

5. **A5【有限精确检查，域闭合化归】**：先把「链可能走出域」这一洞补上。对一切 K ≥ 92C 有 1 ∈ F_92(K)，故 ε_opt(K) ≤ ε(1, K) ≤ ε(1, 92C) =: ε_ub（ε(1, ·) 严格递减，用 C 的下界代入给上界，实测 ε_ub = `1.548697222499×10⁻²³`）。再做 6456 项精确检查：对每个 q ≤ 6456，取最小的 p（= ⌊q·δ_lo⌋ + 1，它是「p/q > δ」的一切候选 p 的下界），验证 p/q ≥ δ_hi + ε_ub。**6456 项全部通过**，最小余量在 q = 6291（p = 9971）处为 `1.443273×10⁻⁷`。于是 Ψ_92(K) ≥ 6457 对一切 K ≥ 92C 成立，而 **6457 > 92C**（余量 0.3658），故链一旦在域内就永不离开 D_92。

### 2.6 证书 B（上侧，日志 [5] 节）：对一切 K_lo ≥ T_lo，首步越界

1. **B1【精确判定】**：92 ∈ F_92(T_lo)。
2. **B2【精确比较】**：ε(92, T_lo) 的上界 < (γ − δ) 的下界，负余量 `1.136322×10⁻¹⁶⁴`。
