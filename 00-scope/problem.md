# 问题陈述与成功标准

## 问题

定义映射 $T:\mathbb{Z}\to\mathbb{Z}$：

- 若 $n$ 为偶数，$T(n)=n/2$；
- 若 $n$ 为奇数，$T(n)=(3n+1)/2$（加速形式，跳过必然紧随的除二步）。

科拉茨猜想：对每个正整数 $n$，存在 $k\ge 0$ 使 $T^k(n)=1$。

等价的说法包括：

1. 不存在发散轨道（轨道无界）；
2. 不存在非平凡环（除 $1\to1$ 之外的环）；
3. 逆向树（从 1 出发用分支 $x\mapsto 2x$ 与 $x\mapsto (2x-1)/3$ 生成）包含所有正整数。

这三点合起来才等价于原猜想，分开看，任何一条单独成立都不够。本工作会把"无环"与"无发散"分开处理，这是历史上最常用的切法。

## 本工作的成功标准

1. **文献边界准确**：八条研究线的关键结果逐条能回到原始来源，无一条凭记忆断言。
2. **计算地基可复核**：至少给出一个有明确范围的全量验证结果（例如 $n\le X$ 全部归于 1），并说明 $X$ 之上未被触及。
3. **实验结论有独立重算**：每个实验的关键数字由另一套方法独立重算，不一致处必须披露。
4. **六条路线有精确失败点**：每条路线的尝试必须逐步骤标注状态（已证 / 缺口 / 错误 / 等价于原命题），并经受独立反驳。
5. **不夸大**：任何"证明了"字样必须伴随完整可核验的论证。做不到就明确写"未证明"。

## 明确不承诺的事

本工作不承诺证明科拉茨猜想。任何在缺少同行评审的情况下宣称证明的结果都应当被当作待核实的宣称；本工作若产生局部新结论，也只在其被独立复核后才标为"已确立"。
