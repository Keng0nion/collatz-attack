# stopping-times

（研究线：停时与密度。检索与核对日期：2026 年 10 月 18 日；同日按引文核对意见修订一次，修订内容见文末「修订记录」。本笔记按三类可信度标注：经同行评审的已证定理、仅预印本或自发布的宣称、被撤回的宣称（本次检索发现一处已撤回条目，即第 7 条；未发现被反驳的已发表结果）。凡我未亲自打开原文者，逐条标注「原文未打开」，并注明结论由哪几处独立来源转述。）

## 这条线在问什么

Collatz 迭代有两条彼此独立、且常被混为一谈的量化问题。约定加速映射 T(n) = n/2（n 偶）、T(n) = (3n+1)/2（n 奇），这正是 Terras 论文使用的形式。

一、停时与密度。设 χ(n) 为最小的 k ≥ 1 使 T^k(n) < n；称 χ 为停时（Terras 1976 的定义 0.1）。问：{n : χ(n) < ∞} 有多“大”（自然密度）？更强的问法：把阈值 n 换成 n^θ（θ < 1），{n : 存在 k，T^k(n) < n^θ} 的密度是多少？这是 Terras 1976 起，经 Everett 1977、Allouche 1979、Korec 1994，直到 Tao 2019/2022 的“几乎所有 n 的轨道都会下探”序列。

Terras 另引入第二个停时（本笔记称系数停时 τ）：最小的 k 使 λ_k(n) := 3^(S_k(n))/2^k < 1，其中 S_k(n) 为 n, T(n), …, T^(k−1)(n) 中奇数的个数。τ 只依赖前 k 个奇偶符号，因而在每个模 2^k 剩余类上为常数（原文命题 1.6）。

二、计数下界。设 π_a(x) 为 1 ≤ n ≤ x 中轨道包含 a 的整数个数（a ≢ 0 (mod 3)；a = 1 即“到达 1 的计数”）。问：π_a(x) ≥ x^β 中 β 能取到多大？这是 Crandall 1978、Sander 1990、Krasikov 1989、Wirsching 1993、Applegate 与 Lagarias 1995，直到 Krasikov 与 Lagarias 2003 的 x^0.84。

两类结果不可互推：第一类只控制“下探”这一弱化性质（下探后到达的较小值仍可能落在坏集中），第二类给的是计数函数的多项式下界，等价于下密度至少 x^(β−1)（我的换算），离“密度为正”仍很远。

## 关键结果

### 一、停时与密度

1. Terras 停时分布定理 —— 1976，Riho Terras，Acta Arithmetica 30 (1976), 241 至 252，DOI 10.4064/aa-30-3-241-252，扫描 PDF（我逐页读图核对）。内容（我的转述，量词照原文）：
   - 定理 1.2 给出判据：E_k(n) = E_k(m) 当且仅当 n ≡ m (mod 2^k)；推论 1.3 断言 n ↦ E_k(n) 以 2^k 为周期且取遍全部 2^k 个模式；推论 1.4 给出密度：对每个固定奇偶模式 (ε_0, …, ε_(k−1))，集合 {n : 前 k 个奇偶符号等于该模式} 的自然密度精确等于 2^(−k)。
   - 对每个 k ≥ 1，极限 F(k) := lim_(m→∞) (1/m)·#{n ≤ m : χ(n) ≥ k} 存在，且等于 P[τ ≥ k]（定理 1.11；P 的定义是把 τ 的值在 [1, 2^k] 这段整数上数一遍）。原文式子 (6)：P[τ ≥ k] = 2^(−k)·#{n ∈ [1, 2^k] : 对 1 ≤ i ≤ k−1 有 λ_i(n) ≥ 1}。
   - 主要结果（原文第 241 页的宣告）：lim_(k→∞) F(k) = 0；故 {n : χ(n) = ∞} 的自然密度为 0，即有限停时的正整数集自然密度为 1。
   - 我的推导与检验（标注：这一步是我的工作，不是原文表述）：由上式可化为 F(k) = A(k−1)/2^(k−1)，其中 A(m) 为满足 S_i ≥ i·log_3 2（1 ≤ i ≤ m）的长度 m 的 0、1 串个数。我用 Python 在 n ≤ 250000 上验证：k ≤ 8 时经验密度与 1/2、1/4、1/4、3/16、1/8、1/8、13/128 逐项吻合到 5 位小数；k = 9、10 时实测计数 18553/250000 = 0.074212 与 19/256 = 0.0742188 在第 5 位小数相差 1（因 250000 不是模式周期 2^8、2^9 的整数倍，有不到一个周期的对齐差，我核对了这一点）。同一计算复现“平台” F(3) = F(4)、F(6) = F(7)、F(9) = F(10)（即 χ = 3、6、9 的密度为 0，这是该显式形式给出的结论），并复现了原文的极值事实：n ≤ 250000 中 χ 的最大值为 135，且在 n = 35655 处唯一取到（原文第 251 至 252 页有同样记载）。
   - 我的推导还复现了原文列出的密度表值 F(135)：我用动态规划算得 F(135) = 5.331277×10^(−5)，与原文印出的 5.3312×10^(−5) 一致（这是我核对原表值的方式）。
   - 附带（条件性结论，原文第 250 至 252 页）：Terras 猜想 τ(n) = χ(n) 对所有 n ≥ 2 成立（文献中称 Terras 的系数停时猜想，见已撤回的 arXiv:2605.13886 摘要用词）；并指出若该猜想成立则不存在非平凡循环，而他的“跳跃值表”（Table C：k = 4、5、8、27、46、65、149、233、317、401、485、1539、2593 对应 m(k) = 1、5、25、109、282、808、2420、4863、9267、19585、72059、238672、420845）在 τ ≤ 2592 的范围内验证了该猜想，从而排除周期 ≤ 2592 的循环（这是 1976 年的计算边界，且“排除循环”依赖该猜想）。

2. Everett 独立证明 —— 1977，C. J. Everett，Advances in Mathematics 25 (1977), 42 至 45，DOI 10.1016/0001-8708(77)90087-1。【原文未打开】。结论（由 Korec 1994 正文第 85 页与 Tao 2019 论文引言两处独立转述，两处我都亲自打开）：{y : 存在 n，T^n(y) < y} 的渐近密度等于 1。

3. Terras 补足密度公式 —— 1979，Riho Terras，Acta Arithmetica 35 (1979), 101 至 102，DOI 10.4064/aa-35-1-101-102，扫描 PDF（我逐页读图核对）。原文开篇自述：该文补上一个“起关键作用的密度公式”的细节，因为其存在性与正确性曾受到 A. Garsia、H. Moeller 与编辑的质疑。文中的定理：δ[χ ≥ k] = P[τ ≥ k]（δ 为自然密度），并给出 δ[χ < k] + δ[χ ≥ k] = 1 与 P[τ < k] + P[τ ≥ k] = 1。Lagarias 注释书目（我打开）对此的记载是：Terras 1976 中“无穷停时集渐近密度为零”的证明曾被 Möller (1978) 批评，本文提供补充细节。结论：该定理如今被当作已证，但其证明史有一段修正。

4. Allouche 把下探加强到幂次 —— 1979，Jean-Paul Allouche，Séminaire de théorie des nombres（Bordeaux 与 Talence），1978 年至 1979 年，Exposé No. 9，15 页，CNRS；JSTOR 44166344。【原文未打开（JSTOR 收费墙）】。结论（由两处独立来源互证）：对任意固定 θ > 3/2 − log_3 2 = 0.869070…，集合 {n : 存在 k，T^k(n) < n^θ} 的自然密度为 1；这是他在 Hasse 型广义映射类上的定理对 3x+1 的特例（其一般形式未给显式常数）。两处出处与核对细节：
   - Korec 1994 第 86 页（审稿人转述；我读扫描图核对到常数表达式 3/2 − log_3 2 = 0.86907…，我在本机复核：1.5 − 0.6309298 = 0.8690702）。
   - Tao 2019 论文引言（我核对 arXiv v7 的 HTML 源码，其 alttext 为 \theta>\frac{3}{2}-\frac{\log 3}{\log 2}\approx 0.869）。注意：Tao 原文印的是 (log 3)/(log 2)，与紧随的数值 ≈ 0.869 自相矛盾（3/2 − 1.5850 < 0），应为原文笔误；数值自洽的写法是 (log 2)/(log 3) = log_3 2，即 3/2 − log_3 2 = 0.869070…。数学内容不受影响，且与 Korec 的转述互证。

5. Korec 定理 —— 1994，Ivan Korec，Mathematica Slovaca 44 (1994), no. 1, 85 至 89，DML 数字化 PDF（我打开全文，文本与扫描图都核对）。定理 1：对每个实数 c > log_4 3 = 0.79248125…，集合 M_c = {y ∈ N : 存在 n，T^n(y) < y^c} 的渐近密度为 1。原文另注：步数 n 可被 log_2 y 控制，但“不能与 y 无关地取常数”（否则等于证明猜想）；证明用两条引理：奇偶模式的周期与等分布（引理 1），以及一条中心极限定理推论（引理 2，要求参数 d > 1/2）。论文没有声称 log_4 3 是该方法的下界极限（我的核对）。注意定理对应的常数是 log_4 3，而摘要写作 y^(0.7925)，两者一致。

6. Tao 定理 —— 2019 预印本、2022 发表，Terence Tao，arXiv:1909.03562（我读 v7 全文，该版本页眉标注 2026 年 7 月 16 日），期刊：Forum of Mathematics, Pi 10 (2022), Paper No. e12（期刊信息读自 arXiv 页面；期刊页面未打开）。定理 1.3：对任意函数 f : N+1 → R 且 f(N) → +∞，有 Col_min(N) < f(N) 对“几乎所有”N 成立，其中“几乎所有”是对数密度意义（该文定义 1.2）；例如 Col_min(N) < log log log log N 对几乎所有 N。定量版本（据其引言所述定理 3.1）：对任意 δ > 0 存在常数 C_δ ≪ exp(δ^(−O(1)))，使 {N : Col_min(N) ≤ C_δ} 的下对数密度 ≥ 1 − δ。其引言明确：把结论推进到绝对常数 C_0“几乎与全猜想一样难”，超出本文方法；把对数密度换成自然密度是合理的猜想但未证。同处并注明：Allouche 与 Korec 这类结果“可以用自然密度而非对数密度”表述；Tao 引言亦把 Krasikov 与 Lagarias 的 x^0.84 列为已知的计数下界。

7. 【已撤回】Terras 奇偶向量密度的“有限化”加强 —— arXiv:2605.13886，作者 Tong Niu。v1 提交于 2026 年 5 月 11 日；v2 于 2026 年 5 月 20 日撤回（我打开该页确认：页面标明 “This paper has been withdrawn by Tong Niu”；Comments 栏的撤回理由是：Rozier 与 Terracol 的 arXiv:2502.00948v4（2026 年 4 月）已枚举加速 Collatz 映射中长度 ≤ 60 的全部 593 条悖论序列并识别出那七对 (j, q)，(46, 73) 的中项观察可由其数据直接得出，故撤回以避免重复）。该文摘要自述曾给出三件事：Terras 奇偶向量密度的有限化加强形式、悖论序列的闭式计数、有界长度悖论序列的密度零定理（带显式常数），并声明不对 Collatz 猜想与 Terras 系数停时猜想作任何宣称——这些内容我读自该页，但该文现已撤回，不应作为存续的预印本引用；其撤回理由反过来把 Rozier 与 Terracol 的枚举（我核对了该文现状：v5，2026 年 5 月 17 日，未被撤回；我只读了它的题录与摘要页）标记为本线可引用的相关来源。

### 二、计数下界 π_a(x) ≥ x^β

8. Crandall 的首个下界 —— 1978，R. E. Crandall，Mathematics of Computation 32 (1978), 1281 至 1292，DOI 10.1090/S0025-5718-1978-0480321-3（DOI 经 Crossref 核对）。【原文未打开】。结论（转引自 Lagarias 注释书目第 47 条，我打开该 PDF）：π_1(x) > x^c 对某个常数 c > 0 成立；原书目的评估是“其证明似乎给出 c = 0.05”——这是书目作者的评估，不是原文声明（原文未计算 c）。同条另记：他证明除平凡循环外无长度小于 17985 的循环。

9. Sander 的推进 —— 1990，J. Sander，Acta Arithmetica 55 (1990), 241 至 248，DOI 10.4064/aa-55-3-241-248（条目页我已打开确认存在）。【原文未打开】。结论（转引自 Lagarias 注释书目第 153 条）：把 Crandall 的方法推进到“使猜想成立的 ≤ x 的整数个数至少 x^(3/10)”。

10. Krasikov 引入差不等式系统 —— 1989，I. Krasikov，International Journal of Mathematics and Mathematical Sciences 12 (1989), no. 4, 791 至 796，DOI 10.1155/S0161171289000979；EMIS 镜像 PDF（我打开并抽读摘要与正文开头）。摘要原文：对使 3x+1 猜想成立的整数计数 θ(x) 建立差不等式系统，在“最简单情形”（即 k = 2）得到 θ(x) > c·x^(3/7)（3/7 ≈ 0.4286）。该系统 I_k（每个 k ≥ 2 一套，模 3^k）是此后一切 x^β 记录的引擎。

11. Wirsching 用 k = 3 —— 1993，G. J. Wirsching，Acta Arithmetica 63 (1993), 205 至 210，DOI 10.4064/aa-63-3-205-210（条目页我已打开确认存在）。【原文未打开】。结论 γ = 0.48：由 Applegate 与 Lagarias 1995 II 预印本正文（我打开）与 Krasikov 与 Lagarias 2003 引言（我打开）两处独立记载。

## 当前的技术极限（记录值是多少、谁保持、为什么停在那里）

记录值：x^(0.84)（实际线性规划值是 γ = log_2 1.7922310 = 0.8417560），由 Krasikov 与 Lagarias 2003 保持。核对范围（我的检索，不可能穷尽）：Lagarias 的综述（arXiv:2111.02635，2010 年书章，2021 年挂 arXiv；我打开）中条目 (W5) 正是“≤ X 且迭代到 1 的整数个数至少 X^0.84，对充分大的 X”；当前英文维基百科的 “Lower bounds” 一节只记 0.84（我打开）；Tao 2026 年 7 月的 arXiv 版 v7 仍把 0.84 作为已知结果引用（我打开）；arXiv API 与网络检索未见任何同行评审的新指数（截至 2026 年 10 月 18 日）。未被同行评审的宣称（第 15 条）不计入记录。

为什么停在这里，是四堵性质不同的墙：

1. 差不等式方法在每个级别 k 上的天花板。对每个 k，Krasikov 与 Lagarias 2003 的定理 2.2 说明：从 I_k 能提取的最佳指数就是线性规划 LN_k^T(λ) 的可行 λ 上确界 λ_k（指数 γ_k = log_2 λ_k）。他们论文结尾（§6）讨论：这个界“很可能就是 I_k 的正单调解所能给的最大值”，做到这一点需要两个条件（λ_k 被取到；主不等式在最优解处全部取等），他们相信对一切 k ≥ 2 成立，但“这可能难以证明”；在 k ≤ 11 上实验成立。也就是说：在这个方法框架内，同级别的结果不会超过表中 γ_k。
2. 通往 x^(1−ε) 的条件至今未证。Applegate 与 Lagarias 1995 II 给出：在其猜想 4.1（无截断规划的 λ 值支配一切“分裂后再截断”得到的规划）之下，Krasikov 猜想（对任意 ε > 0，x^(1−ε) 型界可由足够大的 k 的 I_k 推出）成立的必要条件是 λ_k → 2；并且 λ_k → 2 又等价于最优解的平均量满足 c̄_(k−1,k)/c̄_(k,k) → 1。Krasikov 与 Lagarias 2003 §6 把 λ_k → 2 直接写成 π_1(x) > x^(1−ε) 的充要条件。λ_k → 2 本身至今未证。
   数值趋势（原文表 2 的数据，我的观察）：k = 2 至 11 的 γ_k 单调增（0.4366 到 0.8418），但增量在衰减（相邻增量依次为 0.175、0.078、0.045、0.027、0.022、0.021、0.014、0.013、0.012）。只用这十项做外推无法判定是否趋近 1；这是我在数据上做的判断，不是原文结论。
   一处文献不一致（我发现，未定论）：Applegate 与 Lagarias 1995 II 预印本声称 λ*(L_k^NT) 随 k 严格递增（给出脚注论证），而 Krasikov 与 Lagarias 2003 §6 把“严格递增”列为未决问题。
3. 方法层面的障碍（Applegate 与 Lagarias 1995 II §4 的要点）：要证 Krasikov 猜想，必须使用非平凡的分裂规则，因为他们证明了“无分裂不等式”不够强；两种分裂策略（Advanced Splitting 与 8 mod 9 Splitting）在实验上似乎保留了足够信息，但最优解“没有明显规律”；变量消去量存在上限（Ultimate Splitting 的实验）。他们据此称这件事“令人惊讶地复杂”，是值得研究的方向。换句话说：障碍不是算力，而是缺少对最优解结构的解析理解；反过来，这也留着一层“算力墙”：类数随 k 按 3^(k−1) 增长（k = 11 时 59,049 类；要走到 k = 17 是 43,046,721 类）。
4. 密度一线的墙，以及“密度不能有效计数”的问题。证明只对固定 k 的“前 k 个奇偶符号”给出精确密度（精确为 2^(−k)，这是有限（finitary）层面的精确性）；Korec 明确指出步数不能与 y 无关；把“下探 n^θ”迭代成“下探 n^(θ²)…”会遇到 Tao 指出的测度不变性障碍（几乎所有的 [1, x] 可能被迭代送进 [1, x^(θ²)] 里的稀疏坏集）；Tao 的突破是换一个具乘法不变性的概率测度，代价是“对数密度”（自然密度版本只列为 plausible），并且无法把 f 换成常数 C_0。
   一个更尖锐的限制（我的计算与原文的自述吻合）：F(k) 衰减极慢，因而“密度”不能转化为初始区间的计数估计。我的动态规划给出 F(50) ≈ 3.54×10^(−3)、F(100) ≈ 2.64×10^(−4)、F(135) ≈ 5.33×10^(−5)、F(200) ≈ 3.32×10^(−6)（每步约乘 0.96）。我在 n ≤ 250000 上实测计数与“密度乘以区间长度”的比值：k = 20 为 1.000、30 为 1.007、40 为 0.977、50 为 0.965、60 为 0.945、80 为 0.831、100 为 0.697、135 为 0.075（期望 13.3，实测 1）。Terras 本人也记下同一现象：他按 F(135) = 5.3312×10^(−5) 算出在 3 ≤ n ≤ 250000 中“本来可以期望发现 13 个 τ(n) ≥ 135 的数”，而实际只有一个（χ(35655) = 135）。原因解释（我的推理，非文献结论）：密度是对完整周期 2^(k−1) 而言的，而 250000 远小于 2^(k−1)，初始区段里的计数与密度乘长度可以相差一个很大的因子，F(k) 没有误差项可供使用。
   另一条算术观察（我的）：Korec 的阈值 log_4 3 = 1/(2·log_3 2)，正好由 Terras 的临界奇步密度 log_3 2 = 0.6309… 决定；但 Korec 论文未声称该常数最优，我也未找到把它证为硬极限的文献。

## 未解决的缺口

1. π_1(x) > c(ε)·x^(1−ε)（对每个 ε > 0 存在 c(ε) > 0）未证。Lagarias 综述里明写“remains an open problem”；这与 λ_k → 2 未证是同一缺口的两种说法（Krasikov 猜想，1995 年由 Applegate 与 Lagarias 转述命名）。
2. λ_k → 2 未证；λ_k 是否严格递增在文献中说法不一致（见上）；λ_k 是否有解析表达式（而非逐 k 的数值优化）同样未知（本次检索未找到相关记载，标注为未核实）。
3. “到达 1”的集合下密度是否为正：未知。x^(0.84) 只给下密度至少 x^(−0.16)（我的换算），与“正密度”相距极远。
4. Tao 定理的自然密度版本未证（他本人称 plausible）；把 f(N) 换成绝对常数 C_0 他说“几乎与全猜想一样难”。
5. Terras 系数停时猜想 τ(n) = χ(n)（对所有 n ≥ 2）：本次检索未找到证明或反驳的文献；Terras 1976 证明它蕴含无循环，并在 τ ≤ 2592 范围内验证了它（其“跳跃值表”），从而条件性地排除周期 ≤ 2592 的循环。
6. F(k)（即 P[τ ≥ k]）尾部的精确渐近常数：Terras 用“修改二项式系数”的递推（其定理 1.14）；我验证了密度公式本身（k ≤ 8 与经验吻合到 5 位小数、F(135) 复现原表值），但没有核实其尾部渐近的解析常数（例如增长比 ρ = lim A(m)/A(m−1) 的精确值，我的数值估计 ρ ≈ 1.92）。
7. 我未核实的两处对照：(a) OEIS 条目 A100982（标题 “Number of admissible sequences of order n; related to 3x+1 problem and Wagon's constant”，我已打开该条目页）与我按 Terras 定义算出的可容许串计数（1、1、2、3、4、8、13、19、38）不逐项吻合——该条目的“order”归一化与我的不同，其与 Terras 计数的对应关系未核实；(b) Crandall 的 c = 0.05 是书目作者的评估，不是原文声明（我未打开原文）。
8. 四处关键原文我未能打开（Allouche 1979、Crandall 1978、Wirsching 1993、Sander 1990）：其结论分别由两处以上独立来源转述互证，但我没有直接读到原文；Applegate 与 Lagarias 1995 我读的是作者主页预印本（发表版页面两次抓取失败），发表版数值经 zbMATH 审稿互证。

## 若要在这一线推进，必须跨过什么门槛

1. 解析地理解线性规划最优解的结构，以证明 λ_k → 2（或至少给出 λ_k 的渐近下界）。这是差不等式路线通往 x^(1−ε) 的充要门槛（Applegate 与 Lagarias 1995 II；Krasikov 与 Lagarias 2003 §6）。现有证据显示这件事不能靠“把 k 再算大一点”解决：需要关于最优解结构的新定理，而不是更大的算力。
2. 或者放弃 I_k 系统，构造新的不等式族或新的迭代算术工具——因为 I_k 在每个级别 k 上的上限已被 Krasikov 与 Lagarias 的定理 2.2 锁死（在他们两个猜测条件之下）。
3. 密度路线：构造对 Collatz 迭代具备足够乘法不变性的概率测度，并把结论从对数密度升级到自然密度（Tao 留下的门槛）；再进一步，从“下探到常数 C”升级到“下探到 1”，必须处理坏集的迭代像问题，目前无已知途径。
4. 若要获得经同行评审的新记录：把类似第 15 条那样的计算做成可复现、可评审、带精确证书的论文（其证书是整数向量，原则上可独立检验）——这是本线目前唯一“看得见”的推进方向，但它的上限仍受门槛 1 与 2 约束（每提高一个级别 k 只涨一点点，且需要 λ_k → 2 才能到 x^(1−ε)）。
