### 1.2 结论：精确不等式

固定被检验的 `m`（反证假设里那个 m）与一对 `(K, m₂)`，`m₂` 可行（即满足第 11 条）。令

```
v      := (m₂/m) · K · (δ − 1)/(δ^{m₂} − 1)
A      := 0                       若 m₂ = m
         := 3/X₀                  若 m₂ = m − 1
         := (97(m − m₂) + 73)/(54 X₀)   其余
ε(K,m₂) := (1/(3K log 2)) · [ A + 3/(2^v − 1) + 3(m₂ − 1)/X₀ ]
```

则把 `Σ_{i=1}^{m} T(n_i)` 拆成三段——前 `m − m₂` 项用第 9 条（Theorem 14），首个窗口元素用第 8 条推得的下界 `2^v − 1 ≤ n_{m−m₂+1}` 与 Remark 7（得 `T(n_{m−m₂+1}) < 3/(2^v − 1)`），尾部 `m₂ − 1` 项用第 14 条——再代入第 10 条，得

```
(K + L)/K  <  δ + ε(K, m₂).
```

再用第 13 条把 `ε` 换成 `K` 的下界：`K ≥ q_min(ε)`（`q_min` 即 Lemma 22 的分母算子）。自举是

```
K₀ = 7 × 10¹¹
K_{j+1} = max { q_min(ε(K_j, m₂)) : m₂ 可行 }
```

（可行集随 `K` 增大而增大。脚本的实现是先用 argmin 取使 `ε` 最小的 `m₂`，再算 `q_min`；因 `q_min` 关于 `ε` 单调不增，两者在并列情形之外等价）。判据为：**若最终 `K* > 1.4784 · m · δ^m`，则该 m 被排除。**

**与印出版唯一的差别**就是 `ε` 括号第三项：印出版与勘误版用 `3(m₂ − 1)/(2^v − 1)^δ`，本版用 `3(m₂ − 1)/X₀`。

**本次已跑的一个结构性事实**：本版的括号关于 `m₂` 单调递增（`A` 每加一个 `m₂` 减少 `97/(54X₀) ≈ 1.796/X₀`，尾部每加一个 `m₂` 增加 `3/X₀`，净增约 `1.204/X₀ > 0`；在最后两级 `m₂ = m − 1` 与 `m₂ = m` 处 `A` 换成特例式，但中间项 `3/(2^v − 1)` 随 `v` 减小而上升，括号仍不下降），所以**最优恒为 `m₂ = 1`**，此时尾部为空、`3/(2^v − 1)` 亦可忽略，`ε ≈ A(m)/(3K log 2)`。这不是我预设的，而是脚本在 `m = 55…96` 每一步数值搜索出来的（输出里 `m2 used` 一栏全部为 `[1]`）。

**本版的数值结论**（比较用的上界必须按 SdW 自己的分段取，见 §3.6）：

1. `K*(91) = 4640282259296926456`，`1.4784 · 91 · δ⁹¹ = 2.14072842064 × 10²⁰`，比值 `0.0216761837446` ⟹ **m = 91 不被排除**（m = 91 正落在 `91 ≤ m ≤ 515619` 段，系数 `1.4784` 是这一段的，故这个比值不受本次更正影响）；
2. 逐 m 扫描 `m = 2 … 96`：`m = 2 … 82` 全部被排除，`m = 83 … 96` 全部挡回 ⟹ **上限 82**；
3. `m = 83`：`K* = 4640282259296926456`。按 SdW 定理 3(d) 的 78 至 90 段常数 `1.3993`：上界 `1.3993 · 83 · δ⁸³ = 4640504765304765034.6`，比值 `0.999952051335`（差 `4.79×10⁻⁵`）；按定理 3(c) 的逐 m 表印值 `4.6403×10¹⁸`：比值 `0.99999618`，但印值只有五位有效数字，见 §7.6。

## 五、被质疑那一步的裁定

印出版原文（`hercher5.txt` 第 796 至 801 行，上标被抽取压平；我按 `p14-14.png` 渲染图核对过 `δ` 的位置）：

```

                                nm−m2 +1+ℓ < nm−m2 +1 ≤ nδm−m2 +1 ,
                                            3
we get the inequality T (nm−m2 +1+ℓ ) < (2v −1) δ .
```

**两条独立缺陷，本次都已数值核对**：

1. **幂不等式方向反**：`δ^ℓ > δ`（`ℓ ≥ 2`），底数 `n_{m−m₂+1} > 1`，故 `n^{(δ^ℓ)} > n^δ`。本次已跑：`δ² = 2.51210612869226100901481 > δ`；`2^{δ²} = 5.704522494691117635350455 > 2^δ = 3.0`。
2. **推导方向反（致命）**：`T(n) < 3/n` 关于 `n` 递减。论文对晚窗口极小值只有**上界**（Lemma 20 的 `n_{i+1} < n_i^δ`），由此得到的是 `T` 的**下界**；要得到宣称的 `T(n_{i₀+ℓ}) < 3/(2^v − 1)^δ`，需要的是**下界** `n_{i₀+ℓ} > (2^v − 1)^δ`，论文从未建立它。本次已跑的量级：第一次自举时该阈值是 `1.2257371457178125228×10⁴⁰`，为 `X₀` 的 `1.529723×10¹⁹` 倍；第七步（`m₂ = m = 91`）时是 `1.16897670868×10³⁶`，为 `X₀` 的 `1.4588859×10¹⁵` 倍。

**裁定：fails**。这里我要把口径说准：缺陷 1 让印出版那串不等式里出现了**假命题**；缺陷 2 让「由 Lemma 20 推出该式」这条路**根本不通**，无论 `ℓ` 取值。二者都不是「换个常数就好」的局部问题。

**一处我不同意材料转述的地方（我的推断）**：三方材料第 40 行转述说所需下界「in fact contradicts Lemma 20 (`n_{i+1} < nᵢ^δ`) for `ℓ = 1`」。按原文，护栏只给 `2^v − 1 ≤ n_{i₀}`（一个下界），Lemma 20 给 `n_{i₀+1} < n_{i₀}^δ`（一个上界）；两者并不直接矛盾——只有当 `n_{i₀}` 与 `2^v − 1` 相等或几乎相等时才互斥。论文对 `n_{i₀}` 超出 `2^v − 1` 多少没有任何定量信息，所以严格说：**所需下界不被论文假设蕴含，但也不被它们直接否证**（`ℓ = 1` 时它只在窄带 `((2^v−1)^δ, n_{i₀}^δ)` 内与 Lemma 20 相容）。这不改变裁定，但改变「为什么错」的说法。

## 六、这一步在什么额外假设下才会成立

把印出版那一步单独拿出来看：它对每个 `ℓ = 1, …, m₂ − 1` 宣称

```
T(n_{i₀+ℓ}) < 3 / (2^v − 1)^δ .
```

**充分的额外假设（最直接的一条）**：

> (H1) 对每个 `ℓ = 1, …, m₂ − 1`，`n_{i₀+ℓ} > (2^v − 1)^δ`。

在 (H1) 下，由 Remark 7 立即得 `T(n_{i₀+ℓ}) < 3/n_{i₀+ℓ} < 3/(2^v − 1)^δ`，印出版那一步成立。本次已跑的量级说明 (H1) 有多强：它要求圈内元素比 `X₀` 大 15 至 19 个数量级（随自举步不同）。论文的假设里没有任何东西蕴含 (H1)。

**等价的其它说法**：

> (H1′) 在窗口上把 Lemma 20 换成反向不等式 `n_{i₀+ℓ} ≥ n_{i₀}^{δ^ℓ}`（`ℓ ≥ 1`）。

因为此时 `n_{i₀+ℓ} ≥ n_{i₀}^{δ^ℓ} ≥ (2^v − 1)^{δ^ℓ} ≥ (2^v − 1)^δ`（`ℓ ≥ 1`、底数大于 1）。注意 Lemma 20 的**证明是一串上界**（`n_{i+1} ≤ ½·C^{k_i}(n_i) < … < n_i^δ`），反向不等式在论文里没有任何支撑。

**不能充当额外假设的东西**（避免误读）：

1. **不可以用 Lemma 20 本身**：它是上界，方向不对；
2. **不可以把护栏用反**：`2^v − 1 ≤ n_{i₀}` 只给「首个」窗口元素，对 `ℓ ≥ 1` 的元素无效；
3. **勘误的凸性论证是另一回事**：2026 年勘误（`corrigendum.txt` 第 12 至 83 行，作者本人逐字承认 `contains an error`）改用 `S(x) := Σ 3/(2^{x_i} − 1)` 在多面体顶点上取最大，得到的是 `3/(2^v − 1) + 3(m₂ − 1)/(2^{δv} − 1)`——它是对**整个窗口和**的界，然后弱化成印出版的形状；那是一条**新的论证路线**（依赖 `S` 的凸性与顶点枚举，我在本报告里没有复核它），不是「印出版这一步在什么假设下成立」。健全版正是**不接受**这条路线（争点简报第 89 行口径）；
4. **`m₂ = 1` 时该步空洞**：窗口里没有「后来的」元素，尾部为零——健全版的最优解恰好就是这个情形，所以它根本不与争议步打照面。
