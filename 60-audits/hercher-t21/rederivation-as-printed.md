## 五、被质疑那一步：判定与反例

### 5.1 两条缺陷（都在本机跑出）

**缺陷一：中间不等号对 `ℓ ≥ 2` 为假。**
`δ ≈ 1.5849625 > 1`，故 `ℓ ≥ 2` 时 `δ^ℓ > δ`；底数 `n_{m−m₂+1} ≥ 2^v − 1 > 1`，故 `n^{(δ^ℓ)} > n^δ`，方向与印出的 `≤` 相反。数值：`δ² = 2.512106128692261009 > δ`；取 `n = 2`，`2^{δ²} = 5.7045224946911176354 > 2^δ = 3`。
量级：`δ⁹⁰ / δ = δ⁸⁹ = 6.3341777 × 10¹⁷`。而印出版在最后一轮取 `m₂ = m = 91`，该步被调用在 `ℓ = 1, …, 90` 上——即除 `ℓ = 1` 外**全部**取到了假的那个不等号。

**缺陷二：推理方向与 `T` 的单调性相反（致命）。**
`T(n) < 3/n` 关于 `n` 递减。印出版对后来的窗口极小值只给出**上界** `n_{m−m₂+1+ℓ} < n_{m−m₂+1}^{δ^ℓ}`，由递减性这只给出 `T` 的**下界**。要得到 `T(n_{m−m₂+1+ℓ}) < 3/(2^v−1)^δ`，需要的是**下界** `n_{m−m₂+1+ℓ} ≥ (2^v − 1)^δ`，印出版从未建立它（护栏只对窗口的**第一个**元素成立）。

#### 5.2.1 需要的额外假设（此处为应交叉反驳而修订）

印出那一步在窗口尾部这一段用到的推理原料只有两条：`2^v − 1 ≤ n_{m−m₂+1}` 与 `n_{m−m₂+1+ℓ} < n_{m−m₂+1}^{(δ^ℓ)}`。据此：
