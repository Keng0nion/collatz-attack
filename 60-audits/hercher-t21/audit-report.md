### 2.1 争议步骤与记号

3. 反证假设存在 m 圈；`n_1, …, n_m` 为按出现次序的局部极小值，`k_i` 为紧跟 `n_i` 的连续 `o-step` 数，`K = Σ k_i`，`L` 为圈内偶数个数；`T(n_i) := Σ_{t=0}^{k_i−1} 1/C^t(n_i)`（Definition 6，`hercher5.txt:170` 至 `:189`；Theorem 16，`:509`）。
4. Remark 7：对一切 i，`T(n_i) < 3/n_i < 3/X₀`（`hercher5.txt:190`）。
5. Lemma 8：`k_i ≤ x_i := log₂(n_i + 1)`（`hercher5.txt:207`；勘误第 27 行同）。

7. Theorem 21 的假设：存在正整数 `m₂ ≤ m`，使 `(δ^{m₂} − 1)/(δ − 1) · log₂((162/97)·X₀) ≤ (m₂/m)·K`；记 `v := (m₂/m)·K·(δ − 1)/(δ^{m₂} − 1)`；窗口为指标集 `{m − m₂ + 1, …, m}`（第 13 页陈述与第 14 页证明，`materials-primary.md:58` 至 `:72`，按渲染图核对）。记 `c := log₂((162/97)·X₀)`，本次已跑：`c = 70.1808063283083668248487894995`。
8. **单调性是本争议的枢纽**：`T(n) < 3/n` 关于 n **递减**——关于 n 的**上界**只能给出 `T` 的**下界**。

**争议步骤逐字**（第 14 页底部；`hercher5.txt:796` 至 `:801` 的抽取原文上标被压平，下面的转写按 `p14-14.png` 渲染图核对；与 `dispute.md:67` 至 `:72`、`materials-primary.md:42` 至 `:45` 一致，材料记录）：

1. 前置护栏（正确）：由 `v` 的定义得 `2^v − 1 ≤ n_{m−m₂+1}`，于是 `T(n_{m−m₂+1}) < 3/(2^v − 1)`；注意它只覆盖窗口的**第一个**元素。
2. 争议步（逐字）：`n_{m−m₂+1+ℓ} < n_{m−m₂+1}^{(δ^ℓ)} ≤ n_{m−m₂+1}^{δ}`；
3. 由它断言：对 `ℓ = 1, …, m₂−1`，`T(n_{m−m₂+1+ℓ}) < 3/(2^v − 1)^δ`（δ 是分母括号整体的上标）；
4. 服务的终式（同页，`hercher5.txt:808` 至 `:811`）：

   `Σ_{i=1}^{m} T(n_i) < (97(m − m₂) + 1)/(54·X₀) + 3/(2^v − 1) + 3(m₂ − 1)/(2^v − 1)^δ`，

   其中尾部项 `3(m₂ − 1)/(2^v − 1)^δ` 正是争议步的产物。（陈述页印 `+73`、证明末行印 `+1`，两处出入见第六节第 8 条。）

这一步为什么推不出来，有两条**互相独立**的缺陷（本次已跑复现两条的数值形态，见第四节问题 1）：

1. **第二个不等号对 ℓ ≥ 2 为假**：`δ^ℓ > δ` 而底数 `n_{m−m₂+1} > 1`，故 `n^{(δ^ℓ)} > n^δ`，方向与印出的 `≤` 相反；
2. **推理方向反**：`T(n) < 3/n` 关于 n 递减，论文对晚窗口极小值只有上界，只能推出 `T` 的下界；要得到宣称的上界，需要的是**逐项下界** `n_{m−m₂+1+ℓ} > (2^v − 1)^δ`，论文从未建立它（护栏只覆盖窗口的第一个元素）。

### 2.2 三个版本各自的说法（并排关键不等式）

三者**共享**的前置部分完全相同：Theorem 16、`T(n_i) < 3/n_i`、`2^v − 1 ≤ n_{m−m₂+1}`、`T(n_{m−m₂+1}) < 3/(2^v − 1)`，以及第一段 `Σ_{i=1}^{m−m₂} T(n_i) < A`。**唯一分歧**是窗口尾部 `Σ_{i=m−m₂+2}^{m} T(n_i)`（共 `m₂ − 1` 项）的处理：

| **印出版**（Hercher 2023） | 由 Lemma 20 迭代加 `T` 递减，直接断言每项都 `< 3/(2^v−1)^δ` | `n_{m−m₂+1+ℓ} < n_{m−m₂+1}^{(δ^ℓ)} ≤ n_{m−m₂+1}^{δ} ⟹ T(·) < 3/(2^v−1)^δ` | `3(m₂−1)/(2^v−1)^δ` | 七步到 m = 91 |
