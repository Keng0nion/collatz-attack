## 二、争议是什么

### 2.1 争议步骤与记号

记号（出处行号指 `/tmp/hercher-audit/hercher5.txt` 的 `pdftotext -layout` 抽取，详见 `dispute.md:24` 至 `:49` 的记号表）：

2. `X₀ := 695 · 2⁶⁰ = 801280445701758648320`，凡 `n ≤ X₀` 的轨道都到平凡圈（Definition 4，`hercher5.txt:80` 至 `:83`）。
3. 反证假设存在 m 圈；`n_1, …, n_m` 为局部极小值，`k_i` 为紧跟 `n_i` 的连续 o-step 数，`K = Σ k_i`，`L` 为偶数的个数；`T(n_i) := Σ_{t=0}^{k_i−1} 1/C^t(n_i)`（Definition 6，`hercher5.txt:170` 至 `:189`；Theorem 16，`:509`）。
4. Remark 7：对一切 i，`T(n_i) < 3/n_i < 3/X₀`（`hercher5.txt:190`）。
5. Lemma 20：`n_{i+1} < n_i^δ`（`hercher5.txt:673` 至 `:674`，Hercher 注明它也可在 Simons 与 de Weger 的文中找到）。
6. Theorem 21 的假设：存在正整数 `m₂ ≤ m`，`(δ^{m₂}−1)/(δ−1) · log₂((162/97)·X₀) ≤ (m₂/m)·K`；记 `v := (m₂/m)·K·(δ−1)/(δ^{m₂}−1)`；窗口为指标集 `{m−m₂+1, …, m}`（第 13 页陈述与第 14 页证明，按渲染图核对；`materials-primary.md:58` 至 `:72`）。
7. `T` 与 `3/n` 的关系是**递减**的：n 越大，`T(n) < 3/n` 给的界越紧。

**争议步骤逐字**（第 14 页底部；`hercher5.txt:796` 至 `:801` 抽取原文上标被压平，下面是按 `p14-14.png` 渲染图核对的转写，与 `dispute.md:67` 至 `:72`、`materials-primary.md:42` 至 `:45` 一致）：

1. 前置护栏（正确）：由 `v` 的定义得 `2^v − 1 ≤ n_{m−m₂+1}`，于是 `T(n_{m−m₂+1}) < 3/(2^v − 1)`；注意它只覆盖窗口的**第一个**元素。
2. 争议步：`n_{m−m₂+1+ℓ} < n_{m−m₂+1}^{(δ^ℓ)} ≤ n_{m−m₂+1}^{δ}`；
3. 由它断言：对 `ℓ = 1, …, m₂−1`，`T(n_{m−m₂+1+ℓ}) < 3/(2^v−1)^δ`（δ 是分母括号整体的上标）；
4. 服务的终式（同页，`hercher5.txt:808` 至 `:811`）：

   `Σ_{i=1}^{m} T(n_i) < (97(m−m₂)+1)/(54·X₀) + 3/(2^v−1) + 3(m₂−1)/(2^v−1)^δ`，

   其中尾部项 `3(m₂−1)/(2^v−1)^δ` 正是争议步的产物。（陈述页印 `+73`，证明末行印 `+1`；两处出入见第六节第 7 条。）

这一步为什么在论文自己的假设下推不出来，有两条**互相独立**的缺陷（`dispute.md:74` 至 `:79`；两份重推各自复算，见第四节问题 1）：

1. **第二条不等式对 ℓ ≥ 2 为假**：`δ^ℓ > δ` 而底数 `n_{m−m₂+1} > 1`，故 `n^{(δ^ℓ)} > n^δ`，方向与印出的 `≤` 相反；
2. **推理方向反**：`T(n) < 3/n` 关于 n 递减，论文对晚窗口极小值只有**上界**，只能推出 `T` 的**下界**；要得到宣称的上界，需要的是**逐项下界** `n_{m−m₂+1+ℓ} > (2^v−1)^δ`，论文从未建立它。
