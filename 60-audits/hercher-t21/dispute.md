按 `p14-14.png` 渲染图核对的转写（这是争议的核心）：

1. 前置护栏（正确）：`v ≤ log(n_{m−m₂+1}+1)/log(2)`，等价地 `2^v − 1 ≤ n_{m−m₂+1}`；于是 `T(n_{m−m₂+1}) < 3/(2^v − 1)`；
2. 争议步：`n_{m−m₂+1+ℓ} < n_{m−m₂+1}^{(δ^ℓ)} ≤ n_{m−m₂+1}^{δ}`；
3. 结论：于是 `T(n_{m−m₂+1+ℓ}) < 3 / (2^v − 1)^δ`（δ 是分母括号整体的上标，按渲染图核对）；
4. 该步服务的终式（同页）：`Σ_{i=1}^{m}T(n_i) < (97(m−m₂)+1)/(54·X₀) + 3/(2^v−1) + 3(m₂−1)/(2^v−1)^δ`，其中尾部项 `3(m₂−1)/(2^v−1)^δ` 正是争议步的产物。

### 1.3 这一步为什么不成立（两条**互相独立**的缺陷）

1. **不等式方向反（第二个不等号）**：`δ^ℓ > δ` 对一切 `ℓ ≥ 2`（`δ ≈ 1.58496 > 1`），而底数 `n_{m−m₂+1} > 1`，故 `n^{(δ^ℓ)} > n^{δ}`。「已核验」：`δ² = 2.512106128692261009 > δ`，取 `n = 2` 有 `2^{δ²} = 5.7045224946911176354 > 2^δ = 3`。
2. **推导方向反（致命）**：`T(n) < 3/n` 关于 `n` **递减**，故对后来的窗口极小值只能给出**上界**时，得到的是 `T` 的**下界**；要得 `T(n_{m−m₂+1+ℓ}) < 3/(2^v−1)^δ`，需要的是**下界** `n_{m−m₂+1+ℓ} > (2^v − 1)^δ`，而印出版从未建立它。

两条都不是「局部可修」的：窗口内可证的「大」只对**第一个**窗口元素成立（`2^v − 1 ≤ n_{m−m₂+1}`），后续元素没有逐项下界。

### 1.4 三个版本的不等式并排

三者**共享**的前置部分完全相同：Theorem 16、`T(n_i) < 3/n_i`、`2^v − 1 ≤ n_{m−m₂+1}`、`T(n_{m−m₂+1}) < 3/(2^v − 1)`、以及第一段 `Σ_{i=1}^{m−m₂}T(n_i) < A`。**唯一分歧**是窗口尾项 `Σ_{i=m−m₂+2}^{m}T(n_i)`（共 `m₂−1` 项）：

| | 尾部处理 | 关键不等式 | 带来的 `ε` 括号第三项 |
|---|---|---|---|
| **印出版** | 由 `T` 递减 + 假的幂不等式断言每项 `< 3/(2^v−1)^δ` | `n_{m−m₂+1+ℓ} < n_{m−m₂+1}^{(δ^ℓ)} ≤ n_{m−m₂+1}^{δ} ⟹ T(·) < 3/(2^v−1)^δ` | `3(m₂−1)/(2^v−1)^δ` |
| **勘误版** | 保留同一结论，改为经 `S` 的凸性与多面体顶点重证 | `T(n_{m−m₂+1}) + Σ_{i=m−m₂+2}^{m}T(n_i) < S(x_{m−m₂+1},…,x_m) ≤ S(v, δv, …, δ^{m₂−1}v) ≤ S(v, δv, …, δv) = 3/(2^v−1) + 3(m₂−1)/(2^{δv}−1) < 3/(2^v−1) + 3(m₂−1)/(2^v−1)^δ` | 同印出版：`3(m₂−1)/(2^v−1)^δ` |
| **第三方健全版** | 把该步判为「不是局部可修的」，退回 Remark 7 的逐项平凡界 `T(n_i) < 3/X₀`（该仓库文档未提及 2026 年勘误） | `Σ_{i=m−m₂+2}^{m}T(n_i) < 3(m₂−1)/X₀` | `3(m₂−1)/X₀` |

**一处口径不一致，请注意**：第三方的散文写「the best provable tail bound is `∑T ≈ m·3/X0`」，而其 Lean 的尾项用 `3 * ((m2 : ℝ) - 1) / X0`（三方材料第 44 行与第 46 行）。本简报一律按 Lean 的 `3(m₂−1)/X₀` 记；在我重建之下该口径的最优 `m₂ = 1`，尾部为零，故此不一致不影响 `82` 这个结论。

三者的 `ε` 因此分别是（`m₂ = m` 时 `A = 0`）：

1. 印出版与勘误版：`ε = (1/(3K log 2)) · ( A + 3/(2^v − 1) + 3(m₂−1)/(2^v−1)^δ )`
2. 第三方健全版：`ε = (1/(3K log 2)) · ( A + 3/(2^v − 1) + 3(m₂−1)/X₀ )`

两者第三项在 `m₂ = 91`、`v ≈ 75.6` 处相差极大（「已核验」：`(2^v−1)^δ ≈ 1.58 × 10³⁶` 而 `X₀ ≈ 8.01 × 10²⁰`，比值约 `2.0 × 10¹⁵`）——这就是「`91` 与 `82` 之分」的全部数值来源。

### 1.5 `K` 的下界算子（Lemma 22 的换算，三个版本都用到）

给定偏差上界 `ε`，由 `δ < (K+L)/K < δ + ε` 反解 `K` 的下界：

1. 在开区间 `(δ, δ+ε)` 内写 `δ = [a₀; a₁, a₂, …]`、`δ+ε = [a₀; a₁, …, a_{k−1}, b_k, …]`，其中 `k` 是两个连分数首次分歧的指标；
2. 取 `γ := [a₀; a₁, …, a_{k−1}, min(a_k, b_k) + 1]`，其分母记作 `q_min(ε)`；
3. Lemma 22 断言：`(δ, δ+ε)` 内每个分数的分母都不小于 `q_min(ε)`；而 `(K+L)/K` 约简后的分母整除 `K`，故 **`K ≥ q_min(ε)`**。

自举把这三件事串成不动点迭代：用当前的 `K` 下界算 `ε`（经最大可行 `m₂` 与 `v`），`ε` 经 Lemma 22 换算出更好的 `K` 下界，如此反复；每一步若新 `K > 1.4784·m·δ^m`（SdW 上界），则该 `m` 被排除。

连分数前 50 项（`δ` 的，供重推者直接引用，已核验）：`[1, 1, 1, 2, 2, 3, 1, 5, 2, 23, 2, 2, 1, 1, 55, 1, 4, 3, 1, 1, 15, 1, 9, 2, 5, 7, 1, 1, 4, 8, 1, 11, 1, 20, 2, 1, 10, 1, 4, 1, 1, 1, 1, 1, 37, 4, 55, 1, 1, 49]`。

## 二、三个版本各自的说法

1. **印出版**（Hercher 2023，JIS 26，文章 23.3.5，第 14 页）：由 Lemma 20 迭代（`n_{i+1} < n_i^δ`）加上 `T` 递减，直接断言窗口内每个后来的局部极小值都满足 `T(n_{m−m₂+1+ℓ}) < 3/(2^v−1)^δ`，据此把窗口尾部界为 `3(m₂−1)/(2^v−1)^δ`，并经七步自举得到 `m ≤ 91`。

3. 健全口径的 `82` 相对 `83` 的余量很小，且依赖上界系数（`1.4784` 差 5.7%，`1.3993` 差 `5×10⁻⁵`）。**先定系数，再谈 `82`。**
