## 一、勘误版的假设与结论（精确不等式）

### 1.1 全部假设（逐条，含出处）

记号同争点简报：δ := log 3 / log 2；X₀ := 695·2⁶⁰；m ＝ 环内局部极小值个数；k_i ＝ 紧跟 n_i 的连续 o-step 数，K ＝ Σk_i；x_i := log₂(n_i + 1)；T(n_i) := Σ_{t=0}^{k_i−1} 1/C^t(n_i)；v := (m₂/m)·K·(δ−1)/(δ^{m₂}−1)；c := log₂((162/97)·X₀)。

(A1) Theorem 16（`hercher5.txt` 第 509 至 513 行，原件逐字）：
    δ < (K+L)/K < δ + (1/(3K·log 2))·Σ_{i=1}^{m} T(n_i)。

(A2) Remark 7（第 190 行，原件逐字）：对一切 i，T(n_i) < 3/n_i。

(A3) Lemma 8（第 207 行，原件逐字）：k_i ≤ log₂(n_i + 1) ＝ x_i。

(A4) Lemma 20（第 673 至 674 行，原件逐字）：n_{i+1} < n_i^δ，等价地 x_{i+1} < δ·x_i。

(A5) 鸽笼窗口（印出版与勘误共用的第一步，第 768 至 775 行，原件逐字）：存在 m₂ 个连续局部极小值，使
    k_{m−m₂+1} + ⋯ + k_m ≥ (m₂/m)·K。

(A6) 勘误新增的窗口选择（`corrigendum.txt` 第 31 至 34 行，原件逐字）：把这 m₂ 个连续局部极小值取成使
    x_{m−m₂+1} + ⋯ + x_m 最大
    的那一组。此选择仍在同一个环上做循环移位。由 (A3) 与 (A5) 得 Σx ≥ Σk ≥ (m₂/m)·K；由最大性得 x_{m−m₂} ≤ x_m，再由 (A4) 得**回绕约束**
    x_{m−m₂+1} < δ·x_{m−m₂} ≤ δ·x_m。

(A7) m₂ 的定义不等式（Theorem 21 陈述，第 697 至 702 行，按渲染图核对）：
    (δ^{m₂} − 1)/(δ − 1) · c ≤ (m₂/m)·K，1 ≤ m₂ ≤ m。
    注意 c ＝ 70.18… > 1（已核验），故 (m₂/m)K ≥ c·(δ^{m₂}−1)/(δ−1) > (δ^{m₂}−1)/(δ−1)。

(A8) 第一段的上界（Theorem 21 陈述与证明末行；**本报告未重推，按论文原样采用**）：
    Σ_{i=1}^{m−m₂} T(n_i) < A，其中
    A ＝ 0（m₂ ＝ m）、A ＝ 3/X₀（m₂ ＝ m−1）、A ＝ (97(m−m₂) + 73)/(54·X₀)（其余）。

(A9) Lemma 22（第 822 至 845 行，原件逐字）：设 0 < α < β，其连分数在指标 k 处首次分歧，则 (α, β) 内每个分数的分母不小于 γ ＝ [a₀; a₁, …, a_{k−1}, min(a_k, b_k) + 1] 的分母。

### 1.2 勘误版要证的结论（精确不等式）

在 (A1) 至 (A9) 之下，勘误版断言

(C1)（聚合尾界，`corrigendum.txt` 第 15 至 20 行与第 60 至 82 行，原件逐字）
    T(n_{m−m₂+1}) + Σ_{i=m−m₂+2}^{m} T(n_i) < 3/(2^v − 1) + 3(m₂ − 1)/(2^{δv} − 1) < 3/(2^v − 1) + 3(m₂ − 1)/(2^v − 1)^δ。

其推导链（多数步与印出版共享）为：

(S1) T(n_i) < 3/n_i ＝ 3/(2^{x_i} − 1)（由 (A2)），故窗口内的和 ≤ S(x_{m−m₂+1}, …, x_m) ＝ Σ_{i} 3/(2^{x_i} − 1)；
(S2) S 在可行多面体 P ＝ {x_i ≥ 1；x_{i+1} ≤ δx_i（窗口内相邻）；x_{m−m₂+1} ≤ δx_m（回绕，来自 (A6)）；Σx ≥ (m₂/m)K} 上的最大值在顶点取到；
(S3) 顶点只能是 (v, δv, …, δ^{m₂−1}v) 的循环置换，其中 v 由 Σx ＝ (m₂/m)K 定出；
(S4) 于是 S ≤ Σ_{j=0}^{m₂−1} 3/(2^{δ^j v} − 1) ≤ 3/(2^v − 1) + (m₂−1)·3/(2^{δv} − 1)；
(S5) 收尾 (2^v − 1)^δ < 2^{δv} − 1（已核验，见 §4.2），给出 (C1) 的第二个不等号。

### 1.3 勘误版**没有**证的命题（重要）

印出版第 14 页断言的是**逐项**不等式

(P) 对 ℓ ＝ 1, …, m₂−1：T(n_{m−m₂+1+ℓ}) < 3/(2^v − 1)^δ，

其推出链条是 n_{m−m₂+1+ℓ} < n_{m−m₂+1}^{(δ^ℓ)} ≤ n_{m−m₂+1}^{δ}，再对递减的 T 取上界。勘误明确承认这条推导「contains an error」（`corrigendum.txt` 第 12 至 14 行，原件逐字），并**只**重证聚合形式 (C1)，**不**重证 (P)。就 Theorem 21 证明的最终装配而言，需要的是 (C1)（因为 T(n_{m−m₂+1}) 与尾部在印出版里是分别估的，加起来正是 (C1) 的左端），故勘误版覆盖了原证明所需的同一结论，但 (P) 本身在这一版本里不再成立（也不被使用）。

用版本说法对照：印出版与勘误版给出的 ε 括号第三项同为 3(m₂−1)/(2^v−1)^δ，第三方健全版为 3(m₂−1)/X₀。

## 二、判定：争议步在勘误版下的状态

**逐项命题 (P)：不成立**（勘误自认，且我复算否证了它的关键一步，见 §4.1）。

**聚合命题 (C1)：成立**，但勘误原文的写法需要补三处才自足。

1. **窗口选择必须按 Σx 读**（原件逐字是「let the cycle be entered in such a way that this sum is maximal」，上文那句「this sum」指代的是刚写下的 x 和而不是 Σk）。按 Σx 读，回绕约束 (A6) 才成立，顶点识别才成立；按 Σk 读则不成立。
2. **「凸函数在（无界）多面体上取最大值于顶点」未加论证**。P 的回收锥含于非负卦限（绕链一圈得 x_i ≤ δ^{m₂}x_i，故任一回收方向 d_i ≥ 0），沿回收方向 S 不增，故 S 在 P 上取到最大值；凸函数在凸多面体上的最大值必有一个在顶点取到（若最大点不极端，凸性使其分解两端之一也最大，维数递减至顶点）。这两句合起来补上这一处。
3. **严格不等号使可行集非闭**（勘误写 x_{m−m₂+1} < δx_m）。由于最终只需要 S 的上界，把这条读成「≤」并把多面体闭化是合法的，也才能谈「顶点」。这一处属表述，不影响结论。

**结论：conditional。** 也就是说：勘误版替代论证的结论正确、与论文自身假设相容，并在补上上述三处（第 1、3 处是读法与表述，第 2 处是几句可补的论证）之后成为完整证明；其数值后果（m ≤ 91）我独立复现，且余量很大。但勘误原文并未把这三处写出来，故不宜径直标为「已严格成立」。

附带诚实说明：我最初尝试给 (S4) 一条绕开顶点论的更简证明（用 x 逐点支配以 M ＝ max x_i 为峰的循环几何序列，得 S(x) ≤ Σ_k f(M/δ^k)），该尝试在我自己的数值反例下失败——h(M) 关于 M **递减**，而 Σx ≥ W 只给出 M 的**上界**，方向相反（脚本 `[2c]` 一节保留了正确的那一半：S(x) ≤ Σ_k f(M/δ^k) 通过了 3000 余个样本的检验）。故本报告不采用那条路线，只用勘误原文的顶点论加第二节的三处补充。

## 六、这一步在什么额外假设下才会成立

### 6.1 勘误版：补上三处即为完整证明

1. **窗口按 Σx 取最大**（不是按 Σk）。勘误原文的「this sum is maximal」只能读作 x 和；只有这样才有回绕约束 x_{m−m₂+1} ≤ δx_m，顶点识别也才用得上下述计数。这是**假设（读法）**，原文措辞允许，但需明确。
2. **最大值在顶点取到的论证**（无界多面体的处理）。需要的补充是：回收锥含于非负卦限（对回收方向 d，绕链一圈有 d_i ≤ δ^{m₂}d_i，故 d_i ≥ 0）；S 沿回收方向单调不增（f 递减）；由 (A7) 知 x_i ＝ 1 不可行，故下界约束不起作用，极小面维数递减即可取到顶点。这属于**需补的引理**，不长但原文没有。
3. **把 x_{m−m₂+1} < δx_m 读成 ≤**。严格不等号使 P 非闭，「顶点」无从谈起；由于我们只要 S 的上界，闭化是合法且无损的。这属于**表述修正**。

三者都不涉及新的数论输入。补上后，(C1) 成立，m ≤ 91 与余量 37.1 倍随之成立。

### 6.2 逐项命题 (P) 需要什么才可能成立

要使 (P) 复活，需要一条印出版与勘误都没有的**逐项下界**：对 ℓ ＝ 1, …, m₂−1 有 n_{m−m₂+1+ℓ} > (2^v − 1)^δ（或任何足以支配 3/(2^v−1)^δ 的下界）。Lemma 20 只给上界（n_{i+1} < n_i^δ），鸽笼只给窗口的 o-step **总量**，两者都不能把下界分配到单个晚窗口极小值上。因此 (P) 不是局部可修的——这与第三方指控一致；但 Theorem 21 的最终装配并不需要 (P)，只需 (C1)。

### 6.3 与第三方健全版的差别

第三方把窗口尾项换成 3(m₂−1)/X₀（只由 Remark 7 支撑）。两者的差别是纯数值的：在 m ＝ 91 第七步处，(2^v−1)^δ/X₀ ＝ 1.46×10¹⁵，故勘误版的第三项比健全版小十五个量级，这就是 91 与 82 之分。我的复算支持勘误版的第三项（我验证了它的每一步），但在第二节的三处补充到位之前，我不把勘误版写成「已严格成立」。
