## 一、屏障机制：n 同余 -1 模 2^k 的那一类数前 k 步只升不降

运行命令：

```bash
"/Users/luna/Documents/math IA/collatz-attack/20-experiments/.venv/bin/python" \
  40-formal/independent-checks/barrier_and_exponents.py
```

验证方式：对 k 从 1 到 24、乘数 m 取 1、2、3、5、7、12345、10^18 加 7，共 168 组，令 n = m·2^k − 1，用加速映射 T(x) = (3x+1)/2（奇数输入）迭代 k 步，逐一检查三件事。

结果：**168 组全部通过，零失败**。三条检查是：

1. 前 k 步的每一步输入都是奇数（即这 k 步全是奇数步）；
2. 序列严格递增；
3. 实际迭代值与闭式 n_j = 3^j · m · 2^(k−j) − 1 完全一致。

样例（k = 20、m = 1，即 n = 1048575）：前六个值是 1048575、1572863、2359295、3538943、5308415、7962623，第 20 步的值是 3486784400，与闭式 3^20 − 1 = 3486784400 相符，整段严格递增。

**为什么成立（三步归纳，写出来是为了以后能形式化）**：设 n = m·2^k − 1。第一步有 (3n+1)/2 = 3m·2^(k−1) − 1，它同余 −1 模 2^(k−1) 且为奇数；归纳可得第 j 步的值是 3^j·m·2^(k−j) − 1，同余 −1 模 2^(k−j) 且为奇数；相邻两项之比为 3/2，故严格递增。

**这条对死路清单意味着什么，以及不意味着什么**：对任何「用有限个剩余类覆盖全部正整数、并对每类证明在固定步数内降到自身以下」的证书形式，取 k 大于该固定步数，则这一类数全部违反要求，所以该形式的证书不存在。**注意范围**：本次验证的是上述机制本身；边界地图里这条死路已被标注为「笔记作者的推断（文献侧支持为 Hercher 2023 引理 8 与 Simons 与 de Weger 对 Steiner 的重述）」，并且明确写了**允许归约到已验小数的更强覆盖形式不被此论证排除**。本记录不改变这个标注：它把机制验实了，没有把推断升级为定理。

## 二、指数与门槛换算

1. **γ_11 = log_2(1.7922310) = 0.841756597818。** Krasikov 与 Lagarias 2003 表 2 印的是 0.8417560，两者相差 5.98×10⁻⁷，落在第 7 位小数，属论文表格自身的取整。边界地图写的「约 0.84175」是 5 位小数截断，按四舍五入应写 0.84176；实质无影响，「0.84 是保守表述」这一结论不变。这一条属于显示精度问题，不是错误，记录在此免得后来者重复排查。
2. **log_4 3 = 0.7924812504**，边界地图写 0.7925，相符（Korec 定理阈值）。
