第六组实验（逆向树）的数字此前没有经过主代理的任何独立核对，本记录补上这一块。脚本在 `40-formal/independent-checks/reverse_tree_recheck.py`，约六十行，**不复用实验的任何代码**（实验用的是 Python 加 C 两套实现，我这里是完全另写的一套，只跑深度 24，以及与前向停时无关的独立覆核）。

## 一、先记我自己的一个错误（值得保留，因为它有欺骗性）

第一版实现忘了做根节点去重。根 1 的第二个孩子是 (2·2 减 1)/3 = 1，所以「1、2」这一对会在朴素广度优先里无限再生：每层多带一个奇节点，节点数被放大到约 2.3 倍（第 24 层我算出 1534，报告是 665），而且**结构性恒等式看起来处处成立**——多出来的那个奇节点恰好补上了 d = 1 的缺口，把本该出现的唯一例外掩盖掉了。也就是说，这个 bug 会让一个错误的实现得出「比正确实现更漂亮」的结论。加上全局去重集合、使各层恰好等于停时的纤维之后，全部数字与报告逐格吻合。

## 二、核对结果（全部一致）

1. **层结构自我校验**：我算出的第 d 层与「停时等于 d 的节点集」在 2299 个节点上逐点一致，不一致 0 个。
2. **结构性恒等式**：第 d+1 层奇数个数等于第 d 层中同余 2 模 3 的节点个数，d 从 0 到 23 的**唯一例外是 d = 1**，与报告所说完全相同。
3. **表格逐格对照**（我算／报告）：第 8 层为 6、1、2 对 6、1、2；第 16 层为 68、18、23 对 68、18、23；第 24 层为 665、160、220 对 665、160、220。第 24 层的增长常数我算 0.667255，报告表格同行为 0.667255。
4. **覆盖上界全部复现**：M(25) = 25（缺席者 27）、M(70) = 53（缺席者 55）、M(71) = 71（缺席者 73）、M(73) = 95（缺席者 97）、M(75) = 127（缺席者 129），括号里的第一个缺席奇数及其停时（70、71、73、75、77）也都与报告一致。
5. **顺带核到一条**：停时 σ(871) = 113，且我算出 M(113) = 1159（即深度 113 足以覆盖全部不超过 1000 的奇数），与报告「覆盖到 1000 需深度 113、由 871 达到」相符。

## 三、这次没覆盖什么

1. **深跑本身没重跑**：报告的第 65 层（3.548 亿节点、三次运行一致）与补跑的第 66 层，我只核了前 25 层的层结构，没有重跑深跑；深跑的可信度依赖报告自己的双向校验（层内严格递增、每个孩子的父节点在上一层二分可查）与三次运行的逐字一致。
