## 附带发现：Eliahou 周期形式的三个常数来自 log2(3) 的连分数分子

边界地图第一节第 9 条记录了 Eliahou 的周期形式「p = 301994a + 17087915b + 85137581c」。本次验算顺手检查了这三个常数的来历：它们**恰好是 log2(3) 连分数第 13、15、16 个收敛分数的分子**（对应分母分别为 190,537、10,781,274、53,715,833）。

这说明 Eliahou 的周期形式不是凭经验拼出来的常数集合，而是连分数逼近的直接产物，也解释了为什么它与 q_23 门槛属于同一套机制。这一点在八份笔记里没有写明，属本次验算新增的观察；它只是对已知机制的确认，不构成新结论。
