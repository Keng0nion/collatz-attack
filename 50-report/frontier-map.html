一总览

上半是八条文献线在 2026 年 10 月 18 日核对节点上的现状（来源 10-literature/frontier.md 与 10-literature/notes/ 下八份笔记）； 下半是六条证明路线在第二轮与第三轮之后的最终状态，每条附上它在反驳中最致命的一击（来源 30-proof-attempts/ 下六条路线的 attempt.md 与反驳文件）。 带「仅预印本」「未核实」「争议」字样的条目一律按原样保留标注。

八条文献线：现状

线在问什么现状（一句话）
verification
计算验证		 被计算机完整验证到哪个上限；树搜索与模类剪枝的覆盖性建立在什么之上；为什么推不远。 最高已发表纪录：所有小于 2^71 ≈ 2.361×10^21 的正整数到达 1（Barina 2025，同行评审论文，但纪录本身是有限计算，不是定理）。项目自报前线 2075×2^60 ≈ 2^71.02。三大瓶颈：成本对范围线性、范围对算力指数、以及「有限验证通向全称命题」没有桥梁。
stopping-times
停时与密度		 下探到自身以下、乃至下探到 n^θ 以下的集合有多大；计数下界 π_a(x) ≥ x^β 的 β 能到多大。 密度侧到 Korec 1994 的 θ > log_4 3 ≈ 0.7925 与 Tao 2022 的「任意发散函数」；计数侧到 Krasikov 与 Lagarias 2003 的 x^0.84（λ = 1.7922310，实际指数 γ ≈ 0.84175）。差不等式框架内每级 k 的硬上限被 KL 定理 2.2 锁死，λ_k → 2 未证。
tao-almost-all
几乎有界		 Tao 2019 与 2022 的「几乎所有轨道取到几乎有界值」的确切量词、密度语义与定量引理。 定理：对任意 f(N) → ∞，Col_min(N) < f(N) 对下对数密度 1 的 N 成立。自然密度升级仍不可及（Gonçalves 等明确写「不可及」，Tao 自己写「看来可以达到」）；固定常数 C_0 版被 Tao 自评为「很可能与整个猜想一样难」。
cycles
环与 m 圈		 非平凡环必须满足什么方程；由此能挤出的 m 下界、奇数项下界与周期下界各是多少。 环方程 x = c/(2^n − 3^m)（Böhm 与 Sontacchi 1978）。m 侧到 m ≤ 91（Hercher 2023 加 2026 勘误；此档有未裁决争议，第三方 Lean 只到 82）；K > 1.375×10^11；周期下界标准口径至少 355,504,839,929、加速口径至少 217,976,794,617（后者缺一手出处）。界对 m 指数增长，对 K 次指数增长。
two-adic
2 进与遍历		 把 T 共轭到 2 进移位之后，共轭映射本身的算术性质、Syracuse 随机变量、以及测度论能给出什么。 Z_2 侧动力学完全解决：存在唯一同胚 Φ 把加速映射共轭到移位，Φ 是等距且保测度，T 因此是 Bernoulli，且 Φ 与其逆处处不可微。周期猜想（Φ 保持有理数）只证了一半。核心困难：动力学被完全理解的空间与猜想所谈的整数集几乎不相交。
undecidability
不可判定性		 推广成一族映射之后判定问题到哪一层；具体小图灵机的硬度边界停在哪里。 族层面：Conway 1972 判定不可判定；Kurtz 与 Simon 2007 的 {g : range(g) = ω} 是 Π⁰₂ 完备。具体机器：7910 状态机停机独立于 ZFC（假设 ZFC 一致），745 状态（学士论文），254 与 250 状态（社群加 Coq，未评审）；BB(5) = 47,176,870（仅预印本，带 Coq），BB(6) 被 Antihydra 阻塞。原猜想是单个实例，这些结果一条都不约束它。
claims-2024-2026
宣称窗口		 2024 年至 2026 年间有哪些新的「完整证明」类稿件，以及它们的状态。 截至 2026 年 10 月 18 日，窗口内找不到任何一条获得数学界承认的完整证明；所有「完整证明」稿都落在 arXiv 的 math.GM 或 arXiv 之外的自我出版渠道。唯一被媒体当作反证报道的形式化事件（2026 年 7 月）已公开否认，原因是一枚 Lean 内核漏洞。
barriers
障碍与死路		 哪些一般性证明框架已被证明无法奏效；哪些只是当前技术天花板。 硬障碍：不可判定性、零测集、无界下降深度、势函数与证书形式的不可能性。天花板：各种纪录停在哪里、为什么停在那里。两处以「缺口」形式存在（更一般的覆盖形式、自动机路线），不应宣称已被排除。最常见的错误是把族层面的结果当成对原猜想的约束。

六条证明路线：最终状态与最致命的一击

算术路线 arithmetic-cycles 主目标未完成

目标：不存在非平凡正环（把「无环」与「必达 1」分开，只处理后一半里的无环）。工具是 Böhm 与 Sontacchi 环方程、2^k 与 3^m 的分离性、连分数。

立住的局部结论： 1. 窗口判据的可达范围定理：该判据能排除的整数 K 必满足 K < (3X0 − 1)ln 2，渐近约 2.0795 X0，无论连分数数据多好。 2. 幸存者族与阶梯上界：未被排除的不是散点，而是收敛项分母的倍数族。 3. 有理候选定理：任何「对每个奇偶字都成立」的必要条件都不可能排除任何参数对；能起排除作用的只能是整性或由整性派生的结构不等式。 4. 1 圈这一档被封闭：K ≤ 20000 用精确整数逐个检验（唯一通过的是 K = 1），K ≥ 108 一侧由 Rhin 型下界排除（转引）。 5. 最大元定向前缀引理与 c_max 公式。

最致命的一击：全称收尾一定失效。U(m) 随 m 以 δ^m 量级增长，而 L(m) 由验证界与连分数台阶决定、随 m 只减不增，因此对每个固定 X0 都存在交叉点之后失效（本项目实测交叉点 68 与 77，文献记录 91）。更要紧的是，从 Λ 的上界推出「K 的上界」这一步本身未证：反驳方逐行核对 Simons 与 de Weger 第 806 至 813 行后确认该步未证，作者如实保留为缺口，没有再修补。

反驳结果：第二轮反驳推翻了两处——「印反版被已知负环直接证伪」不成立（那是把正环侧含 (1 + X0^(−1))^m 的常数套到了负环上，负侧只变弱、永远不可能被负环证伪）；负侧的族构造必须用偶数项下标，不能与正侧写成同一条。两处作者都已接受并改正。

丢番图与超越论路线 diophantine-transcendence 主目标不成立

目标：只用初等工具（Simons 与 de Weger 的链式增长与连分数事实、Hercher 的自举），把 m 圈前沿推到超过 91，且不使用 Rhin 的线性型对数下界。

立住的局部结论：副目标被证明不可能。作者给出并核验一条天花板引理：在本机具结构内，分离界（无论初等还是超越论、无论多强）对终点门槛的全部贡献上界是 7.3%（m = 91 处理想与实际之比 1.073），而 m = 92 的缺口是 3.89 倍；另一处口径下所需提升是 1.19×10^18 倍，而 Dirichlet 定理把任何分离界的提升空间封在约 100 倍以内。数值上，本机具唯一可达的增量是把 X0 抬到约 1.723×10^22 才能让 M* = 92。

最致命的一击：一致性。终点一步「圈蕴含 K < K_up」要求分离界对一切 K 一致有效；初等连分数分离界是逐区间的，把它当一致界用，等价于额外假设「log_2 3 的部分商尾部不超过一个显式双重指数阈值」，而 log_2 3 的部分商上界没有任何已知定理。Rhin 1987 不可替代的原因不是精度，而是一致性——它把无穷合取变成有限合取。

反驳结果：第二轮反驳指出 Hercher 的 Theorem 21 尾部有公开争议（zbMATH 审稿人指出「靠近末尾有潜在缺陷」，一个第三方 Lean 项目断言 82 到 91 那一步错误、只承认 m ≤ 82），作者据此把 m ≤ 91 降格为条件结论。第三轮反驳进一步主张那个 82 站不住：最坏情形论证与 Hercher 自己的 Lemma 20 相矛盾，勘误的凸性替代推导经补全后被复核为有效。这一争议在本页记录为「未裁决」，两种口径并列。

形式化与自动机路线 formal-automata 两层都已封闭

目标：把受限版本的科拉茨映射编码成自动机与线性递推并尝试判定，再精确说明它在何处不能升级为对原猜想的结论。

立住的局部结论： 1. 编码定理：T^k(n) 的仿射公式、下降集 D_k 是 2 自动集、以及「猜想 ⟺ 并集 D_k 覆盖除 1 外的全体正整数」这一等价改写（这是等价，不是推进）。 2. 2 进闭包版本被完全解决，而且答案与猜想相反：到达 1 的充要条件是奇偶词尾部为 1 与 0 交替，到达集可数、补集满测度，反例包括 −1 与正有理三圈 4/5 → 2/5 → 1/5 → 4/5。 3. 残类二分与坏类计数（a ≤ 24 的坏类个数表）、非下降集的精确结构、显式下降判据与 θ_w < 3^len(w)。 4. 代价定理：任何「L 不是 2 自动集」型的不可能性定理（类的定义含余有限集）都蕴含猜想为假。

最致命的一击：这条路线没有第三条出口，而且是方向性的失败而非技术困难。受限版本的真值与猜想不一致（2 进侧几乎一切点都不到达 1）；不可能性方向在逻辑上自毁（证明它等于证否猜想）；剩下的只有「等价改写」与「关于证书形式的分类」，对原猜想零进展。

反驳结果：反驳指出两处并都被接受——残类二分第 3 条的「已证」标签超出证明（只证出有限例外版本，完整等价需要额外输入 (∗)，而 (∗) 等价于 Terras 系数停时猜想）；显式下降判据末句漏写同余条件、按字面为假（反例 k = 3、m = 1、n = 7）。两处都已改正，后者还新增了 θ_w < 3^len(w) 这条引理。

最小反例路线 minimal-counterexample 主定理未证

目标：不存在 n ≥ 2 使 χ(n) = ∞（即不存在永不下降到自身的正整数）。

立住的局部结论： 1. 筛饱和引理：χ(x) = ∞ 当且仅当对一切 k 有 x mod 2^k 落在 E_k 内；附三条否决结论（同余约束饱和、有限层永不矛盾、2^k − 1 类恒存活）。 2. 二分定理：轨道无界当且仅当 3^(S_j) > 2^j 对无穷多层成立；等价地轨道有界当且仅当存在 j₀ 使一切 j ≥ j₀ 有 3^(S_j) < 2^j（此时入环）。 3. 归约定理：猜想可由 (β)（对一切 n ≥ 2 有 τ(n) < ∞）与 Terras 系数停时猜想 (CST) 推出；而 (β) 与「无非平凡环」两者并不足以推出猜想。 4. 首失败几何、c 的双侧界（与 Rozier 与 Terracol 定理 2.2 逐字同式）。

最致命的一击：情形 II 拦在中间。它指满足 χ(N) = ∞、τ(N) < ∞、轨道无界的 N；这一情形同时通过 (β) 与 (α) 的自检，本框架的分类逻辑无法排除它。跨过它需要把已知抓手（悖论序列的显式族、首失败几何、大小约束与双侧界）联合起来找矛盾，迄今没人做过。

反驳结果：反驳推翻的正是初版对情形 II 的表述——初稿写「现有数论工具对发散轨道无可用抓手」，遗漏了 Rozier 与 Terracol 的定理 3.2、定理 2.2 下界与推论 3.3。作者逐条打开来源并本机复现后确认反驳成立，整段撤下改写。第一轮另有三条失实陈述与一条承重步骤被撤下（φ 迭代推演、χ ≤ τ 更弱、K 与 α 等价、一处界的错误形式）。

量化改进路线 tao-quantitative 目标未证

目标：把 Tao 型「几乎所有轨道取到几乎有界值」的论证拆到引理级，然后尝试证明其中某个更强的估计，目标是把「几乎有界」推到固定阈值。

立住的局部结论：倾斜恒等式（把 F(m+1) 精确分解为衰减因子、边界因子与倾斜期望三部分）；轮换恒等式与块结构（好位置、连续块、Σe_t = K 精确）；劣质块不等式与条件性的 m^(−1/4)；以及一个数值猜想 F(k) ≈ 10.8·exp(−(k−1)D)·(k−1)^(−3/2)（常数在 m 从 1000 到 30000 内波动 ±4%）。这些全部不是对猜想的推进，而是本路线的边界刻画与失败点定位。

最致命的一击：单层级界永远是正数。Tao 的 Theorem 3.1 对每个固定 N_0 = C 给出 Λ(A_C) ≤ K(log C)^(−c)，右端与 x 无关，框架内没有任何一步会把常数变成 0。另一半是结构性的：对数密度型估计看不见单条坏轨道——单条坏轨道加它的加倍链，对 [1, X] 的对数权重至少是 1/N_0，是常数，与框架的一切 o(log X) 型结论相容。

反驳结果：反驳推翻了作者的一条「矫正后的边界陈述」——「凡 B 族逐层信息不足的映射，必然违反 Tao 型逐层结论」为假，作者自己用来复核反驳意见的那张玩具映射就是反例（该映射上 Λ(B_2) = 1/2 > 0 而 Λ(A_M) = 0 对一切 M 成立）。作者复核后撤回并改写：正确的逆否命题是析取形式，在 Tao 型成立的前提下 T2 等价于「某个固定 m 的 B 层对数密度为正」。

2 进与遍历控制路线 two-adic-control 主目标未证

目标：周期猜想 PC_3——每个分母为奇数的有理 2 进整数 x，其加速映射轨道最终周期。

立住的局部结论（都是否定性的）： 1. 等距刚性定理：2 进等距且与移位交换的映射只有 id 与 σ(x) = −1 − x；推论是任意两个奇数 a、b 之间的等距共轭恰好两条，且保奇偶的那一条唯一。 2. 整数不保持定理：在相当广的 (a, b) 对上，任何双射共轭（不作连续、可测、等距任何假设）都不保持整数，并附显式见证。 3. 搬运命题：把「有理点都是最终周期点」沿共轭搬运，其真值条件正是猜想本身，搬运不提供独立信息。

最致命的一击：三层封堵，合起来即「共轭在算术上不透明」。测度与拓扑层次——猜想所谈的集合与最终周期点集都是可数稠密零测贫集，任何保测同构型不变量无法区分二者；共轭刚度层次——自由度只剩 {id, σ}；算术搬运层次——唯一可能的共轭都不保持整数。而主目标本身等价于「3x + b 族无发散轨道」，其中 b = 1 那一档就是猜想的无发散半边，路线内部没有工具。

反驳结果：反驳推翻了初版的一处断言（涉及共轭的层结构），作者复核后接受、修改正文并补上正确的论证，并借此新增了「窗口 4 的连续双射分类」这条严格结论。反驳方附赠的一条更强主张（一般定理「连续且与移位交换的双射必为等距」）作者未能核实，记录为未核实、不采纳为定理。

六条路线的共同形状：每条都能把「能与不能」划清，都能立住若干自证的小定理，也都在同一个位置停下来——从密度型或逐档型的结论跨到全称命题的那一步， 以及从有限验证跨到无穷范围的那一步。没有任何一条给出猜想本身的部分结果。

二停时探索器

输入任意正整数 n，页面用内联 JavaScript 逐步算出它的科拉茨轨道（标准映射：奇数走 3n + 1，偶数走 n/2）， 并报告总停时（到达 1 所需的步数）、轨道峰值、以及「是否到达 1」。全部计算在本页内完成，不调用任何网络接口。

按 Enter 或点「计算」。内部用 BigInt 精确整数运算，故 3n + 1 不会溢出；可接受的输入上限为 10^18，步数上限为 1000000， 轨道显示上限为 400 项（超出时显示首尾两段，步数与峰值仍按完整轨道统计）。

  • Korec 1994（同行评审）：对每个 c > log_4 3 ≈ 0.7925，{y : 存在 n 使 T^n(y) < y^c} 的自然密度为 1。
  • Allouche 1979（讲义，经两处互证）：θ > 3/2 − log_3 2 ≈ 0.8691 的同一结论；注意 Tao 论文该式的印刷笔误。
  • Terras 1976 与 Everett 1977（同行评审）：有限停时的正整数集合自然密度为 1，且 δ[χ ≥ k] = P[τ ≥ k]。
  • Krasikov 与 Lagarias 2003（同行评审）：π_a(x) ≥ x^0.84 对 a 不整除于 3、充分大 x 成立（γ ≈ 0.84175）。这是已发表的计数下界记录。
  • Hercher 2023 加 2026 勘误（同行评审，含争议）：不存在 m ≤ 91 的非平凡 m 圈；K > 1.375×10^11。m ≤ 91 一侧未被裁决。
  • 周期下界记录：标准映射至少 355,504,839,929；加速映射至少 217,976,794,617（后者只有二手来源，可复算）。
  • Eliahou 1993 与 Halbeisen 与 Hungerbühler 1997（同行评审）：周期形式与改进判别法（验证到约 2^47.6 时环长下界跳到 102,225,496）。
  • Böhm 与 Sontacchi 1978（同行评审）：环方程 x = c/(2^n − 3^m)，以及「若 u^n(x) = x 则 |x| < 3^n」。
  • Barina 2025（同行评审论文，但记录是有限计算）：所有小于 2^71 ≈ 2.361×10^21 的正整数到达 1。
  • Bernstein 1994 与 Bernstein 与 Lagarias 1996（同行评审）：存在唯一同胚 Φ 把加速映射共轭到 2 进移位，Φ 等距、保测度、处处不可微；另一已知定理：T 在 Z_2 上的每个周期轨道都由有理数组成。
  • Conway 1972 与 Kurtz 与 Simon 2007（同行评审）：广义 Collatz 的判定问题不可判定，且 {g : range(g) = ω} 是 Π⁰₂ 完备。只约束族与统一方法。
  • 具体图灵机与 ZFC：7910 状态机（同行评审，假设 ZFC 一致）、745 状态（学士论文）、254 与 250 状态（社群加 Coq，未评审）。
  • BB(5) = 47,176,870（仅预印本，带 Coq 形式化）；BB(6) 被 Antihydra 阻塞（社群记录）。

已确证（本项目自算，范围受限）

  • 全量扫描：n ≤ 2^28 的每一个整数都到达 1；最大总停时 956（n = 226588897）；与 OEIS 逐条核对零不一致。
  • 环的全枚举：周期不超过 34 的非平凡整数环一个也没有（无条件，覆盖 k ≤ 34 的全部 2^k 个奇偶向量）。
  • 自算验证界：X0 = Y0 = 10^12；在该前提下，已知五个环之外、元素绝对值至少 10^12 的正环周期至少 17,087,915。
  • 逆向树：从 1 出发显式建树到 65 层、累计 354,832,309 个节点；增长比值 1.333347 对 4/3 相差 +0.0010%；但显式建树只完整覆盖到 n = 25，第一个漏掉的奇数是 27。
  • 停时分布：n ≤ 2^24 全精确；最大总停时 704（n = 15,733,191）；两尾都比同矩正态重，t = 500 处的超越计数约为正态预测的 1900 倍。
  • 证书搜索：按位加权势函数在 2^18 与 2^20 截断上 UNSAT（核为 {x = 3, x = 4}）；并给出初等证明：任何取整数值的函数 V 都不可能使 V(T(x)) ≤ V(x) − 1 在 [1, N] 上成立。
  • 奇偶向量：停时层集不是完整剩余类之并（最小反例 j = 2、x = 5 与 x = 1）；精确版判据在 x ≤ 2^18、j ≤ 12 上逐点零不符。

已知死路 含死因

已被文献排除或撤回

  • 解析泛函方程路线（Opfer 2011）：作者本人撤回，承认推理不完整。
  • 「Lean 反证」事件（2026）：不是数学结果，是 Lean 内核漏洞的产物（已由事故报告与修复确认）。
  • Metzger 1995「唯一循环」：作者在补记中承认证明有缺口。
  • 撤回与载体消失：一篇 arXiv 稿被作者撤回（与既有枚举重复）；一条 Zenodo 记录已被删除（API 返回 410）。

被结构性障碍排除

  • 纯测度论或遍历论的证明：整数集在 Z_2 中可数、测度零；且 3x+1 与 5x+1 在 Z_2 上完全同构而在整数上行为不同——任何对全部奇 a 同时有效的纯测度论证必然失败。
  • 统一覆盖广义 Collatz 的算法或统一定理：被 Conway 1972 与 Kurtz 与 Simon 2007 排除。注意这只杀统一判定，不杀具体实例的证明。
  • 固定下降深度的势函数与有限覆盖同余：取 k 大于步数上限，类 n ≡ −1 (mod 2^k) 中每个数前 k 步全为奇步、严格上升，故「有限个剩余类加固定步数下降」的证书不存在。
  • 对符号不敏感的论证：负整数上存在三个非平凡环（−1、−5 与 −7 与 −10、从 −17 起的 11 元环）。
  • 对常数不敏感的论证：5x+1 有环 13 → 33 → 83 → 13。证明必须用到只对 a = 3 成立的事实。
  • 靠增大 k 推进差不等式的指数：每级 k 的最佳指数就是线性规划的 λ_k，被 Krasikov 与 Lagarias 定理 2.2 锁死，算力无效。
  • 有限验证通向全称命题：无已知桥梁；任何有限计算都是单称命题的合取，每翻倍算力约换一位。
  • 势函数路线：位权形式的严格下降势函数不存在（一对点上的和恒为零）；多项式加有界位权形式同样不存在。

六条路线各自的死因

  • 算术路线：全称收尾一定失效（U(m) 指数增长、L(m) 递减），且 U 侧判据本身未证。
  • 丢番图与超越论路线：初等分离界是逐区间的，缺一致性；分离界的收益上限只有 7.3%。
  • 形式化与自动机路线：受限版本真值与猜想相反；不可能性方向蕴含猜想为假。
  • 最小反例路线：情形 II（χ = ∞、τ 有限、轨道无界）无法排除。
  • 量化改进路线：单层级界永远是正数；密度型估计看不见单条坏轨道。
  • 2 进与遍历控制路线：共轭在算术上不透明（零测、刚度、整数不保持三层封堵）。

需要固定排除的误读

  • 「BB(6) 独立于 ZFC」不是定理，而是障碍陈述。
  • 「科拉茨猜想本身独立于 PA 或 ZFC」无任何一方结果。
  • 「广义不可判定性蕴含原猜想不可判定」是过度解读。
  • 「2 进侧已完全解决，所以猜想在 2 进侧已被证明」恰相反：2 进侧的答案是几乎一切点都不到达 1。
  • 「至多有限个例外」不等于「有界」：例外集有限，但它的成员可能永不下降。

活口清单 按距真证明可能最近排序

排序是本项目作者的工具判断，不是文献结论。没有任何一条能在现有基础上直接给出证明。

  1. 排除任意长非平凡循环（猜想的一半，机械最完整）。需要：关于 log 2 与 log 3 分离性的一致显式下界，并去掉对验证界的依赖。
  2. 排除发散轨道（另一半，含 Tao 的固定 C_0 中间目标）。需要：轨道显式伪随机性质定理或刚性不变量。
  3. 把 Tao 定理全有效化并与 2^71 验证合并（最可操作）。Tao 自己在脚注把这一点列为「原则上可能」，无人完成。
  4. 自然密度升级。需要随机仿射映射的联合细尺度混合，或把乘性误差压到自然密度可容忍的范围。
  5. 差不等式路线推到 x^(1 − ε)。需要线性规划族最优解结构的解析理论；每级 k 的框架内上限已锁死。
  6. 周期记录的机械推进到下一档。门槛 q_23 + q_24 = 890,638,885,193；「若验证到 2^75 则环长至少 2,302,268,119,908」是仅预印本的条件估计，未完成。
  7. m ≤ 91 记录的裁决与端到端形式化。三方分歧（第三方 Lean 主张 82、论文加勘误主张 91、另一个 Lean 项目条件性主张 101），勘误的替换推导无第三方复核。
  8. 2 进侧的周期猜想（这条线上唯一对猜想有直接逻辑贡献的条目）。只证了一半；若全证则蕴含「整数上无发散轨道」。
